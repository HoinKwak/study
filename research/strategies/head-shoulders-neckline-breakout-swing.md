# [스윙] 헤드앤숄더(역헤드앤숄더) 넥라인 브레이크아웃

- **출처**: https://www.quantconnect.com/research/15603/head-amp-shoulders-ta-pattern-detection/ (QuantConnect Research, 상관관계+DTW+Savitzky-Golay 필터 기반 알고리즘 H&S 탐지, WebFetch로 원문 확인) /
  https://altfins.com/knowledge-base/chart-patterns/ (altFINS, AI 패턴엔진 "성공률" 수치 — WebFetch로 원문 확인했으나 **방법론 비공개**, 아래 표기 참조) /
  https://medium.com/@minkeliu_29243/the-head-and-shoulders-pattern-in-technical-analysis-48cbca1ca9ea (알고리즘 H&S 탐지 개념 정리, Python 구현 예시)
- **참여지표**: - (퀀트 리서치·교육 콘텐츠, SNS 참여지표 미확인. 다만 H&S는 차트 패턴 중 가장 널리 알려진 반전형으로 트레이딩 커뮤니티 전반의 인지도가 매우 높음)
- **백테스트 근거**: **부분 확인(WebFetch 원문 확인, 단 시장·방법론에 명확한 한계)**.
  - **QuantConnect**: 상관관계·DTW·Savitzky-Golay 평활화로 100개 무작위 참조패턴과 비교하는 알고리즘 탐지 방식. **2022-01-01~2023-06-01, 1,817건 거래, Sharpe 비율 0.55**(동기간 SPY 매수보유 -0.179, SPY 공매도보유 0.409 대비 우위). **⚠️ 대상은 크립토가 아니라 (문맥상) 미국 주식/ETF 유니버스로 추정** — 원문에 승률·PF 수치는 없음, Sharpe만 제시. 크립토 재현은 미검증.
  - **altFINS**: "Inverse Head and Shoulders 84%, Head and Shoulders 82% 성공률"이라 명시하나, **표본 크기·기간·자산군·"성공"의 엄밀한 정의 방법론이 전혀 공개되지 않음**(유일한 설명: "가격이 패턴 길이만큼의 기간 내에 목표가에 도달하면 성공"). **신뢰도 낮음으로 분류, 정량 근거로 인용하지 않고 참고용으로만 표기**.
  - **결론**: 크립토 대상 정량 백테스트는 원문 미확인. QuantConnect의 Sharpe 0.55/1,817건은 실제 검증이나 타 자산군. **채택 전 우리 알트 유니버스로 자체 백테스트 필수.**
- **타임프레임**: 4h 봉으로 패턴(피벗) 탐지, 4h 종가 브레이크아웃 확인. (패턴 형성에 통상 수주 소요 — 15m/1h로는 노이즈 과다)
- **시장/대상**: BTC·ETH·시총상위 알트 무기한(유동성 상위, 패턴이 왜곡 없이 잡히는 종목)

## 진입 규칙
- **피벗 탐지**: 프랙탈 방식 — 좌우 `pivot_lookback`=5봉(4h) 동안 가장 높은/낮은 종가를 스윙고점/스윙저점 피벗으로 확정.
- **하락반전형(H&S, 숏)**: 연속된 피벗고점 3개가 P1(좌숄더) < P2(헤드) > P3(우숄더) 순서로 나타나고,
  1. 헤드 돌출: `P2 ≥ max(P1,P3) × (1 + head_prominence_pct)` (헤드가 양 숄더보다 `head_prominence_pct`=3% 이상 높음).
  2. 숄더 대칭: `|P1-P3| / max(P1,P3) ≤ shoulder_symmetry_tol`=40% (완전 대칭 불요구, 느슨한 허용범위).
  3. **넥라인**: P1-P2 사이 저점(T1)과 P2-P3 사이 저점(T2)을 연결한 직선.
  4. 패턴 폭: 전체 패턴 형성 기간이 `min_pattern_bars`=15~`max_pattern_bars`=90봉(4h, 약 2.5일~15일) 이내.
  5. **트리거**: 4h 종가가 넥라인(T1-T2 연장선) 아래로 `breakout_buffer_pct`=0.5% 이상 이탈 → 숏 진입.
  6. (선택 필터) 우숄더(P2→P3 구간) 평균 거래량이 좌숄더(P1→T1 구간) 평균 거래량보다 낮고, 브레이크아웃봉 거래량이 최근 20봉 평균의 `vol_breakout_mult`=1.3배 이상 (교과서적 "숄더 진행에 따른 거래량 감소 + 넥라인 이탈 시 거래량 증가" 패턴 확인).
- **상승반전형(역H&S, 롱)**: 위 조건을 상하 대칭으로 뒤집음(피벗저점 3개, T1/T2는 고점, 넥라인 상향 돌파 시 롱).

## 청산 규칙
- 익절: **측정폭(measured move)** = 헤드(P2)와 넥라인 간 수직거리 × `measured_move_mult`=1.0(범위 0.8~1.3)를 브레이크아웃 지점에서 투영한 목표가.
- 손절: 우숄더(P3) 극값 ± `stop_buffer_pct`=1.0% (숏은 P3 위, 롱은 P3 아래).
- 시간 청산: 브레이크아웃 후 `max_hold_bars`=40봉(4h≈6.7일, 범위 20~60) 내 목표 미도달 시 ATR 트레일링(×2.0)으로 전환.

## 파라미터
- pivot_lookback=5봉 (범위 3~8)
- head_prominence_pct=3% (범위 2~6%)
- shoulder_symmetry_tol=40% (범위 25~50%)
- min_pattern_bars=15 / max_pattern_bars=90 (4h 기준)
- breakout_buffer_pct=0.5% (범위 0.3~1.0%)
- vol_breakout_mult=1.3 (선택 필터, 범위 1.0~1.8)
- measured_move_mult=1.0 (범위 0.8~1.3)
- stop_buffer_pct=1.0%
- max_hold_bars=40 (범위 20~60)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 4h OHLCV만으로 구현 가능(프랙탈 피벗 탐지 + 거래량, 전부 캔들 데이터). 오더북/틱/실시간청산 불필요.
- 주의: 패턴 탐지 로직 자체가 **여러 조건의 순차 매칭**(피벗 3개 순서·대칭성·넥라인 각도)이라 다른 스펙보다 구현이 복잡함(단순 지표 임계값 비교가 아님) — 벡터화가 어려워 루프 기반 탐지가 필요할 수 있음. 파라미터가 느슨하면 저품질 패턴이 대량 검출(과다신호)되고, 너무 엄격하면 표본이 희소해짐 — 그리드서치로 민감도 확인 필수.

## 스카우트 메모
- **강점**: 우리 보유 스펙 260개 중 **정확히 이 고전 패턴(H&S)이 없음** — `wolfe-wave`, `harmonic-pattern-xabcd`, `cup-and-handle`, `triangle-consolidation` 등 다른 구조적 패턴과는 기하학적 정의가 명확히 다름. 크립토 트레이딩 커뮤니티에서 가장 잘 알려진 반전 패턴이라 재현성·설명력 측면에서 신뢰도 높음.
- **의심점**: (1) 정량 백테스트가 크립토 대상이 아님(QuantConnect는 자산군 불명확, 추정 주식). (2) altFINS의 82~84% 수치는 방법론 비공개로 **신뢰 불가** — 절대 인용 금지, 참고용으로만 명시. (3) 패턴 탐지 알고리즘 자체의 파라미터 민감도가 커서 "발견자 편향(우연히 눈에 띄는 패턴만 기억)"이 백테스트에서도 재현될 위험(느슨한 파라미터로 다수 패턴을 기계적으로 훑어야 이 편향을 피할 수 있음). (4) 예상 표본 빈도는 사전에 정확히 알 수 없어(패턴 매칭 조건에 크게 좌우) 백테스트 착수 시 **탐지된 패턴 수를 가장 먼저 확인**해 "수십 건 이상" 기준 충족 여부를 판단해야 함.
- **우리 슬리브와의 관계**: 완전 신규 축(가격 구조 기하학적 패턴, 오실레이터·OI·펀딩과 무관) — 상관관계 낮은 분산 후보. 구현 난이도가 높아 백테스트 우선순위는 중간 이하로 권장(먼저 저난이도 후보로 인프라 검증 후 착수).
