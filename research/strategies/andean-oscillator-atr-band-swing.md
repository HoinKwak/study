# [스윙] 안데안 오실레이터(Andean Oscillator) + ATR 밴드 스캘핑/스윙

- **출처**: 백테스트 집계 https://tradesearcher.ai/strategies/2300-andean-scalping (WebFetch로 원문 수치 확인) / 원 지표 설명(Alex Grover 고안, 2023): https://alpaca.markets/learn/andean-oscillator-a-new-technical-indicator-based-on-an-online-algorithm-for-trend-analysis
- **참여지표**: -(백테스트 집계 사이트 기반, 173개 개별 백테스트 결과 취합)
- **백테스트 근거**: **있음(WebFetch로 원문 페이지 수치 확인)**.
  - 개별 예시(4h): **CROUSDT R:R 1.47 / 총ROI 115.91% / 169트레이드**, **CAKEUSDT R:R 1.43 / 총ROI 115.49% / 164트레이드**.
  - 집계(173개 백테스트, 크립토+주식 혼합 — 자산군 분리 통계는 원문에 없음): **PF 1.3 / 연환산수익률 +11%/yr / 평균순익 +22% / 평균 MDD 15% / Sharpe 0.12**.
  - ⚠️ 원문 사이트 자체가 "**과최적화(overfitting) 우려**"를 명시. Sharpe 0.12는 매우 낮아(위험 대비 수익 미미) 집계로는 약한 엣지. 개별 종목(CROUSDT·CAKEUSDT)의 100%대 ROI는 소수 심볼 결과이며 자산군별(크립토만) 통계는 원문에 분리돼 있지 않아 확인 불가.
- **타임프레임**: 4h (예시 백테스트 기준)
- **시장/대상**: 크립토 다수 심볼(CRO·CAKE 등 알트) — 바이낸스 선물 유니버스로 대체 가능

## 진입 규칙
- Andean Oscillator의 Bull/Bear 컴포넌트(재귀적 온라인 필터로 산출되는 추세 강도 값)와, 그 신호선(시그널선, 완만한 이동평균 기반)을 비교.
- 롱: Bull 컴포넌트가 시그널선을 위로 교차(교차 임계에 1.1배 필터 적용 — 미세한 노이즈 크로스 배제) + ADX 필터(추세 강도 확인, 최적화된 임계값 사용 — 구체 수치는 원문 텍스트에서 파싱되지 않음, **재확인 필요**).
- 숏: Bear 컴포넌트가 시그널선을 위로 교차 + ADX 필터.
- ⚠️ 원문 WebFetch 결과에 "SMA 1000, 1.1배 필터"로 표기됐으나 이는 텍스트 추출 과정의 파싱 오류일 가능성이 있음(안데안 오실레이터는 통상 length 파라미터가 수십 단위) — **정확한 length 값은 원 스크립트(Pine) 직접 열람으로 재확인 필요**, 아래 파라미터는 [추정] 표기.

## 청산 규칙
- 익절/손절: **ATR 밴드 3배수**(진입가 ± ATR×3.0)로 TP/SL 동시 설정.
- 시간/조건 청산: 원문에 명시 없음(추세 반전 시 청산으로 추정 [추정]).

## 파라미터
- andean_length=10~50 [추정, 원문 미확정 — 재확인 필요]
- signal_filter_mult=1.1 (교차 노이즈 배제용)
- atr_mult=3.0 (범위 2.0~4.0)
- adx_threshold=원문 "BTC용 최적화됨"이라고만 언급, 구체값 미확인

## 코딩 난이도 / 데이터 요구
- 필요한 지표: Andean Oscillator(표준 TA 라이브러리에 없음 — 재귀식 직접 구현 필요, 공식은 alpaca.markets 학습자료 참조), ATR, ADX.
- 주의: **바이낸스 REST OHLCV로 완전 구현 가능.** 오더북/틱 불필요. 단 지표 자체가 비표준이라 재귀식 구현 오류(오프바이원, 초기화값) 위험이 있음 — 구현 후 TradingView Pine 결과와 수치 대조 검증 권장.

## 스카우트 메모
- 강점: 148개 기존 스펙에 없는 **완전히 새로운 지표 계열**. 4h 스윙 타임프레임 + ATR 3배 밴드 구조는 우리 볼린저 눌림목 중기 슬리브와 메커니즘이 달라 다변화 가치 있음.
- 의심점: 집계 성과가 약함(PF1.3, **Sharpe 0.12**는 사실상 무의미한 수준) — 사이트 자체 경고대로 과최적화 의심. 개별 종목 100%+ ROI는 생존편향/체리피킹 가능성 배제 못 함. 파라미터(length) 원문 확인 실패로 재현에 추가 조사 필요.
- 우리 단타 슬리브와의 관계: **독립적**(신규 지표, 중복 없음). 다만 근거가 약해(Sharpe<0.15) 백테스트 우선순위는 낮음 — 구현 전 원 지표 공식부터 정확히 확보 권장.
