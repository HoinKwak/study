# [단타] 이동평균 엔벨로프(%밴드) 평균회귀 스캘프

- **출처**: TradingView "Moving Average Envelopes Backtest" by HPotter —
  https://www.tradingview.com/script/Np9Bv8xo-Moving-Average-Envelopes-Backtest/ (WebFetch 확인) /
  개념 보강: QuantifiedStrategies "Moving Average Envelope — Strategy, Rules, Returns"
  https://www.quantifiedstrategies.com/moving-average-envelope/ (WebSearch로 개념만 확인, 원문 정량
  수치는 봇차단으로 미확인 — 인용 안 함) / TradingView 공식 문서 "Envelope (ENV)"
  https://www.tradingview.com/support/solutions/43000502260-envelope-env/
- **참여지표**: HPotter "Moving Average Envelopes Backtest" **조회수 5,421,010 / 부스트(좋아요) 13,292**
  (2018-03-03 게시, WebFetch 확인). TradingView 역대 최다 조회 전략 스크립트 중 하나로 신뢰도 매우 높음
  (저자 HPotter는 TradingView "Pine Wizard" 인증, 유료 신호방 아님, 오픈소스).
- **백테스트 근거**: **없음(참여지표 기반)**. 스크립트 페이지 자체에는 정량 백테스트 수치가 표시돼
  있지 않음("For purpose educate only" 면책 문구만 존재, WebFetch로 확인) — **참여지표(조회 540만)로만
  스크리닝**, 정량 성과는 반드시 우리 프레임에서 처음부터 검증해야 함.
- **타임프레임**: 신호 15m~1h (기존 scalp15m 슬리브와 동일 계열 TF 후보), 확인 1h.
- **시장/대상**: BTC·ETH·유동성 상위 알트 무기한.

## 진입 규칙
- 기준선: EMA(20) (범위 10~30).
- 엔벨로프: 기준선 × (1 ± envelope_pct). envelope_pct는 **자산별 변동성 적응형** — 최근 20봉 ATR%
  (ATR/종가)의 1.5배를 기본값으로 사용(고정 %가 아닌 ATR 연동으로 크립토 변동성 급변 대응, BB/켈트너와
  달리 "이동평균 중심 고정폭 밴드"라는 점에서 표준편차·ATR 밴드와 성격이 다름).
- **롱**: 종가가 하단 엔벨로프를 하회한 뒤(밴드 밖 이탈) **다음 캔들이 하단 엔벨로프 위로 재진입하는
  종가 확정 시** 진입 (밴드 이탈 후 복귀 확인 — 단순 터치 즉시진입 대비 다이신호 억제).
- **숏**: 종가가 상단 엔벨로프를 상회한 뒤 다음 캔들이 상단 엔벨로프 아래로 재진입 시 진입.
- 게이트: ADX(14, 1h) < 25 (추세장 제외, 평균회귀 유효 국면인 횡보/약추세에서만 진입 — 크립토는
  강추세 시 밴드가 계속 벗어나므로 이 필터 없이는 역추세 손실 위험 큼, 원문도 "강추세 시 오작동" 경고).

## 청산 규칙
- 익절: 기준선(EMA20) 재접촉 시 전량 청산 (엔벨로프 평균회귀 표준 청산).
- 손절: 진입 반대방향 엔벨로프 폭의 1.0배 추가 이탈(롱은 하단밴드보다 envelope_pct만큼 더 하회, 숏은 반대) — 즉 밴드폭 기준 ATR 연동 손절.
- 시간 청산: 진입 후 N=8봉(15m 기준 2시간) 내 기준선 미도달 시 강제청산(횡보 국면 소진 방지).

## 파라미터
- ma_period=20 EMA (범위 10~30)
- envelope_pct=ATR%(20)×1.5 (범위 1.0~2.5× ATR%, 또는 고정 2~4% 대안)
- adx_filter=25 (범위 20~30, 이하일 때만 진입)
- reentry_confirm=1봉 (밴드 재진입 확인 캔들 수)
- time_stop=8봉

## 코딩 난이도 / 데이터 요구
- 필요한 지표: EMA(20), ATR(14 또는 20), ADX(14). 전부 표준 지표 — 구현 난이도 낮음.
- 주의: 바이낸스 REST 캔들만으로 완전 충족. 오더북/틱·OI 불필요. 우리 기존 "볼린저 눌림목 중기"·
  "볼린저 돌파+거래량+OI 단타"와 **밴드 계산방식이 다름**(엔벨로프=이평 중심 고정%/ATR% 오프셋 vs
  볼린저=표준편차) — 실제로 다른 신호를 낼지는 상관관계 확인 필요.

## 스카우트 메모
- 강점: **참여지표(조회 540만, 역대급)가 이 배치 최상위** — 스크리닝 규칙 2번(참여지표 눈에 띄게 높음)에
  정확히 부합. 규칙 자체는 매우 단순·재현 가능. ADX 필터로 추세장 역행 위험을 구조적으로 낮춤.
  ATR% 정규화 엔벨로프는 크립토 알트코인처럼 변동성 편차가 큰 유니버스에도 이론상 적용 용이.
- 의심점: 정량 백테스트 근거 전무(순수 참여지표), "For purpose educate only" 면책 — 원저자도 실전
  검증을 보장하지 않음. QuantifiedStrategies 원문은 "파라미터에 따라 수익성이 크게 갈린다"고 명시적으로
  경고(정량 수치는 미확인이나 이 경고 자체는 페이지 스니펫에서 확인) → 파라미터 스윕 필수.
  단순 평균회귀라 강추세장 대량 손절 리스크 존재(ADX 필터 미작동 구간 취약).
- 우리 단타 슬리브와의 관계: **대체 아님, 보완 후보**. 기존 볼린저 돌파(추세추종형) 단타와 반대 성격
  (평균회귀형)이라 국면 분산 가치 있음. 다만 기존 "볼린저 밴드 페이드(레인지)" 전략과 사상은 유사(밴드
  이탈→복귀 페이드) — 밴드 계산방식만 다르므로 **백테스트로 실질 차별화 여부 먼저 확인 권장**.
