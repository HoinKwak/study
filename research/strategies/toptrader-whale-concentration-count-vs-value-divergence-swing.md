# [스윙] 탑트레이더 내부 괴리 — 계좌수비율 vs 포지션가치비율 (고래 집중도 다이버전스)

- **출처**: 데이터 필드 정의 — https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Top-Trader-Long-Short-Ratio (바이낸스 공식, `count_toptrader_long_short_ratio`=상위 트레이더 **계좌 수** 기준 롱/숏 비율, `sum_toptrader_long_short_ratio`=상위 트레이더 **포지션 규모(명목가치)** 기준 롱/숏 비율 — 같은 "상위 트레이더" 코호트 내에서 서로 다른 가중 방식으로 산출되는 두 지표임을 원문에서 확인). 벌크 덤프 존재 확인 — 기존 스펙 `toptrader-vs-global-ratio-spread-divergence-swing.md`에서 2026-08-09 `data.binance.vision/data/futures/um/daily/metrics/` 7종목 전부 다운로드 검증 완료(같은 인프라 재사용).
  **본 스펙의 정확한 "코호트 내부(계좌수 vs 포지션가치) 괴리" 규칙은 스카우트가 자체 설계 — 외부에 이 정확한 백테스트는 없음, 지어내지 않음.**
- **참여지표**: - (자체 설계). "계좌 수 기준과 포지션 규모 기준이 다르면 소수 초대형 계좌가 다수 중형 계좌와 다른 베팅을 하고 있다"는 해석 프레임 자체는 CoinGlass 등에서 두 지표를 나란히 제공하는 이유로 통용되나, 정량 백테스트는 확인되지 않음.
- **백테스트 근거**: **없음(자체 설계, 정량 근거 지어내지 않음)**. 채택 전 자체 백테스트 필수.
- **타임프레임**: 4h 신호(5분 원본 → 4h 집계), 스윙 슬리브.
- **시장/대상**: BTC·ETH·BNB·SOL·XRP·DOGE·ADA 무기한. `metrics` 덤프 7종목 전부 2020-09~ 존재(기존 스펙에서 실측 확인, 4.5년 히스토리 재사용 가능).

## 진입 규칙
- **주의(기존 스펙과의 차이 명시)**: 기존 `toptrader-vs-global-ratio-spread-divergence-swing.md`는 "상위 트레이더(sum, 포지션 규모)" **대(對)** "전체 계정(count_long_short_ratio, 리테일 포함 전원)"을 비교하는 **서로 다른 두 코호트 간** 스프레드다. 본 스펙은 **같은 상위 트레이더 코호트 내부**에서 계좌 수 가중치(`count_toptrader_long_short_ratio`)와 포지션가치 가중치(`sum_toptrader_long_short_ratio`)를 비교하는 **완전히 다른 축**(코호트 자체는 하나, 가중 방식만 다름)이라 중복이 아님.
- 각 시계열을 독립적으로 최근 `zscore_window`(예 180봉=4h 기준 약 30일) 롤링 z-score화: `z_count`(계좌수비율), `z_sum`(포지션가치비율).
- `whale_div = z_sum - z_count` (양수면 소수 초대형 계좌(포지션가치 지배)가 다수 중형 상위계좌(계좌수 지배)보다 상대적으로 더 롱 편향 = "진짜 고래"가 "준-고래 다수"보다 확신에 찬 롱, 음수면 반대).
- **롱(초대형 고래 컨빅션 추종)**: `whale_div >= +div_th`(예 +1.5) **AND** 가격이 최근 `trend_ma`=EMA(50, 4h) 위에서 정합(추세 방향 확인, 역추세 방지) → 롱.
- **숏**: `whale_div <= -div_th` **AND** 가격이 EMA(50,4h) 아래 → 숏.
- **대조군 필수**: 정방향(초대형 고래 추종)과 반전(초대형 고래가 오히려 리테일 성격의 소수 대형자금이라 역발상 페이드가 맞을 수 있음) 둘 다 백테스트해 비교.

## 청산 규칙
- 익절: R:R `rr_target`=2.5 또는 `whale_div`가 0으로 복귀(괴리 해소) 중 먼저 도달.
- 손절: 진입가 ∓ ATR(14,4h) × 2.0.
- 시간 청산: `max_hold`=20봉(4h×20=80h) 내 미도달 시 강제청산.

## 파라미터
- zscore_window=180봉(4h 기준, 범위 90~360)
- div_th=1.5 (범위 1.0~2.0)
- trend_ma=EMA50(4h)
- atr_sl_mult=2.0 (범위 1.5~3.0)
- rr_target=2.5 (범위 2.0~3.5)
- max_hold=20봉(4h 기준)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: `metrics` 덤프의 `count_toptrader_long_short_ratio`·`sum_toptrader_long_short_ratio`(5분 간격 → 4h 리샘플), EMA50, ATR14. **로더는 기존 `toptrader-vs-global-ratio-spread-divergence-swing.md` 검증 시 구축될 metrics 파서를 그대로 재사용 가능**(같은 파일의 다른 컬럼만 추가로 참조).
- 주의: 과거 라운드에서 XRP/DOGE/ADA 등 일부 종목·구간에 metrics 0-fill 결측이 있었던 사례(OI캐피출레이션 스펙) 있으므로 결측 처리(0-fill 오염 배제) 선행 검증 필수. 오더북·틱·실시간청산 불필요.

## 스카우트 메모
- **예상 표본 빈도**: [추정] 두 지표(계좌수·포지션가치 비율) 모두 상위 트레이더 코호트 전체를 요약한 값이라 z-score 극단(|whale_div|≥1.5)은 상시 발생하지 않고, 여기에 EMA50 추세 정합까지 요구하므로 **종목당 월 1~4회 수준**으로 [추정](실측 필요) — 4.5년 히스토리로 절대 표본 수는 확보되나 저빈도.
- **gross 엣지 가설**: "포지션 규모 기준 비율은 소수 초대형 계좌(자본력·정보우위 가능성 큰 진짜 스마트머니)가 지배하고, 계좌 수 기준 비율은 다수의 중형~대형(하지만 최상위는 아닌) 계좌가 지배한다"는 구조적 차이에서, 둘의 괴리가 "진짜 큰손과 준-큰손 다수의 견해차"를 드러낸다는 논리 — **이 다리(포지션 규모=정보우위)는 검증되지 않은 가정**이며, 기존 `long-short-account-ratio-contrarian-swing.md` 메모에서 이미 "고래 1명의 대형 포지션과 리테일 다수가 동일 가중치로 집계되는 왜곡"을 지적한 바로 그 문제를 정면으로 다루는 시도이나 반대로 작동할 위험도 동일.
- **⚠️ 정규화 수식 점검**: 두 롤링 z-score(`z_count`, `z_sum`) 모두 **평균 차감(demean)을 포함한 표준 z-score**(`(x - rolling_mean)/rolling_std`)로 정의해 데미닝 누락 문제(직전 라운드 인덱스 스냅백 결함)를 피함. 다만 `count_toptrader_long_short_ratio`·`sum_toptrader_long_short_ratio` 자체가 구조적으로 1보다 크게 편향된(롱 쏠림이 기본값인) 시계열일 가능성이 있어(크립토 파생시장은 통상 롱 편향) **원시값이 아닌 z-score라도 기저 분포의 비대칭(예: 상승장 지속기간 동안 지속적으로 양수)이 남아있는지 백테스트 착수 시 반드시 히스토그램으로 확인**.
- **엣지 대비 거래빈도**: 월 1~4회 저빈도로 수수료 부담은 작을 전망이나, 저빈도=자동 통과가 아님(위클리 아웃사이드바 등 과거 저빈도 FAIL 전례) — gross 엣지부터 확인 필수.
- **독립성/클러스터링 위험 — 큼**: 상위 트레이더 포지셔닝 괴리는 시장 전체 레버리지 사이클과 동조화될 가능성이 높음(기존 `toptrader-vs-global-ratio-spread-divergence-swing.md`와 동일 우려) — 이벤트(일자) 단위 클러스터링 진단 최우선 권고, 명목표본이 부풀려질 가능성 큼.
- **7종목 신호 충분성**: 데이터 존재는 7종목 전부 확인됨. 다만 DOGE·ADA 등은 상위 트레이더 코호트 자체의 절대 계좌 수가 적어(유동성 낮은 알트) 비율의 노이즈가 더 클 수 있음.
- **강점**: 기존 metrics 인프라를 100% 재사용(신규 데이터 수집 비용 0)하면서도, 기존 두 스펙(`long-short-account-ratio-contrarian-swing.md`=단일 지표 레벨극단, `toptrader-vs-global-ratio-spread-divergence-swing.md`=코호트 간 스프레드)과는 명확히 다른 **코호트 내부 가중방식 괴리**라는 세 번째 축.
- **의심점**: 정량 근거 전무, 클러스터링 위험이 스펙 단계에서 이미 명백(직전 다수 라운드 FAIL의 공통 원인 패턴과 동일). 정방향/반전 대조군 비교 생략 시 과거 허위PF 재발 위험.
- **우리 슬리브와의 관계**: 기존 두 롱숏비율 계열 스펙과 데이터 원천은 겹치나 신호 생성 메커니즘(코호트 내부 가중방식 비교)이 달라 중복 채택보다는 **셋 중 어느 축이 진짜 엣지가 있는지 비교 검증**하는 용도로 유용.
