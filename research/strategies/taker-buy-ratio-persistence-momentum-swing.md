# [스윙] 캔들 내재 테이커 매수비율 지속형 모멘텀 (Taker Buy/Sell Ratio Trend-Following)

- **출처**: https://cryptocoffeeshop.substack.com/p/understanding-and-analysis-of-the (CryptoCoffeeShop Substack, "Understanding and Analysis of the Taker Buy/Sell Volume for Bitcoin Trading" — 자체 백테스트 포함) /
  데이터 필드 근거: https://developers.binance.com/docs/derivatives/coin-margined-futures/market-data/Taker-Buy-Sell-Volume , 현물/선물 klines 표준 응답 필드 `taker_buy_base_asset_volume`.
  기존 보유 `cvd-taker-volume-divergence-scalp.md`(같은 데이터 필드지만 **다이버전스/반전** 메커니즘, 5m/15m 단타)와 **명확히 다른 메커니즘**(단순 임계값 돌파 후 **추세추종 지속** 보유, 스윙 타임프레임)임을 확인 후 채택.
- **참여지표**: - (블로그 자체 백테스트, SNS 참여지표 미집계)
- **백테스트 근거**: **있음(원문 WebFetch로 확인)**. 대상: **BTC 일봉(daily)**, 표본기간 **2021-01-01~2024-08-31**. 지표: 테이커 매수/매도 거래량 비율(ratio = buy_volume/sell_volume). 규칙: ratio > buy_threshold(1.05) → 롱 진입, ratio < sell_threshold(0.95) → 청산.
  - **1차(초기 파라미터) 결과**: 총수익 **142.72%**, 연수익 **38.93%**, MDD **48.69%**, 승률 **18.0%**, Sharpe **1.08**, 총 134트레이드.
  - **그리드서치 최적화(최고 Sharpe) 결과**: 총수익 **152.79%**, 연수익 **41.68%**, MDD **41.24%**, 승률 **11.73%**(더 낮아짐), Sharpe **1.49**, Calmar **1.01**.
  - **⚠️ 중요 경고**: 승률이 극히 낮음(11~18%)에도 총수익이 양(+)인 전형적 "저승률·고손익비" 추세추종 프로파일 — 소수의 큰 승리 트레이드에 의존. **수수료·슬리피지 반영 여부 원문 미명시(미포함 추정)**, 출구규칙이 "비율 역전 시 청산"뿐이라 손절 로직 부재, MDD가 41~49%로 매우 큼. 저자 스스로 "in-sample/out-of-sample, walk-forward 추가 검증 필요"라고 명시 — **과최적화 위험 원문에서 인정됨**. 우리 프레임에서 재현 시 수수료 반영 필수 + 알트 유니버스 확장 시 재검증 필요.
- **타임프레임**: 원문은 **일봉(1d)**. 우리 인프라 적용 시 4h로 낮춰 빈도 확보 가능(원문과 다른 조정임을 명시).
- **시장/대상**: 원문은 BTC 단일종목. 확장 시 ETH·시총상위 알트(유동성 높아야 taker 비율 노이즈 작음).

## 진입 규칙
- 지표: 바이낸스 klines 표준 필드로 계산 — `ratio = taker_buy_base_asset_volume / (volume - taker_buy_base_asset_volume)` (매수량/매도량).
- 롱: `ratio > buy_threshold(1.05)`.
- 숏(원문에는 없음, 대칭 확장 — [설계 판단]): `ratio < (2 - buy_threshold)` 즉 매도 우세가 대칭적으로 강할 때, **AND** 가격이 하락 추세(EMA20 아래)로 정합.
- **지속성 필터(원문 대비 개선안, [설계 판단])**: 원문은 단일봉 크로스만으로 진입해 승률이 매우 낮았음(11~18%) → 노이즈 감소를 위해 `persist_bars`(예 2봉) 연속 임계값 충족 시에만 진입하는 옵션 추가 권장(백테스트로 원문 대비 승률 개선 여부 검증).

## 청산 규칙
- 익절/청산(원문 규칙): `ratio < sell_threshold(0.95)`로 역전 시 전량 청산.
- 손절: 원문에 없음 — **[설계 판단]** ATR(14, 4h) × 2.5 하드 스탑 추가 권고(원문 MDD 41~49%가 과도하므로).
- 시간/조건 청산: 원문에 없음 — max_hold(예 20봉=4h×20≈3.3일) 시간청산 옵션 추가 검토.

## 파라미터
- buy_threshold=1.05 (범위 1.02~1.10) — 원문 기준값
- sell_threshold=0.95 (범위 0.90~0.98) — 원문 기준값
- persist_bars=1(원문) 또는 2~3([설계 판단] 승률 개선 시도)
- atr_stop_mult=2.5 ([설계 판단], 원문 없음)
- max_hold=20봉(4h 기준, [설계 판단])

## 코딩 난이도 / 데이터 요구
- 필요한 지표: klines 표준 응답 필드(`volume`, `taker_buy_base_asset_volume`)만으로 계산 — **추가 REST 엔드포인트 불필요**(우리가 이미 매 봉마다 받는 캔들 데이터에 포함된 필드). 구현 난이도 매우 낮음.
- 주의: 오더북/틱/실시간청산 불필요. **원문 백테스트에 수수료·슬리피지 미반영 가능성이 높아 재현 시 반드시 우리 프레임 수수료(왕복 ~0.14%)를 넣고 재검증**(승률이 원래도 낮아 수수료에 특히 취약할 수 있음).

## 스카우트 메모
- 강점: **백테스트 근거가 가장 구체적**(수치·표본기간·파라미터가 명확히 원문에 존재, 이번 발굴 중 신뢰도 최상위). 데이터 요구가 사실상 0(기존 캔들 수집에 필드 이미 포함) — 구현·검증 비용 최소.
- 의심점: 승률 11~18%로 극히 낮고 MDD 41~49%로 매우 큼 — "수익은 양수지만 실전에서 견디기 어려운 프로파일"일 수 있음. 저자 스스로 과최적화 가능성을 인정. 수수료 미반영 추정이라 우리 프레임에서 크게 악화될 위험.
- 우리 슬리브와의 관계: 기존 단타 CVD 다이버전스(반전형)와 데이터 소스는 같지만 **메커니즘이 정반대(추세추종 vs 반전)**라 중복 아님. 백테스트 근거가 가장 명확해 **최우선 검증 후보**로 추천.
