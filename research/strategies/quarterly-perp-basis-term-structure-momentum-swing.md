# [스윙] 분기물-무기한 베이시스 텀 구조(Term Structure) 모멘텀

- **출처**: 개념/데이터 정의 — https://www.binance.com/en/academy/glossary/contango-and-backwardation (바이낸스 아카데미, 콘탱고/백워데이션 정의) / https://www.cfbenchmarks.com/blog/revisiting-the-bitcoin-basis-how-momentum-sentiment-impact-the-structural-drivers-of-basis-activity (CF Benchmarks, 베이시스가 시장 포지셔닝·심리를 반영한다는 리서치) / 계약 존재 확인 — 바이낸스 USDⓈ-M 선물은 무기한 외 **분기물(Quarterly, 예: BTCUSDT_250926)** 계약을 별도 심볼로 상장(만기 3개월 단위)
- **참여지표**: - (학술·거래소 리서치 기반, SNS 참여지표 없음. 기존 보유 `perp-spot-basis-spread-mean-reversion-swing.md`와 데이터 원천은 유사하나 **대상 페어(현물 대신 분기 선물)와 메커니즘(평균회귀 대신 추세추종 필터)이 다름** — 아래 스카우트 메모 참조)
- **백테스트 근거**: **없음(개념 기반)**. "베이시스(콘탱고 폭)가 확대되는 구간은 강세 포지셔닝이 누적되는 국면, 축소·역전(백워데이션)은 약세 전환·디레버리징 국면"이라는 정성적 명제만 리서치 자료에서 확인됨. 정량 수익률·승률 수치는 원문에 없어 지어내지 않음 — **채택 전 자체 백테스트 필수, 우선순위 낮음**.
- **타임프레임**: 1d 신호(베이시스는 완만하게 움직이므로 4h 이하는 노이즈 과다), 진입은 4h 확인봉.
- **시장/대상**: **BTC·ETH 무기한 한정** — 바이낸스 USDT-마진 분기물이 유동성 있게 상장된 코인이 BTC·ETH뿐이라 유니버스 확장 불가.

## 진입 규칙
- 베이시스 정의: `basis(%) = (quarterly_price - perp_price) / perp_price * 100` (동일 코인, 만기까지 가장 가까운 근월물(front-quarter) 종가 기준).
- 베이시스 모멘텀: `basis_roc = basis(t) - basis(t-N)` , N=5봉(1d 기준 5일).
- **롱(콘탱고 확대=강세 컨펌)**: `basis > 0`(콘탱고 상태) **AND** `basis_roc > 0`(베이시스 확대 중, 즉 선물 프리미엄이 커지는 추세) **AND** 가격이 Donchian(20, 1d) 상단 돌파 → 브레이크아웃 방향과 베이시스 확대가 같은 방향일 때만 무기한 롱 진입(추세 컨펌 필터로 사용, 역추세 아님).
- **숏(백워데이션 전환=약세 컨펌)**: `basis_roc < 0`이 지속돼 `basis`가 0 이하(백워데이션)로 전환 **AND** 가격이 Donchian(20, 1d) 하단 이탈 → 무기한 숏 진입.
- 본 봇은 분기물 자체를 보유하지 않고, 베이시스는 **무기한 방향성 트레이드의 확인 필터**로만 사용(분기물-무기한 차익거래 포지션이 아님).

## 청산 규칙
- 익절: ATR(14, 1d) × 3.0 트레일링 스톱.
- 손절: 진입가 대비 ATR(14, 1d) × 1.5, 또는 베이시스 모멘텀이 진입 방향과 반대로 재전환(`basis_roc` 부호 반전) 시 조기 청산.
- 시간 청산: 없음(추세추종이므로 트레일링 스톱에 위임).

## 파라미터
- basis_roc_lookback=5 (범위 3~10, 1d 기준)
- donchian_len=20 (범위 10~40)
- atr_stop_mult=1.5 (범위 1.0~2.5)
- atr_trail_mult=3.0 (범위 2.0~4.0)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 분기물 종가(별도 심볼 klines), 무기한 종가, Donchian 채널, ATR.
- 주의: **바이낸스 REST(`/fapi/v1/klines?symbol=BTCUSDT_250926`)로 구현 가능**하나, 분기물 심볼은 **매 분기 만기 후 새 심볼로 교체**되므로 `exchangeInfo`에서 현재 근월물 심볼을 동적으로 조회하는 롤오버 로직이 필요(운영 복잡도 있음). 과거 데이터도 만기별로 심볼이 달라 백테스트 시 여러 심볼을 이어붙여야 함(데이터 준비 난이도 중간). `data.binance.vision` 선물 덤프에 분기물이 포함되는지 별도 확인 필요(포함 안 되면 라이브 API로만 최근 구간 검증 가능).

## 스카우트 메모
- 강점: 기존 188개 스펙에 없는 **완전히 새로운 데이터 원천**(분기물 vs 무기한 텀 구조)이며, 기존 `perp-spot-basis-spread-mean-reversion-swing.md`(현물-무기한 스프레드, **평균회귀**)와 자산쌍·메커니즘이 명확히 다름(분기물-무기한, **추세 컨펌 필터**).
- 의심점: 근거가 순수 개념 수준(백테스트 없음)이고, 유니버스가 BTC·ETH 2종뿐이라 우리 다변화된 알트 유니버스 전략 대비 활용도가 제한적. 분기물 롤오버 운영 복잡도가 기대 엣지 대비 과함 — 백테스트 우선순위는 최하위권.
- 우리 단타 슬리브와의 관계: 독립적(신규 데이터원). 다만 구현 복잡도 대비 근거 약함 → 백테스트 순번 후순위 권장.
