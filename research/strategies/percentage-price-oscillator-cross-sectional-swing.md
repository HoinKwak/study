# [스윙] PPO(%) 크로스섹션 모멘텀 스크리너 로테이션

- **출처**: PPO 정의·표준 파라미터: https://school.stockcharts.com/ (StockCharts, PPO=12/26/9 EMA 표준) 및 다수 교육자료의 "MACD를 %로 정규화해 종목 간 비교 가능하게 만든 지표"라는 공통 설명. 크로스섹션 로테이션 설계 자체는 본 스카우트가 PPO의 정규화 특성(가격 스케일 무관 비교 가능)에 착안해 우리 유니버스($10M+ 전 종목)에 적용한 구조화.
- **참여지표**: - (PPO는 표준 지표라 개별 바이럴 게시물 조회수 없음. MACD 대비 "종목 간 절대값 비교가 가능하다"는 점이 정규화 목적으로 널리 알려진 사실.)
- **백테스트 근거**: 없음(원문은 지표 정의 자료, 크로스섹션 로테이션 설계는 자체 구성) — 정량 수치 원문 미확인. 참여지표 기반 아님(표준 지표 정의 기반) 명확히 표기.
- **타임프레임**: 1d 신호(전 유니버스 매일 랭킹) / BTC 1d EMA200 시장 레짐 필터
- **시장/대상**: 바이낸스 선물 유니버스 전체($10M+ 거래대금, 기존 동적 유니버스 재사용) — 크로스섹션 로테이션

## 진입 규칙
- 지표(종목별, 1d): PPO = (EMA(12) − EMA(26)) / EMA(26) × 100. Signal = EMA(9, PPO). Histogram = PPO − Signal.
- 매일 유니버스 전 종목의 PPO 값을 내림차순 랭킹.
- 롱(로테이션 진입): 해당 종목이 PPO 상위 25% 이내 + PPO > 0 + 최근 3봉 이내 PPO가 Signal을 상향 크로스(신규 모멘텀) + BTC 1d 종가 > BTC 1d EMA(200)(시장 전체 상승 국면일 때만 롱 로테이션 가동) → 상위 랭킹 N종목(예: 5~8개) 균등 진입.
- 숏(옵션, 시장중립 변형): PPO 하위 25% + PPO<0 + Signal 하향 크로스 종목을 동시 숏(롱 익스포저와 상쇄) — 단순 롱온리 버전이 기본, 시장중립은 옵션.

## 청산 규칙
- 익절: 없음(로테이션형) — 랭킹이 상위 25% 밖으로 밀려나면 청산.
- 손절: 개별 종목 진입가 − ATR(14,1d)×2.0.
- 시간/조건 청산: 7일(1d×7)마다 전체 리밸런스 — 랭킹 재계산 후 상위권 이탈 종목 청산, 신규 상위권 종목 진입. BTC가 1d EMA200 아래로 마감하면 전체 롱 포지션 청산(레짐 필터).

## 파라미터
- ppo_fast=12, ppo_slow=26, ppo_signal=9 (표준값, 변경 비권장)
- rank_top_pct=25% (범위 15~30%), top_n=5~8종목
- fresh_cross_window=3봉
- rebalance_days=7 (범위 5~14)
- sl_atr_mult=2.0
- market_filter=BTC_1d_EMA200

## 코딩 난이도 / 데이터 요구
- 필요한 지표: EMA(12/26/9) per 종목, 매일 전 유니버스 랭킹 계산, ATR. 모두 바이낸스 REST 캔들로 충족(유니버스는 기존 `connectors/universe.py` 로직 재사용).
- 주의: 오더북/틱/OI 불필요. 다만 "전 유니버스 매일 스캔·랭킹"은 우리 기존 단일종목 전략보다 계산량이 큼(종목 수 × 지표 계산) — 백테스트 시 룩어헤드(당일 랭킹에 미래 데이터 포함 여부) 각별 주의.

## 스카우트 메모
- 강점: PPO는 %정규화라 알트코인처럼 가격 스케일이 천차만별인 유니버스에서 MACD보다 종목 간 비교에 이론적으로 더 적합 — 우리 봇의 동적 유니버스(다수 알트) 구조와 궁합. 스윙 리밸런스(7일)라 수수료 부담 낮음.
- 의심점: 크로스섹션 로테이션은 기존 `cross-sectional-altcoin-momentum-rotation-swing.md`(ROC 기반 랭킹)와 상위 개념(모멘텀 랭킹 로테이션)이 겹침 — 차이는 랭킹 지표가 ROC가 아니라 PPO(EMA差 정규화)라는 점뿐이라, 백테스트 결과가 기존 ROC 로테이션과 실질적으로 다른 신호를 내는지(상관관계) 확인 필요. 중복 위험이 5개 후보 중 가장 큼.
- 우리 단타 슬리브와의 관계: **중장기(스윙) 신규 후보**, 라이브 단타와 직접 대체 없음. 기존 로테이션 전략과 통합/양자택일 검토 대상.
