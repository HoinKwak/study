# [단타] 캔들 VWAP 포지션(풋프린트 근사) 소진 다이버전스 리버설 스캘프

- **출처**: 자체 설계 — 데이터 필드 근거: https://binance-docs.github.io/apidocs/futures/en/#kline-candlestick-data
  (바이낸스 선물 klines 표준 응답, `quote_asset_volume`=8번째 필드·`volume`=6번째 필드. 2026-08-13 직접 curl로
  `data.binance.vision` 덤프에 두 필드 모두 정상 존재 확인). "체결 가격대별 거래량 분포(풋프린트)"로 캔들 내부의
  매수/매도 압력 위치를 읽는다는 개념은 오더북 심도·틱데이터 기반 풋프린트 차트 커뮤니티에서 널리 통용되는
  통설이나, **오더북/틱 없이 표준 캔들 필드(고가·저가·거래대금·거래량)만으로 "캔들 내 거래대금가중평균가(VWAP)
  위치"를 근사해 이 정확한 규칙으로 백테스트한 외부 자료는 찾지 못함 — 스카우트 자체 설계, 지어내지 않음**.
  기존 보유 스펙과의 차별점: `volume-profile-poc-value-area-scalp.md`·`volume-profile-session-poc-magnet-tape-speed-scalp.md`는
  **세션 단위**로 여러 캔들의 거래량을 가격대별로 누적해 POC(최대거래가격대)를 구하고,
  `average-trade-size-accumulation-breakout-swing.md`는 거래대금/체결건수 비율(평균 체결 규모)의 **다중일
  축적 추세**를 본다. 본 스펙은 **단일~소수 캔들 내부**에서 거래대금이 고가·저가 중 어느 쪽에 더 집중됐는지의
  "위치"만을 쓰는 점에서 세 스펙 모두와 메커니즘이 다르다(2026-08-13 `quote_asset_volume`·`vwap_pos`·`footprint`
  키워드로 기존 315개 스펙 전수검색, 신규 확인).
- **참여지표**: - (자체 설계, 참여지표 없음)
- **백테스트 근거**: **없음(자체 설계, 정직히 표기)**. 채택 전 자체 백테스트 필수.
- **⚠️ 예상 표본 빈도**: 5m봉 기준 "포지션 극단(≥0.75 또는 ≤0.25) AND 반대쪽 극단 마감"이라는 이중조건이라
  단일봉만으로는 드물 것으로 예상. [추정] 종목당 **연 300~800건** 수준(체결건수흡수 스퀴즈보다는 흔하고
  Hikkake보다는 드물 것으로 예상 — 검증 전 추정이므로 백테스터 착수 시 실측 빈도를 최우선 보고할 것. 예상의
  5배를 초과하면 두 조건이 사실상 상시 함께 성립하는 것이므로 정의결함 의심).
- **gross 엣지 가설**: 캔들 내에서 거래대금이 고점 근처에 몰렸는데도 정작 종가는 저점 근처로 마감했다면,
  고점 부근의 매수 시도가 매도벽에 흡수되며 실패했다는 뜻(전형적 "실패한 돌파/소진" 마이크로구조 패턴) —
  이런 소진 이후에는 단기 되돌림(반전) 경향이 있다는 것이 풋프린트 트레이더들의 통설.
- **엣지 대비 거래빈도**: 저빈도(연 300~800건)라 왕복 수수료 0.14% 부담이 상대적으로 작음. gross PF가
  최소 1.10~1.15 이상이면 net에서 생존 가능성 있을 것으로 추정.
- **독립성/클러스터링 위험**: 단일 캔들 내부 미시구조 이벤트라 매크로 지표(펀딩·OI)보다 종목 간 동시발생
  가능성은 낮을 것으로 예상되나, 시장 전체가 급락/급등하는 순간에는 다수 종목이 동시에 대형 꼬리를 만들 수
  있어 **동시진입일 비율을 반드시 실측 보고**할 것.
- **⚠️ 전제의 내적 일관성(가장 중요한 자체 우려, 반드시 대조군으로 검증)**: `vwap_pos`(거래대금가중 위치)는
  캔들의 **위꼬리/아래꼬리 비율(순수 OHLC 형태, 거래대금 가중치 없음)**과 강한 상관을 가질 위험이 크다 —
  둘 다 "캔들 내에서 가격이 고점·저점 중 어디에 더 오래·많이 머물렀는가"를 다른 방식으로 재는 것이기 때문.
  즉 `vwap_pos`가 핀바(pin bar)·꼬리 캔들 패턴에 진짜 독립적인 정보를 더하는 게 아니라, 이미 존재하는
  `pin-bar-rejection-key-level-scalp.md`류의 가격패턴을 다른 산식으로 재확인하는 **동어반복(tautology)에
  가까울 위험**이 있다(과거 실현변동성 비대칭 게이트가 EMA 크로스 방향과 동어반복이었던 사례와 동일 함정).
  **채택 전 반드시 대조군 필수**: ① `vwap_pos` 조건을 빼고 순수 "종가가 반대쪽 극단(≤30%/≥70%) 마감"만으로
  거래한 버전(캔들 형태만), ② `vwap_pos` 조건은 유지하되 "반대쪽 극단 마감" 조건은 뺀 버전. 세 버전(본 스펙,
  대조군①, 대조군②)의 gross PF·거래빈도를 나란히 비교해 `vwap_pos`가 순수 캔들형태 대비 부가가치를 내는지
  확인해야 채택 여부 판단 가능.
- **연 단위 이벤트 주의**: 해당 없음(5m 고빈도 신호).
- **타임프레임**: 5m 신호 산출 / 15m EMA20 확인.
- **시장/대상**: BTC·ETH·BNB·SOL·XRP·DOGE·ADA 무기한(표준 7종목, klines 표준 필드는 전 종목 보유).

## 진입 규칙
- **캔들 VWAP**: `candle_vwap(t) = quote_asset_volume(t) / volume(t)` (해당 캔들 동안 체결된 평균 가격,
  거래대금가중). `volume(t)=0`이면 해당 봉 스킵.
- **VWAP 포지션**: `vwap_pos(t) = (candle_vwap(t) - low(t)) / (high(t) - low(t))` (0~1, `high=low`면 스킵).
  1에 가까울수록 거래대금이 고점 부근에 집중, 0에 가까울수록 저점 부근에 집중.
- **종가 포지션**: `close_pos(t) = (close(t) - low(t)) / (high(t) - low(t))`.
- **노이즈 배제**: 해당 봉의 `(high-low)/close`가 최근 60봉 ATR%(5m) 대비 하위 20%ile 미만(레인지 너무
  좁음, 계산 왜곡 위험)이면 신호 배제.
- **숏(고점소진)**: `vwap_pos(t) >= 0.75` **AND** `close_pos(t) <= 0.30` (거래대금은 고점 몰렸는데 종가는
  저점권 마감) → 숏.
- **롱(저점소진)**: `vwap_pos(t) <= 0.25` **AND** `close_pos(t) >= 0.70` → 롱.
- 15m 확인: 15m EMA20 기울기가 진입 방향과 강하게 반대(예: 뚜렷한 상위TF 추세 역행)면 신호 스킵.

## 청산 규칙
- 익절: ATR(14, 5m) × 1.8 트레일링, 또는 R:R 1.5 목표 도달.
- 손절: 소진봉의 반대쪽 극값(숏이면 소진봉 고가) 재돌파, 또는 진입가 ∓ATR(5m,14)×1.0 중 더 타이트한 쪽.
- 시간 청산: `max_hold`=16봉(5m×16≈1.3시간) 내 목표 미도달 시 강제청산(소진-반전 가설은 단기간에 결론나야
  함).

## 파라미터
- vwap_pos_th=0.75/0.25 (범위 0.65~0.85 / 0.15~0.35)
- close_pos_th=0.30/0.70 (범위 0.20~0.40 / 0.60~0.80)
- range_pctile_floor=20 (범위 15~30, 이보다 좁은 레인지는 배제)
- atr_stop_mult=1.0 (범위 0.8~1.5)
- atr_trail_mult=1.8 (범위 1.3~2.5)
- rr_target=1.5 (범위 1.2~2.0)
- max_hold=16봉(5m, 범위 10~24)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 5m·15m klines 표준 필드(`quote_asset_volume`, `volume`, `high`, `low`, `close`), 롤링 percentile,
  ATR(14), EMA20. **전부 바이낸스 REST/`data.binance.vision` klines 덤프만으로 계산 가능**(추가 엔드포인트
  불필요).
- 주의: 오더북 심도·틱데이터·실시간청산 불필요. 신규상장·저유동 종목은 `volume`이 작아 `candle_vwap`이
  소수 대형체결에 휘둘려 노이즈가 클 수 있음(유니버스는 $10M+ 거래대금 종목으로 한정 권장).

## 스카우트 메모
- **강점**: 오더북/틱 없이 캔들 표준 필드만으로 풋프린트 개념을 근사 — 데이터 인프라 리스크가 낮고, 이미
  수집 중인 캔들 데이터에 필드가 전부 포함돼 있어 추가 API 호출이 필요 없음.
- **의심점(최우선)**: 위 "전제의 내적 일관성" 항목에 정리한 대로, `vwap_pos`가 단순 캔들 형태(꼬리 비율)와
  동어반복일 위험이 이 스펙의 핵심 리스크 — 대조군 2종 비교 없이는 채택 판단 불가.
- **우리 슬리브와의 관계**: 라이브 `scalp15m`(볼린저 이탈+거래량+OI 브레이크아웃, 추세추종)과 정반대
  메커니즘(평균회귀/소진 반전)이라 상관이 낮을 가능성 — 대체보다는 보완 후보. 다만 5m TF는 과거 교차검증에서
  "3·5분 적자" 이력이 있어(구 5m/10m 슬리브) 5m 단독 진입이 아니라 15m 확인을 필수로 설계에 포함시켰음에 유의.
