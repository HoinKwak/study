# [스윙] 크립토 공포탐욕지수(Fear & Greed Index) 극단 컨트래리언

- **출처**: https://medium.com/crypto-alpha-drip/your-one-trade-of-the-year-a8f90f702dd4 (Medium, "Your One Trade of the Year" — 백테스트 수치 WebFetch 원문 확인) / 지수 데이터: https://alternative.me/crypto/fear-and-greed-index/ (무료 공개 REST API, 일봉 갱신)
- **참여지표**: - (백테스트 수치 근거로 채택, 참여지표는 비공개)
- **백테스트 근거**: 원문(WebFetch 확인) — **BTC 매수 조건 "F&G ≤ 10", 매도 조건 3가지 비교**:
  - **F&G > 35에서 매도**: **연평균 수익률 14.6%, 누적수익률 133.4%, 최대낙폭(MDD) −25.3%** (3가지 변형 중 최저 MDD, 최고 성과로 원문이 명시)
  - F&G > 50, F&G > 65 매도 변형도 테스트했으나 **>65 변형이 "가장 저조"**했다고 원문이 명시(구체 수치는 원문에 미기재)
  - **한계**: 원문에 정확한 백테스트 기간(연도 범위)·거래 횟수(N)·승률·수수료 반영 여부가 명시되지 않음 → 표본·방법론 불투명, 재검증 필수. "롱온리 현물/보유 관점" 백테스트로 추정되며 **레버리지·숏 사이드는 원문에 없음**(우리 무기한 선물 적용 시 확장 설계 필요).
- **타임프레임**: **일봉 지수**(F&G는 하루 1회 갱신) 기반 포지션 진입/청산 판단 — 보유기간은 수일~수개월 규모의 저빈도 스윙/포지션 성격.
- **시장/대상**: BTC(원문 예시). ETH 등 확장 시 별도 검증 필요(지수는 시장 전체 심리이므로 알트에도 적용 가능하나 원문은 BTC 전용).

## 핵심 아이디어 (신규성)
- 우리 스택 전체에 **가격/거래량/파생지표 외 "외부 심리 지수"를 트리거로 쓰는 전략이 전무**. F&G는 변동성·모멘텀·소셜·설문·도미넌스 등을 합성한 alternative.me의 공개 지수로, **바이낸스가 아닌 별도 무료 REST API**가 필요(추가 데이터 소스 — 우선순위 낮춤 근거).

## 진입 규칙
- 롱: 일봉 F&G 지수가 **≤ 10**(극단적 공포)로 하락한 날 종가(또는 익일 시가)에 진입.
- 숏: 원문엔 숏 규칙 없음(롱온리 백테스트). [설계 판단, 원문 미검증] 대칭 설계 시 F&G ≥ 90(극단적 탐욕) 진입 숏 — **단 크립토는 구조적 상승 편향이 있어 숏 사이드는 원문 근거 없이 고위험, 별도 검증 전 도입 비권장**.

## 청산 규칙
- 익절/청산: F&G 지수가 **35 초과**로 회복되면 청산(원문에서 최고 성과 변형). 대안(원문 열위 변형): 50 또는 65 초과 청산 — **65 변형이 최저 성과**였음이 원문에 명시되므로 채택 시 35 기준 우선.
- 손절: 원문에 명시 없음(공백). [설계 판단] 진입가 대비 −20~30% 하드 스탑 검토(F&G≤10 자체가 이미 패닉 저점 근사이나 추가 하락 리스크 있음).
- 시간 청산: 원문 없음. F&G가 장기간(예: 60일) 10~35 밴드에서 못 벗어나면 별도 검토 필요.

## 파라미터
- entry_fng=10 (범위 5~15)
- exit_fng=35 (범위 30~50, 65는 원문상 최저 성과로 비권장)
- hard_stop_pct=25% (범위 15~35%, [설계 판단] 원문에 없음)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: **alternative.me Fear & Greed Index API**(무료, 인증 불필요, 일봉) — 바이낸스 REST가 아닌 **외부 API 신규 연동 필요**. OHLCV는 진입/청산 가격 산정용으로만 필요(바이낸스로 충족).
- 주의: 지수는 하루 1회만 갱신되므로 인트라데이 정밀 타이밍 불가(스윙/포지션 전용). 외부 API 장애·중단 리스크 있음(단일 무료 소스 의존).

## 스카우트 메모
- 강점: **정량 백테스트 근거가 비교적 구체적**(연 14.6%/누적 133.4%/MDD −25.3%, 3가지 청산 변형 비교까지 제시) — 저빈도·고R 스윙 철학과 부합, 수수료 부담이 거의 없는 구조(연 1~수 회 매매).
- 의심점: 백테스트 기간·표본·수수료 미기재로 방법론 불투명. 극단적 저빈도(연 몇 건)라 표본 부족 리스크 큼 — 통계적 유의성 낮음, "몇 번의 대박 트레이드"에 의존하는 백테스트일 가능성. 우리 무기한 선물 레버리지·숏 사이드로 확장 시 원문 밖 설계가 대부분.
- 우리 스택과의 관계: 완전히 새로운 데이터 축(심리 지수)이라 중복 없음. 다만 매매 빈도가 너무 낮아(연 1~수 건) 포트폴리오 슬리브로는 보조 신호(레짐 필터)로 쓰는 편이 실전적일 수 있음 — 예: 다른 스윙 전략의 진입 필터로 병용.
