# 초퍼니스 인덱스 레짐필터 브레이크아웃 [스윙]

- **출처**: 지표 원안 Bill Dreiss(1994) / TradingView 빌트인 "Choppiness Index (CHOP)" https://www.tradingview.com/support/solutions/43000501980-choppiness-index-chop/ / 구현 스크립트 예: "MM Chop Filter" by MoneyMovesInvestments https://www.tradingview.com/script/OnKfG9cF-MM-Chop-Filter/ (Chop and Explode Indicator 기반 개작)
- **참여지표**: MM Chop Filter 스크립트 565 likes(WebFetch로 확인, TradingView 초퍼니스 관련 스크립트 목록 중 필터형으로는 상위권). CHOP 자체는 TradingView 빌트인 지표라 개별 조회수는 없음(광범위 사용).
- **백테스트 근거**: 없음(참여지표 기반). WebFetch로 원문 확인 시도했으나 quantifiedstrategies.com의 정량 수치 페이지는 봇 차단으로 원문 확인 불가 → 해당 사이트발 수치는 인용하지 않음(정량 완전 미확인). 임계값(38.2/61.8)은 지표 표준 공식·통용 관례로 검증된 것이며 성과수치가 아님.
- **타임프레임**: 4h 레짐 판정 / 1h 진입 트리거. (검색 스니펫 근거: "15m~4H에서 가장 신뢰도 높음")
- **시장/대상**: BTC·ETH·알트 무기한.

## 진입 규칙
- CHOP 계산(표준식, n=14): `CHOP = 100 * log10( SUM(TR,n) / (MAX(High,n) - MIN(Low,n)) ) / log10(n)`
- **레짐 필터**: 4h CHOP이 최근 X봉 내 61.8 이상(횡보/압축)에서 **38.2 아래로 하락 돌파** = "압축 해소, 추세 시작" 시그널.
- 롱: 위 레짐 전환 시점 이후 N봉 이내에 1h 종가가 최근 20봉 레인지 상단(직전 압축 구간 고점) 상향 돌파 + 거래량 ≥ 20MA×1.5.
- 숏: 동일 조건에서 레인지 하단 하향 돌파.
- (선택 필터) ADX(14) ≥ 20으로 CHOP 전환 후 실제 추세 강도 재확인.

## 청산 규칙
- 익절: 압축폭(레인지 상단-하단)의 1.0~1.5배 measured move, 또는 CHOP이 다시 61.8 이상으로 재상승(추세 소멸)하면 분할청산.
- 손절: 돌파 반대편 레인지 극값(진입 반대쪽 레인지 경계) 바로 너머.
- 시간 청산: 돌파 후 20봉(1h) 내 measured move 미달성 시 절반 청산 후 트레일.

## 파라미터
- chop_period=14 (표준, 범위 10~20)
- chop_range_lookback=20~30봉 (61.8 진입 여부 판정 구간)
- chop_high=61.8 / chop_low=38.2 (지표 표준 임계값, 고정 권장)
- vol_mult=1.5 (범위 1.2~2.0)
- adx_min=20 (선택, 범위 15~25)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: TR/ATR 합산(CHOP 자체), 롤링 최고/최저(레인지), 거래량 MA, ADX(선택). 전부 캔들+거래량 기반.
- 주의: 바이낸스 REST 캔들+거래량으로 완전 충족. 추가 데이터 불필요.

## 스카우트 메모
- 강점: 우리 보유 목록에 "레짐(트렌드/횡보) 자체를 정량 필터로 명시적 스코어링"하는 지표가 없음(regime.py는 내부 로직으로 존재하나 리서치 후보로는 신규). bollinger-squeeze-breakout·nr7-volatility-contraction·vcp-volatility-contraction과 "압축→돌파" 구조는 유사하지만, 그것들은 밴드폭/레인지 자체를 압축 지표로 쓰고 이건 **TR/레인지 비율의 로그 정규화**라는 별도 공식이라 신호 상관이 낮을 가능성.
- 의심점: 정량 백테스트 완전 부재(참여지표도 강하지 않음, 565 likes는 중간 수준). CHOP은 후행지표라 돌파 초입을 놓칠 수 있음 — 진입 필터가 이미 여러 개(레짐+레인지돌파+거래량+선택 ADX)라 실제 신호 빈도가 매우 낮을 위험(스윙 슬리브 특성상 빈도 낮은 건 허용되나, 아예 신호가 안 나올 수도 있음 — 백테스트로 신호 빈도부터 확인 필요).
- 우리 단타 슬리브와의 관계: 기존 볼린저 돌파+거래량+OI 단타(스퀴즈≤35%)와 컨셉이 유사(압축 후 돌파)하나 필터 지표가 달라 **부분 중복 가능성 있음** — 채택 시 기존 스퀴즈 필터와 CHOP 필터의 상관을 먼저 확인 권장.
