# [단타] 글로벌 포지션비율 vs 테이커 체결플로우 다이버전스 (스퀴즈 조기포착)

- **출처**: 개념 — https://bitcoinworld.co.in/bitcoin-funding-rate-divergence-rally-signal/ (BitcoinWorld, "포지셔닝(펀딩·롱숏비율)과 실제 시장심리/체결흐름 간 괴리가 스퀴즈 신호"라는 정성적 논지 — WebFetch로 원문 확인, **정량 수치는 원문에 없음**을 확인) /
  데이터 필드 근거: `data.binance.vision`의 `metrics` 일별 덤프에 **서로 다른 두 계열**이 함께 존재함을 직접 확인(`count_long_short_ratio`=전체 계정 롱/숏 **계정수** 비율, `/futures/data/globalLongShortAccountRatio`에 대응; `sum_taker_long_short_vol_ratio`=테이커 매수/매도 **체결거래량** 비율, `/futures/data/takerlongshortRatio`에 대응). 기존 보유 `long-short-account-ratio-contrarian-swing.md`(계정비율 단독 극단 컨트래리언), `toptrader-vs-global-ratio-spread-divergence-swing.md`(상위트레이더 vs 전체 **포지션비율끼리** 스프레드), `cvd-taker-volume-divergence-scalp.md`(캔들 내재 테이커볼륨과 **가격의** 다이버전스, 5m봉 단위)와 **모두 다른 조합**: 이 스펙은 "**포지션(계정비율)**"과 "**최근 체결플로우(테이커비율)**"라는 서로 다른 두 metrics 필드끼리의 다이버전스를 처음으로 결합함.
- **참여지표**: - (뉴스/애널리스트 논평 기반, SNS 참여지표 미집계. "포지셔닝-플로우 괴리"는 코인글래스·크립토퀀트 등 파생 데이터 업체 리포트에서 자주 언급되는 정성적 개념)
- **백테스트 근거**: **없음(개념 기반, 정직히 표기)**. BitcoinWorld 원문은 2024-09·2022-12 두 사례를 정성적으로만 언급하고 승률·표본·PF 등 정량 수치를 전혀 제시하지 않음(WebFetch로 직접 확인, 인용하지 않음). 채택 전 자체 백테스트 필수.
- **타임프레임**: 1h 신호(metrics 5분 데이터를 1h로 집계해 노이즈 감소) / 15m 진입 확인.
- **시장/대상**: BTC·ETH·시총상위 알트 무기한(BNB/SOL/XRP/DOGE/ADA — metrics 덤프에 종목별 존재 확인 필요, BTC는 확인 완료).

## 진입 규칙
- 지표 정의(둘 다 로그변환 후 롤링 z-score로 **데미닝**): `pos_z(t) = zscore_60d( log(count_long_short_ratio(t)) )`, `flow_z(t) = zscore_60d( log(sum_taker_long_short_vol_ratio(t)) )` — 두 비율 모두 1 부근(롱=숏)이 아니라 **구조적으로 1보다 큰 값에 장기 편향**될 수 있음(리테일 계정의 만성적 순매수 편향 등)을 전제하고, 로그변환 + 60일 롤링 평균차감 z-score로 이 구조적 편향을 제거한 뒤에만 비교.
- 다이버전스 스코어: `div(t) = pos_z(t) - flow_z(t)`.
- **숏(롱스퀴즈 경계)**: `pos_z(t) >= +1.5`(계정 포지셔닝이 자기 역사 대비 극단적으로 롱 쏠림) **AND** `flow_z(t) <= -0.5`(최근 실제 체결 플로우는 매도 우위로 전환, 즉 포지션은 안 줄었는데 흐름은 이미 반대) **AND** `div(t) >= 2.0`(괴리 폭 자체가 임계 이상) → 숏.
- **롱(숏스퀴즈 경계)**: 대칭 — `pos_z(t) <= -1.5` **AND** `flow_z(t) >= +0.5` **AND** `div(t) <= -2.0` → 롱.

## 청산 규칙
- 익절: `div(t)`가 0 부근(±0.3)으로 정상화되면 청산, 또는 R:R 1.8 목표 도달.
- 손절: 진입가 ∓ATR(1h,14)×1.5.
- 시간/조건 청산: `max_hold`=24봉(1h×24=1일) 초과 시 무조건 청산. `pos_z`가 진입 방향과 반대로 재차 확장되면(스퀴즈 가설 무효화) 조기 청산.

## 파라미터
- zscore_window=60일(1h 기준 1440봉, 범위 30~90일)
- pos_z_entry=1.5 (범위 1.2~2.0)
- flow_z_entry=0.5 (범위 0.3~0.8)
- div_entry=2.0 (범위 1.5~2.5)
- div_exit=0.3
- atr_stop_mult=1.5
- rr_target=1.8
- max_hold=24봉(1h)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: `data.binance.vision`의 `metrics` 덤프 2개 필드(`count_long_short_ratio`, `sum_taker_long_short_vol_ratio`), 5분 데이터를 1h로 리샘플(평균 또는 마지막값), ATR.
- 주의: 오더북/틱/실시간청산 불필요. **`count_toptrader_...`(상위트레이더 전용) 필드는 과거 리뷰에서 2022년 상당 구간 결측이 확인됐으나, 본 스펙이 쓰는 `count_long_short_ratio`·`sum_taker_long_short_vol_ratio`는 전체(글로벌) 필드로 같은 리뷰에서 "정상(결측 없음)"으로 확인된 바 있음** — 다만 본 라운드에서 직접 재확인한 것은 아니므로 백테스트 착수 시 재검증 권고.

## 스카우트 메모
- **예상 표본 빈도**: `pos_z`가 ±1.5 이상은 정규분포 가정 시 약 13%의 시간, 여기에 `flow_z`·`div` 조건까지 AND로 겹치면 크게 줄어듦 — [추정] 종목당 연 20~60건 정도로 예상하나, **두 필드가 서로 독립이 아닐 가능성**(포지션이 극단이면 최근 체결도 같은 방향으로 쏠렸을 가능성, 즉 `pos_z`와 `flow_z`가 오히려 양의 상관일 수 있음)이 있어 실제 발생빈도가 예상보다 훨씬 낮을 위험을 사전에 인지.
- **gross 엣지 가설**: 포지션(누적 잔량)과 최근 체결플로우(유량)는 개념적으로 다른 시계열이라(계정비율은 스톡, 테이커비율은 최근 플로우) 진짜 독립정보일 가능성이 있으나, 두 지표 모두 궁극적으로 같은 시장(매수/매도 압력)에서 파생되므로 **상관이 예상보다 높을 위험**을 반드시 실측해야 함(과거 회전율레짐·체결건수흡수 스펙에서 "상호배타적"이라 가정한 두 조건이 실제로는 강한 양의 상관이었던 사례 반복 방지).
- **엣지 대비 거래빈도**: 조건이 3중 AND라 빈도가 낮을 가능성 높음 — 표본부족으로 판단불가에 그칠 위험을 사전 인지, 파라미터를 다소 완화한 버전(div_entry 낮춤)도 병행 스윕 권고.
- **독립성/클러스터링 위험**: 시장 전체가 급변동하는 매크로 이벤트(청산 캐스케이드 등) 시 여러 종목이 동시에 `pos_z`·`flow_z` 극단을 보일 가능성 높음 — 7종목 동시신호 비율을 반드시 실측하고 이벤트 단위 재집계 병행.
- **표준 7종목 신호 충분성**: BTC는 metrics 덤프 확인됐으나 나머지 6종목은 이번 라운드에 필드 존재만 전제하고 직접 curl 검증은 못함 — 백테스트 착수 시 우선 7종목 전부 덤프 존재·결측률을 먼저 확인할 것.
- **지표 정의 수학적 타당성(데미닝)**: 로그변환 + 60일 롤링 z-score로 구조적 편향(장기평균이 1이 아닐 수 있음)을 명시적으로 제거하도록 설계 — 과거 인덱스가격 스냅백 스펙이 데미닝 누락으로 상시-극단 상태를 "3σ 이벤트"로 오판했던 실수를 반복하지 않기 위한 조치.
- **전제의 내적 일관성 + 실측 대조 계획**: 위 gross 엣지 가설에 명시한 대로 `pos_z`와 `flow_z`의 상관을 **백테스트 최우선 진단 단계**에서 실측(피어슨 상관계수 산출)하고, 강한 양의 상관(예 |r|>0.4)이면 두 조건의 결합이 사실상 단일조건과 다름없어 "독립정보 결합"이라는 전제가 무너짐을 인정하고 즉시 재설계 또는 폐기할 것.
- **연 단위 이벤트 주의**: 해당 없음(1h 해상도로 연중 반복 발생 가능한 신호).
- 우리 단타 슬리브와의 관계: 기존 단타(볼린저 이탈+거래량+OI)와 신호원이 완전히 다름(포지셔닝·플로우 다이버전스) — 데이터 존재만 확인됐지 가설 자체의 검증가치는 중간. 상관 진단을 먼저 돌려볼 것을 권장.
