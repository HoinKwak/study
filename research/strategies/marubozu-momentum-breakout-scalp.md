# [단타] 마루보즈(장대 몸통봉) 모멘텀 돌파

- **출처**: https://www.strike.money/technical-analysis/marubozu (Strike.money — WebFetch 원문 확인, 자체 백테스트 수치 명시) / 개념 보강: https://trendspider.com/learning-center/marubozu-candlesticks-a-traders-guide/ , https://fxopen.com/blog/en/what-is-the-marubozu-candlestick-pattern-2/
- **참여지표**: - (교육 사이트 기반, SNS 참여지표 미집계). 다만 캔들패턴 자체는 Bulkowski 등 다수 실증 연구에 반복 등장하는 고전 패턴.
- **백테스트 근거**: **Strike.money 자체 백테스트(WebFetch 원문 확인)** — 마루보즈 패턴 100건 대상, **인도 NSE 대형·중형주, 일봉**. 진입: 마루보즈 고가 상향 돌파(다음 봉 확인 후) → **1:1.5 손익비 목표 시 승률 63%(63승/37패)**, **1:2 손익비 목표 시 승률 51%(51승/49패)** — "1:1.5가 더 안정적 성과"라고 결론. **⚠️ 주식시장·소표본(100건) 결과이며 크립토 재현 데이터는 없음** — 원문에 정확히 승률·손익비 매칭 수치는 확인했으나 PF·MDD·기간은 명시 안 됨.
- **타임프레임**: 5m~15m 신호 / 1h 확인
- **시장/대상**: BTC·ETH·시총상위 알트 무기한

## 진입 규칙
- **마루보즈 정의**: 몸통(시가-종가 절대값) / 전체 레인지(고가-저가) ≥ **70%**(body_ratio_th, 원문 명시 임계값) — 꼬리가 거의 없는 장대 몸통봉.
- 롱: 상승 마루보즈(종가>시가, body_ratio≥70%) 확정 → **다음 봉이 마루보즈 고가를 상향 돌파** 시 그 봉 종가(또는 돌파 즉시) 진입. 원문은 "다음 봉으로 방향 확인 후 진입"을 명시 권장.
- 숏: 하락 마루보즈(종가<시가, body_ratio≥70%) 확정 → 다음 봉이 마루보즈 저가를 하향 돌파 시 진입.
- (권장 필터, 원전엔 없으나 크립토 다이 특성상 권장) 마루보즈 봉의 거래량 ≥ 직전 20봉 평균×1.3 — 원문도 "이동평균·거래량과 결합해야 신뢰도 상승"이라 언급.

## 청산 규칙
- 익절: **1:1.5 R:R 고정 목표**(원문 백테스트 기준 최적, 승률 63%) — 1:2 목표(승률 51%)는 대안으로 A/B 비교.
- 손절: 마루보즈 봉의 반대쪽 끝(롱=저가 아래, 숏=고가 위).
- 시간 청산: N봉(예: 5m 기준 12~20봉) 내 목표 미달 시 청산.

## 파라미터
- body_ratio_th=0.70 (원전 고정값, 범위 0.65~0.80로 민감도 테스트 가능)
- vol_confirm_mult=1.3 (범위 1.0~1.5, 옵션)
- rr_target=1.5 (원전 최적, 범위 1.0~2.0)
- max_hold_bars=16 (5m 기준)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 캔들 몸통/레인지 비율(OHLC만으로 계산), 거래량 이동평균(선택 필터).
- 난이도: **매우 낮음**. 단일 캔들 형태 판정 + 다음 봉 돌파 확인만으로 구현 가능, 상태 유지 최소.
- 주의: 오더북·틱데이터 불필요, 바이낸스 REST 캔들만으로 완전 재현 가능. 다만 크립토는 변동성이 커 "몸통비율 70%" 임계가 주식보다 자주 충족될 수 있어 신호 과다 발화 위험(거래량 필터로 완화 권장).

## 스카우트 메모
- **강점**: 규칙이 극도로 단순(단일 캔들 판정)해 구현·백테스트가 매우 빠름. 원문에 **정확한 승률·표본수·R:R별 결과가 명시**돼 있어(비록 주식) 참고 기준선을 잡기 좋음. 기존 3봉 패턴(`inside-bar-mother-bar-breakout-scalp`, `three-line-strike-candlestick-reversal-scalp`)과 달리 **단일봉 모멘텀 돌파** 패턴이라 지표 중복 없음.
- **의심점**: 백테스트가 인도 주식 일봉 100건이라 표본이 작고 크립토 5~15m과는 변동성 구조가 다름 — 신호 빈도가 크립토에서 훨씬 높을 것으로 예상되며, 그만큼 승률이 주식보다 낮아질 가능성. 반드시 우리 프레임워크로 재검증 필요.
- **우리 슬리브와의 관계**: 기존 볼린저 돌파+거래량+OI 단타와 **트리거 메커니즘이 다름**(볼린저 밴드 이탈이 아니라 단일 캔들 몸통비율)이라 보완재 후보. 신호 빈도가 유사 시간대에 겹칠 수 있어 상관관계 확인 필요.
