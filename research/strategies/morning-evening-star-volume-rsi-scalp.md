# [단타] 모닝스타/이브닝스타 3캔들 반전 + 거래량·RSI 확인

- **출처**: 지표 정의 — 서양 캔들패턴(Morning Star / Evening Star, Steve Nison 계열 표준 정의)을 크립토 무기한 연속거래(갭 없음) 환경에 맞게 재정의. **정확한 이 규칙(파라미터·필터 조합)은 스카우트 자체 설계 — 외부에 이 정확한 백테스트는 없음, 지어내지 않음.** 기존 보유 `doji-oi-plateau-exhaustion-reversal-scalp.md`(도지+OI), `engulfing-candle-rsi-volume-reversal-scalp.md`(장악형), `pin-bar-rejection-key-level-scalp.md`(핀바), `three-line-strike-candlestick-reversal-scalp.md`, `three-soldiers-crows-volume-continuation-scalp.md`, `tweezer-top-bottom-volume-confirm-swing.md`와 겹치는 캔들 패턴 축이지만, **3봉 조합 중 "강한추세봉→소형 인디시전봉→반대방향 강한 되돌림봉"이라는 모닝/이브닝스타 특유의 3단 구조는 407개 기존 보유 목록에 없음**(직접 대조 확인).
- **참여지표**: - (자체 설계, 고전 패턴)
- **백테스트 근거**: **없음(자체 설계, 정직히 표기)**. 채택 전 자체 백테스트 필수.
- **타임프레임**: 1h 신호 / 15m 확인(체결 타이밍만).
- **시장/대상**: BTC·ETH·BNB·SOL·XRP·DOGE·ADA 무기한.

## 진입 규칙
- 데이터: 1h klines(O/H/L/C/V), ATR(14,1h), RSI(14,1h), EMA(20,1h).
- **캔들1(추세봉)**: 강한 방향성 봉 — `|close-open| >= 1.0×ATR14` **AND** `body/range >= 0.6`.
- **캔들2(스타/인디시전봉)**: 소형 몸통 — `body <= 0.35×ATR14`(갭 정의는 크립토 연속거래 특성상 생략, 몸통 크기만으로 인디시전 판정).
- **캔들3(반전확인봉)**: 캔들1과 반대 방향의 강한 봉 — `|close-open| >= 1.0×ATR14` **AND** 캔들3 종가가 캔들1 몸통의 **50% 이상**을 되돌림(`close3 >= open1 - 0.5×(open1-close1)` 롱 기준).
- **거래량 확인**: 캔들3 거래량 >= 최근 20봉 평균 거래량 × 1.3.
- **RSI 확인(롱=모닝스타)**: 캔들1 또는 캔들2 종가 시점 RSI(14) <= 40(과매도권 진입 이력).
- **롱 진입**: 캔들1 하락(음봉) + 캔들2 인디시전 + 캔들3 상승(양봉, 50%+되돌림) + 거래량확인 + RSI<=40 이력 → 캔들3 종가(또는 익봉 시가)에 롱.
- **숏 진입**: 대칭(이브닝스타) — 캔들1 상승 + 캔들2 인디시전 + 캔들3 하락(50%+되돌림) + 거래량확인 + RSI(14)>=60 이력 → 숏.

## 청산 규칙
- 익절: ATR(1h,14) × 2.0 트레일링, 또는 R:R 1:2 선도달.
- 손절: 캔들2 저가(롱) / 캔들2 고가(숏) 대비 소폭(0.1×ATR) 버퍼.
- 시간 청산: 진입 후 12봉(1h, 12시간) 경과 시 시장가 청산.

## 파라미터
- body1_atr_mult=1.0 (범위 0.8~1.3), body2_atr_mult=0.35 (범위 0.25~0.5)
- retrace_pct=50% (범위 38~62%), vol_mult=1.3 (범위 1.1~1.8)
- rsi_th=40/60 (범위 35~45 / 55~65)
- tp_atr_mult=2.0, sl_buffer_atr=0.1, max_hold=12봉(1h)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: ATR(14), RSI(14), 20봉 평균거래량 — 전부 1h klines에서 계산 가능. 오더북·틱 데이터 불필요.
- 주의: 크립토는 갭이 사실상 없으므로 원래 정의의 "갭업/갭다운" 조건은 의도적으로 생략(몸통 크기 기준으로만 대체) — 이 완화가 패턴 빈도를 과다하게 늘릴 위험을 백테스트에서 실측 확인 필요.

## 스카우트 메모
- **예상 신호 빈도**: [추정] 3봉 연속 특정 형태 결합이라 빈도는 낮을 것으로 예상 — 종목당 **연 40~120건**(1h TF, 필터 엄격도에 따라). 갭 조건 생략으로 원 정의보다 빈도가 높아질 수 있어 실측 카운트를 최우선 확인.
- **비용 감당 산술**: 왕복수수료 0.14%. TP 목표(ATR×2.0)가 메이저 1h ATR 기준 통상 1~2%대라 명목 엣지가 존재한다면 수수료 부담은 상대적으로 작음. 다만 빈도가 예상보다 높게(수백 건) 나오면 net에서 잠식될 수 있어 gross·net 반드시 병기.
- **전제의 내적 일관성**: 캔들1(추세강도)·캔들3(거래량)·RSI(모멘텀)는 서로 다른 통계량(가격 몸통·거래량·정규화 모멘텀)이라 동어반복 위험은 낮을 것으로 예상하나, RSI<=40과 캔들1 몸통강도는 둘 다 "하락압력"을 반영하므로 **예상 상관 0.3~0.4 수준**(중간 상관, 완전 동어반복은 아님)으로 사전 명시. 상관이 0.7 이상으로 실측되면 RSI 필터가 사실상 캔들1 조건의 재포장일 가능성을 의심.
- **종목 간 신호 상관**: 시장 전체 반전 국면(BTC 급락→반등)에 메이저 전종목이 동시에 패턴을 형성할 가능성 있어 **예상 상관 0.3~0.5**(중간). LOO·종목확장을 통계력으로 오인하지 않도록 이벤트 단위(동일 캔들3 날짜) 클러스터링 진단 권고.
- **정규화 게이트 논증**: RSI<=40/>=60은 자기 백분위 게이트가 아니라 절대 임계값(고정 스케일)이라 시장 상태와 무관하게 대략 시간의 20~35% 정도 통과하는 기본 발화율을 가짐(RSI 분포 특성상) — 이 자체는 정보가 아니라 **패턴(캔들1·2·3 형태) 조건과의 결합에서 선택성이 나와야 함**을 백테스트에서 확인.
- **수익의 인과 경로**: 강한 매도 소진(캔들1) → 관망/실망매물 소화(캔들2) → 거래량 동반 매수세 확인(캔들3)이라는 고전 반전 서사. 크립토 연속거래 환경에서 "갭"이라는 핵심 요소가 빠진 변형이라 원 정의의 효험이 그대로 이전된다는 보장은 없음 — 정직히 인정.
- **라이브 실행 가능성**: 1h 신호, 캔들3 마감 시점에만 판정되므로 메이커 지정가로 캔들3 종가 근방 진입 시도 가능. 15m 확인TF은 체결 타이밍 미세조정용.
- **사전 폐기조건(사후 변경 금지)**: (a) OOS PF(R) < 1.0 또는 t 비유의 (b) OOS net PF < 1.05(수수료 이전부터 무엣지) (c) LOO에서 BTC·ETH 제외 시 OOS 붕괴(메이저 의존) (d) 방향반전(패턴을 반대로 매매) 대조군이 정방향과 통계적으로 구분 불가 또는 더 우수.
- **강점**: 407개 기존 스펙에 정확히 이 3봉 구조가 없음(직접 대조), 규칙이 명확·재현 가능.
- **의심점**: 갭 생략 변형이 원 정의의 핵심을 훼손했을 가능성, RSI·캔들강도 상관 위험.
- **우리 단타 슬리브와의 관계**: 라이브 `scalp15m`(볼린저 돌파+거래량+OI, 15m)과 타임프레임(1h)·신호원(캔들패턴 vs 볼린저 돌파)이 달라 보완적. 기존 캔들패턴류 스펙들과는 축은 같으나 정확한 패턴 미중복.
