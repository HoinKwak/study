# [스윙] RSI 레인지시프트(Cardwell) 정상반전 추세추종

- **출처**: https://blog.elearnmarkets.com/relative-strength-index-rsi-range-shift/ (elearnmarkets 블로그, Andrew Cardwell "Dr. RSI" 레인지시프트 개념 — WebFetch로 원문 확인) / 보강: https://www.tradingview.com/chart/XAUUSD/aB1EGX45-The-Cardwell-RSI-Range-Shift-Strategy/ (TradingView 차트 아이디어), https://www.prorealcode.com/topic/andrew-cardwell-strategy-on-rsi/ (포럼 토론)
- **참여지표**: - (교육 블로그/포럼, SNS 참여지표 미집계). Andrew Cardwell은 RSI 창시자 Welles Wilder 이후 RSI 응용법(레인지시프트·포지티브/네거티브 리버설)을 정립한 것으로 트레이딩 교육계에서 널리 인용되는 인물.
- **백테스트 근거**: 없음(정성적 개념 문서, 정량 수치 원문 미확인). 원문 인용 레인지 정의만 명확: **슈퍼불리시 60~80 / 불리시 40~80(레인지시프트 후) / 사이드웨이 40~60 / 베어리시 20~60 / 슈퍼베어리시 20~40**. "정상반전(positive reversal)"은 원문에 개념만 언급되고 구체 트리거·수치 임계는 없어 **본 스펙은 레인지시프트 규칙 부분만 원문 기반, 진입 트리거는 스카우트 설계로 보강**(아래 명시).
- **타임프레임**: 4h 신호 / 1d 확인. RSI 레인지 안정성 확인에는 저잡음 TF 필요.
- **시장/대상**: BTC·ETH·시총상위 알트 무기한

## 진입 규칙
- 지표: RSI(14, Wilder 표준).
- **레인지시프트(체제전환) 판정**: 최근 shift_lookback(예 20봉) 동안 RSI가 40선을 하회한 적 없이(종가 기준) 40~80 레인지에서 움직이면 **불리시 레인지 확정**(업트렌드 체제). 반대로 60선을 상회한 적 없이 20~60 레인지면 **베어리시 레인지 확정**(다운트렌드 체제).
- **롱(불리시 레인지 중 눌림목)**: 불리시 레인지 확정 상태에서 RSI가 되돌림으로 40~50 구간까지 하락했다가 **종가 기준으로 다시 50 위로 재돌파** → 그 봉 종가에 롱 진입("40선 지지 확인 후 재상승"을 추세지속 매수 시그널로 코딩, 원문의 "RSI won't fall below 40 and finds support there" 개념을 트리거화 — [스카우트 설계 보강, 원문에 정확 트리거 없음]).
- **숏(베어리시 레인지 중 반등)**: 베어리시 레인지 확정 상태에서 RSI가 50~60까지 반등했다가 종가 기준 50 아래로 재하락 → 숏 진입.
- 무효화: 불리시 레인지 중 RSI가 종가 기준 40을 하회하면 레인지시프트 붕괴(체제 종료)로 간주, 신규 롱 진입 중단.

## 청산 규칙
- 익절: 목표 없음(추세추종형) — 트레일링. 직전 스윙고점을 상회하는 새 고점마다 SL 상향 트레일(구조 기반) 또는 3R 고정 목표 옵션.
- 손절: 진입 시 최근 스윙 저점(롱)/고점(숏) 바로 아래/위. [설계 보강, 원문 없음]
- 시간/조건 청산: 레인지시프트 붕괴(RSI가 40을 하회, 불리시 레인지 기준) 시 즉시 전량 청산.

## 파라미터
- rsi_period=14 (Wilder, 원문 표준)
- range_bull_lo=40, range_bull_hi=80 / range_bear_lo=20, range_bear_hi=60 / range_side=40~60 (원문값)
- shift_lookback=20봉 (범위 10~40) — 레인지시프트 확정에 필요한 최소 유지 기간, [스카우트 설계]
- pullback_zone=40~50 (불리시 기준, [설계값])
- reentry_confirm=close_above_50 (필수, 종가 재돌파)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: RSI(14)만 필요, 순수 OHLC 캔들 기반. 스윙 고/저점(SL용)은 롤링 극값.
- 주의: 바이낸스 REST 캔들로 완전 충족. 오더북/틱 불필요. "레인지시프트 확정"의 lookback 파라미터가 원문에 없어 재현 시 자체 캘리브레이션 필요 — 과최적화 위험 있음(shift_lookback 스윕 시 결과 민감도 반드시 확인).

## 스카우트 메모
- 강점: 우리 보유 RSI 계열(`rsi2-mean-reversion`, `bollinger-rsi-divergence-reversal`, `rsi-failure-swing-wilder-reversal-swing`, `multitf-rsi14-4h-entry-daily-200ma-filter-swing`)은 전부 **역추세 또는 다이버전스** 프레임인 반면, 이건 **RSI를 추세필터로 쓰고 되돌림을 추세지속 매수신호로 해석**하는 정반대 프레임(Cardwell 본인이 "RSI는 모멘텀지표보다 추세추종지표로 더 가치 있다"고 언급) — 메커니즘이 명확히 다름.
- 의심점: (1) 원문에 진입 트리거 수치가 없어 대부분 재현 로직이 스카우트 설계 보강(레인지시프트 lookback·재돌파 트리거) — 원저자 의도와 다를 수 있음. (2) 정량 백테스트 전무, 참여지표도 약함 — 채택 우선순위는 낮은 편이나 규칙 자체는 명확히 코딩 가능. (3) `bos-choch-market-structure-swing.md`(가격구조 기반 추세전환)과 목적은 유사(추세체제 판별+지속매매)하나 지표(RSI vs 가격 스윙포인트)가 완전히 달라 중복 아님.
- 우리 슬리브와의 관계: 현재 스윙 슬리브(RSI 역추세 초기진입 → 슈퍼트렌드 피라미딩)와는 **RSI 사용 방향이 정반대**(우리는 RSI 극단=역추세 진입 신호, 이건 RSI 레인지=추세필터) — 직접 대체보다는 별도 실험 슬리브로 검증 권장.
