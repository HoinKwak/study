# [단타] 클래식 스토캐스틱(%K/%D) 과매수·과매도 크로스오버 스캘프

- **출처**: https://nordfx.com/useful-articles/mastering-the-stochastic-oscillator / https://tiomarkets.com/en/article/stochastic-oscillator-guide-in-scalping / https://www.gate.com/learn/articles/what-is-stochastic-oscillator-k (Gate Learn)
- **참여지표**: - (교육 콘텐츠 다수, 특정 바이럴 게시물 조회수 확인 안 됨). 조지 레인(George Lane)의 클래식 스토캐스틱은 크립토 스캘핑 커뮤니티에서 가장 자주 언급되는 표준 오실레이터 중 하나.
- **백테스트 근거**: 없음(개념·규칙 설명 위주). 정량 수치 원문 미확인 — 지표 설명 기반으로 분류. (주의: StochRSI·Stochastic Momentum Index(Blau)는 이미 보유 스펙에 있으나, 본 전략은 **원조 %K/%D 공식**(RSI를 거치지 않고 가격 range 기준 직접 계산)이라 별개 지표.)
- **타임프레임**: 15m 신호 / 1h EMA200 추세 필터
- **시장/대상**: BTC·ETH·주요 알트 USDT-M 무기한

## 진입 규칙
- 지표: %K(14,3 스무딩), %D=SMA(%K,3). 과매수=80, 과매도=20. (스캘핑용 대안 파라미터: %K(5,3), %D(3) — 더 민감·더 잦은 신호.)
- 롱: %K와 %D가 모두 20 미만(과매도)에서 %K가 %D를 상향 크로스 + 이후 %K가 20을 재상향 돌파(이중 확인, 휩쏘 감소) + 1h 종가 > 1h EMA(200)(강한 하락추세에서 역행 롱 방지).
- 숏: %K와 %D가 모두 80 초과(과매수)에서 %K가 %D를 하향 크로스 + %K가 80 재하향 돌파 + 1h 종가 < 1h EMA(200).

## 청산 규칙
- 익절: %K가 반대 극단(롱은 %K≥80, 숏은 %K≤20) 도달 시 청산, 또는 1.5R(=SL폭×1.5) 도달 시.
- 손절: 신호봉 저가(롱)/고가(숏) − ATR(14,15m)×1.0.
- 시간/조건 청산: 진입 후 20봉(15m×20=5시간) 내 목표/손절 미도달 시 시간 청산(레인지 소멸 대비).

## 파라미터
- k_period=14 (범위 5~14), k_smooth=3, d_period=3
- os_level=20, ob_level=80
- atr_period=14, sl_atr_mult=1.0, tp_R=1.5 (범위 1.2~2.0)
- trend_filter_ema=200 (1h)
- time_exit_bars=20

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 스토캐스틱 %K/%D(롤링 최고/최저 기반), EMA, ATR. 모두 바이낸스 REST 캔들만으로 충족.
- 주의: 오더북/틱/OI 불필요. 구현 매우 단순(롤링 min/max + SMA).

## 스카우트 메모
- 강점: 구현이 가장 단순한 축에 속하는 평균회귀형 신호(과매수/과매도 되돌림). 이중 확인(재돌파) 조건이 있어 순수 크로스보다 휩쏘가 줄 것으로 기대.
- 의심점: 검색 결과 자체가 "강한 추세에서는 스토캐스틱이 극단에 오래 머물며 역행 신호가 반복 실패할 수 있다"고 명시적으로 경고 — 추세장 필터(1h EMA200)만으로 충분히 걸러지는지 백테스트 필요. RSI2/RSI 계열 기존 다수 전략(rsi2-mean-reversion 등)과 "과매도 반등" 컨셉이 유사할 수 있어 중복 신호 여부 확인.
- 우리 단타 슬리브와의 관계: **대체 후보**. 현재 라이브 scalp15m은 돌파형(볼린저 이탈)인데 이 전략은 평균회귀형이라 국면 보완 가능성(추세장엔 돌파, 횡보장엔 스토캐스틱) — 다만 우리 봇은 단일 슬리브 100%라 병행 도입 시 레짐 스위칭 로직 필요.
