# [스윙] 스테이블코인 공급비율(SSR) RSI 극단 역추세 (BTC)

- **출처**: 개념 원류 — CryptoQuant User Guide, "Stablecoin Supply Ratio (SSR)" —
  https://userguide.cryptoquant.com/cryptoquant-metrics/stablecoin/stablecoin-supply-ratio (SSR 정의: BTC
  시가총액 ÷ 스테이블코인 합산 시가총액, 매수여력 프록시). 구체적 시그널 사례: OneSafe Blog, "Bullish
  Breakthrough: Stablecoin Supply Ratio Plummets to 21" — https://www.onesafe.io/blog/stablecoin-supply-ratio-plummets-21-bitcoin
  (**WebSearch 요약으로 확인, WebFetch 직접 재확인은 시도했으나 SSR 계산 세부는 페이지에 미기재** — "SSR RSI가
  21까지 하락하는 구간이 역사적으로 강세장 직전 국면과 겹쳤다", "SSR 자체가 구조적 저점 약 9.6 부근에서 반복적으로
  유동성 주도 변곡점을 형성했다"는 서술은 검색 결과 인용문으로만 확인, **원문 페이지 직접 접근으로 표·수치를
  재검증하지 못함** — 정량 주장은 신뢰도 낮음으로 표기.
- **참여지표**: - (온체인 지표 블로그, SNS 참여지표 미집계). SSR은 CryptoQuant·Glassnode 등 온체인 데이터
  업체가 표준 대시보드 지표로 제공할 만큼 크립토 분석 커뮤니티에서 널리 쓰이는 매크로 지표.
- **백테스트 근거**: **없음(2차 서술 인용, 원문 정량 검정 미확인)** — "SSR RSI 21", "SSR 9.6" 등은 특정 시점의
  사례적 관찰이며 표본·통계적 유의성 검정이 제시되지 않음. **반드시 자체 장기 백테스트로 임계값·선행성 검증
  필요**, 원문 수치를 신뢰 근거로 인용하지 않음.
- **타임프레임**: 1d (SSR·RSI 산출 및 시그널 모두 일봉 기준 — 매크로/온체인 성격상 저빈도 신호).
- **시장/대상**: BTC 무기한 단일자산(SSR은 BTC 시가총액 기반 지표라 BTC 전용, 알트 확장은 별도 검증 필요).

## 핵심 아이디어
SSR은 "BTC 시가총액 대비 스테이블코인(잠재 매수여력) 규모"를 나타낸다. **SSR이 낮을수록/하락할수록** 스테이블코인
여력이 BTC 시총 대비 커진 것이므로 잠재 매수세가 강하다(강세 신호)는 논리다. 원 RSI 오실레이터를 가격이 아니라
**SSR 시계열 자체에 적용**해, SSR이 통계적으로 "과매도"(즉 SSR이 급격히 낮아진) 국면을 매수 타이밍으로 삼는다.

## 진입 규칙
- **SSR 산출**: `SSR = BTC_market_cap / (USDT_market_cap + USDC_market_cap)` (상위 2대 스테이블코인 합산 —
  CoinGecko `/coins/markets` 또는 `/global` API의 market_cap 필드로 산출, 필요시 DAI·FDUSD 등 추가 가능).
- **SSR_RSI**: SSR 일별 값에 RSI(14) 적용(일반 가격 RSI와 동일 공식, 입력만 SSR로 대체).
- **롱**: `SSR_RSI ≤ 25`(범위 20~30, "SSR 과매도" = SSR이 급락해 매수여력이 급증한 국면) 도달 후 **25선을 상향
  돌파**하는 날(바닥 확인 크로스)의 다음 봉 시가에 진입. 확인 필터: BTC 종가가 50일 SMA 위 또는 위로 근접
  회복 중(예: 50일 SMA 대비 -5% 이내).
- **숏**: `SSR_RSI ≥ 75`(범위 70~80) 도달 후 75선을 하향 돌파(SSR 과매수 = 매수여력 고갈)하는 날 진입, BTC
  종가가 50일 SMA 아래일 때만.

## 청산 규칙
- **시간 청산**: 진입 후 **8주(56일)**(범위 4~12주, 28~84일) 경과 시 목표 미도달이어도 강제 청산 — 매크로
  신호 특성상 보유기간이 김.
- **손절**: 진입가 대비 **-12%**(범위 -8%~-18%).
- **트레일링**: 진입 후 신고가(롱)/신저가(숏) 대비 **-20%** 트레일링 스탑으로 시간 청산보다 먼저 이익 보호.
- **조기 청산**: 롱 포지션 보유 중 SSR_RSI가 반대 극단(≥75)에 도달하면 매수여력 소진으로 판단해 즉시 청산
  (숏은 대칭 — SSR_RSI≤25 도달 시 청산).

## 파라미터
- ssr_stablecoins=[USDT, USDC] (확장 시 DAI, FDUSD 등 추가)
- ssr_rsi_period=14 (일봉)
- long_entry_threshold=25 (범위 20~30)
- short_entry_threshold=75 (범위 70~80)
- sma_trend_filter=50일
- hold_max=56일 (범위 28~84)
- stop_loss_pct=12% (범위 8~18%)
- trailing_pct=20%

## 코딩 난이도 / 데이터 요구
- 필요한 지표: RSI(14, SSR 시계열 입력) — 계산 자체는 표준.
- **⚠️ 신규 데이터 소스 필요**: 바이낸스 REST만으로는 불가. BTC 시가총액·USDT/USDC 시가총액을 CoinGecko API로
  받아야 함(`/coins/markets?ids=bitcoin,tether,usd-coin` 등) — CoinGecko는 이미 우리 유니버스·24h거래대금 산정에
  쓰이는 소스라 신규 커넥터 부담은 크지 않으나, **시가총액 필드는 현재 우리가 쓰는 파생 API(`derivatives/
  exchanges/binance_futures`)와 다른 엔드포인트**라 별도 연동 필요.
- 주의: 오더북·틱데이터 불필요. 일봉 단위라 API 호출량 매우 적음. CoinGecko 무료 티어 레이트리밋 고려.

## 스카우트 메모
- **강점**: 온체인/매크로 유동성 지표로 크립토 커뮤니티에 널리 알려진 개념(가격 자체가 아닌 "잠재 매수여력"을
  프록시하는 독립적 정보원)이라, 우리가 이미 보유한 가격/거래량/펀딩 기반 지표들과 상관이 낮을 가능성 —
  포트폴리오 분산 관점에서 검증 가치 있음.
- **의심점**: (1) 원문 인용이 사례적 관찰 수준(정량 검정 없음)이라 신뢰도가 다른 후보(OU 모멘텀 연장,
  CUSUM)보다 낮음. (2) 스테이블코인 총발행량은 최근 수년간 구조적으로 계속 증가해왔고(특히 2024~2026 규제
  명확화 이후), SSR이 장기 하락 추세를 가질 수 있어 **RSI 임계값이 시대에 따라 의미가 달라질 위험**(정상성
  문제) — 롤링 z-score나 퍼센타일 기반 임계값으로 대체 검토 필요할 수 있음. (3) BTC 단일자산 전용이라
  포트폴리오 슬리브로 확장성 제한적.
- **우리 슬리브와의 관계**: `fear-greed-index-extreme-contrarian-swing.md`(설문 기반 심리지표)와 개념적으로
  유사한 "매크로 극단 역추세" 계열이지만, SSR은 **실제 온체인 자금(스테이블코인 발행량) 기반**이라 심리
  서베이보다 조작 저항성이 높다는 차별점. 신규 데이터 인프라(CoinGecko market_cap) 구축이 선행돼야 해
  백테스트 우선순위는 낮음(다른 4개 후보 검증 후 여유 있을 때 착수 권고).
