# 펀딩비율 극단 컨트래리언 페이드 (퍼프 센티먼트)

- **출처**: https://www.altrady.com/blog/crypto-trading-strategies/crypto-funding-rates-explained / https://zipmex.com/blog/how-to-analyze-funding-rates-in-crypto/ / https://www.sciencedirect.com/science/article/pii/S2096720925000818 (펀딩 아비트라지 리스크·수익 실증)
- **참여지표**: - (교육/리서치)
- **백테스트 근거**: 없음(정성적/일화). 통설·사례: 8h 펀딩 **> +0.1%** = 롱 과열(컨트래리언 숏 후보), 펀딩이 양→음 전환 = 센티먼트 반전 시그널. 2022-11 FTX 붕괴 시 극단 음수 펀딩 저점 매수가 600%+ 포착(일화). 델타뉴트럴 펀딩차익은 연 15~25%지만 이건 **방향성 컨트래리언**이라 별개 — 실측 필요.
- **타임프레임**: 8h 펀딩 이벤트 기준, 진입/청산은 1h~4h 캔들. 저빈도(펀딩 극단은 드묾).
- **시장/대상**: BTC·ETH·(유동성 있는 알트) 무기한

## 진입 규칙
- 데이터: 바이낸스 `fapi/v1/fundingRate`(과거 8h 펀딩) + `premiumIndex`(현재/예측 펀딩).
- 숏(롱 과열 페이드): 펀딩률이 롤링 분포 극단(예: 최근 30일 상위 5% 또는 **절대 > +0.10%/8h**)에 도달 **그리고** 가격이 상단 볼린저/최근 스윙고 부근 정체 → 숏.
- 롱(숏 과열 페이드): 펀딩 < −0.10%/8h (또는 하위 5%) **그리고** 가격 하방 소진(반전캔들) → 롱.
- 확인 게이트: 추세필터(가격이 EMA200 반대편으로 폭주 중이면 페이드 금지) — 펀딩 극단만으론 진입 X.

## 청산 규칙
- 익절: 펀딩률이 중립(≈0)으로 정상화 또는 R:R 1.5~2.0 도달.
- 손절: 진입가 −2×ATR 또는 다음 펀딩에서도 극단 심화 시(엣지 무효) 청산.
- 시간 청산: 2~6개 펀딩주기(16~48h) 내 미회귀 시 청산.

## 파라미터
- funding_abs_th=0.10%/8h (범위 0.05~0.20%)
- funding_pctile=95/5 (범위 90/10~99/1) — 롤링 분위수 대안
- roll_window=30일 (범위 14~60일)
- trend_ma=EMA200 (페이드 금지 게이트)
- rr=1.8 (범위 1.5~2.5)
- max_hold=48h

## 코딩 난이도 / 데이터 요구
- 필요한 지표: **펀딩률 히스토리(바이낸스 REST fundingRate/premiumIndex)** + 캔들(EMA200, ATR, 볼린저). 
- 주의: 오더북/틱/실시간청산은 불필요하나 **캔들 외 추가 REST 엔드포인트(fundingRate)** 가 필요 — 인프라에 펀딩 수집·정렬 로직 추가해야 함. 그 외 데이터 부담 낮음. (우리가 이미 OI 를 쓰므로 펀딩 수집도 유사 난이도.)

## 스카우트 메모
- 강점: **가격 외 독립 데이터(센티먼트)** → 순수 가격전략과 상관 매우 낮음, 분산 큼. 펀딩 극단은 드물어 **초저빈도** → 수수료 내성 유리. 우리가 이미 OI 를 쓰므로 "OI+펀딩" 센티먼트 게이트로 결합 여지.
- 의심점: **수치 백테스트 부재**(일화 위주) → 후순위. 펀딩 극단이 "곧 반전" 을 보장 안 함(과열이 더 과열될 수 있음) → 추세필터·손절 필수. 알트는 펀딩 왜곡·수집품질 이슈.
- 우리 단타 슬리브와의 관계: 완전 신규 축(펀딩). 단독 슬리브보다 **기존 스캘프의 컨트래리언 필터/사이징 조정**(펀딩 극단이면 추격 자제)으로 먼저 붙여보는 것도 유효.
