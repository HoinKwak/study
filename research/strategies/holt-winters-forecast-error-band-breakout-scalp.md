# [단타] Holt 지수평활 예측오차밴드 이탈 브레이크아웃 (Holt Double-Exponential-Smoothing Forecast-Error Band Breakout)

- **출처**: 자체 설계 — 데이터 근거: `data.binance.vision` 선물 klines(15m). 개념: 고정 윈도우
  단순이동평균+표준편차(볼린저)가 아니라, **Holt 이중지수평활(레벨+추세 성분을 지수가중으로 적응
  추정)의 1-스텝 예측값과 실제 종가의 오차**를 표준화해 밴드를 만든다. Holt는 SMA/EMA보다 최근 데이터에
  더 빠르게 적응(추세 성분이 있어 상승/하락장에서 밴드 중심이 가격을 더 빨리 따라감)하므로, 같은
  "밴드 이탈" 신호라도 **밴드 중심의 적응 속도가 다르면 이탈 판정 시점·빈도가 달라질 수 있다**는
  가설. Holt-Winters(원래는 계절성 포함 버전)라는 이름을 쓰지만 크립토 15m엔 뚜렷한 계절 성분을
  전제하지 않으므로 **계절성 없는 Holt 이중지수평활(Holt's linear trend method)**만 사용한다.
  **정량 근거 없음(자체 설계)** — Holt 예측오차 밴드를 크립토 스캘프에 쓴 외부 백테스트는 WebSearch로
  확인 못 함.
  ⚠️**기존 스펙과의 차별점(2026-09-07, 565개 전수에서 "holt"·"winters"·"exponential-smoothing" 키워드
  0건 확인)**: 이동평균 계열은 다수 존재(`ema-9-21-crossover`·`hull-moving-average-crossover-scalp`·
  `mcginley-dynamic-adaptive-ma-crossover-swing`·`tillson-t3-moving-average-crossover-swing`·`kama-atr-
  adaptive-trend-swing`·`frama-fractal-adaptive-ma-trend-swing` 등)하나 전부 **적응형 이동평균의 크로스
  오버(방향 신호)**를 쓴다. 본 스펙은 이동평균을 방향 신호가 아니라 **예측 모델(1-스텝 예측)로 쓰고
  그 예측오차의 표준화된 크기를 밴드 폭으로 사용**한다는 점에서 다르다 — 즉 "어떤 이동평균을 쓰는가"가
  아니라 "밴드를 이동평균+고정 표준편차가 아니라 예측오차 분산으로 정의하는가"가 핵심 차이. 다만
  구조적으로 여전히 "레벨 회귀선 + 이탈 임계값"이라는 큰 틀은 볼린저·켈트너 계열과 같아서, 결과가
  또 하나의 밴드 지표에 그칠 위험은 최우선 의심점으로 정직히 남긴다.
- **참여지표**: - (자체 설계)
- **백테스트 근거**: 없음(자체 설계, 정직히 표기). 채택 전 자체 백테스트 필수.
- **타임프레임**: 15m 신호 / 1h 확인 (스캘프)
- **시장/대상**: BTC·ETH·BNB·SOL·XRP·DOGE·ADA 무기한

## 진입 규칙
- **Holt 적합**: 레벨 `l_t = α*close_t + (1-α)*(l_{t-1}+b_{t-1})`, 추세 `b_t = β*(l_t-l_{t-1}) + (1-β)*b_{t-1}`,
  `α=0.3`·`β=0.1`(고정, 최적화 없이 표준값 사용 — 과최적화 방지). 1-스텝 예측 `f_t = l_{t-1}+b_{t-1}`.
  예측오차 `e_t = close_t - f_t`. `e_std = stdev(e, window=60)`(15m, 15시간).
- **롱**: 종가가 `f_t + e_std*2.0`을 상향 이탈 **AND** 이탈 캔들 거래량 z(20봉) `>=1.2` **AND** 1h
  확인캔들 종가가 1h Holt 예측선(별도 1h 계열로 동일 방식 재계산) 위.
- **숏**: 종가가 `f_t - e_std*2.0` 하향 이탈, 대칭 조건.
- 밴드 재진입(mean-reversion) 모드는 별도로 다루지 않는다 — 본 스펙은 브레이크아웃(추세추종) 단일
  가설만 사전 등록한다(혼합 방지).

## 청산 규칙
- 익절: ATR(14,15m)×2.0 트레일링(신고가/신저가 경신 시 갱신).
- 손절: 진입가 대비 ATR(14,15m)×1.3, 또는 종가가 다시 `f_t` (예측 중심선)를 재돌파하면 즉시 청산
  (돌파 실패=가설 무효화) 중 먼저 도달하는 쪽.
- 시간 청산: 12봉(3시간) 내 미도달 시 시장가 청산.

## 파라미터
- alpha=0.3 (범위 0.2~0.5) · beta=0.1 (범위 0.05~0.3) · e_std_window=60 (범위 30~120)
- z_entry=2.0 (범위 1.5~2.8) · vol_z_min=1.2 (범위 0.5~2.0) · atr_sl=1.3 · atr_trail_tp=2.0
- time_exit_bars=12

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 15m/1h 종가, Holt 이중지수평활(재귀식 — 벡터화 어려움, 순차 루프 또는 numba/cython
  없이 순수 파이썬 루프로 구현 시 속도 저하 가능성 있음, 종목당 전체기간 15m 봉 수 감안해 성능 확인
  필요), 거래량 z-score(20봉), ATR(14,15m).
- 주의: **재귀식 특성상 warm-up 구간(초기 수백 봉)은 레벨·추세가 안정화되지 않아 신호 제외** 필요.
  오더북·틱 불필요.

## 스카우트 메모
- **강점**: 순수 klines만으로 구현 가능하고 파라미터가 표준값(α=0.3,β=0.1)으로 고정돼 과최적화
  여지가 작다. Holt는 추세 성분이 있어 강한 단방향 구간에서 밴드 중심이 볼린저(SMA 기반)보다 가격에
  더 밀착해 붙는데, 이것이 "너무 밀착해 이탈이 거의 없거나"(과소적합) "밴드가 가격을 계속 따라가
  이탈 신호가 통상 밴드보다 늦게 나오거나"(추세추종 특성상 오히려 유리할 수도) 어느 쪽인지는 실측
  전엔 모른다 — 그래서 이 스펙의 핵심 검증은 성능 자체보다 "볼린저·켈트너 대비 신호 시점·빈도가
  실제로 다른가"이다.
- **최우선 의심점**: ①**핵심 우려 — 결국 또 하나의 이동평균 밴드에 불과할 위험**. 백테스트 착수 시
  같은 엔진에서 **볼린저(SMA20+2σ)·켈트너(EMA20+ATR×2) 게이트와 신호 시점 상관(전체구간·트리거
  시점 양쪽)**을 최우선 실측하고 |r|>0.85(신호 발생 이진변수 기준 일치율 85% 이상)면 "재포장"으로
  간주할 것 ②`α=0.3,β=0.1` 고정값이 크립토 15m 변동성 특성에 부적합할 수 있다(원래 Holt는 저빈도
  경제 시계열용으로 개발된 파라미터 관행) — 스윕에서 최소 3×3 조합 확인 ③예측오차 `e_t`의 분포가
  두꺼운 꼬리(fat-tail)라 `e_std`(표준편차)가 극단치에 민감해 밴드가 실제보다 넓어지는 구간이 있을
  위험 — 신호빈도가 예상보다 훨씬 낮아지면 이 가능성부터 점검할 것.
- **비용 감당 산술**: 예상 표본빈도 [추정] 종목당 연 100~300건(2σ 이탈이 정규가정 시 시간의 약
  4.6%, 거래량 확인·1h 컨펌 결합 시 실제 독립신호는 그 1/3~1/5 — 검증 안 된 어림값, 1차 진단 최우선
  실측). 왕복 0.14%를 ATR×1.3~2.0 구조가 감당하려면 평균 R 최소 +0.12~0.18 필요.
- **사전 폐기조건(사후 변경 금지, 표본단위 명시)**: (a) OOS n<20이면 판단불가 (b) OOS net PF(R)
  캘린더일 de-clustering **t**<1.96이면 폐기 방향 근거 (c) gross(수수료 0) PF(R)<1.05면 즉시 폐기
  (d) 볼린저·켈트너 대조군 대비 신호 이진 일치율이 85% 이상(=재포장 확정)이면 폐기 (e) 게이트없음
  (순수 돌파, 밴드 없이 N봉 신고가/신저가) 대조군 대비 부트스트랩 우위 60백분위 미만이면 부가가치
  없음으로 폐기.
- **관계**: 우리 라이브 `scalp15m`(볼린저 이탈+거래량+OI)과 트리거 메커니즘이 유사(밴드 이탈+거래량
  확인)해 **대체 후보**로 검토 가능하나, 최우선 의심점 ①이 해소돼야 의미 있는 비교가 된다.
