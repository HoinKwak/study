- **출처**: 자체 설계(구조적 가설). 2026-08-21 기존 397개 스펙을 `grep`으로 전수 확인한 결과
  `6h`(6시간) 봉이 **본문에 실제로 트레이딩 로직으로 쓰인 사례가 없음**을 확인(기존
  `12h-native-candle-range-expansion-trade-size-breakout-swing.md`가 "1m/3m/5m/15m/30m/1h/2h/4h/
  6h/8h/12h/1d/3d/1w는 기존 스펙에 최소 1건 이상 등장"이라 서술했으나, 이는 **"인터벌 표기 나열"에서의
  단순 언급**(예: 바이낸스 공식 지원 interval 목록 인용문)일 뿐 **6h·2h를 실제 봉 데이터로 써서 신호를
  만든 스펙은 없음**을 재확인 — `grep "6h 네이티브\|6시간 네이티브"` 결과 0건, `12h-native...` 파일

  경로 실물 존재 및 2026-08-15 최신 파일 200 OK로 직접 curl 확인 완료(지속 갱신 중).
  **12h 스펙과의 명확한 차별점(중요)**: `12h-native-candle-range-expansion-trade-size-breakout-
  swing.md`는 **단일 봉의 레인지 확장 자체를 트리거**로 쓰고(그 봉이 이미 큰 폭으로 움직인 것을
  추종) 확인 필드로 **평균체결규모(ATS)**를 쓴다. 본 스펙은 정반대로 **여러 봉에 걸친 레인지 압축

  필드도 ATS가 아니라 **OI(미결제약정) 확장**을 쓴다(신규 레버리지 유입 여부로 돌파의 진위 판별).
  타임프레임도 6h(00/06/12/18 UTC 경계, 펀딩 정산 시각(00/08/16)·12h 경계(00/12) 어느 것과도
  정렬되지 않는 독립적 해상도)로 다르다.
- **참여지표**: - (자체 설계, 참여지표 없음)
- **백테스트 근거**: 없음(구조적 가설 기반).
- **타임프레임**: 6h 네이티브 캔들(신호·진입 모두 6h, 별도 확인 TF 없음).
- **시장/대상**: BTC·ETH·BNB·SOL·XRP·DOGE·ADA 무기한(표준 7종목).

## 진입 규칙
- **스퀴즈 판정**: 직전 `squeeze_n`=4봉(24h) 각각의 True Range(TR)가 롤링 `tr_window`=60봉(15일)
  TR 분포의 하위 `tr_pctile`=30%ile 이하 — 4봉 **전부** 충족해야 스퀴즈 상태로 인정.
- **압축 구간 정의**: 스퀴즈 4봉 구간의 최고가(`sq_high`)·최저가(`sq_low`)(Donchian 상/하단).
- **브레이크아웃 봉**: 스퀴즈 종료 직후 봉의 종가가 `sq_high + ATR(14,6h)×breakout_mult`(상단) 또는
  `sq_low - ATR(14,6h)×breakout_mult` (하단)을 돌파해 마감.
- **OI 확장 확인**: 브레이크아웃 봉의 `sum_open_interest`(`oi_last`) % 변화가 `oi_confirm_min`=1.5%
  **이상**(방향 무관, 절대 증가 — 신규 레버리지 유입 여부만 확인. 상단 돌파든 하단 돌파든 신규
  포지션 진입이 있었는지가 핵심이지 롱/숏 방향성 OI는 구분하지 않음, 방향성 데이터는 metrics에서
  직접 얻을 수 없으므로 총량 증가로 대리).
- **롱**: 상단 브레이크아웃 **AND** OI 확장 확인 → 롱.
- **숏**: 하단 브레이크아웃 **AND** OI 확장 확인 → 숏.
- OI 확장 조건 미충족(브레이크아웃은 발생했으나 신규 레버리지 유입 없음)이면 "가짜 돌파"로 간주해
  무신호.

## 청산 규칙
- 익절: 목표가 = 진입가 ± (압축구간 레인지 높이 `sq_high - sq_low`) × `measured_move_mult`=1.5.
- 손절: 압축구간 반대쪽 경계(롱이면 `sq_low`, 숏이면 `sq_high`).
- 시간 청산: `max_hold_bars`=12봉(6h×12=3일).

## 파라미터
- squeeze_n=4봉(범위 3~6), tr_window=60봉(범위 40~90), tr_pctile=30%(범위 20~40%)
- breakout_mult=1.0(범위 0.7~1.3), oi_confirm_min=1.5%(범위 1.0~3.0%)
- measured_move_mult=1.5(범위 1.2~2.0), max_hold_bars=12(범위 8~18)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 6h 네이티브 klines(TR·ATR14), `metrics` 덤프 `sum_open_interest`(6h로 리샘플,
  `oi_last`), 롤링 percentile.
- 주의: **REST/`data.binance.vision`으로 완전 구현 가능**(6h 네이티브 klines 실존 확인, metrics는
  기존 다수 스펙에서 검증된 방식으로 6h 리샘플). `metrics` 2022년 일부 구간 0-fill 결측 이력 —
  결측 구간은 OI 확장 판정에서 제외.

## 스카우트 메모

### 사전 검증 체크리스트
- **예상 신호 빈도**: TR이 변동성 클러스터링 특성상 완전 독립이 아니므로 "4봉 연속 하위 30%ile"
  발생률은 독립가정(0.3^4≈0.8%)보다 훨씬 높을 것으로 예상 — [추정] 종목당 스퀴즈 진입 **연
  20~40회**. 이 중 OI 확장 확인까지 통과하는 것은 [추정] 종목당 **연 8~15건**, 7종목 풀링 **연
  60~100건**. 실측이 이 범위에서 크게 벗어나면(특히 OI 확장 확인 통과율이 극히 낮으면) 아래
  "전제의 내적 일관성" 문제를 우선 점검한다.
- **⚠️ 전제의 내적 일관성 사전 검토(최우선 실측 대상)**: "레인지 압축(저변동성)"과 "OI 급증(신규
  레버리지 유입)"이 상호배타적일 위험이 있다 — 통상 저변동성 구간은 거래 관심 자체가 낮아 OI도
  같이 정체되는 경우가 많을 수 있다(볼린저 스퀴즈 계열 다수 스펙에서 거래량이 압축기에 함께
  줄어드는 패턴이 자주 관찰됨). 이 경우 "스퀴즈 직후 브레이크아웃 봉에서의 OI 확장"이라는 결합조건
  자체가 극히 희소하거나, 반대로 압축기 OI가 이미 낮아 확장 판정(%변화)이 기저효과로 과다 검출될
  위험(작은 절대 OI 변화도 %로는 커 보임)도 있다 — 1차 진단에서 **압축기 평균 OI 수준과 비압축기
  평균 OI 수준을 직접 비교**하고, %변화 대신 절대 명목가치 변화도 함께 확인해 기저효과 오염 여부를
  판별한다.
- **동어반복 점검**: 본 스퀴즈-브레이크아웃 신호가 `three-day-native-candle-range-compression-
  breakout-swing.md`(3일봉 압축)·`weekly-narrow-range-nr-compression-breakout-swing.md`(주봉
  압축)·`bollinger-squeeze-breakout-daily.md`(일봉 볼린저 스퀴즈)와 신호 발생일 기준 **일 단위로
  버킷화한 겹침 비율**을 1차 진단에서 반드시 계산 — 겹침 90% 이상이면 "해상도만 다른 동일 압축
  이벤트의 재탐지"로 판정하고 결론을 해당 상위 스펙 결과에 종속시킨다. `12h-native-candle-range-
  expansion-trade-size-breakout-swing.md`(방향은 반대지만 같은 "레인지+확인필드" 족보)와도 브레이크
  아웃 시점 상관을 함께 기록.
- **종목 간 신호 상관 사전 예상**: 변동성 압축/확장 국면은 시장 전체 저변동성기(예: 연말·연초
  거래 소강)에 동시 발생하는 경향이 있어 [추정] 동시진입일 비율 15~30%(특히 BTC·ETH가 리드하고
  알트가 후행하는 패턴 예상) — de-clustering 필수.
- **정규화 게이트 논증**: `tr_pctile=30%` 자기 백분위 게이트는 정의상 30%에 근접한 발화율을 갖도록
  설계돼 있으나, "4봉 연속"이라는 결합 조건 때문에 실제 발화율은 정보(변동성 클러스터링의 실재
  여부)에 따라 크게 달라진다 — TR을 시점만 무작위 셔플한 대조군으로 "4봉 연속 스퀴즈" 발생 빈도를
  비교해, 셔플 대조군이 실제와 크게 다르면(예: 셔플 시 압축 빈도가 급감) 변동성 클러스터링이 실재
  하는 정보임을, 비슷하면 압축 정의 자체가 무정보 게이트임을 확인한다.
- **수익 인과 경로**: 저변동성 압축 구간은 시장 참여자 의견 불일치가 최소화된 상태(균형)이며, 이
  균형이 신규 레버리지 유입(OI 확장)을 동반해 깨질 때는 정보에 기반한 방향성 베팅(가짜 돌파가
  아닌 실제 포지션 구축)일 가능성이 높다 — OI 확장이 없는 브레이크아웃은 유동성 공백에 의한 노이즈
  돌파(가짜 돌파)로 걸러내는 것이 이 전략의 핵심 부가가치.
- **라이브 실행 가능성**: 6h klines는 표준 REST kline 엔드포인트로 실시간 조달 가능, OI는
  `/futures/data/openInterestHist`(30일 제한, 본 스펙 롤링윈도우 15일로 충분) 사용 가능 — 라이브
  반영에 구조적 장애 없음.
- **핵심 대조군 정의**: ① OI 확장 확인 없이 순수 레인지 브레이크아웃만으로 진입(OI 필드의 부가가치
  분리). ② 스퀴즈 조건 없이 아무 때나 20봉 Donchian 브레이크아웃+OI확장만으로 진입(압축 사전조건의
  부가가치 분리). ③ 방향반전 대조군.
- **사전 폐기 조건**: (a) 스퀴즈-OI확장 결합조건이 독립기대치의 1/20 미만으로 극히 희소하면 표본
  부족으로 판단불가 조기 종결. (b) 위 세 기존 압축 스펙과 신호일 겹침 90% 이상이면 동어반복으로
  폐기. (c) 무비용 시뮬 IS gross PF<1이면 폐기. (d) 대조군①②를 뚜렷이 못 이기면(부가가치 부재)
  폐기.
- **강점**: 기존에 실제로 쓰인 적 없는 네이티브 해상도(6h)를 다루고, 압축→확장이라는 이미 검증된
  구조(볼린저 스퀴즈류)를 OI라는 다른 확인축과 결합해 ATS 계열과 차별화했다.
- **의심점**: 저변동성-OI확장 결합조건의 내적 일관성(양립 가능성) 자체가 불확실 — 1차 진단에서
  가장 먼저 확인해야 할 리스크. 기존 압축 계열 스펙(3d·주봉·일봉 볼린저)과의 동어반복 위험도 상존.
- **우리 슬리브와의 관계**: 현재 라이브 15m 스캘프(볼린저 이탈+거래량)와 타임프레임이 크게 달라
  (6h, 보유 최대 3일) 직접 경쟁하지 않는 보완적 스윙~단타 경계 후보. 우선순위는 중간(내적일관성
  1차 진단 결과를 먼저 확인 후 본백테스트 진행 여부 판단).
