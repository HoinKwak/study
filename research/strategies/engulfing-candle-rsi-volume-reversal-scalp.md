# [단타] 장악형 캔들(Engulfing) + RSI + 거래량 확인 반전

- **출처**: https://www.altrady.com/blog/crypto-trading-strategies/bullish-engulfing-pattern (Altrady 블로그, 크립토 전용) /
  https://www.altrady.com/blog/crypto-trading-strategies/bearish-engulfing-pattern / 보조: https://xerogravity.com/blog/candlestick-pattern-cryptocurrency
- **참여지표**: - (블로그/교육 콘텐츠, 정량 조회수·추천수 미집계. 캔들패턴 자체는 트레이딩뷰·유튜브에 매우 흔히 재생산되는 대중적 셋업)
- **백테스트 근거**: **약함/원문 미확인 — 참여지표 기반으로 취급**.
  - Altrady 블로그: "지지선 부근 하락추세 후 거래량 확인 장악형 캔들 승률 65~75%(크립토 주요 페어)" — **표본수·기간·방법론 전혀 명시 안 됨**, 원문 WebFetch로 확인했으나 근거 데이터 없이 서술만 존재. 신뢰도 낮음.
  - xerogravity.com: "장악형 단독 64%, 거래량+RSI 결합 시 78%(BTC 일봉 기준)" — 마케팅성 블로그, 표본·방법론 불명, "삼중천장 85%" 등 과장 수치도 병기돼 있어 **신뢰도 매우 낮음**.
  - ⚠️ 검색 중 "RSI 필터로 62%→67% 개선" 문구를 접했으나 **원문 단일 출처를 특정하지 못해 스펙에서 제외**(정량 인용 환각 방지 원칙에 따름).
  - **종합: 정량 수치는 전부 2차 블로그 발이며 원문에 표본/기간/방법론이 없어 신뢰 불가. 코딩 가능한 규칙 자체는 명확하므로 참여지표(대중적 패턴) 기반으로 채택, 백테스트로 처음부터 재검증 필수.**
- **타임프레임**: 15m~1h 신호 (원 콘텐츠는 타임프레임 불특정 → 우리 최소해상도 15m로 검증)
- **시장/대상**: BTC·ETH·주요 알트 무기한

## 진입 규칙
- 지표: 캔들 몸통(|Close-Open|), RSI(14), 거래량 MA(20).
- **불리시 장악형**: 직전봉이 음봉이고, 현재봉이 양봉이며 현재봉 몸통이 직전봉 몸통을 완전히 감쌈(현재 Open ≤ 직전 Close, 현재 Close ≥ 직전 Open).
- 롱: 불리시 장악형 + RSI(14) 진입 시점 <35(과매도권 이탈) + 장악봉 거래량 ≥ 최근 20봉 평균×1.5(거래량 확인).
- 숏: 대칭(베어리시 장악형: 직전 양봉→현재 음봉이 완전히 감쌈) + RSI(14) >65 + 거래량 배수 조건 동일.
- (선택) 근접 지지/저항(최근 20봉 스윙 고저) 부근에서 발생한 경우만 채택 — 무작위 발생 필터.

## 청산 규칙
- 익절: R:R 최소 1:2(리스크=진입가-손절가). 1차 목표 도달 시 50% 분할청산 후 나머지는 ATR 트레일링(×1.5).
- 손절: 장악봉의 반대 극값(롱=장악봉 저가, 숏=장악봉 고가) 바로 아래/위.
- 시간 청산: 신호 후 N봉(예 10봉, 15m 기준 2.5시간) 내 R:R 1:1 미도달 시 청산(모멘텀 소멸 컷).

## 파라미터
- rsi_period=14, rsi_long_th=35 (범위 25~40), rsi_short_th=65 (범위 60~75)
- vol_ma=20, vol_mult=1.5 (범위 1.2~2.0)
- rr_target=2.0 (범위 1.5~3.0), partial_pct=50%
- time_stop_bars=10 (범위 6~20)
- sr_lookback=20 (선택, 근접 지지/저항 필터용)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: OHLC(장악형 판정), RSI(14), 거래량 MA(20), ATR(트레일링용). **전부 바이낸스 REST 캔들로 충족.**
- 난이도: 낮음. 순수 캔들 패턴 매칭(2봉 비교)이라 룩어헤드 버그만 주의(신호봉 종가 확정 후 다음 봉 시가 진입).
- 주의: 오더북/틱/실시간 데이터 불필요.

## 스카우트 메모
- 강점: 규칙이 극히 단순(2봉 몸통 비교 + RSI + 거래량)해 구현·백테스트가 빠름. "지지/저항 근접" 필터를 켜면 저빈도화되어 수수료 부담을 줄일 여지 있음.
- 의심점: **정량 근거가 전부 신뢰도 낮은 블로그 발**이라 실제 엣지는 미지수. 캔들패턴 계열(마루보즈·쓰리라인스트라이크)이 이미 FAIL로 확인된 전례(`marubozu-momentum-breakout-scalp`, `three-line-strike-candlestick-reversal-scalp`는 아직 미검증이나 유사 계열 다수가 이 목록에서 FAIL) → **캔들패턴 단독 엣지에 회의적 접근 필요**. RSI/거래량 필터가 실제로 승률을 개선하는지 자체 백테스트로 반드시 확인.
- 우리 단타 슬리브와의 관계: scalp15m(볼린저 이탈+거래량+OI)과 트리거 메커니즘이 다름(밴드이탈 vs 2봉 패턴) → 상관 낮아 **보완** 후보. 단, 근거 신뢰도가 낮아 후순위.
