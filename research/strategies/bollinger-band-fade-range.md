# 볼린저밴드 페이드 (레인지 평균회귀, ADX 게이트)

- **출처**: https://vantixs.com/blog/bollinger-mean-reversion-crypto-bot (Vantixs, 수수료 반영 크립토 백테스트) / 보강: https://quant-signals.com/bollinger-bands-trading-strategy/
- **참여지표**: - (백테스트 기반 블로그)
- **백테스트 근거**: **BTC/USDT 4H, 2023-01~2025-12, 수수료 taker 0.075% + 슬리피지 0.05% 반영.** 전체 필터셋 적용 시 **승률 68.9%, PF 1.78, 총수익 +38.6%, MaxDD −8.3%, 74 트레이드.** 레짐별: 레인지(ADX<15) PF 1.62·승률 74.2% / 추세(ADX>25) PF −0.74(필터로 제외). ETHUSD 별도 테스트 PF 1.59. **핵심: 3년에 74트레이드 = 초저빈도 → 수수료 내성 구조적으로 유리.**
- **타임프레임**: 4h 신호(원전, 가장 견고) / 1h 도 가능하나 빈도↑·엣지 희석 주의.
- **시장/대상**: BTC·ETH 무기한

## 진입 규칙 (모두 참이어야 진입)
- 롱: (1) 종가 < 하단 볼린저밴드 **그리고** (2) RSI(14) < 30 **그리고** (3) ATR비율(현ATR/ATR20평균) < 1.5 **그리고** (4) ADX(14) < 25 (강추세 없음) **그리고** (5) 밴드폭(Bandwidth) > 4%.
- 숏: 종가 > 상단밴드 + RSI(14) > 70 + ATR비율 < 1.5 + ADX < 25 + 밴드폭 > 4%.

## 청산 규칙
- 익절: 가격이 중심선(SMA20) 도달 시 청산 (밴드 → 평균 회귀).
- 손절: 진입가 −2×ATR(14) (롱) / +2×ATR (숏).
- 시간 청산: 20봉(4h 기준 80시간) 초과 시 강제 청산.
- 계정 하드리밋: 트레이드당 −2% 손실.

## 파라미터
- bb_len=20, bb_std=2.0 (고정)
- rsi_len=14, rsi_long=30, rsi_short=70 (범위 25~35 / 65~75)
- adx_max=25 (범위 20~25) — **레인지 전용 게이트**
- atr_ratio_max=1.5 (범위 1.3~2.0) — 변동성 폭발 시 진입 금지
- bandwidth_min=4% (범위 3~6%)
- time_stop=20봉 (범위 12~30)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 볼린저(20,2), RSI(14), ATR(14) 및 ATR20평균, ADX(14), Bandwidth. 전부 캔들로 계산.
- 주의: **바이낸스 REST 캔들로 100% 충족.** 오더북/틱 불필요. 우리 코드에 이미 볼린저·ADX·ATR 존재 → 재사용 가능.

## 스카우트 메모
- 강점: **수수료·슬리피지를 명시적으로 넣은 크립토 퍼프 백테스트**(우리 라운드1 기준 최상급 근거). 74트레이드/3년 = EMA크로스(559트레이드, 수수료가 자본의 55%)의 정반대 → 페이드 계열 저빈도라 수수료 생존 현실성 높음. ADX·ATR·밴드폭 3중 레짐필터가 "추세장 칼받기" 를 차단.
- 의심점: 4h 엣지를 1h로 낮추면 유지될지 미검증. 밴드폭>4% 조건이 크립토 저변동 구간을 거를 수 있음(진입 매우 드묾 → 표본 부족 위험). 단일 소스 → 재현 필수.
- 우리 단타 슬리브와의 관계: **명확히 새로움.** 우리 스캘프는 볼린저 "스퀴즈 돌파"(모멘텀). 이건 볼린저 "밴드 페이드"(역추세·레인지). ADX 게이트가 정반대(우리는 ≥25 요구, 이건 <25). 서로 다른 레짐을 커버 → 포트폴리오 분산 큼.
