# [단타] Ultimate Oscillator 임계값 돌파 (조정 파라미터)

- **출처**: Cryptohopper 블로그(백테스트 포함) — https://www.cryptohopper.com/blog/crypto-trading-101-trading-op-with-the-ultimate-oscillator-is-op-8956
  (WebFetch로 원문 직접 확인). 지표 자체: Larry Williams, 1976 고안 Ultimate Oscillator(3개 기간 가중
  평균 오실레이터).
- **참여지표**: 원문 자체는 조회수 비공개(크립토호퍼 사내 블로그). 다만 Ultimate Oscillator는
  TradingView 기본 내장 지표로 크립토 커뮤니티에 광범위하게 사용됨. 백테스트 근거가 명확해 참여지표
  대신 정량 근거로 채택.
- **백테스트 근거(원문 확인, WebFetch)**: OP(Optimism) 코인 대상, 바이낸스 전체 가용 기간, 차트 주기
  **20분**, UO 기간(1, 24, 30) / 과매도 35 / 과매수 60 으로 조정한 설정에서 **수익률 608%**
  (단순 보유 90% 대비 초과), **최대낙폭 39%**(단순 보유 80% 대비 축소), 거래당 수수료 0.1% 반영,
  전액 계좌 사용, 슬리피지 미반영. **단일 종목(OP) 단일 구간 백테스트**이므로 과최적화 위험 높음
  — 다른 종목·구간 재현 여부 원문 미확인.
- **타임프레임**: 20분 원문 권장(바이낸스 비네이티브 → 15m 또는 30m 근사 필요) / 상위TF 확인 없음
- **시장/대상**: 알트코인 무기한(원문은 OP 단일종목, 유동성 상위 알트 일반화는 검증 안 됨)

## 진입 규칙
- Ultimate Oscillator 산식: `BP = close - min(low, prevClose)`, `TR = max(high, prevClose) - min(low, prevClose)`,
  `Avg1 = sum(BP,7)/sum(TR,7)`, `Avg2 = sum(BP,14)/sum(TR,14)`, `Avg3 = sum(BP,28)/sum(TR,28)`,
  `UO = 100 × (4×Avg1 + 2×Avg2 + Avg3) / 7` (표준 7/14/28 기간). 크립토호퍼 조정판은 기간을
  **(1, 24, 30)**으로 변경(원문 확인, 표준 7/14/28과 다름 — 사실상 다른 지표에 가까움, 재현 시 주의).
- 롱: UO가 과매도 임계값(기본 30, 크립토호퍼 조정 35) 아래로 떨어졌다가 다시 그 위로 상향 돌파.
- 숏: UO가 과매수 임계값(기본 70, 크립토호퍼 조정 60) 위로 올랐다가 다시 그 아래로 하향 돌파.
- (확장 옵션, 원문 언급) 강세/약세 다이버전스 — 가격 저점 하락 + UO 저점 상승 시 롱 신뢰도 강화.
  단, 다이버전스 자동 탐지 로직은 원문에 코드로 제시되지 않음 — 자체 구현 필요.

## 청산 규칙
- 익절: 반대 임계값 도달(과매수 60/70 상향 돌파 시 롱 청산) 또는 고정 R 배수(원문 미제시,
  자체 보강 필요: 예 1.5R).
- 손절: 진입 직전 스윙 저점/고점 또는 ATR 기반(원문 미제시, 자체 보강: `1.0×ATR(14)`).
- 시간/조건 청산: 없음(원문 미제시).

## 파라미터
- uo_p1=7, uo_p2=14, uo_p3=28 (표준) 또는 uo_p1=1, uo_p2=24, uo_p3=30 (원문 크립토호퍼 조정,
  범위 재현 필요 — 표준 대비 이례적 조합이라 과최적화 의심)
- oversold=30 (원문 조정 35), overbought=70 (원문 조정 60)
- fee_rt=0.1%/편도(원문 가정)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: OHLC만으로 계산 가능(BP/TR 누적합) — 구현 난이도 낮음.
- 주의: 원문의 20분봉은 바이낸스 비네이티브(15m/30m 근사 또는 5m 리샘플 필요). 단일 종목(OP)
  단일 기간 백테스트라 일반화 검증 안 됨 — 우리 백테스트에서 표준 파라미터(7/14/28, 30/70)와
  원문 조정 파라미터(1/24/30, 35/60) 둘 다 스윕 권장.

## 스카우트 메모
- 강점: 원문 백테스트가 WebFetch로 직접 검증됐고 규칙이 완전히 코딩 가능. OHLC만 필요해 데이터
  인프라 요구가 가장 낮은 후보 중 하나. 기존 보유 오실레이터(CCI/MFI/Williams%R/Fisher/스토캐스틱RSI)와
  달리 UO는 3개 기간을 가중합산하는 구조라 신규 계통.
- 의심점: 크립토호퍼 조정 파라미터(1/24/30)는 표준(7/14/28)과 근본적으로 다른 지표에 가까워
  원저자가 왜 이 숫자를 택했는지 근거 불명 — 전형적 과최적화 신호. 단일 종목·단일 기간·표본외
  검증 없음. 손절/익절 규칙이 원문에 없어 자체 보강 필요(현재 상태로는 미완성 스펙).
- 우리 슬리브와의 관계: 보완(신규 오실레이터 계통). 백테스트 시 표준 파라미터부터 검증 권장,
  조정 파라미터는 과최적화 여부 확인용 대조군으로만 사용.
