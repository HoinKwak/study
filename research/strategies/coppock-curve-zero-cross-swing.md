  횟수는 원문에 명시 없음(수익률 비교만 제시). **크립토 대상 백테스트는 원문에 없음 — 정량 수치는

  1d/4h 대역과 부합.
- **시장/대상**: 원문은 AAPL 단일종목. 크립토 적용은 BTC·ETH 등 시총상위 대상 [추정] 확장.

## 진입 규칙
- Coppock Curve 산식(원문 확인): `Coppock = WMA(ROC(close,14) + ROC(close,11), 10)`
  (WMA=가중이동평균, ROC=변화율%, 기간 14/11/10 원문 명시 그대로)
- 롱(제로라인 상향 크로스): **직전 4개 봉의 Coppock 값이 모두 0 이하**이고 **현재 봉이 0 초과로
  전환**될 때 진입(원문 규칙 그대로: "past four readings are below the zero line and the current
  reading is above the zero line").
- 숏은 원문에 별도 언급 없음(원 지표는 매수 타이밍용으로 설계) — 대칭 적용 시: 직전 4개 봉이
  모두 0 이상이고 현재 봉이 0 미만 전환 시 숏(원문 매도규칙과 동일 구조를 대칭 적용, [추정]).

## 청산 규칙
- 익절/청산: 원문 매도 규칙 그대로 — **직전 4개 봉의 Coppock 값이 모두 0 이상**이고 **현재 봉이
  0 미만으로 전환**될 때 반대 포지션 청산(원문 명시).
- 손절: 원문 미제시 — 자체 보강 필요(예: 2.0×ATR(14, 1d)).
- 시간/조건 청산: 없음(원문 미제시). 저빈도 장기 모멘텀 지표라 보유기간이 길 수 있음(주 단위~월 단위).

## 파라미터
- roc_long=14, roc_short=11, wma_len=10 (원문 명시 그대로, 고정 권장)
- confirm_bars=4 (제로크로스 확인 봉 수, 원문 명시)
- signal_tf=1d (범위 4h~1d)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: ROC(변화율) 2개 + WMA — OHLCV 종가만으로 계산 가능, 구현 난이도 낮음.
- 주의: 오더북/틱 불필요. 다만 지표 특성상 신호 빈도가 매우 낮음(원문도 "월봉이 최적, 일봉/주봉
  이하는 신뢰도 하락" 경고) — 크립토 4h~1d 적용 시 신호 빈도·유효성 재검증 필수.

## 스카우트 메모
- 강점: 산식이 단순하고(ROC+WMA) 원문 백테스트가 WebFetch로 직접 확인됨. 제로크로스+4봉 확인
  구조라 휩쏘 방지 설계가 명확. 기존 보유 오실레이터(TRIX·AO·CCI 등)와 달리 두 ROC 기간의
  가중합산이라는 독자 구조.
- 의심점: **정량 백테스트가 주식(AAPL) 대상**이라 크립토 재현 여부 미검증(정직히 표기). 승률/PF/
  거래횟수 등 세부 통계가 원문에 없어 "수익률 비교"만으로 판단 — 표본 부족. 원래 월봉용 지표를
  일봉/4h로 축소 적용 시 신호 왜곡 가능성 원문도 인정.
- 우리 슬리브와의 관계: 보완(신규 저빈도 장기 모멘텀 계통, 기존 스윙 전략들의 회전율보다도 낮을
  가능성 — 수수료 부담 최소화 측면에서 매력적이나 표본 수 부족으로 통계적 유의성 확보가 관건).
  주식 백테스트만 있어 백테스트 우선순위는 중간~후순위 권장.
