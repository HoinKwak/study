# [단타] OBV(온밸런스거래량) 이동평균 브레이크아웃 + 다이버전스 확인 스캘핑

- **출처**: https://forextester.com/blog/on-balance-volume-obv/ (FTO, OBV 트렌드라인·이동평균·다이버전스 규칙 정리) /
  https://www.quantifiedstrategies.com/on-balance-volume-strategy/ (QuantifiedStrategies.com, OBV 백테스트 수치 — 접근 시 봇 검증 페이지로 막혀 원문 수치는 2차 인용) /
  https://www.coingecko.com/learn/on-balance-volume-obv-indicator-crypto (CoinGecko Learn, 크립토 맥락 OBV 가이드)
- **참여지표**: 없음(정량 참여지표 미집계) — OBV는 Joseph Granville 고안(1963)의 고전 거래량 지표로 TradingView 기본 내장, 업계 표준 재현성으로 스크리닝.
- **백테스트 근거**: **혼재(약함)**. QuantifiedStrategies.com 2차 인용에 따르면 ① "OBV+오토코릴레이션(ACI)" 결합 전략은 365일 표본에서 신호 9회·승률 55.56%·수익 $698.3(표본이 매우 작아 데이터스누핑 위험 명시적으로 지적됨), ② "OBV-SMA 크로스" 단순 전략은 23회 트레이드에서 승률 26.09%(손실), 파라미터 조정 후(SMA·기간 변경) 승률 31.43%로 소폭 개선되었으나 여전히 저조. **결론: 단순 OBV 전략 자체의 엣지는 약하다는 것이 3자 백테스트 결과 — 확인용 보조지표로만 채택 권고, 단독 전략으로는 비권장**.
- **타임프레임**: 5m 신호 / 15m 확인
- **시장/대상**: BTC·ETH·거래대금 상위 알트 무기한(거래량 데이터가 유의미한 유동성 필요)

## 진입 규칙
- OBV 정의: `OBV_t = OBV_{t-1} + volume_t`(종가>전봉 종가 시 +) `- volume_t`(종가<전봉 종가 시 -) `+0`(동일 시).
- OBV 이동평균: `OBV_MA = SMA(OBV, obv_ma_period)`(원문 예시 20 WMA/SMA).
- **롱**: ① OBV가 OBV_MA를 상향 돌파(골든크로스) **AND** ② OBV·OBV_MA 둘 다 상승 기울기(slope>0, 최근 slope_bars=3봉 연속) **AND** ③ 가격이 최근 breakout_lookback(예 20봉) 스윙 고점을 종가 기준 돌파(거래량 확인 브레이크아웃).
- **숏**: ① OBV가 OBV_MA를 하향 돌파(데드크로스) **AND** ② 둘 다 하락 기울기 **AND** ③ 가격이 최근 20봉 스윙 저점을 종가 기준 하향 돌파.
- **다이버전스 보조 신호(옵션, 반전형)**: 가격이 신저점을 형성했는데 OBV는 더 높은 저점(불리시 다이버전스) → 역추세 롱 후보로 별도 관리(승률이 더 낮을 수 있어 브레이크아웃형과 분리 검증 권장).

## 청산 규칙
- **익절**: 목표 R배수(rr_ratio, 예 1.5R). 또는 OBV가 다시 OBV_MA를 역교차하면 조기 익절.
- **손절**: 돌파 신호봉의 반대편 극값(롱은 신호봉 저가, 숏은 신호봉 고가) 바로 너머.
- **시간/조건 청산**: 진입 후 invalidate_bars(예 8봉=5m×8=40분) 내 목표 미도달 + OBV 기울기가 평탄화(slope≈0)되면 조기 청산.

## 파라미터
- obv_ma_period=20 (범위 14~30)
- slope_bars=3 (범위 2~5, 연속 기울기 확인 봉수)
- breakout_lookback=20 (범위 15~30)
- rr_ratio=1.5 (범위 1.2~2.0)
- max_hold_bars=8 (5m 기준, 범위 6~16)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: OBV(종가·거래량만으로 계산), OBV의 SMA, 스윙 고/저.
- 주의: 완전히 표준 klines(종가+거래량)만으로 구현 가능 — 데이터 요구 최소. 다만 3자 백테스트 근거 자체가 저조한 승률(26~31%)을 보고하고 있어, **단순 크로스오버 단독으로는 채택 우선순위가 낮음**. 가격 브레이크아웃 확인(③ 조건)을 필수로 강제해 원문의 "단순 크로스"보다 신호 질을 높이는 방향으로 재설계했음 — 이 강화 버전은 우리 자체 검증 없이는 유효성 미지수.

## 스카우트 메모
- **강점**: 데이터·구현 난이도가 매우 낮음(캔들만으로 완결). 거래량 기반 브레이크아웃 확인 지표로서 기존 볼린저+거래량 스캘핑 전략의 **보조 필터**로 결합 가치가 있음(단독 전략보다 필터 역할이 유망).
- **의심점**: 3자 백테스트(QuantifiedStrategies 2차 인용)에서 단순 OBV-SMA 전략의 승률이 26~31%로 저조하게 나타남 — **이번 라운드 후보 중 단독 엣지 신뢰도가 가장 낮음**. "OBV+ACI" 조합의 55.56% 승률도 표본이 9회에 불과해 통계적 유의성이 낮다고 원 자료 자체가 경고. 단독 전략으로 채택하지 말고, 기존 프로덕션 단타(볼린저 돌파+거래량 급증)의 **거래량 급증 판정을 OBV 방향성으로 교차검증하는 보조 필터**로 활용을 권고.
- **우리 슬리브와의 관계**: 기존 `cvd-taker-volume-divergence-scalp.md`(테이커 매수/매도 델타 다이버전스)와 "거래량 기반 다이버전스"라는 개념이 겹침(OBV는 총거래량 방향성 누적, CVD는 매수/매도 방향 세분화 누적) — CVD가 더 정교한 데이터(taker_buy_volume)를 쓰므로 **OBV는 CVD의 하위호환에 가까움**. 신규 채택보다는 기존 CVD 전략의 검증 우선순위를 높이는 편이 합리적.
