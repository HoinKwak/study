# [단타] 세션별 수익률 분해(Asian/Europe/US) 지속 드리프트 모멘텀

- **출처**: 방법론 아이디어 원천 — 주식시장의 "오버나잇 vs 인트라데이 수익률 분해" 계열 연구(예: Cliff Asness/AQR, Lou-Polk-Skouras "A Tug of War" 류)의 구조를 UTC 기준 3개 크립토 세션(Asian 00-08·Europe 08-16·US 16-24)에 이식. **이 정확한 규칙·파라미터는 스카우트 자체 설계 — 외부에 이 정확한 크립토 백테스트는 없음, 지어내지 않음.** 기존 보유 `asian-session-range-london-open-breakout-scalp.md`(레인지 브레이크아웃)·`london-ny-overlap-volume-surge-trend-continuation-scalp.md`(거래량서지)·`killzone-session-timing.md`(ICT 타이밍)와는 **"세션 자체의 누적 수익률 방향성이 통계적으로 지속되는가"를 롤링 t-검정으로 필터링**한다는 점에서 메커니즘이 다름(레인지·거래량이 아닌 수익률 자체의 시계열 유의성).
- **참여지표**: - (자체 설계)
- **백테스트 근거**: **없음(자체 설계, 정직히 표기)**. 채택 전 자체 백테스트 필수.
- **타임프레임**: 1h/4h 원본 데이터로 세션 경계(00/08/16 UTC) 수익률 계산 / 진입은 세션 시작 시점.
- **시장/대상**: BTC·ETH·BNB·SOL·XRP·DOGE·ADA 무기한.

## 진입 규칙
- 데이터: 1h klines 종가. 세션 정의(UTC): Asian=[00:00,08:00), Europe=[08:00,16:00), US=[16:00,24:00).
- 일별 세션수익률: `r_asian(d) = close(08:00,d)/close(00:00,d) - 1`, `r_euro(d) = close(16:00,d)/close(08:00,d) - 1`, `r_us(d) = close(00:00,d+1)/close(16:00,d) - 1`.
- 각 세션별 **트레일링 20일** 평균·표준편차로 t-stat 계산: `t_session = mean(r_session, 20d) / (std(r_session,20d)/sqrt(20))`.
- **세션 선택**: 매 세션 시작 직전, 3개 세션의 `|t_session|` 중 가장 큰 것을 선택. `|t_session| >= 2.0`(사전 지정 임계)이면 해당 세션에서만 거래.
- **롱**: 선택된 세션의 `t_session >= +2.0` → 해당 세션 시작 시점(00/08/16 UTC)에 롱, 세션 종료 시점 청산.
- **숏**: `t_session <= -2.0` → 숏.
- **다중비교 보정**: 3개 세션 × 7종목 = 21개 검정을 동시에 수행하므로, 최종 유의성 판단 시 Bonferroni 보정(임계 p를 21로 나눔) 적용 — 기존 보유 `btc-month-of-year-seasonality-swing.md`에서 사용한 방법론과 동일 기준.

## 청산 규칙
- 익절: 세션 종료 시점(8시간 후) 시장가/메이커 청산(고정 홀딩 — 별도 TP 없음, 세션 자체가 보유기간).
- 손절: 세션 중 |손실| >= ATR(1h,14)×2.0 시 조기 손절(파국적 역행 방지).
- 시간/조건 청산: 세션 종료 시각 도래 시 무조건 청산(익절 목표 없이 세션 경계가 곧 청산 조건).

## 파라미터
- t_window=20일 (범위 15~40), t_th=2.0 (범위 1.5~2.5)
- session_sl_atr_mult=2.0 (범위 1.5~3.0)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 1h 종가만으로 세션 수익률·롤링 평균/표준편차 계산 가능. 오더북·틱 데이터 불필요.
- 주의: **롤링 20일 창은 인접일끼리 19/20 관측치를 공유**해 `t_session` 시계열 자체가 강한 자기상관을 가짐 — 트리거 이벤트를 명목 건수 그대로 세면 표본이 부풀려짐. 반드시 **고유 세션-레짐 블록 단위로 de-clustering**해 t 재계산할 것(예: 연속 발화 구간을 1개 이벤트로 묶음).

## 스카우트 메모
- **예상 신호 빈도**: [추정, 넓은 범위로 사전 명시] `|t|>=2.0` 임계가 20일 롤링 창의 자기상관 때문에 진성 무작위보다 훨씬 자주(연속 구간으로) 발화할 것으로 예상 — 선택된 단일 세션 기준 종목당 **연 50~150건**(de-clustering 전 명목 건수는 이보다 훨씬 많을 수 있음, 최우선으로 명목:고유 비율 실측). 예상 범위를 크게 벗어나면(예: 명목 20배 이상 상회) 게이트 결함으로 간주.
- **비용 감당 산술**: 8시간 고정 홀딩, 왕복수수료 0.14%. 메이저 세션 평균 수익률 크기는 통상 0.3~0.8%대로 추정되나, **선택 편향(3개 중 최대 |t| 선택)이 포함된 사후 유의성**이라 실제 지속 엣지는 이보다 훨씬 작을 가능성 높음 — net PF가 임계에 근접하면 즉시 폐기.
- **전제의 내적 일관성**: `r_asian+r_euro+r_us = r_daily`이므로 세 세션 수익률은 **구조적으로 완전 독립이 아님**(하루 전체 추세가 강하면 세 세션 모두 같은 부호로 치우치는 경향) — **예상 페어 상관 0.2~0.4**(약~중간, 완전 동어반복은 아님)로 사전 명시. 상관이 매우 높게(>0.7) 나오면 "3개 세션 중 최대 선택"이 사실상 "일간 추세 하나"를 3번 카운트하는 것과 다르지 않음을 의심해야 함.
- **종목 간 신호 상관**: 동일 UTC 시각의 메이저 코인들은 함께 움직이므로 **예상 상관 0.5~0.8**(높음) — LOO·7종목 확장은 통계력이 아니라 착시 표본을 만들 위험이 큼(과거 BTC-금 로테이션 사례와 동일 함정). 이벤트 단위(동일 세션·동일 날짜) de-clustering 필수, 실질 독립표본 수를 반드시 별도 보고.
- **정규화 게이트 논증**: `t_session` 임계 2.0은 롤링 자기 백분위가 아니라 **통계적 유의성 검정**이므로, 진짜 무효과 하에서는 명목 발화율이 낮아야 정상(정규분포 기준 양측 5%대). 자기상관으로 인해 이보다 훨씬 자주 발화한다면, 그 초과분은 정보가 아니라 **창 중첩 아티팩트**이므로 de-clustering 후 실질 발화율을 반드시 재확인.
- **수익의 인과 경로**: [추정, 다소 취약함을 인정] 특정 시간대의 지역별 자금흐름(아시아 리테일 vs 미국 기관 등)이 통계적으로 지속되는 편향을 만든다는 가설이나, **주된 정당성은 인과 서사가 아니라 다중비교 보정을 거친 실증 검정 자체**임을 명시 — 기존 보유 요일/월별 계절성 스펙과 동일한 위상.
- **라이브 실행 가능성**: 세션 경계(00/08/16 UTC)가 기존에 이미 라이브에서 다루는 펀딩 정산 시각과 일치해 스케줄링이 단순함. 1h 데이터로 신호 계산, 세션 시작 시점 메이커 진입 시도 가능.
- **사전 폐기조건(사후 변경 금지)**: (a) Bonferroni 보정 후 21개 검정 중 유의(p<0.05/21)한 세션·종목 조합이 0건이면 즉시 FAIL (b) de-clustering 후 고유 이벤트 t가 비유의 (c) OOS net PF < 1.0 (d) 세 세션 페어 상관이 0.7 초과로 실측되어 "독립적 3세션"이라는 설계 전제가 무너지는 경우 — 결과와 무관하게 설계 결함으로 별도 기록.
- **강점**: 407개 기존 스펙에 "세션별 수익률 자체의 통계적 지속성"을 롤링 t-검정으로 게이트하는 구조는 없음(레인지·거래량서지·타이밍 계열과 메커니즘이 다름).
- **의심점**: 세션 간 구조적 비독립성, 선택편향(최대 |t| 세션 선택), 자기상관에 의한 명목 발화율 과대.
- **우리 단타 슬리브와의 관계**: 라이브 `scalp15m`과 타임프레임·신호원 모두 다름(1h 세션 vs 15m 볼린저 돌파). 기존 세션 계열 스펙(레인지·거래량서지)과는 축은 겹치나 메커니즘 다름.
