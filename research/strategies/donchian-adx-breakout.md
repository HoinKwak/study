# 돈치안 채널 브레이크아웃 + ADX/볼륨 필터

- **출처**: https://trendspider.com/learning-center/donchian-channel-trading-strategies/ (TrendSpider) / 필터 근거: https://www.altrady.com/blog/crypto-trading-strategies/donchian-channel-strategy , https://arxum.com/donchian-channel/
- **참여지표**: - (교육/백테스트 블로그)
- **백테스트 근거**: 다수 백테스트(BTC·EURUSD) — 추세장에선 설계대로 작동, 횡보장에선 빠르게 붕괴.
  - EURUSD 4H raw 승률 52% → **볼륨 확인 추가 58% → ADX>20 필터 추가 63%** (필터의 단계적 개선 근거).
  - 크립토는 추세 지속성이 커 돈치안 돌파에 적합하다는 평가(정량 수치는 자산별 상이 → 재검증 필요).

## 진입 규칙
- 채널: 상단 = 최근 N봉 최고가, 하단 = 최근 N봉 최저가, 중간선 = (상+하)/2.
- 롱: 종가가 상단 밴드(최근 N봉 신고가) 위로 마감 + ADX > 20(추세 강도) + 돌파 봉 거래량 > 직전 5~10봉 평균.
- 숏: 종가가 하단 밴드(최근 N봉 신저가) 아래로 마감 + ADX > 20 + 거래량 확인.
- (옵션 확인: 롱 시 RSI > 60.)

## 청산 규칙
- 익절: 추세 지속 시 트레일. 중간선(mid band)을 트레일링 스탑/부분청산 트리거로 사용.
- 손절: 가격이 중간선 반대로 교차 시 청산, 또는 진입 봉 반대 극단.
- 시간/조건 청산: ADX < 20 로 추세 소멸 시 청산(옵션).

## 파라미터
- donchian_period=20 (범위 10~20 인트라데이 / 50~100 스윙)
- adx_period=14, adx_min=20 (범위 18~25)
- vol_lookback=10, vol_mult=1.0 (돌파 봉 vol ≥ 평균, 범위 1.0~1.5)
- exit=mid_band_cross (범위: mid / opposite-band / ADX-fade)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 롤링 max/min(N봉), ADX(DI 기반), 거래량 평균. 모두 캔들 OHLCV.
- 주의: **바이낸스 REST 캔들+거래량으로 완전 충족.** 오더북/틱/OI/청산 불필요. ADX 구현만 약간 손이 감(±DI, ATR).

## 스카우트 메모
- 강점: 필터의 승률 개선 근거(52→58→63%)가 **정량적이고 재현 가능** — ADX·볼륨 필터를 우리 봇에 이식하기 좋음. 크립토 추세 적합성. 우리 scalp.py 의 vol 급증 로직 재사용 가능.
- 의심점: 순수 돌파는 횡보장에서 급격히 붕괴 → 레짐 필터 필수. N봉 신고가 돌파는 볼린저 돌파(scalp.py)와 '돌파' 계열로 개념이 겹칠 수 있음(단, 밴드 산출식은 완전 다름: 롤링 극값 vs σ).
- 우리 단타 슬리브와의 관계: **보완**. 특히 ADX 추세강도 필터는 우리 regime.py 를 보강하는 별도 신호로도 가치. 볼린저 돌파 슬리브에 ADX 필터만 얹는 하이브리드도 검토 가치.
