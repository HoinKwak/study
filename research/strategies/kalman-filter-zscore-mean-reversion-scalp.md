# [단타] 칼만 필터 Z-스코어 평균회귀 (Kalman Filter Trend + Z-Score Mean Reversion)

- **출처**: https://medium.com/@serdarilarslan/implementing-a-kalman-filter-based-trading-strategy-8dec764d738e (Serdar İlarslan, Medium — 파라미터·규칙·백테스트 수치 원문 확인함)
  / 보조: https://pyquantlab.medium.com/trend-following-with-kalman-filter-and-trailing-stops-a-rolling-backtest-2ecb47203611 (PyQuantLab, 유료화로 상세 규칙 미확인 — 개념 참고만)
  / https://www.quantifiedstrategies.com/kalman-filter-trading-strategy/ (봇 차단으로 원문 미확인)
- **참여지표**: - (개인 블로그, 정량 참여지표 없음)
- **백테스트 근거**: **원문 확인됨(WebFetch)**. Serdar İlarslan 글: **자산=AAPL(주식, 크립토 아님)**, Sharpe Ratio **0.6405**, 최대낙폭(MDD) **18.02%**, 승률/총수익 미기재, 표본기간 명시 안됨.
  → **⚠️ 정량 수치는 주식(AAPL) 대상이며 크립토 검증 없음.** 성과 자체도 강하지 않음(Sharpe 0.64는 평범). 채택 사유는 성과가 아니라 **우리 스택에 전무한 상태공간(state-space) 필터 기반 평균회귀 메커니즘**이라는 점.
- **타임프레임**: 원 소스는 미명시(추정 일봉). 크립토 적용 시 **15m 신호** 권장(칼만 필터는 종가만 있으면 어떤 TF든 적용 가능한 범용 스무딩 기법).
- **시장/대상**: BTC·ETH·주요 알트 무기한 (원 백테스트는 주식 — 크립토는 미검증, 자체 검증 필수)

## 진입 규칙
- **칼만 필터(1차원, Local Level Model)**: 상태전이행렬=1, 관측행렬=1, 초기상태평균=0, 초기공분산=1, 관측노이즈 R=1, 과정노이즈 Q=0.01.
  종가 시계열을 필터링해 노이즈 제거된 추세 추정치(state mean, 이하 `KF`)를 매 봉 산출(`pykalman`류 라이브러리 또는 직접 구현한 재귀 갱신식으로 계산 가능).
- **Z-스코어**: 가격과 KF 추정치의 괴리를 표준화. `Z = (Close - KF) / RollingStd(Close - KF, N)` (N=칼만 잔차의 롤링 표준편차 윈도우, 원문엔 구체 N 미기재 → 20~50봉으로 별도 튜닝 필요).
- 롱(평균회귀): `Z ≤ -3.0` (가격이 칼만 추세선 아래로 극단 이탈).
- 숏(평균회귀): `Z ≥ +3.0`.

## 청산 규칙
- 익절(롱): `Z ≥ 0.25` 도달 시 청산(트렌드선 근접 복귀).
- 익절(숏): `Z ≤ -0.5` 도달 시 청산.
- 손절: 진입가 대비 **±2%** 고정(원문 명시값). 크립토 변동성 고려 시 ATR 기반으로 대체 검증 권장(예: 1.5×ATR14).
- 시간청산: 원문 미기재 — N봉(예 20~30봉, 15m 기준 5~7.5시간) 초과 시 강제청산 안전장치 추가 권장.

## 파라미터
- kf_transition_cov(Q)=0.01 (칼만 필터 과정노이즈, 범위 0.001~0.05 — 작을수록 스무딩 강함/추세 지연↑)
- kf_observation_cov(R)=1.0 (고정)
- zscore_window=20~50봉 (원문 미기재, 튜닝 필요)
- entry_z=±3.0 / exit_z_long=0.25 / exit_z_short=-0.5 (원문 값)
- stop_pct=2% (원문 값, ATR 대체 검증 권장)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 종가 시계열만으로 칼만 필터 재귀 갱신(추가 라이브러리 없이 numpy로 직접 구현 가능 — 상태공간 1차원 재귀식은 몇 줄), 잔차의 롤링 표준편차.
- 주의: **바이낸스 REST 캔들(종가)만으로 완전 충족.** 오더북/틱 불필요. 데이터 요구는 이 리스트 중 최소 수준(종가 단일 컬럼).

## 스카우트 메모
- 강점: 우리 163개 기존 스펙 어디에도 **상태공간 모델(칼만 필터) 기반 스무딩+Z스코어**가 없음 — 완전 신규 메커니즘. 이동평균(EMA/SMA/KAMA/FRAMA 등)과 달리 매 스텝 베이지안 업데이트로 노이즈/신호를 분리해, 우리 기존 이동평균 계열 다수와 신호 상관이 낮을 가능성. 데이터 요구·구현 난이도 최저(종가만).
- 의심점: **원문 백테스트가 크립토가 아닌 AAPL(주식)**, 성과도 평범(Sharpe 0.64) — "성과가 검증된 전략"이 아니라 "메커니즘이 신선한 전략"으로 분류해야 함. Z-스코어 롤링윈도우(N)가 원문에 없어 자체 튜닝 필요(과최적화 리스크). ±3 진입 임계값은 정규분포 가정 시 매우 드문 이벤트라 15m에서는 신호 빈도가 낮을 수 있음(장점이자 단점 — 수수료 부담엔 유리).
- 우리 단타 슬리브와의 관계: 기존 볼린저 돌파(추세추종형)와 정반대 성격(평균회귀형) → **보완**. ehlers-laguerre-rsi-mean-reversion, ibs-internal-bar-strength 등 기존 평균회귀 계열과 목적은 유사하나 **필터링 방식(상태공간 vs 오실레이터)이 근본적으로 달라** 신호 상관 낮을 것으로 추정 — 백테스트로 상관 확인 권장.
