# [스윙] BTC 채굴 난이도 조정(Difficulty Retarget) 서프라이즈 — 마이너 항복/증설 레짐

- **출처**: 개념적 배경(직접 재현 대상 아님) — Hash Ribbons 지표, Charles Edwards/Capriole Investments(2019) 창안. https://capriole.com/hash-ribbons-bitcoin-bottoms/ , https://bitbo.io/news/bitcoin-hash-ribbons-end-miner-capitulation/ (**WebSearch로 확인**: 해시레이트 30일/60일 SMA 데드/골든크로스로 "마이너 항복" 국면을 정의, 2013년 이후 **14회 매수신호 중 64.29% 수익, 평균 보유 253일, 사이클 고점까지 평균 수익률 5000%+, MDD -15%**).
  **⚠️ 위 수치는 해시리본(30일/60일 SMA 교차, 신호당 평균 253일 보유) 고유의 것이며, 본 스펙은 신호 메커니즘을 다르게 설계**(아래 참조) — **원문 수치를 본 스펙의 기대 성과로 인용하지 않는다.**
  데이터 정의 근거 — https://mempool.space/api (BTC 난이도 조정 히스토리 무료 공개 API), https://api.blockchain.info/charts/difficulty (블록체인닷컴 대체 소스).
- **참여지표**: - (온체인 지표, SNS 참여지표 미집계). 해시리본 자체는 크립토 커뮤니티에서 매우 널리 인용되는 유명 지표(TradingView 공식 지표로도 배포).
- **백테스트 근거**: **없음(본 스펙 고유 메커니즘은 자체 설계, 해시리본 수치는 배경 참고용으로만 인용)**.
- **⚠️ 예상 신호빈도 사전 명시 — 해시리본 대비 저빈도 함정을 의도적으로 회피한 설계**: 해시리본(30/60일 SMA 크로스)은 **2013년 이후 13년간 단 14회**만 신호가 발생해 우리가 최근 여러 라운드에서 겪은 "표본 원천부족→판단불가" 함정에 정확히 해당한다(예: BTC 200주MA·CME COT·Pi Cycle과 동일 문제). 이를 피하기 위해 본 스펙은 **SMA 교차가 아니라 매 난이도 재조정 이벤트(약 2016블록≈평균 14일마다, 연 약 26회) 자체의 변화율(%)을 신호원**으로 삼는다 — BTC 선물 데이터가 존재하는 2020~2026 약 6년 구간에서 약 150~160회의 재조정 이벤트가 있고, 상/하위 백분위 10%씩을 극단으로 잡으면 **원시 트리거는 종목당(BTC 단일) 약 30건 내외**로 예상한다. 이는 해시리본의 14건보다는 낫지만 여전히 표본이 넉넉하지 않음을 인정 — 백테스터는 실제 트리거 수를 최우선 보고하고 30건 미만이면 백분위 15/85로 완화하는 것을 검토할 것.
- **⚠️ 전제의 내적 일관성 사전 검토**: 음의 난이도 조정(해시레이트 이탈)은 역사적으로 **약세장/가격 급락 국면에 시기적으로 몰리는 경향**(2018, 2022, 2026 사례 확인)이 있어 롱 신호 표본이 소수의 매크로 드로다운 구간에 **클러스터링**될 위험이 크다 — 다른 다수 매크로 스펙에서 반복 확인된 함정과 동일 유형. 백테스터는 트리거를 일자 단위로 declustering(고유 이벤트 수)해 명목 표본과 별도로 보고할 것. 반대로 양의 대형 조정(해시레이트 급증)은 강세장 후반부 채굴 설비 증설 러시와 겹칠 수 있어 숏 신호도 유사한 클러스터링 위험을 안고 있음.
- **타임프레임**: 재조정 이벤트 단위(비고정, 평균 약 14일 간격) 신호 / 4h~1d 확인·진입.
- **시장/대상**: **BTC 무기한 단일종목 한정**(난이도 조정은 BTC 고유 온체인 메커니즘 — 다른 PoW 코인은 별도 데이터소스 필요해 확장 불가, ETH는 PoS 전환으로 해당 없음).

## 진입 규칙
- **데이터**: `mempool.space/api/v1/mining/difficulty-adjustments`(무료, 인증불요, 과거 전체 재조정 이력 제공) 또는 `blockchain.info/charts/difficulty` 대체. 각 재조정 시점(UTC 타임스탬프)과 조정률(%) 확보.
- **조정 서프라이즈 정의**: `diff_change[k] = (difficulty[k] / difficulty[k-1] - 1) × 100` (k번째 재조정 이벤트).
- **정규화**: `diff_change_pctile[k] = percentile_rank(diff_change[k], window=20회(최근 약 9~10개월치 재조정))` (z-score 대신 비모수 백분위 — 난이도가 BTC 역사 전반에 걸쳐 구조적으로 우상향해온 점을 감안, 고정 절대 임계값 대신 최근 구간 상대 극단으로 정의).
- **롱(채굴 항복 확인 후 반등, 해시리본과 동일 방향성이나 반응속도가 빠름)**: `diff_change_pctile[k] <= 10`(재조정 시점 기준 최근 20회 중 하위 10% — 큰 폭의 마이너 이탈) **AND** 재조정 이후 첫 3봉(4h) 내 종가가 재조정 시점 종가 대비 신저가를 갱신하지 않음(패닉 하락이 아닌 안정화 확인) → 안정화 확인 봉 종가에 롱 진입.
- **숏([설계 판단], 원문 해시리본엔 대칭 규칙 없음)**: `diff_change_pctile[k] >= 90`(대형 해시레이트 증설, 통상 강세장 후반부 채산성 개선 러시와 동행) **AND** RSI(14,1d) 약세 다이버전스(가격 신고가 vs RSI 미갱신) 동시 확인 → 과열 후반부 국면으로 판단해 숏.

## 청산 규칙
- 익절: ATR(14,4h)×3.0 트레일링(구조적 레짐 전환이라 스윙성 넓은 트레일 사용).
- 손절: 진입가 ∓ ATR(14,4h)×1.5.
- 시간/조건 청산: 다음 난이도 재조정 이벤트 도래 시(신규 레짐 정의 갱신) TP/SL 미도달이어도 재평가·필요 시 청산.

## 파라미터

- extreme_low_pctile=10 (범위 5~15), extreme_high_pctile=90 (범위 85~95)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 난이도 재조정 이력(신규 외부 API — mempool.space 또는 blockchain.info), RSI(14,1d), ATR(14,4h).
- 주의: **본 봇 라이브 인프라는 현재 온체인 난이도 데이터를 보유하지 않음 — 신규 fetch 파이프라인 구축 필요**(둘 다 무료·인증불요, REST GET 단순 응답이라 구현 난이도 자체는 낮음). 재조정 시각이 정확히 4h/1d 봉 경계와 일치하지 않으므로 이벤트 타임스탬프를 캔들 타임스탬프에 정렬(해당 이벤트 이후 첫 봉부터 신호 유효)하는 처리가 필요 — 룩어헤드 방지에 유의.

## 스카우트 메모
- **강점**: 이 목록 내 최초의 **순수 온체인 네트워크 데이터**(가격·거래량·파생지표가 전혀 아님) 기반 스펙 — 완전히 새로운 데이터 소스축. 해시리본이라는 검증된 유명 지표의 핵심 통찰(마이너 항복=구조적 저점 근접)을 계승하되, **2주 단위 재조정 이벤트 자체를 신호원**으로 삼아 해시리본의 치명적 약점(13년간 14건, 판단불가 위험)을 스펙 설계 단계에서 정면으로 회피한 점이 이번 라운드 지침(저빈도·저표본 축 회피)에 가장 부합.
- **의심점**: 그럼에도 여전히 예상 표본(약 30건)이 넉넉하지 않고, 매크로 드로다운 구간 클러스터링 위험을 스스로 인정함 — 과거 여러 판단불가/FAIL 사례와 유사한 패턴이 재현될 가능성을 배제 못 함. 신규 온체인 API 커넥터 구축이 필요(비용은 낮음). BTC 단일종목이라 유니버스 확장 불가.
- **우리 슬리브와의 관계**: 완전 신규 메커니즘·완전 신규 데이터축. 기존 스윙 슬리브와 대체·중복 없음 — 다만 BTC 단일종목 한정이라 포트폴리오 기여도는 제한적.
