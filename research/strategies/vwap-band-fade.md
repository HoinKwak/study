# VWAP 표준편차밴드 페이드 (2~3SD 극단 역추세)

- **출처**: https://crosstrade.io/learn/trading-strategies/vwap-reversion (VWAP Reversion) / https://trendsandbreakouts.com/vwap-bands / https://academy.exmon.pro/vwap-standard-deviations-the-only-honest-indicator-in-2026
- **참여지표**: - (교육/블로그 기반, 백테스트 수치는 정성적)
- **백테스트 근거**: 없음(정성적). 통설: ±2.0SD 안에 가격의 ~95% 존재 → 2~3SD 터치는 통계적 극단. "ADX 높을 때 페이드는 반복 실패" 라는 경고가 일관 → **레짐필터 필수**. 수치 백테스트 부재이므로 우선순위는 위 볼린저페이드/RSI-2보다 낮음.
- **타임프레임**: 15m 신호 / 1h 확인 (VWAP 일 리셋 기준). 크립토는 밴드폭 10~15% 확대 권장.
- **시장/대상**: BTC·ETH 무기한

## 진입 규칙
- 롱: 가격이 하단 **−2.0SD(또는 −2.5SD) 밴드까지 급락(거래량 버스트 동반)** 후 그 봉 또는 다음 봉이 **반전 캔들**(하단꼬리 길고 종가 > 시가)로 마감 → 진입. 목표는 1SD/VWAP 복귀.
- 숏: 가격이 상단 +2.0SD 밴드 급등 후 반전 캔들(윗꼬리, 종가 < 시가) → 진입.
- 레짐 게이트(필수): ADX(14) < 20~25 일 때만. VWAP 기울기가 완만할 때만(급경사면 추세로 간주해 진입 금지).

## 청산 규칙
- 익절: VWAP 중앙선 도달(1차) / 반대편 1SD(공격적). 부분청산 후 나머지 트레일.
- 손절: 진입 밴드 바깥 +0.5SD(예: 롱이면 −2.5SD 아래) 또는 진입가 −1.2×ATR.
- 시간 청산: 당일 종료(00:00 UTC) 전 전량 청산 → 오버나이트/펀딩 회피.

## 파라미터
- vwap_anchor=daily(00:00 UTC)
- band_sd=2.0 (범위 2.0~3.0)
- adx_max=25 (범위 20~25)
- reversal_confirm=1봉 반전캔들 (범위 0~2봉)
- rr_target=VWAP or 1SD (범위)
- exit_end_of_day=on

## 코딩 난이도 / 데이터 요구
- 필요한 지표: VWAP(일 리셋, typical×vol 누적), VWAP 표준편차밴드, ADX(14), ATR(14), 거래량 버스트(RVOL). 전부 캔들+거래량.
- 주의: **바이낸스 REST 캔들+거래량으로 충족.** 오더북/틱 불필요. VWAP SD 밴드 계산(누적 분산) 구현이 유일한 신경쓸 점.

## 스카우트 메모
- 강점: 데이터 완전 충족. "극단에서만" 발화 → 저빈도. 반전캔들+ADX필터로 칼받기 억제.
- 의심점: **수치 백테스트 없음**(정성적 근거만) → 위 두 전략보다 후순위. 라운드1의 vwap-reclaim 과 개념 인접.
- 우리 단타 슬리브와의 관계: 라운드1 `vwap-reclaim-intraday` 는 **VWAP 라인 재탈환**(중심선 크로스) 신호, 이건 **2~3SD 극단밴드 페이드**(외곽 역추세) → 신호 발생 지점이 다르므로 중복 아님/보완. 단 둘 다 VWAP 계열이라 하나만 먼저 검증 권장.
