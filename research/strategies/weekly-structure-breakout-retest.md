# [스윙] 주간 구조 브레이크아웃 + 4h 리테스트 (HTF Structure)

- **출처**: https://www.horizontrading.ai/learn/break-and-retest-strategy (Break & Retest) / https://www.altrady.com/blog/swing-trading/trend-breakout-moving-average-setups-crypto-swing-trading / https://coinbureau.com/guides/how-to-backtest-your-crypto-trading-strategy
- **참여지표**: - (표준 프라이스액션 기법, 스윙 가이드 다수 인용)
- **백테스트 근거**: 없음(정성적, 표준 기법). 가이드 통설: **일·4h 차트의 리테스트가 가장 신뢰도 높다(참여자 다수 관측)**. 크립토 리테스트 허용오차 0.8% 권장, "최소 200트레이드 백테스트 후 판단" 권고. 실측 필요.
- **타임프레임**: **주봉으로 레벨 산출(스윙 고/저)**, 4h 로 돌파·리테스트 트리거. (프라이스액션 멀티 TF)
- **시장/대상**: BTC·ETH 무기한

## 진입 규칙
- 레벨: 최근 완료된 주간 스윙 고점(WSH)/저점(WSL) = 직전 N주(예 8~12주) 내 확정된 고/저 피벗.
- 롱: 4h **종가가 WSH 위로 돌파** → 이후 되돌아와 WSH를 **리테스트**(±0.8% 이내에서 지지) → 반등 확인 캔들(불리시 엔걸핑/핀바/종가 > WSH) → 진입. **돌파봉 자체엔 진입 안 함.**
- 숏: 4h 종가가 WSL 아래로 돌파 → WSL 리테스트에서 저항(반락 확인 캔들, 종가 < WSL) → 진입.
- 게이트(옵션): 돌파 방향이 주봉 EMA20 방향과 일치, 돌파봉 RVOL ≥ 1.5.

## 청산 규칙
- 익절: 다음 상위 주간 구조 레벨(직전 주간 반대극/미측정 스윙), 또는 R:R 2:1~3:1 고정.
- 손절: 리테스트 레벨 반대편 — 롱=WSH 아래 최근 4h 스윙저점 또는 −1.5×ATR(4h); 숏=WSL 위.
- 시간/조건 청산: 돌파 후 M봉(예 12개 4h≈2일) 내 리테스트 미발생 시 셋업 취소. 리테스트가 실패해 레벨을 반대 종가로 재이탈하면 즉시 컷.

## 파라미터
- pivot_lookback=8주 (범위 6~12), retest_tol=0.008 (범위 0.005~0.012)
- rr_target=2.5 (범위 2.0~3.0), atr_mult_sl=1.5 (범위 1.0~2.0)
- retest_window=12봉(4h) (범위 6~18), rvol_min=1.5 (게이트 옵션)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 주봉/4h OHLCV, 스윙 피벗 검출(N봉 좌우 최고/최저), ATR, 거래량 RVOL, EMA. **전부 바이낸스 REST 로 가능.** 확인 캔들 패턴(엔걸핑/핀바)은 OHLC 로 판정. 오더북 불필요.
- 난이도: 중. 피벗 검출 + 돌파/리테스트 2단계 상태머신 + 확인캔들 로직.

## 스카우트 메모
- 강점: **주간 구조 = 매우 큰 이동폭** → R:R 2.5:1 이상 확보 시 수수료(0.14% 왕복)는 노이즈. 저빈도(주간 레벨 돌파는 드묾). "돌파봉 추격 금지+리테스트 확인"이 크립토 가짜돌파를 걸러 승률 방어.
- 의심점: 리테스트가 안 오고 그냥 가버리는 강한 추세를 놓침(기회비용). 허용오차·확인캔들 정의에 따라 성과 민감 → 표본외 검증 필수. 정성적 기법이라 코드화 시 "리테스트/확인캔들" 규칙을 엄격히 수치화해야 함.
- 우리 스윙 슬리브와의 관계: **보완**. 기존 prior-day-high-low-retest 는 **일 앵커+15m(인트라데이)** 이고, 이건 **주간 앵커+4h(스윙)** 로 TF·구조 스케일이 완전히 다름(중복 아님). 기존 RSI 역추세 스윙과도 진입 논리 상반(구조 돌파 추종 vs 극단 역추세) → 분산.
