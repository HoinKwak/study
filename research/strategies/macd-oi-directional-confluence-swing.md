# [스윙] MACD 부호·방향 + OI 증감 방향 합치 (누적/분산 국면 게이트)

- **출처**: https://tw.tradingview.com/chart/BTCUSD/qtaBuoGR-trading-system-divergences-on-open-interest/ (TradingView, 작성자 fvb, 2018-03-20 게시) — WebFetch로 원문 직접 확인.
- **참여지표**: **좋아요 367** (WebFetch로 확인). 2018년 게시물로 최신 참여도는 아니나, "OI+MACD 결합"이라는 컨셉 자체가 검색 결과 여러 2차 자료(divergence 지표 등)에서 반복 언급되는 아이디어.
- **백테스트 근거**: **없음(참여지표 기반)**. 원문에 성과 수치 전혀 없음. 원 스크립트는 Bitfinex BTC/USD 전용으로 명시돼 있어 바이낸스 이식은 완전 미검증.
- **타임프레임**: 원문 미명시(스크립트 게시일 특성상 일봉 추정) — 스윙 슬리브 편입 시 4h~1d로 검증 권장.
- **시장/대상**: 원문은 Bitfinex BTC/USD 한정 명시 — 바이낸스 BTC·ETH 무기한으로 이식 시 미검증.

## 진입 규칙
- 롱("녹색 존"): **MACD(라인) < 0 이고 MACD가 증가 중**(저점에서 반등 시작) **그리고** 미결제약정(OI)이 직전 봉 종가 대비 **증가**. → 가격 하락 후 반등 초입에 신규 자금(OI 증가)이 유입되는 "누적 국면"으로 해석.
- 숏("적색 존"): **MACD > 0 이고 MACD가 감소 중**(고점에서 하락 시작) **그리고** OI가 직전 봉 대비 **감소**. → 상승 후 되돌림에 포지션 청산(OI 감소)이 겹치는 "분산 국면"으로 해석.
- 충돌 규칙(원문 명시): 매수·매도 신호가 동시에 발생하면 **무시**(둘 다 성립 불가능한 논리이나 원저자가 명시한 안전장치로 유지).

## 청산 규칙
- 원문에 명시적 청산 규칙 없음(진입 조건의 반대 신호 발생 시 포지션 전환으로 추정).
- 채택 시 필수 보완: 손절 = 진입가 ± ATR(14)×2.0, 익절 = MACD 부호 반전 또는 고정 R:R 2:1 중 먼저 도달.
- 시간 청산: 원문 없음 — 채택 시 최대 홀딩 N봉(4h 기준 20~40봉) 제한 권장.

## 파라미터
- macd_fast=12, macd_slow=26, macd_signal=9 (원문 미기재 → 표준값 채택)
- oi_compare=직전 봉 종가 대비 증감(원문 명시, 별도 임계값 없음 — 그대로 "증가/감소" 이진 판정)
- (보완) stop_atr_mult=2.0, rr_target=2.0, max_hold=20~40봉(4h 기준)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: MACD(12,26,9), 미결제약정(OI) 시계열. **바이낸스 선물 REST `openInterestHist`로 OI 캔들 확보 가능**(단, 과거 데이터는 최근 30일 제한 — 장기 백테스트 시 데이터 소스 제약 주의, 우리 기존 OI 관련 스펙들과 동일한 제약).
- 주의: 원문이 Bitfinex 전용으로 명시돼 바이낸스 OI 데이터 특성(집계 방식·업데이트 주기)과 다를 수 있어 그대로 이식 시 재정의 필요. MACD 자체 "증가/감소" 판정(전봉 대비 기울기)은 노이즈에 취약할 수 있어 스무딩(예: 3봉 평균 기울기) 검토 권장.

## 스카우트 메모
- 강점: MACD를 가격이 아닌 **"OI 증감 방향과의 합치 여부"로 게이팅**하는 방식이 기존 보유한 OI 관련 스펙들(다이버전스·펀딩+OI+가격 3중 확인·CVD)과 메커니즘이 달라 신호 상관이 낮을 가능성. 로직 자체는 매우 단순해 코딩 난이도 낮음.
- 의심점: 2018년 구식 스크립트로 백테스트·참여지표 모두 약함(좋아요 367, 성과 수치 전무). Bitfinex 전용 명시라 바이낸스 이식이 완전 미검증 상태. "OI 직전봉 대비 증감"이라는 이진 판정은 노이즈가 많아 그대로 쓰면 신호가 과도하게 잦을 위험 — 최소 임계값(예: OI 변화율 ±0.5% 이상) 추가 검토 필요.
- 우리 스윙 슬리브와의 관계: 기존 `oi-roc-price-divergence-squeeze-reversal-scalp.md`(OI 변화율과 가격의 다이버전스), `funding-oi-price-triple-confirm-carry-momentum-swing.md`(펀딩+OI+가격 3중 확인)와 인접 영역이나, **가격 지표(MACD)의 부호+기울기와 OI 증감을 직접 매칭**하는 방식은 이번이 처음 — 백테스트 우선순위는 낮음(근거 최약체), 다른 후보 검증 후 여유 있을 때 시도 권장.
