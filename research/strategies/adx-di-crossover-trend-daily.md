# [스윙] ADX/DI 크로스오버 추세추종 (일봉)

- **출처**: https://quant-signals.com/adx-trading-strategy/ (Quant Signals, "763 Backtests Show How to Filter Weak Trends")
- **참여지표**: - (백테스트 기반 블로그)
- **백테스트 근거**: **BTCUSD 일봉 — DI 크로스오버(단순판): 162 트레이드, 승률 43.8%, PF 1.56, MaxDD 5.8%, 기대값 +0.315R.** 손절 ATR×2.0, 목표 R:R 2:1 고정. 별도 "추세필터 강화판"(EMA9/21 크로스 + ADX>25 + DI방향일치)은 **30트레이드로 표본 81% 급감, 승률 36.7%, PF 1.16** — 필터 과함으로 성과 열화, 채택 비권장. **수수료·슬리피지 전혀 미반영(원문 명시)** → 재검증 시 PF 하락 가능성. 정확한 표본기간은 원문에 명시되지 않아 확인 필요.
- **타임프레임**: 1d
- **시장/대상**: BTC 무기한 (ETH 등 확장 가능)

## 진입 규칙
- 롱: DI+ 가 DI- 를 상향 돌파(크로스오버) **AND** ADX(14) > 20
- 숏: DI- 가 DI+ 를 상향 돌파(크로스오버) **AND** ADX(14) > 20

## 청산 규칙
- 손절: 진입가 대비 ATR(14) × 2.0
- 익절: 손절폭의 2배(R:R = 2:1) 고정 목표
- 시간/조건 청산: 명시 없음(체계적 R:R 청산 우선). 반대 DI크로스 발생 시 조기 청산 옵션 고려 가능.

## 파라미터
- adx_period=14 (범위 10~20)
- adx_threshold=20 (범위 15~25)
- atr_period=14 (범위 10~20)
- atr_sl_mult=2.0 (범위 1.5~3.0)
- rr_ratio=2.0 (범위 1.5~3.0)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: ADX/+DI/-DI(Wilder 방식), ATR(14) — 전부 바이낸스 OHLCV REST 캔들로 계산 가능. 오더북/틱 불필요.
- 난이도: 낮음. DI 크로스오버 판정 + ADX 임계값 게이트 + ATR 기반 고정 R:R 청산.

## 스카우트 메모
- 강점: 규칙이 명확·결정론적. ADX>20 필터로 레인지장 진입을 걸러내는 고전적 추세추종. 일봉 저빈도(162트레이드/기간불명이나 연환산 시 소수)라 수수료 부담이 작을 것으로 기대.
- 의심점: 수수료·슬리피지 완전 미반영이 원문에 명시 — 우리 프레임(수수료 반영)으로 재검증 시 PF 1.56이 상당히 낮아질 수 있음(승률 43.8%로 낮은 편이라 손익비 의존도가 큼). "강화판" 필터는 표본 소실이 커 신뢰 불가 → 단순 DI크로스판만 채택 권장.
- 우리 스윙 슬리브와의 관계: **부분 보완**. 기존 `donchian-adx-breakout.md`(채널 돌파 + ADX 필터)와 목적(추세장에서만 진입)은 겹치나 1차 트리거 지표가 다름(DI 크로스 vs 채널 돌파) → 신호 상관이 낮을 가능성이 있어 별도 검증 가치 있음. 중복이라기보단 "같은 레짐필터, 다른 트리거" 관계.
