# [스윙] USDC/USDT 스테이블코인 상대점유율 로테이션 플라이트투퀄리티 게이트 + BTC/ETH 추세추종

- **출처**: 자체 설계. 개념적 배경(정성적) — 2022년 UST(테라) 붕괴, 2023년 SVB발 USDC 디페그, Tether의
  준비금 투명성 논란 등의 시기마다 "USDC(더 규제친화적·투명성 높은 스테이블코인) 점유율이 오르면 시장이
  안전자산을 선호한다(flight to quality)"는 서사가 크립토 업계에 반복 회자됨(구체 SNS 팔로워·좋아요 집계는
  못함). **이 정확한 규칙(USDC/USDT 상대점유율 모멘텀 → 방향 게이트)으로 백테스트한 원문은 찾지 못함 —
  지어내지 않고 자체 설계로 명시**.
  ⚠️기존 보유 스펙과의 차별점(중복 아님을 확인): `stablecoin-supply-growth-rate-leading-liquidity-swing.md`
  는 스테이블코인 **총합 공급 성장률**(유동성 유입/유출 자체)을, `stablecoin-supply-ratio-ssr-rsi-extreme-swing.md`
  는 **BTC시총 대비 스테이블 공급 비율의 레벨**을, `stablecoin-depeg-flight-to-safety-swing.md`는 **드문
  디페그 이벤트**(1.00에서 순간 이탈)를 다룬다. 본 스펙은 이 셋과 달리 **두 스테이블코인 간 상대 점유율의
  완만한 추세 이동**(디페그 없이도 USDT에서 USDC로, 또는 그 반대로 자금이 서서히 옮겨가는 정상 상태의
  로테이션)을 본다는 점에서 데이터·메커니즘이 명확히 다름.
- **참여지표**: - (자체 설계, 개념은 업계 통용 상식이나 정량 참여지표 미집계).
- **백테스트 근거**: **없음(자체 설계, 정량 근거 지어내지 않음)**.
- **타임프레임**: 상대점유율 레짐 — 1d / BTC·ETH 4h 진입.
- **시장/대상**: BTC·ETH(스테이블코인 신뢰도는 시스템 전체 리스크 지표이므로 개별 알트 확장 근거 약함,
  [설계판단]으로 2종목 한정).

## 진입 규칙
- 데이터: CoinGecko `/coins/tether/market_chart`·`/coins/usd-coin/market_chart`
  (`vs_currency=usd&days=max&interval=daily`)의 `market_caps` 필드. 2026-08-25 curl로 `usd-coin`
  엔드포인트 HTTP 200·최근 30일 데이터 직접 확인(무료·무인증). Tether(`tether`) 엔드포인트도 동일 포맷일
  것으로 [추정](USDC와 동일 API 구조이므로 실패 가능성 낮음, 착수 시 별도 재확인 필요).
  ⚠️CoinGecko 무료 티어는 요청 빈도 제한이 있고 장기간(수년) `days=max` 요청 시 응답 지연·부분 실패
  가능성 있음 — 1차 진단에서 전체 구간 결측률부터 확인.
- `usdc_share(t) = mcap_usdc(t) / (mcap_usdc(t) + mcap_usdt(t))` (USDC의 2강 스테이블코인 내 상대점유율,
  0~1 범위로 자체 정규화됨 — 별도 z-score 불필요, [설계판단]).
- `share_roc_14d(t) = usdc_share(t) - usdc_share(t-14일)` (14일 변화, %p 단위 그대로).
- **롱 게이트**: `share_roc_14d(t) >= +share_th`(USDC 점유율 상승=플라이트투퀄리티 진행 중, 시장이 신중
  모드)이면 **오히려 역발상으로 해석**: 원 서사대로면 "리스크오프=하락 베팅"이 자연스러우나, 과거 실제
  USDC 점유율 상승 국면(2023 상반기 SVB 이후 회복기 등)이 꼭 하락장이 아니었을 수 있어 **방향은 사전
  가정하지 않고 백테스트로 결정** — 두 방향(정방향: 점유율↑=숏 게이트, 역방향: 점유율↑=롱 게이트)을
  **둘 다 구현해 병행 비교**([설계판단], 아래 "전제의 내적 일관성" 참조).
  - 정방향판: `share_roc_14d >= +share_th` → BTC·ETH 신규 **숏만 허용**(Donchian(20,4h) 하단 이탈 시 진입).
  - 역방향판: `share_roc_14d >= +share_th` → BTC·ETH 신규 **롱만 허용**(Donchian(20,4h) 상단 돌파 시 진입).
- `share_roc_14d(t) <= -share_th`(USDT로 점유율 회귀=리스크온/공격적 트레이딩 선호 [가설])는 반대 게이트로
  동일하게 양방향 병행.

## 청산 규칙
- 익절: ATR(4h,14)×2.5 트레일링.
- 손절: 진입가 ∓ATR(4h,14)×1.5.
- 시간/조건 청산: 게이트 부호가 반전되면 신규진입만 차단(기존 포지션은 트레일링 위임, [설계판단]).

## 파라미터
- share_roc_window=14일 (범위 7~30)
- share_th=0.5%p (범위 0.3~1.5%p, 즉 usdc_share가 14일간 0.5%p 이상 이동)
- donchian_len=20 (4h, 범위 10~30)
- atr_stop_mult=1.5, atr_trail_mult=2.5

## 코딩 난이도 / 데이터 요구
- 필요한 지표: CoinGecko market_chart 2개 엔드포인트(USDT·USDC 시가총액, 무료·무인증) + BTC·ETH 4h
  klines(Donchian·ATR). 오더북/틱/실시간청산 불필요.
- 주의: CoinGecko 시가총액은 **유통량×스팟가**로 산출되므로 USDC·USDT 모두 페그가 거의 항상 유지된다는
  전제 하에선 사실상 유통량 비율과 거의 동일 — 단, 드문 디페그 순간(위 depeg 스펙이 다루는 이벤트)에는
  가격 변동 자체가 점유율 계산을 일시 왜곡할 수 있어 **디페그 이벤트 구간은 별도 플래그해 제외 검토**
  (동어반복·오염 방지).

## 예상 신호 빈도·임계값 백분위
- [추정] `usdc_share`는 통상 완만하게(연 단위로 몇 %p) 이동하는 시계열이라 14일에 0.5%p 이상 변화가
  **분포상 어느 백분위인지 1차 진단에서 반드시 실측**(예상은 [추정] 상위/하위 20~30% 수준, 즉 상당히
  자주 발화할 위험 — 직전 라운드 "테이커매수비율 브레드스"가 임계값을 사실상 중앙값으로 잡아 실패한
  전례를 반영해, **분포 실측 없이 %p 절대값을 감으로 정하지 않는다**는 원칙을 여기서도 적용).
- 연 예상 트리거(4h 확인까지 거친 최종 진입): [추정] 15~40건 수준.

## 비용 감당 산술
- 4h ATR 트레일링 스윙, 연 15~40건이면 왕복수수료(0.14%) 총 비용은 연 2.1~5.6%p — ATR 배수 기반 손익폭이
  이를 감당하려면 gross PF가 최소 1.15 이상은 되어야 함(과거 "OI컨퍼메이션" gross1.395·연200건에도
  net 0.688로 무너진 전례를 반영해 보수적으로 잡음).

## 사전 폐기조건 (⚠️사후 변경 금지)
1. 정방향판·역방향판 **둘 다** OOS gross PF(R) < 1.10 또는 t 비유의 → FAIL(방향 자체를 못 정한 것이므로
   양쪽 다 죽으면 재설계 없이 폐기).
2. 한쪽만 살아남더라도 OOS 거래 건수 < 15건이면 → 판단불가.
3. **판정 단위**: 트레이드 단위 기본. 단 `share_roc` 레짐이 수 주~수개월 지속되는 완만한 시계열 특성상
   같은 레짐 내 여러 트레이드의 자기상관 위험이 커 **레짐 전환(이벤트) 단위로도 재집계**, 두 단위 결과가
   크게 어긋나면 이벤트 단위를 우선.
4. 디페그 이벤트 구간(위 depeg 스펙의 트리거 시점)을 제외해도 결과가 유지되는지 확인 — 제외 시 결과가
   반전되면 "디페그 이벤트가 전체 성과를 설명"하는 것으로 별도 명기(과거 token-unlock·ETF유출스트릭
   사례처럼 소수 사건 의존 여부 진단).

## 전제의 내적 일관성 자문
- **핵심 위험**: 방향 가설이 사전에 확정되지 않음(정방향·역방향 병행 설계 자체가 이 불확실성을 인정한
  것) — "USDC 점유율 상승=안전선호=하락 베팅"이라는 직관이 실제로는 반대일 수 있음(예: USDC 점유율 상승이
  단순히 미국 규제친화적 자금 유입 증가를 반영해 오히려 강세장 신호일 수도 있음). **이 스펙의 존재
  이유는 방향을 미리 정하지 않고 데이터로 가리는 것**.
- USDT의 시가총액이 USDC보다 압도적으로 커서(2026년 기준 통상 3~5배) `usdc_share`가 구조적으로 낮은
  수준(0.15~0.30 부근)에서 좁게 움직일 수 있음 — 레벨이 아니라 변화율(ROC)을 쓰므로 이 구조적 편향은
  일부 완화되나, 절대 레벨의 장기 추세(예: USDC가 수년간 꾸준히 점유율을 확대/축소해온 구조적 추세)가
  있다면 `share_roc`의 부호 분포도 편향될 수 있어 1차 진단에서 실측 필수.

## 동어반복 점검
- `share_roc_14d`와 BTC 자체의 24h 변동성(realized vol)·펀딩비 극단(기존 `funding-rate-extreme-contrarian`
  류)의 상관을 **전체구간 + 트리거 시점 한정** 둘 다 실측 — "스테이블코인 로테이션"이 사실상 "이미 시장이
  변동성 높아졌다"의 재확인에 불과한지 확인.
