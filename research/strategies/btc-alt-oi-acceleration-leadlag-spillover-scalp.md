# [단타] BTC→알트 미결제약정(OI) 가속도 리드-래그 전이 스캘핑

- **출처**: 자체 설계. 데이터 필드 근거: `metrics` 덤프 `sum_open_interest_value`(명목 OI, 5분 간격)
  — 기존 다수 OI 스펙에서 필드 실재 확인됨. 기존 보유 스펙과의 차별점:
  `btc-led-lagged-spillover-majors-scalp.md`는 **가격**(레인지 돌파+거래량) 리드-래그이고,
  `oi-breadth-regime-gate-btc-trend-swing.md`·`multi-timeframe-oi-slope-divergence-regime-swing.md`
  등은 **단일 종목 자기 자신의 OI 추세**를 본다. `binance-okx-cross-exchange-oi-growth-divergence-
  scalp.md`는 **같은 종목의 거래소 간** OI 괴리다. 본 스펙은 **BTC의 OI 가속도(2차 미분)가 알트로
  전이되는 시차**를 보는 것으로, "자산 간(BTC→알트)" + "OI의 2차 미분(가속도, 1차 기울기가 아님)"
  조합은 2026-08-24 기준 432개 스펙 전수 재확인 결과 신규.
- **참여지표**: - (자체 설계)
- **백테스트 근거**: 없음(자체 설계, 정직히 표기).
- **타임프레임**: 15m 신호(BTC 트리거·팔로워 확인) / 1h 확인.
- **시장/대상**: BTC를 트리거, ETH/SOL/BNB/XRP 4종목을 팔로워로 설계(5대 메이저 한정,
  `btc-led-lagged-spillover-majors-scalp.md`와 동일하게 XRP는 문헌상 BTC와 시차관계 약하다는
  지적이 있었으나 **본 스펙은 가격이 아닌 OI 기반이라 그 문헌이 직접 적용되지 않음** — XRP 포함해
  실측 후 LOO로 판단).

## 진입 규칙
- **BTC OI 가속도**: `oi_roc(t) = OI(t)/OI(t-1bar) - 1`(15m 봉 기준), `oi_accel(t) = oi_roc(t) -
  oi_roc(t-1)`. `oi_accel`의 60봉(15h) 롤링 z-score 계산.
- 롱(팔로워): BTC `oi_accel` z-score가 **+2.0을 상향 돌파**(레버리지 급격 유입) + BTC 가격이 동시에
  상승 방향(해당 15m 봉 종가>시가) + **팔로워 자산의 `oi_accel` z-score가 아직 +1.0 미만**(레버리지
  전이가 아직 안 일어난 상태 — "안 따라감" 확인) 상태에서, 팔로워 자산 자체 3봉 ROC가 양(+)이면
  팔로워 롱 진입.
- 숏: 대칭(BTC `oi_accel` z<-2.0 + BTC 하락봉 + 팔로워 z>-1.0 + 팔로워 3봉 ROC 음(-)).

## 청산 규칙
- 익절: 팔로워 자산이 BTC 트리거 이후 자체 `oi_accel` z-score도 +2.0(또는 -2.0)에 도달("따라잡음"
  확인) 시 절반 익절 후 트레일(ATR×1.0), 또는 measured move(진입 ATR×1.2) 도달 시 전량.
- 손절: 진입가 대비 -1.0×ATR(14,15m), 또는 BTC 자체가 트리거 방향과 반대로 되돌리면(BTC 종가가
  트리거봉 시가를 반대로 재돌파) 즉시 청산.
- 시간 청산: 진입 후 8봉(2시간) 내 전이(팔로워 z-score 도달)가 안 일어나면 청산(레버리지 전이는
  단기간 내에만 유효하다는 가설 반영, 자체 설계 — 문헌 근거 아님).

## 파라미터
- btc_accel_zscore_window=60봉 (범위 40~120) · btc_accel_threshold=2.0 (범위 1.5~2.5)
- follower_accel_lag_threshold=1.0 (팔로워 아직 미도달 기준, 범위 0.5~1.5)
- follower_momentum_bars=3 (범위 2~5) · atr_stop_mult=1.0 · atr_trail_mult=1.0
- rr_target=1.2 · max_hold=8봉

## 코딩 난이도 / 데이터 요구
- 필요한 지표: `metrics` 덤프 OI(5개 심볼), 15m 리샘플, 1차·2차 차분, 60봉 롤링 z-score, ATR14,
  3봉 ROC. 캔들+OI로 충족, 오더북/틱 불필요.
- 주의: BTC와 팔로워 캔들·OI 타임스탬프 동기화(둘 다 같은 15m 마감 시각) 필요 — 과거 앵커드VWAP
  건에서 `pd.Timedelta`의 ms→us 업캐스트로 리샘플 인덱스가 깨진 전례 반복 방지(ns 명시 통일).

## 예상 신호 빈도 (사전 추정)
- BTC `oi_accel` z-score가 ±2.0을 넘는 것 자체는 [추정] 15m 봉 기준 연 200~500회 수준(정규분포
  명목상 연 82회이나 과거 여러 z-score 기반 OI 스펙에서 실측이 명목의 2~3배로 나온 전례 반영해 상향
  추정). 여기에 "팔로워 미도달" 게이트가 추가로 걸러 팔로워당 [추정] 연 40~120건. **4개 팔로워가
  같은 BTC 트리거를 공유하므로 팔로워 간 상관이 매우 높을 것으로 예상**(같은 시각 BTC 트리거 → 여러
  팔로워 동시 후보) — 이벤트(BTC 트리거) 단위 고유표본은 팔로워별 표본보다 훨씬 작을 것.

## 비용 감당 산술
- 15m/1h 스캘프, 최대 보유 2시간. 왕복비용 0.14%를 이기려면 평균 |R|이 유의하게 0.14%를 상회해야
  함 — "레버리지 전이 캐치업" 무브가 [추정] 0.3~1.0% 규모라면 산술상 여유 있으나, 결합조건이 많아
  (가속도 임계+미도달 게이트+가격방향+모멘텀) 신호 자체가 노이즈일 위험(과거 여러 다중조건 결합
  스펙이 gross부터 무엣지였던 반복 패턴)을 감안해야 함.

## 사전 폐기조건 (거래 개시 전 확정, 사후 변경 금지)
- 판정 단위: **BTC 트리거 이벤트 단위(캘린더일 de-clustering 아님, 분/시간 단위 이벤트 클러스터
  기준)를 1차**로 판정. 팔로워별 거래 단위 결과는 참고용으로만 병기(팔로워 간 상관이 매우 높을
  것으로 사전에 명시했으므로).
- (a) OOS 이벤트 단위 n<20 → 판단불가.
- (b) OOS net PF(R) < 1.2 **또는** 이벤트 단위 t 비유의(|t|<1.96) → FAIL(OR 결합).
- (c) gross(fee=0·slippage=0)부터 PF<1.05 → 애초에 무엣지로 즉시 FAIL.
- (d) 단일 팔로워(예: SOL) 의존도가 순익의 60%↑ → SUSPECT.

## 전제의 내적 일관성 자문 + 실측 발생빈도 대조 계획
- 우려: "팔로워가 아직 안 따라감" 게이트가 실제로는 **팔로워 자산이 애초에 유동성이 낮아 OI가 느리게
  반응하는 구조적 특성**(레버리지 전이가 아니라 단순 유동성 차이)을 잡아내는 것일 수 있음 → 대조군
  필수: ① 게이트 없이 BTC 트리거만으로 팔로워 즉시 진입, ② `oi_accel` 대신 `btc-led-lagged-
  spillover-majors-scalp.md`와 동일한 **가격** 기반 트리거로 바꾼 버전(OI 축이 가격 축보다 나은지
  직접 비교). ③(채택안)이 ①②보다 뚜렷이 우수해야 함.
- 실측 발생빈도 대조: BTC `oi_accel` z≥2.0의 실측 발생비율을 정규분포 명목(2.28%)과 비교해 최우선
  보고.

## 동어반복(재포장) 점검 계획
- BTC `oi_accel`과 BTC `oi_roc`(1차 미분, 기존 여러 스펙에서 이미 사용)의 상관 확인. |r|>0.7이면
  "가속도"가 사실상 "기울기"의 재포장에 불과할 위험 — 가속도만의 고유 정보량을 별도 확인.

## 정규화 게이트 논증
- 60봉 롤링 z-score로 정규화(OI 절대 규모가 종목·시기별로 크게 다르므로 필수). `follower_accel_lag_
  threshold`도 팔로워 자신의 분포 대비 상대값.

## 수익 인과 경로
- 가설: BTC의 급격한 레버리지 유입(OI 가속)은 시장 전체 리스크온/오프 심리 변화의 첫 신호이고, 이
  심리가 알트로 전이되는 데 수십 분~수 시간의 시차가 있다는 가설(레버리지 확산의 정보 비대칭·유동성
  차이에 기반). 정량 문헌 근거 없음 — 순수 가설.

  명목보다 훨씬 작을 가능성.
