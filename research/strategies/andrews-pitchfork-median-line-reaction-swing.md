# [스윙] 앤드류스 피치포크(Andrews' Pitchfork) 미디언라인 반응 매매

- **출처**: 개념 정의 — https://blog.oneuptrader.com/strategies/andrews-pitchfork-trading-strategies/ (OneUp Trader) /
  https://forextraininggroup.com/rules-for-using-andrews-pitchfork-and-median-lines/ (Forex Training Group, 미디언라인 규칙) /
  https://www.litefinance.org/blog/for-beginners/best-technical-indicators/andrew-pitckhfork/ (LiteFinance)
  — TradingView "Andrew's Pitchfork" 내장 드로잉 툴로 매우 널리 쓰이는 고전 기법(Dr. Alan Andrews 고안). 원문은 대부분 정성적 설명 위주라 **아래 규칙은 원문의 정성적 원리를 코딩 가능하도록 자체 정량화**한 것.
- **참여지표**: - (SNS 참여지표 미집계이나, 피치포크는 TradingView 기본 드로잉 도구로 채택돼 있을 만큼 트레이딩 커뮤니티에서 매우 널리 알려진 기법. "가격이 미디언라인을 향해 회귀하는 경향이 약 80%"라는 정성적 통설이 다수 2차 자료에서 반복 인용되나, **1차 정량 백테스트 원문은 확보 못함**[quantifiedstrategies.com·tradingstrategyguides.com 모두 봇 차단으로 WebFetch 실패, 인용 안 함].
- **백테스트 근거**: **없음(개념 기반, 정직히 표기)**. "80% 회귀" 수치도 원문 1차 검증 실패로 **인용하지 않음** — 반드시 자체 백테스트로 가설 검증 필요.
- **타임프레임**: 4h 피벗 탐지 / 4h~1d 진입.
- **시장/대상**: BTC·ETH·시총상위 알트 무기한 (추세가 뚜렷한 종목에서 피치포크 채널이 잘 형성됨).

## 진입 규칙
- **피벗 탐지**: ZigZag(4h, `deviation=zigzag_pct`(기본 5%))로 교대 스윙고점/저점 계열을 구함. 최근 3개 교대 피벗을 `P0(앵커, 가장 오래됨) → P1 → P2(가장 최근)` 순으로 라벨링(예: 하락추세라면 P0=고점, P1=저점, P2=고점처럼 교대).
- **채널 작도**: 미디언라인(ML) = P0에서 `(P1+P2)/2`(P1·P2의 중점)로 이어지는 직선(연장). 상단 평행선(선진워닝라인) = P1을 지나며 ML과 동일 기울기. 하단 평행선 = P2를 지나며 ML과 동일 기울기. (표준 피치포크 정의 그대로.)
- **롱**: 상승 피치포크(P0가 저점 기준으로 상단 채널 형성 시)에서 종가가 **하단 평행선(P2 통과선)에 근접(터치 또는 0.3×ATR(4h,14) 이내 접근) 후 반등 확인봉**(직전봉 대비 양봉 마감 + 종가가 하단선 위로 복귀) → 롱, 목표는 ML.
- **숏**: 대칭 — 하락 피치포크에서 종가가 상단 평행선에 근접 후 반락 확인봉 → 숏, 목표는 ML.
- **채널 이탈(대안 신호, [설계 판단])**: 종가가 하단/상단 평행선을 반대 방향으로 **breakout_atr_mult(예 1.0×ATR) 이상 이탈**하면 추세 반전으로 간주해 **역방향 진입**(피치포크 붕괴 후 반전 추종) — 원문에서도 "박스 이탈은 반전 신호"로 별도 언급되는 보조 규칙.

## 청산 규칙
- 익절(터치 반등형): 미디언라인(ML) 도달 시 청산, 또는 ML 돌파 시 반대편 평행선까지 트레일링 연장.
- 익절(이탈 반전형): ATR(4h,14)×2.5 트레일링.
- 손절: 터치 반등형은 진입 근거가 된 평행선을 `stop_atr_mult(예 1.2)×ATR` 이상 재이탈 시 손절. 이탈 반전형은 이탈 직전 극값 재복귀 시 손절.
- 시간/조건 청산: `max_hold`(예 15봉=4h×15=2.5일) 초과 시 무조건 청산. 새 ZigZag 피벗이 확정돼 채널 자체가 갱신되면(구채널 무효화) 보유 포지션은 유지하되 신규 진입 중단.

## 파라미터
- zigzag_pct=5% (범위 3~8%, 종목 변동성에 따라 조정)
- touch_atr_tol=0.3 (범위 0.2~0.5)
- breakout_atr_mult=1.0 (범위 0.7~1.5)
- stop_atr_mult=1.2 (범위 1.0~1.8)
- atr_trail_mult=2.5 (범위 2.0~3.0)
- max_hold=15봉(4h)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: ZigZag(스윙 피벗 탐지, 자체 구현 — % 되돌림 기준 표준 알고리즘), 선형대수(직선 방정식으로 미디언라인·평행선 값 매 봉 계산), ATR.
- 주의: 오더북/틱 불필요, OHLC만으로 구현 가능. **난이도는 중간** — ZigZag 피벗 재계산 시 "최근 확정 피벗"과 "아직 미확정(반전 대기중) 잠정 피벗"을 구분해야 룩어헤드를 피할 수 있음(피벗은 그 이후 가격이 deviation% 이상 반대로 움직여야 "확정"되므로, 확정 시점 기준으로만 채널을 그려야 함 — 반드시 백테스트 구현 시 이 시차를 지킬 것).

## 스카우트 메모
- **예상 표본 빈도**: ZigZag 5% 기준 4h봉이면 종목당 스윙피벗이 대략 월 2~4개 정도로 추정[추정치, 실측 필요] → 채널당 터치 기회는 더 드물어 종목당 **연 15~30건** 추정. 표준 7종목 풀링 시 연 100~200건 정도로 표본은 확보 가능할 전망이나 확정 전 실측 필요.
- **gross 엣지 가설**: 채널(등간격 평행선)이 실제 시장의 되돌림 구조를 반영한다면, 하단선 터치는 "추세 내 정상 되돌림의 끝"을 근사하는 자연스러운 지지선일 수 있음 — 이는 신규 발상이 아니라 채널/트렌드라인 매매의 일반 원리이며, 우리가 이미 보유한 `linear-regression-channel-breakout-swing`, `wedge-trendline-convergence-breakout-swing`과 **철학적으로 유사한 축**(추세선/채널 기반)이나, **3피벗 기반 등간격 평행 채널(피치포크)이라는 구체적 기하학적 구성은 처음** — 완전 신규 축은 아니고 기존 "채널/트렌드라인" 축의 새 변형으로 분류하는 것이 정확함.
- **엣지 대비 거래빈도**: 표본이 중간 수준(연 100~200건 풀링)이라 통계적 유의성 확보는 가능할 전망이나, 채널 작도 자체가 파라미터(zigzag_pct)에 민감해 과최적화 위험이 큼 — 스윕 시 결과 안정성 반드시 확인.
- **독립성/클러스터링 위험**: 매크로 급변동 시 여러 종목이 동시에 채널 붕괴(이탈)를 겪을 수 있어 이탈-반전형 신호는 클러스터링 위험 있음. 터치-반등형은 종목별 채널 형성 시점이 달라 상대적으로 독립적일 가능성.
- **표준 7종목 신호 충분성**: ZigZag 기반이라 원리상 모든 종목에서 피벗이 발생하나, 저유동성 알트(ADA·DOGE)는 노이즈가 커 채널이 자주 무효화(재작도)될 위험 — 실측 확인 필요.
- **지표 정의 수학적 타당성**: 미디언라인·평행선은 순수 기하학적 구성(피벗 좌표의 선형 보간)이라 정규화·데미닝 개념 자체가 해당 없음(원 가격 좌표계 그대로 사용).
- **전제의 내적 일관성 + 실측 대조 계획**: "터치-반등형"과 "이탈-반전형" 두 규칙이 동시에 활성화될 수 있어(하단선 터치 직후 곧바로 이탈하는 경우) 신호 충돌 가능 — 백테스트 시 두 규칙을 **별도 실행**해 각각 독립 검증하고, 동시신호 발생 빈도를 실측해 우선순위 규칙(예: 터치 먼저 확인 후 breakout_atr_mult 초과 시에만 이탈형으로 전환)을 명확히 할 것.
- **연 단위 이벤트 주의**: 해당 없음(채널 터치는 연중 반복 발생하는 구조적 신호).
- 우리 단타 슬리브와의 관계: 무관(스윙). 기존 채널/트렌드라인 계열과 축은 겹치나 구체적 구성(3피벗 등간격 평행채널)이 달라 완전 중복은 아님. 구현 난이도(ZigZag 확정 로직)가 중간이라 우선순위는 중간.
