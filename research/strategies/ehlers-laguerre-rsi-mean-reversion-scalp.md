# [단타] Ehlers Laguerre RSI 극단 반전 (Laguerre Filter 기반 저노이즈 RSI)

- **출처**: https://www.tradingview.com/script/vWG3tMJh-Laguerre-RSI-by-KivancOzbilgic-STRATEGY/ (TradingView, KivancOzbilgic 전략판) — 원 지표는 John F. Ehlers *Cybernetic Analysis for Stocks and Futures* (2004) "Laguerre RSI"
- **참여지표**: TradingView 좋아요/부스트 **49,888**, 댓글 **19,150** (2026-07 WebFetch로 원문 페이지 확인, 매우 높은 참여도 — 계정은 TradingView 유명 스크립터 KivancOzbilgic, 유료 신호방 아님)
- **백테스트 근거**: 없음(참여지표 기반). TradingView 페이지 자체에는 승률·PF 등 정량 백테스트 수치가 게시돼 있지 않음(원문 WebFetch로 확인, 수치 부재를 직접 확인함 — 지어내지 않음). Ehlers 원전은 4단 Laguerre 필터로 RSI의 랙(lag)과 노이즈를 줄인다는 이론적 주장만 있고 정량 백테스트는 원저서에 한정적으로만 소개됨. **정량 수치 원문 미확인** → 참여지표(좋아요 5만 근접)로만 스크리닝.
- **타임프레임**: 5m~15m 신호 (Ehlers 원전은 저타임프레임 노이즈 필터링 목적으로 설계) / 1h 추세 확인
- **시장/대상**: BTC·ETH·시총상위 알트 무기한

## 진입 규칙
- Laguerre 필터 4단 계산: `L0 = (1-γ)*price + γ*L0[1]`, `L1 = -γ*L0 + L0[1] + γ*L1[1]`, `L2 = -γ*L1 + L1[1] + γ*L2[1]`, `L3 = -γ*L2 + L2[1] + γ*L3[1]` (γ=alpha, 기본 0.2~0.5).
- Laguerre RSI = `CU/(CU+CD)` where `CU`=상승 성분 합(L0>L1이면 L0-L1, L1>L2면 +L1-L2, L2>L3면 +L2-L3), `CD`=하락 성분 합(반대 부호), 0~1 스케일.
- 롱: LRSI가 **0.15(=15) 아래에서 위로 상향 돌파**.
- 숏: LRSI가 **0.85(=85) 아래로 하향 돌파**.
- (옵션 필터, 원전엔 없으나 크립토 24/7 특성상 권장) 1h EMA200 방향과 같은 방향의 신호만 채택 — 반추세 남발 방지.

## 청산 규칙
- 익절: LRSI가 반대 극단 근접(롱은 0.85, 숏은 0.15) 또는 중앙값(0.5) 재돌파 시 부분청산.
- 손절: 진입가 대비 ATR(14) × 1.5.
- 시간 청산: 최대 보유 N봉(5m 기준 24~48봉 = 2~4시간) 초과 시 강제 청산.

## 파라미터
- gamma(alpha)=0.4 (범위 0.2~0.7, 값이 클수록 부드럽고 랙 증가)
- entry_low=15, entry_high=85 (범위 10~20 / 80~90)
- atr_stop_mult=1.5 (범위 1.0~2.5)
- trend_filter_ma=EMA200(1h) (선택)
- max_hold=36봉 (범위 12~60)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: Laguerre 4단 재귀 필터(종가 기반), ATR(14), 선택적 EMA200. 전부 바이낸스 OHLCV 캔들로 계산 가능.
- 주의: Laguerre 필터는 재귀식이라 최초 N봉 워밍업 필요(초기화 오차 주의). 오더북/틱 불필요.

## 스카우트 메모
- 강점: TradingView 참여지표(좋아요 5만 근접)가 이 리서치에서 확인한 스크립트 중 최상위권 — 커뮤니티 신뢰도 높음. 4단 필터로 일반 RSI보다 휩쏘(whipsaw)가 적다는 것이 Ehlers 이론의 핵심 주장. 규칙이 단순(임계값 크로스)해 구현 난이도 낮음.
- 의심점: 정량 백테스트 근거가 전혀 없어(원문 미확인) 참여지표에만 의존 — 반드시 자체 백테스트로 검증 필요. 원 지표는 "추세 강도 측정"(0.8 위 flat=강한 상승) 용도도 있어 단순 크로스만 쓰면 원저자 의도와 다를 수 있음. 감마(γ) 파라미터 민감도 미검증.
- 우리 단타 슬리브와의 관계: 기존 scalp15m(볼린저 돌파+거래량+OI, **모멘텀 추종**)과 반대로 **극단 되돌림 페이드** 성격 → 상호보완 후보. 다만 RSI2/눌림목 전략(rsi2-mean-reversion.md)과 "극단 오실레이터 반전"이라는 철학은 겹침(산식은 완전히 다름 — Laguerre 필터 vs 단순 RSI(2)+SMA200필터). 병행 채택 시 신호 상관관계 확인 권장.
