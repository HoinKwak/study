# [단타] OI가중 vs 등가중 유니버스 실현변동성 스프레드 레짐 게이트 스캘프

- **출처**: 자체 설계 — 데이터 필드 근거: `data.binance.vision` `metrics` 덤프 `sum_open_interest_
  value`(5분 간격, 7종목 실물 확인 완료) + klines 표준 OHLCV(1h, 실현변동성 계산용). 개념적 배경:
  전통 금융의 "시가총액가중 vs 동일가중 지수 스프레드"가 대형주 쏠림/시장 폭(market breadth) 판별에
  쓰인다는 것은 널리 알려진 프레임(예: S&P500 vs 동일가중 S&P500 스프레드)이나, **이를 크립토 선물
  유니버스의 OI가중 실현변동성 vs 등가중 실현변동성 스프레드로 변형해 BTC 스캘프 게이트로 쓰는 이
  정확한 규칙은 찾지 못함 — 스카우트 자체 설계, 지어내지 않음.**
  **기존 보유 스펙과의 차별점(중요)**: `oi-rolling-percentile-breadth-leverage-saturation-contrarian-
  swing.md`는 **단일 종목의 OI 자기 백분위**(레버리지 포화도)를 본다. `cross-sectional-beta-
  dispersion-regime-gate-trend-swing.md`는 **개별 종목의 BTC 대비 베타 값의 횡단면 분산**(가격
  코무브먼트 이산도)을 본다. `pca-correlation-eigenvalue-regime-trend-swing.md`는 **수익률 상관행렬의
  고유값 분해(PC1 지배도)**로 코무브먼트 "구조"를 본다. `idiosyncratic-volatility-btc-residual-regime-
  gate-swing.md`는 **개별 종목의 BTC 잔차 변동성**(단일 종목 기준)을 본다. 본 스펙은 이들과 달리
  **"변동성이 유니버스 내 어디(대형 OI 종목 vs 소형 OI 종목)에 집중되는가"를 재는 가중 스킴 비교**
  라는, 앞의 넷과는 질적으로 다른 구성이다 — 방향(베타)도, 코무브먼트 구조(상관행렬)도, 개별 잔차도
  아니라 **"실현변동성이라는 하나의 스칼라를, OI 비중으로 가중한 값과 균등가중한 값의 차이"**를 본다
  (전통금융의 대형주-소형주 변동성 쏠림 프레임을 처음 이식).

## 진입 규칙
- **종목별 실현변동성**: `rv_i(t) = stdev(1h 로그수익률, 최근 24봉)`(24h 윈도우).
- **OI 비중**: `w_i(t) = sum_open_interest_value_i(t) / Σ_j sum_open_interest_value_j(t)`(7종목 합 대비).
- **OI가중 실현변동성**: `rv_ow(t) = Σ_i w_i(t) × rv_i(t)`.
- **등가중 실현변동성**: `rv_ew(t) = mean_i(rv_i(t))`.
- **스프레드 z**: `spread(t) = rv_ow(t) - rv_ew(t)`, `spread_z(t) = zscore_90(spread(t))`(90봉=90h 롤링).
- **숏 우선(핵심 쏠림 리스크오프)**: `spread_z(t) >= 1.5`(변동성이 대형 OI 종목에 쏠림) → BTC 15m
  Donchian(20) 하단 이탈 시 숏만 허용(롱 신호 스킵).
- **롱 우선(국지적 소음, 핵심은 평온)**: `spread_z(t) <= -1.0`(변동성이 소형 알트에 쏠림, 핵심은 평온) →
  BTC 15m Donchian(20) 상단 돌파 시 롱만 허용(숏 신호 스킵).
- **중립**: `-1.0 < spread_z(t) < 1.5` → 양방향 모두 허용(대조군 성격).

## 청산 규칙
- 익절: ATR(14,15m)×1.4 트레일링.
- 손절: 진입가 ∓ATR(15m,14)×1.0.
- 시간 청산: `max_hold`=10봉(15m×10=2.5시간) 내 미도달 시 강제청산.

## 파라미터
- rv_window=24봉(1h, 범위 12~48)
- spread_z_window=90봉(1h, 범위 60~150)
- spread_z_short_th=1.5 (범위 1.0~2.0) · spread_z_long_th=-1.0 (범위 -1.5~-0.5)
- donchian_lookback=20봉(15m, 범위 15~30)
- atr_trail_mult=1.4, atr_stop_mult=1.0, max_hold=10봉

- 필요한 지표: 7종목 1h 로그수익률 stdev, `sum_open_interest_value`(5분→1h), 15m Donchian·ATR.
- 주의: 게이트 계산에 7종목 전체가 필요해 단일 종목 계열보다 연산량이 크다(기존 크로스섹셔널 스펙과
  동일 수준). 오더북/틱 불필요.

## 스카우트 메모
- **강점**: "가중 스킴 비교"라는 전통금융 프레임을 처음 이식해 기존 30여개 OI/변동성 계열과 통계적
  구성이 명확히 다르다. 중립 구간을 대조군으로 남겨 게이트의 부가가치를 자체 검증 가능하게 설계.
- **의심점**: BTC OI 비중이 압도적이면 OI가중 값이 사실상 BTC 변동성 재탕이 될 위험이 가장 크다 —
  1차 진단에서 반드시 먼저 확인하고, 상관 과도 시 즉시 폐기.
- 우리 슬리브와의 관계: 라이브 scalp15m과 진입 트리거(Donchian)는 단순하지만 게이트가 다르다 — 채택
  시 scalp15m의 방향 필터로 흡수 가능한 보완재 후보(대체는 아님).
