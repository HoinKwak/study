# [스윙] 볼린저 스퀴즈 → 변동성 확장 브레이크아웃 (일봉)

- **출처**: https://www.quantifiedstrategies.com/bollinger-band-squeeze-strategy/ (QuantifiedStrategies) / https://www.quantifiedstrategies.com/bitcoin-bollinger-bands-trading-strategy-performance-backtest/ / https://www.quantifiedstrategies.com/bollinger-bands-width-indicator/
- **참여지표**: - (백테스트 리서치 블로그, 다수 전략 정량검증으로 인지도 높음)
- **백테스트 근거**: QS BTC 볼린저 계열 백테스트 — 시장노출 34%만으로 ~50% CAGR($100k→$6.2M, 2026 기준 보고). 단 이 수치는 평균회귀형(밴드 되돌림) 버전; **본 스펙은 스퀴즈 후 브레이크아웃(추세)형**이라 별도 실측 필요. BandWidth < 5% = 스퀴즈, > 15% = 극단 변동성이라는 크립토 임계값은 QS BandWidth 문서 기준. **수수료 미포함 → 재검증 필수.**
- **타임프레임**: 1d 신호(원전·가장 견고) / 4h 로 조기 트리거 가능(빈도↑, 엣지 희석 주의).
- **시장/대상**: BTC·ETH 무기한 (유동성 큰 대형만)

## 진입 규칙
- 지표: 볼린저(기간 20, ±2σ). BandWidth = (상단−하단)/중간선.
- 스퀴즈 판정: BandWidth 가 최근 lookback(예 126봉≈6개월) 하위 percentile(예 하위 20%) 또는 절대값 < 0.05(5%) → "압축" 상태로 태깅.
- 롱: 압축 상태에서 **종가가 볼린저 상단(20,+2σ) 위로 마감** + 돌파봉 거래량 > 최근 20봉 평균 × 1.2 → 롱.
- 숏: 압축 상태에서 종가가 하단(20,−2σ) 아래로 마감 + 거래량 확인 → 숏.
- 게이트: 돌파 방향이 EMA200(일봉) 방향과 일치할 때만(역추세 돌파 배제, 옵션).

## 청산 규칙
- 익절: 볼린저 중간선(20SMA) 트레일링 — 종가가 중간선 반대로 마감하면 청산. 또는 밴드폭이 다시 압축(BandWidth 하위 20%)되면 부분청산.
- 손절: 돌파봉 반대 극단(롱=돌파봉 저가, 숏=돌파봉 고가) 또는 −2×ATR(14).
- 시간 청산: 돌파 후 N봉(예 3봉) 내 추세 지속 실패(중간선 회귀)면 청산 → "가짜 돌파" 컷.

## 파라미터
- bb_period=20 (범위 20~30), bb_std=2.0 (범위 2.0~2.5)
- bw_lookback=126 (범위 60~180), squeeze_pct=0.20 (범위 0.10~0.30) 또는 bw_abs=0.05
- vol_mult=1.2 (범위 1.0~1.5), atr_mult_sl=2.0 (범위 1.5~3.0)
- ema_trend=200 (게이트 on/off)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 볼린저(SMA+표준편차), BandWidth, ATR(14), 거래량 MA, EMA200. **전부 바이낸스 REST OHLCV 로 계산 가능.** 오더북/틱/청산 불필요.
- 난이도: 낮음. 상태머신(압축→돌파→트레일)만 관리.

## 스카우트 메모
- 강점: 저빈도(스퀴즈는 드묾) + 변동성 확장 국면만 진입 → **큰 방향성 이동으로 0.14% 왕복 수수료를 압도**하기 쉬운 전형적 구조. 일봉이라 매매 빈도 낮음(연 수십 회).
- 의심점: 크립토는 가짜 돌파가 잦음 → 거래량·EMA200 게이트와 "N봉 내 지속 실패 컷"이 핵심. 스퀴즈 percentile 파라미터 과최적화 위험.
- 우리 스윙 슬리브와의 관계: **보완**. 기존 스윙은 RSI 극단 역추세(평균회귀) 진입이라 추세 초입을 놓침 → 본 전략은 변동성 압축 후 추세 확장을 정면으로 노림(방향성 상반, 헤지/분산 효과). Supertrend 트레일과 로직 충돌 없음(중간선 트레일 사용).
