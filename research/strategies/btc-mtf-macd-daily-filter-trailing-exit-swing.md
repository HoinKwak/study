# [스윙] BTC 멀티타임프레임 MACD(일봉 필터 + 1시간 진입) + 음봉 트레일링 청산

- **출처**: QuantPedia, "How to Design a Simple Multi-Timeframe Trend Strategy on Bitcoin" https://quantpedia.com/how-to-design-a-simple-multi-timeframe-trend-strategy-on-bitcoin/ (**WebFetch로 원문 확인 완료**)
- **참여지표**: - (QuantPedia는 퀀트 리서치 기관 자체 백테스트, SNS 참여지표 미집계. 이 목록 내에서 QuantPedia 출처는 방법론 신뢰도 상위권으로 취급)
- **백테스트 근거**: **원문 WebFetch로 직접 확인.** 표본기간 **2018-12 ~ 2025-11**(비트코인). 세 버전 비교:
  - **MACD Pure**(1h MACD 시그널크로스만): 연수익률 4.6% / 샤프 0.33 / 칼마 0.19 / MDD -23.9% / 거래수 2,262
  - **D1H1 Filter**(일봉 MACD 방향 필터 추가): 연수익률 6.6% / 샤프 0.80 / MDD -12.4% / 거래수 ~1,000
  - **D1H1 + Trailing(음봉청산)**(진입 동일 + 청산을 "1시간봉이 음봉으로 마감하는 첫 봉의 종가"로 변경): **샤프 1.07 / 칼마 0.87**(정확한 연수익률·MDD·거래수는 원문 요약에 수치로 명시되지 않음 — 재확인 필요)
  - **핵심 시사점**: 순수 MACD 크로스는 약하지만(샤프 0.33), **① 일봉 상위추세 필터를 추가하면 샤프 2배 이상 개선**, **② 청산을 지표 재크로스가 아니라 가격행동(음봉 발생) 기반으로 바꾸면 추가 개선** — 필터·청산 설계의 중요성을 보여주는 사례.
  - 표본이 BTC 단일자산·특정 기간(2018~2025)에 국한 — 표본외검증(다른 자산·기간)은 원문에 명시 없음, 우리 프레임워크 재검증 필수.
- **타임프레임**: 1h 신호 진입 / 1d MACD 방향 확인(필터)
- **시장/대상**: BTC 무기한(원 연구 대상). 확장 시 ETH 등 메이저로 별도 검증 필요.

## 진입 규칙
- **상위TF 필터(1d)**: 일봉 MACD(12,26,9) 라인이 시그널선 **위**에 있으면 롱만 허용(그 반대는 숏만 허용 — 원문은 롱 중심 서술이나 무기한 시장 대칭 확장 제안).
- **롱**: 일봉 MACD 라인 > 일봉 시그널선 **그리고** 1시간봉 MACD(12,26,9) 라인이 1시간봉 시그널선을 **상향 돌파**(골든크로스) → 그 1시간봉 종가에 진입.
- **숏**: 일봉 MACD 라인 < 일봉 시그널선 **그리고** 1시간봉 MACD 라인이 1시간봉 시그널선을 **하향 돌파** → 그 1시간봉 종가에 진입.
- 일봉 필터와 어긋나는 방향의 크로스는 무시(역추세 진입 배제).

## 청산 규칙
- **핵심 청산(원문 최종 버전)**: 진입 후 **1시간봉이 처음으로 반대색 캔들(롱 보유 중이면 음봉, 숏 보유 중이면 양봉)로 마감하는 시점의 종가**에서 청산. 즉 지표 재크로스를 기다리지 않고 가격 모멘텀이 한 번이라도 꺾이면 즉시 트레일링 청산 — 원문에서 샤프비율을 가장 크게 개선시킨 요소.
- 손절: 원문 미명시 — 무기한 레버리지 특성상 보강 제안: 진입가 대비 -(2.0)×ATR(14, 1h) 하드 스톱 병행.
- 시간 청산: 없음(음봉/양봉 반전 청산이 사실상의 빠른 시간청산 역할).

## 파라미터
- macd_fast=12, macd_slow=26, macd_signal=9 (1h·1d 동일 표준값)
- daily_filter=on (필수, 원문 핵심 개선 요소)
- exit_mode=first_opposite_candle (원문 채택 방식)
- sl_atr_mult=2.0 (범위 1.5~3.0, 우리 보강 제안)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: MACD(12,26,9) — 1h·1d 두 타임프레임에서 각각 계산. ATR14(손절 보강용).
- 주의: 바이낸스 REST 1h·1d 캔들만으로 완전 충족. 멀티TF 정렬(1d 값을 1h 각 봉에 forward-fill)만 정확히 처리하면 됨 — 우리 기존 멀티TF 전략들(elder-triple-screen 등)과 동일 패턴 재사용 가능.

## 스카우트 메모
- 강점: **이번 라운드 중 가장 신뢰도 높은 백테스트 근거**(QuantPedia 원문 WebFetch 직접 확인, 정확한 샤프·MDD·거래수 수치 존재, 7년 표본). "음봉 발생 즉시 청산"이라는 단순하지만 원문이 실제로 효과를 검증한 청산 설계는 우리 청산 로직에도 참고할 가치가 있음.
- 의심점: 절대 수익률(연 4.6~6.6%)·거래수는 원문 표에 완전히 기재되지 않아 일부 추정 여지 있고, 샤프 0.33~1.07 자체는 "우수"라기보다 "양호~보통" 수준 — 수수료(왕복 0.14%)를 반영하면 MACD Pure(거래수 2,262회/7년≈연 320회)는 손익 잠식 우려, D1H1 Filter(연 ~140회)가 더 현실적.
- 우리 슬리브와의 관계: 기존 `macd-rsi-200sma-trend-filter-swing.md`(4h+1d, RSI+SMA200 필터, 고정 R:R 청산, 출처 신뢰도 낮음·재확인 실패)와 **컨셉은 유사하나 필터·TF·청산 메커니즘이 다름**(RSI 대신 일봉 MACD 방향, 고정 R:R 대신 음봉 트레일링) — 대체재보다는 **같은 MACD 계열의 검증된 대안**으로 병행 백테스트 후 우수한 쪽 채택 권장. **이번 발굴 중 백테스트 우선순위 1순위 추천.**
