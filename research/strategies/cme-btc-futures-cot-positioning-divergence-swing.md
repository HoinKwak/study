## 진입 규칙
- **데이터**: CFTC COT 리포트(Legacy 또는 Disaggregated, "Bitcoin - Chicago Mercantile Exchange") 중 **레버리지드펀드(Leveraged Funds)** 순포지션(롱-숏)을 미결제약정(OI) 대비 비율로 정규화, 최근 3년(또는 CME BTC 선물 상장 2017-12 이후 전체) 롤링 윈도우에서 퍼센타일 산출.
- 롱: 레버리지드펀드 순포지션 비율이 **하위 10퍼센타일**(과도한 순숏) **AND** 자산운용사(Asset Manager)/상업(Commercial) 그룹이 반대로 순롱 또는 중립일 때(다이버전스 확인) — 매주 금요일 데이터 발표 후 다음 거래일 진입.
- 숏: 레버리지드펀드 순포지션 비율이 **상위 90퍼센타일**(과도한 순롱) **AND** 반대 그룹 다이버전스 확인 시.
- **단독 극단만으로는 진입하지 않음** — 반드시 그룹 간 다이버전스(한쪽은 극단, 다른 쪽은 반대/중립)를 요구해 "전체 시장이 같은 방향으로 쏠린" 단순 모멘텀과 구분.

## 청산 규칙
- 익절: 진입가 대비 +6~10% 도달 시.
- 손절: 진입가 대비 -6% 반대 이동 시(다이버전스가 계속 심화되며 추세가 이어지는 실패 케이스 대비 타이트하게).
- 시간/조건 청산: 다음 COT 발표에서 극단 퍼센타일 해소(50퍼센타일 부근 복귀) 시 청산, 또는 최대 4주 보유.

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 없음(가격 지표 아님) — **CFTC COT 데이터를 매주 별도로 취득**해야 함(CFTC.gov Socrata 공개 API 또는 더블록 데이터 페이지 스크레이핑). 바이낸스 REST로는 얻을 수 없는 데이터.
- 주의: ⚠️ **커버리지 한계**(prochart.io 원문 명시): "CME 데이터는 크립토 전체 포지셔닝의 일부일 뿐 — 실제 거래 대부분은 현물거래소·역외거래소에서 이뤄지며 CFTC에 보고되지 않음". 즉 CME 선물(기관 중심)과 바이낸스 무기한(리테일+기관 혼합) 시장의 포지셔닝이 서로 다를 수 있어, 이 신호가 바이낸스 가격에 그대로 전이된다는 보장이 없음. 또한 데이터가 주간이라 **신호가 발표 시점 기준 며칠 지연**된 상태(화요일 스냅샷 → 금요일 발표)라는 룩어헤드 리스크에 특히 주의해 구현해야 함.

## 스카우트 메모
- **강점**: 기존 255개 스펙 중 **규제기관 공식 포지셔닝 데이터(CFTC)를 쓰는 스펙이 전무** — 완전히 다른 데이터 소스이자, "관리형자금 vs 상업헤저" 다이버전스는 전통 상품선물 시장에서 수십 년간 회자된 구조적 논리(추세추종 자금은 고점에서 몰리고 헤저는 반대로 움직이는 경향)로 메커니즘 자체는 낯설지 않음. 주간 데이터라 저빈도 → 수수료 부담 최소.
- **의심점**: **이번 라운드에서 실제로 정량 인용 환각을 걸러낸 사례**(WebSearch 요약의 "60~70% 승률"이 원문에 없음을 WebFetch로 확인해 폐기) — 이는 역설적으로 이 전략에 대한 신뢰를 낮춘다(그럴듯한 승률 수치가 실제로는 근거 없이 떠도는 것일 수 있음을 시사). CME 데이터와 바이낸스 시장 간 대표성 괴리, 데이터 취득 파이프라인 신규 구축 필요성(CFTC API 안정성 미검증)까지 고려하면 **구현 난이도·불확실성이 이번 5개 중 가장 높음**.
- **우리 슬리브와의 관계**: `long-short-account-ratio-contrarian-swing`(바이낸스 자체 롱숏비율)·`top-trader-position-ratio-smart-money-momentum-swing`과 "포지셔닝 컨트래리언"이라는 철학은 유사하나 **데이터 출처(CME/CFTC vs 바이낸스 자체 지표)가 완전히 다름**. 다만 구현 복잡도 대비 근거가 약해 백테스트 우선순위는 이번 5개 중 최하위로 판단.
