# [단타] 바이낸스-OKX 크로스거래소 OI 성장률 괴리 브레이크아웃

- **출처**: 데이터 — OKX 공식 공개(무인증) REST API. 2026-08-10 직접 curl로 실호출해 확인:
  - 현재 OI: `https://www.okx.com/api/v5/public/open-interest?instType=SWAP&instId=BTC-USDT-SWAP` (및 ETH/BNB/SOL/XRP/DOGE/ADA-USDT-SWAP 전부 정상 응답 확인 — 표준 7종목 전부 OKX에도 USDT마진 무기한 존재).
  - 과거 OI 히스토리: `https://www.okx.com/api/v5/rubik/stat/contracts/open-interest-history?instId=BTC-USDT-SWAP&period=1D` — 문서: https://www.okx.com/docs-v5/en/#trading-statistics-rest-api-get-contracts-open-interest-and-volume . **직접 curl로 이분탐색해 실측한 결과 데이터 시작점은 대략 2023-12-31~2024-01-01**(2023-12-01 이전 구간은 빈 배열, 2023-12-31부터 값 존재 확인) — 바이낸스 `metrics` 덤프(2020-09~)보다 훨씬 짧은 **약 2.6년치**만 확보 가능. period 옵션은 5m/1H/1D 등 지원(1H 응답 컬럼: `[ts, oi(계약수), oiCcy(코인수), oiUsd]` 확인됨).
  - **참고(폐기)**: OKX 펀딩레이트 히스토리(`/api/v5/public/funding-rate-history`)도 함께 실측했으나 `after` 파라미터로 페이지네이션해도 **약 3~6개월치만 조회 가능**(2026-02~2026-05 경계에서 데이터 끊김 확인)해 다년 백테스트에 부적합 — 이 스펙에서는 **펀딩 스프레드는 채택하지 않고 OI만 사용**.
  - 개념 배경 — 크로스거래소 OI 성장률 괴리가 특정 거래소의 국지적 레버리지 쏠림(그 거래소 특유의 리테일/봇 트레이더 군집 행동)을 반영한다는 것은 CoinGlass·Coinalyze 등 파생 데이터 플랫폼이 통상 강조하는 프레임(정성적, 정량 백테스트 원문 없음).
- **참여지표**: - (자체 설계, 데이터 필드는 거래소 공식 문서 기반)
- **백테스트 근거**: **없음(자체 설계, 정량 근거 지어내지 않음)**. 크로스거래소 OI 괴리를 방향성 트레이드로 번역한 이 정확한 규칙은 스카우트가 자체 설계 — 채택 전 자체 백테스트 필수.
- **타임프레임**: 1h 신호 / 4h 확인 (OI 히스토리 최소 해상도가 5m~1h대라 1m/5m 단타에는 부적합, 1h가 현실적 하한).
- **시장/대상**: BTC·ETH·BNB·SOL·XRP·DOGE·ADA 무기한 (OKX USDT-마진 스왑에 표준 7종목 전부 존재 실측 확인, 2026-08-10).

## 진입 규칙
- 바이낸스 OI(라이브 `openInterestHist`/백테스트 `metrics` 덤프의 `sum_open_interest`)와 OKX OI(`open-interest-history`의 `oiCcy`, 코인 수량 기준으로 통일)를 각각 최근 `roc_window`=24봉(1h) 대비 % 변화율로 계산: `binance_oi_roc`, `okx_oi_roc`.
- 괴리: `oi_div = binance_oi_roc - okx_oi_roc`.
- **롱(바이낸스 국지적 롱 쏠림 추종)**: `binance_oi_roc >= +oi_roc_th`(예 +5%) **AND** `oi_div >= +div_th`(예 +3%p, 즉 바이낸스가 OKX보다 유의미하게 더 빠르게 OI 증가) **AND** 바이낸스 가격이 동일 구간 상승(가격 ROC > 0) → 바이낸스 특유의 신규 매수세 유입으로 해석해 롱.
- **숏(바이낸스 국지적 숏 쏠림 추종)**: `binance_oi_roc <= -oi_roc_th` **AND** `oi_div <= -div_th` **AND** 가격 ROC < 0 → 숏.
- **대조군 필수**: 위는 "괴리 방향 추종(순방향)" 가설이다. 반대 가설(바이낸스가 OKX보다 과도하게 빠르게 쏠리는 것은 국지적 과열이라 페이드해야 한다)도 배제 못 하므로 **정방향·반전 대조군을 반드시 함께 백테스트**.

## 청산 규칙
- 익절: ATR(14, 1h) × 2.0 트레일링, 또는 R:R `rr_target`=2.0 도달.
- 손절: 진입가 ∓ ATR(14,1h) × 1.3, 또는 신호봉 시가.
- 시간 청산: `max_hold`=12봉(1h×12=12h) 내 미도달 시 강제청산(괴리는 국지적·단기 현상이라는 전제).

## 파라미터
- roc_window=24봉(1h, 범위 12~48)
- oi_roc_th=5% (범위 3~8%)
- div_th=3%p (범위 2~6%p)
- atr_trail_mult=2.0 (범위 1.5~3.0)
- atr_stop_mult=1.3 (범위 1.0~2.0)
- rr_target=2.0 (범위 1.5~2.5)
- max_hold=12봉(1h 기준)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 바이낸스 OI(기존 인프라 재사용, `metrics` 덤프 또는 `openInterestHist`), **OKX OI 히스토리(신규 커넥터 필요)**, ATR.
- 주의: **OKX는 바이낸스처럼 다년치 벌크 CSV 덤프(`data.binance.vision` 격)를 공개하지 않음** — REST 페이지네이션(`begin`/`end`/`limit≤100`)으로 직접 긁어야 하며, 실측 결과 **2023-12말 이전 데이터가 없어 최대 약 2.6년치**만 백테스트 가능(바이낸스 단독 스펙들의 4.5년 대비 짧음, IS/OOS 분할 시 표본이 더 얇아짐 유의). OKX 1H OI 데이터는 봉 종가 시점 스냅샷으로 보임(정확한 집계 기준 미문서화 — 바이낸스 OI와 타임스탬프 정렬 시 오차 가능성 점검 필요). 오더북·틱·실시간청산 불필요.

## 스카우트 메모
- **예상 표본 빈도**: [추정] `binance_oi_roc≥5%`(24시간 OI 5% 이상 변화)는 변동성 국면에 종목당 월 수~십여 회 수준으로 추정되나, 여기에 `oi_div≥3%p` 크로스거래소 괴리 조건까지 AND로 요구하므로 **종목당 연 20~60건 수준**으로 [추정](실측 필요). 과거 라운드에서 "예상보다 20~200배 많이 나온" 전례(Hikkake·인덱스스냅백)가 반복될 위험을 감안해 **1차로 트리거 횟수부터 세어 확인**을 최우선 권고.
- **gross 엣지 가설**: 바이낸스와 OKX는 같은 기초자산을 거래하지만 사용자층(지역·리테일/기관 비중·봇 전략)이 다르므로, 한쪽 거래소에서만 OI가 급증하는 것은 "그 거래소 특유의 국지적 쏠림"(예: 특정 지역 리테일 붐, 특정 봇 군집)일 가능성이 있고 이는 통상 차익거래로 빠르게 마모되지 않는(펀딩 아비트라지처럼 즉시 차익거래되는 구조가 아닌) 방향성 정보일 수 있다는 논리 — 다만 **검증되지 않은 가정**이며, 반대로 "노이즈일 뿐"일 가능성도 동일하게 큼.
- **엣지 대비 거래빈도**: 연 20~60건 추정으로 저빈도에 속해 수수료 내성은 상대적으로 좋을 것으로 기대되나, 최근 라운드 교훈(OI컨퍼메이션 gross1.395·t유의였는데도 연200건에 net 0.688로 무너짐)을 감안하면 **저빈도라도 gross 엣지 크기가 작으면 여전히 취약** — gross PF부터 반드시 확인.
- **독립성/클러스터링 위험**: 거래소 간 OI 괴리도 매크로 이벤트(청산 캐스케이드 등) 시 여러 종목에서 동시에 발생할 수 있음(단, 크로스거래소 "괴리"라는 조건 자체가 시장 전체 동조화보다는 거래소별 특이성을 요구하므로 기존 단일거래소 매크로 스펙들보다는 클러스터링이 약할 가능성 — 실측 필요).
- **7종목 신호 충분성**: OI 데이터 존재는 7종목 모두 확인(OKX·바이낸스 둘 다), 다만 OKX 알트(DOGE·ADA 등) OI 유동성이 BTC·ETH 대비 얇아 노이즈가 클 수 있음.
- **강점**: 완전히 새로운 데이터 원천(바이낸스 밖 첫 거래소 간 비교, DVOL과 마찬가지로 바이낸스 생태계 밖). 라이브 매매는 바이낸스에서만 이뤄지므로 OKX 데이터는 순수 신호원으로만 쓰여 실행 리스크 없음.
- **의심점**: 정량 근거 전무(자체 설계), OKX 히스토리 깊이가 2.6년으로 짧아 IS/OOS 분할 시 표본 부족 위험 큼, OKX 신규 커넥터 구축 비용 있음, 두 거래소 OI의 "코인 수량 기준" 정규화가 정확히 동일 정의인지(콘트랙트 승수 차이 등) 확인 필요.
- **우리 단타 슬리브와의 관계**: 기존 `oi-price-expansion-confluence-trend-continuation-scalp.md`(단일거래소 OI×가격 컨퍼메이션)와 유사한 "OI 확장 추종" 논리이나 **비교축이 가격이 아니라 다른 거래소**라는 점에서 데이터 원천이 명확히 다름 — 두 신호의 상관관계 점검 권고.
