# [스윙] 포인트앤피겨(P&F) 더블탑/더블바텀 브레이크아웃

  https://gocharting.com/docs/charting/chart-types/points-figures (WebFetch/WebSearch로 확인,
  박스크기·리버설 규칙·더블탑/더블바텀 브레이크아웃 정의 원문 확인) /

  https://www.tradingview.com/script/DFdvBC9B-Point-and-Figure-PnF-Momentum/ (WebFetch 확인 —
  단, 이 스크립트는 모멘텀 표시용이며 진입/청산 신호는 자체 정의하지 않음. 참여지표(조회/부스트) 수치가
  페이지 파싱상 상충되어(조회 442 vs 부스트 11,309로 순서가 뒤바뀐 듯) **신뢰도 낮아 인용하지 않음**).
- **참여지표**: 특정 스크립트 수치 인용 보류(위 사유). P&F 자체는 150년 이상 사용된 표준 차트기법으로
  다수 브로커/교육 자료에 정착돼 있음 — 정성적 채택 근거로만 사용.
- **백테스트 근거**: **없음(개념 기반)**. 원문들은 "박스크기가 변동성 대비 너무 작으면 다이신호가
  범람한다" 는 정성적 주의만 제공, 정량 수치 부재. 아래 규칙은 원문의 표준 P&F 방법론(박스크기·3박스
  리버설·더블탑/바텀 브레이크아웃 정의)을 **우리 프레임에서 코딩 가능하도록 구체화**한 것 — 반드시
  먼저 검증.
- **타임프레임**: 원천 OHLC는 4h(박스 갱신용), P&F 컬럼은 시간축 없이 가격변동만 반영(합성 차트).
  보유기간은 통상 수일~수주(스윙).
- **시장/대상**: BTC·ETH·유동성 상위 알트 무기한.

## 진입 규칙
- **박스 크기**: ATR(14, 4h) × 1.0 을 박스 단위로 사용(자산별 변동성에 자동 적응, 고정 %박스 대비 크립토 변동성 급변 시 더 안정적).
- **리버설**: 표준 3박스 리버설(현재 컬럼과 반대방향으로 3박스 이상 움직여야 컬럼 전환).
- P&F 차트를 종가 기준으로 합성: 상승 컬럼(X)이 진행 중이면 종가가 마지막 박스보다 1박스 이상 오를 때마다 X 추가, 하락 3박스 이상이면 O 컬럼으로 전환(반대도 동일).
- **롱**: 현재 X 컬럼의 고점이 **직전 X 컬럼의 고점을 1박스 이상 상회**(더블탑 브레이크아웃) → 롱 진입. 이전 X 컬럼이 2개 연속(트리플탑) 상회 시 신뢰도 가중(선택 필터).
- **숏**: 현재 O 컬럼의 저점이 **직전 O 컬럼의 저점을 1박스 이상 하회**(더블바텀 브레이크다운) → 숏 진입.
- 게이트: 1d EMA200 대비 가격 위치가 진입 방향과 일치할 때만(역추세 브레이크아웃 제외, 선택).

## 청산 규칙
- 익절: **수직 카운트법**(vertical count) — 브레이크아웃 컬럼의 박스 개수 × 박스크기 × 배수(기본 1.0)를 브레이크아웃 지점에서 더해(롱)/빼(숏) 목표가 산출. 목표 도달 시 50% 익절, 잔량은 트레일링.
- 손절: 브레이크아웃 트리거가 된 직전 컬럼의 반대 극값(직전 O 컬럼 저점 하회 시 롱 손절 / 직전 X 컬럼 고점 상회 시 숏 손절) — 통상 진입가 대비 1.5~3박스 폭.
- 시간 청산: 컬럼이 반대방향으로 3박스 리버설 발생 시(추세 종료 신호) 즉시 청산.

## 파라미터
- box_size_mode=ATR(14,4h)×1.0 (범위 0.5~2.0×ATR, 또는 고정% 대안 1~3%)
- reversal_boxes=3 (범위 2~4)
- vertical_count_mult=1.0 (범위 0.5~2.0)
- stop_boxes=1.5~3 (직전 반대컬럼 극값 기준)
- htf_trend_filter=EMA200(1d) on/off

## 코딩 난이도 / 데이터 요구
- 필요한 지표: ATR(14,4h), EMA200(1d). P&F 컬럼 합성 로직(상태기계: 현재 컬럼 방향·박스레벨·리버설 카운트)은 직접 구현 필요 — 표준 인디케이터가 아니므로 **자체 상태기계 코드 작성 필요**(난이도 중상, 룩어헤드 주의: 종가 확정 후에만 컬럼 갱신).
- 주의: 바이낸스 REST 4h/1d 캔들로 충족. 오더북/틱 불필요. 다만 P&F는 통상 틱/인트라바 가격으로 구성되는데 여기선 **종가 기준 근사**(렌코 스펙과 동일한 한계) — 브릭 내부 노이즈 무시로 실제 P&F와 다소 괴리 가능, 백테스트 시 명시.

## 스카우트 메모
- 강점: 시간축이 아닌 순수 가격변동 기반이라 **크립토 24/7 노이즈·저유동 야간 구간의 가짜신호를 자연히 필터링**하는 효과 기대. 더블탑/바텀 브레이크아웃은 규칙이 명확하고 재현 가능.
- 의심점: 정량 백테스트 근거 전무(순수 개념 기반), 참여지표도 신뢰도 낮아 인용 보류 — **우선순위는 렌코(이미 보유) 대비 낮게 잡되, 렌코와 상관관계 낮은 신호 소스로서 분산 가치는 있음**. 종가 기준 근사의 룩어헤드/브릭 재구성 버그 위험(렌코 스펙과 동일 주의) 큼 — 백테스트 리뷰어 정합성 점검 필수.
- 우리 단타 슬리브와의 관계: 스윙 슬리브 후보. 기존 렌코 브레이크아웃(swing)과 컨셉 계열은 유사(가격기반 합성차트)하나 컬럼 구성 규칙(3박스 리버설·더블탑/바텀)이 달라 **보완재**로 취급 가능. 동시 채택시 상관 신호 여부 먼저 확인 필요.
