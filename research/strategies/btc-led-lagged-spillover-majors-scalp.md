# [단타] BTC 주도 크로스에셋 모멘텀 전이(리드-래그 스필오버) 스캘핑

- **출처**: 학술 문헌(정성적 근거, WebFetch로 원문 전체 확인은 실패 — 아래 상세): "Bitcoin's lagged effect on altcoins: a short-term research" https://dergipark.org.tr/en/download/article-file/2206815 (PDF 파싱 실패로 계수·유의성 직접 확인 불가) / "Bitcoin and Main Altcoins: Causality and Trading Strategies" (ResearchGate) https://www.researchgate.net/publication/394315102_Bitcoin_and_Main_Altcoins_Causality_and_Trading_Strategies (403으로 WebFetch 차단) / "Lead-Lag relationship between Bitcoin and Ethereum" (ScienceDirect) https://www.sciencedirect.com/science/article/abs/pii/S0275531919300522
- **참여지표**: - (학술논문, 조회수 개념 없음)
- **백테스트 근거**: **⚠️ 정량 수치 원문 미확인 — WebSearch 스니펫 수준으로만 확인, 직접 대조 불가.** 확인된 정성적 사실(검색엔진 스니펫, 원문 대조 실패로 신뢰도 중간):
  - "BTC의 일별 지연값(lagged value)이 ETH·ADA·BNB에 유의한 양(+)의 상관을 가지나, XRP는 이런 관계 없음"
  - "BTC-BNB는 좌측 꼬리(급락 구간)에서 BTC→BNB 인과, 중앙 구간은 무의미, 우측 꼬리(급등 구간)는 양방향 인과" (분위수 기반, ScienceDirect 관련논문)
  - "BTC-ETH 시차 관계는 존재하나 실제 거래로 차익거래하기엔 미미하다"(1시간/일봉 데이터 기준 논문 결론 — 즉 **단순 시차 매매의 엣지가 약할 수 있음을 시사, 주의 필요**)
  - ResearchGate 논문은 "9 votes 투표시스템", "All(전체 코인 지연정보 활용)", "Dynamic 시스템" 등 구체 전략과 샤프비율을 다룬다고 검색 스니펫에 언급되나 **PDF 403 차단으로 정확한 수치·규칙 원문 확인 실패** → 채택하지 않음.
  - **결론: 본 스펙의 정량 근거는 없음(참여지표도 없음). "메커니즘의 학술적 타당성"만 근거로 채택** — 구체 파라미터(지연봉수·임계값)는 **아래 설계 제안(원문 아님, 우리 자체 설계)**이며 백테스트로 처음부터 검증해야 함.
- **타임프레임**: 15m 신호(BTC 트리거) / 15m~1h 확인(팔로워 자산 진입).
- **시장/대상**: 5대 메이저 한정 — **BTC를 트리거(리더)**, ETH/SOL/XRP/BNB를 **팔로워(래거)**로 설계(단, 문헌상 XRP는 BTC와 유의한 지연관계 없다는 지적 있어 XRP는 제외하거나 낮은 가중치 권장).

## 진입 규칙
- **BTC 트리거 신호**: BTC 15m 종가가 최근 20봉 레인지 상/하단을 **거래량 급증(20MA×1.5 이상)** 동반해 돌파(강한 방향성 확인).
- 롱(팔로워 자산 ETH/SOL/BNB): BTC 상방 트리거 발생 후 **1~3봉(15m 기준 15~45분) 이내**, 해당 팔로워 자산이 **아직 자체 신고가를 만들지 않은 상태**(스필오버 지연 확인)에서 **팔로워 자산 자체 3봉 모멘텀(3봉 전 대비 현재가 ROC)이 양(+)** 이면 팔로워 자산 롱 진입.
- 숏: 대칭(BTC 하방 트리거 + 팔로워 3봉 ROC 음수) 시 팔로워 자산 숏.
- **필터(다중조건, 단일지표 크로스 방지)**: ①BTC 트리거봉 거래량 급증 ②팔로워 자산이 BTC 대비 상대적으로 덜 움직인 상태(팔로워 ATR 대비 이동폭이 BTC ATR 대비 이동폭보다 작음 — "아직 안 따라간" 확인) ③팔로워 자산 자체가 극단 과매수/과매도(RSI14 미도달)가 아닐 것.

## 청산 규칙
- 익절: BTC 트리거봉의 돌파폭(레인지 상/하단 이탈폭)을 팔로워 자산에 비례 환산(베타 근사 1.0)한 1.0~1.5배 measured move, 또는 팔로워 자산이 자체 신고가/신저가 갱신 시 절반 익절 후 트레일.
- 손절: 팔로워 자산 진입가 대비 -1.0×ATR(14, 15m) 또는 BTC 트리거가 무효화(BTC가 돌파 반대 방향으로 레인지 재진입) 시 즉시 청산.
- 시간/조건 청산: 진입 후 8봉(15m×8=2시간) 내 measured move 미달성 시 청산(스필오버 효과는 단기간에만 유효하다는 문헌 시사 반영).

## 파라미터
- btc_range_lookback=20봉 (범위 15~30)
- btc_vol_mult=1.5 (범위 1.2~2.0)
- spillover_lag_bars=1~3봉 (범위, 핵심 튜닝 대상 — 문헌은 정확한 최적 시차 미제공)
- follower_momentum_bars=3 (범위 2~5)
- follower_lag_atr_ratio=0.7 (팔로워/BTC 이동폭 비율 상한, "아직 안 따라감" 판정 — 설계값)
- rr_target=1.0~1.5, stop_atr_mult=1.0
- max_hold_bars=8 (15m 기준)
- exclude_symbols=XRP (선택, 문헌상 BTC와 유의한 시차관계 없다는 지적 반영)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 롤링 레인지(고저), 거래량 MA, ATR(14), N봉 ROC(모멘텀), 자산간 이동폭 비율 계산. 전부 캔들+거래량으로 충족.
- 주의: **바이낸스 REST 캔들+거래량(5개 심볼 동시 조회)으로 충족.** 오더북/틱/실시간청산 불필요. 다만 **BTC와 팔로워 자산 캔들의 타임스탬프 동기화**(둘 다 같은 15m 봉 마감 시각)를 정확히 맞춰야 룩어헤드 편향 없이 시차효과를 검증 가능 — 백테스트 시 이 부분 버그 주의(계측 포인트).

## 스카우트 메모
- **강점**: 5대 메이저 한정이라는 새 방향에 가장 직접적으로 부합(BTC가 다른 메이저를 리드하는 구조적 특성 활용). 다중자산 확인(BTC 트리거 + 팔로워 지연 미반영 확인 + 팔로워 자체 모멘텀)이라 단일지표 크로스가 아님. 청산도 시간제한이 있어 저확률 구간에서 자본이 묶이지 않음.
- **의심점**: **가장 큰 리스크는 정량 백테스트 근거가 전무하다는 것.** 인용 문헌 중 하나(BTC-ETH 리드-래그)는 오히려 "차익거래로 활용하기엔 관계가 미미하다"고 결론지어, 스필오버가 존재해도 수수료를 이기기엔 부족할 가능성을 문헌 스스로 시사함 — **저빈도·고R 확인 없이 그대로 쓰면 실패할 수 있음.** 지연 봉수(spillover_lag_bars)·팔로워 판정 임계값 모두 원문 근거 없는 설계값이라 파라미터 스윕이 필수.
- **우리 슬리브와의 관계**: 완전 신규 메커니즘(자산간 시차 스필오버, 단일자산 지표 아님). 기존 `btc-eth-zscore-spread.md`(페어 평균회귀, 방향 무관 델타중립)·`cross-sectional-altcoin-momentum-rotation-swing.md`(일봉 랭킹 로테이션, 알트 전체 유니버스)와는 **①모멘텀 방향(중립X, 같은 방향 추종) ②트리거 비대칭(BTC가 항상 리더) ③타임프레임(15m 단타)** 모두 달라 메커니즘 중복 아님. 다만 근거가 가장 약해 **백테스트 우선순위는 낮음** — 다른 4개 검증 후 여력 있을 때 시도 권장.
