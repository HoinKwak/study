# [스윙] 공적분 기반 알트코인 페어트레이딩 (통계적 차익거래)

- **출처**: https://github.com/abailey81/Crypto-Statistical-Arbitrage (GitHub, "Multi-venue quantitative crypto trading system" — Phase 2: Altcoin Statistical Arbitrage) /
  보조(학술, 개념 검증): https://ijsra.net/node/2582 (Statistical Arbitrage Strategies Using Cointegration Analysis in Cryptocurrency Markets), https://thesis.eur.nl/pub/67552/Thesis-Pairs-trading-.pdf
- **참여지표**: GitHub 리포지토리(스타 수 등 세부 미확인) — 코드·백테스트 방법론이 README에 구체적으로 공개돼 있어 참여지표보다 **방법론 투명성**으로 채택.
- **백테스트 근거**: **있음(GitHub README 원문 WebFetch로 확인)**.
  - 표본외(Out-of-Sample) 구간: 학습 2022-01~2023-06, 테스트 2023-07~2024-12(18개월).
  - 결과: **Sharpe 1.61**, 총수익률 6.84%, 최대낙폭(MDD) 4.64%, **승률 51.18%**, 총 127트레이드.
  - 수수료 반영: CEX 0.20% 편도 가정 포함(반영된 수치).
  - 유니버스: CEX 50종목 코인테그레이션 페어 선정(16개 크립토 섹터 분산), Kelly 기준 포지션사이징(0.25~0.5배), 동시보유 5~8페어.
  - **주의**: 원 리포는 DEX 페어(Phase 2 일부)·멀티 거래소 BTC 선물 커브 전략(Phase 3, Sharpe 5.81)도 포함하나, **Phase 3는 Binance·Hyperliquid·dYdX 등 여러 거래소 동시 실행이 필요**해 우리 단일거래소(바이낸스) 인프라로는 재현 불가 → **본 스펙은 CEX 단일거래소로 근사 가능한 Phase 2(알트코인 페어트레이딩)만 채택**.
  - 표본외 검증은 됐으나 **수익률 자체(18개월 6.84%)는 크지 않음**(Sharpe는 준수하나 절대수익 작음, MDD도 작아 레버리지 확대 여지는 있음). 127트레이드로 표본 크지 않음.
- **타임프레임**: 페어 선정·공적분 검정은 일봉(1d) 종가 기준(원 리포 가정, 명시 안 됐으나 일반적 관행). 진입/청산 z-score는 일봉 또는 4h로 세분화 검증 가능.
- **시장/대상**: 바이낸스 알트코인 무기한 페어(동일 섹터/상관 높은 종목군 내에서 동적 페어 선정)

## 진입 규칙
- **페어 선정**: 유니버스(우리 유니버스 기준 거래대금 $10M+ 알트, 섹터별 그룹화 — 예: L1, L2, DeFi, 밈코인 등) 내에서 롤링 lookback(예 90일) 가격 로그시계열에 대해 **Engle-Granger 2단계 공적분 검정** 수행, p-value < 0.05 인 페어만 후보.
- **스프레드/Z-score**: 공적분 회귀 잔차(스프레드) = log(A) − β×log(B). 스프레드의 롤링(예 30일) 평균·표준편차로 z-score 계산.
- 롱스프레드(A 롱/B 숏): z-score ≤ **−2.0**(원 리포 CEX 기준) → A 매수 + β비율만큼 B 매도.
- 숏스프레드(A 숏/B 롱): z-score ≥ **+2.0** → A 매도 + β비율만큼 B 매수.
- 리스크 통제: 동시보유 페어 5~8개 상한, 섹터 집중도 40% 이하, 페어간 상관 70% 이하(과도한 유사 페어 중복 방지).

## 청산 규칙
- 익절(평균회귀): z-score가 **0(평균)**으로 복귀하면 청산.
- 손절: z-score가 **±3.0** 도달(공적분 관계 붕괴로 간주) → 강제 청산.
- 시간 청산: 공적분 관계가 롤링 재검정에서 더 이상 유의하지 않게 되면(p-value가 0.05 넘어가면) 포지션 여부와 무관하게 페어 제외·청산.

## 파라미터
- coint_lookback=90d (범위 60~180d), coint_pvalue=0.05
- spread_zscore_window=30d (범위 20~60d)
- entry_z=2.0 (범위 1.5~2.5), exit_z=0.0, stop_z=3.0 (범위 2.5~3.5)
- max_concurrent_pairs=5~8, sector_concentration_max=40%, pair_correlation_max=70%
- position_kelly_frac=0.25~0.5x

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 로그가격, 롤링 공적분 검정(Engle-Granger, statsmodels 등 라이브러리 필요), 스프레드 z-score. **가격 데이터는 바이낸스 REST OHLCV로 충족.**
- 난이도: **중~높음**. 롤링 공적분 검정을 매 리밸런싱마다 유니버스 전체 페어(50종목 → 최대 1,225쌍)에 대해 수행해야 해 계산 비용이 큼(백테스트 시 사전 계산·캐싱 필요). 섹터 분류·페어 선정 로직도 별도 유지보수 필요.
- 주의: 오더북/틱 불필요, 동시주문 실행 슬리피지(양쪽 다리 동시 체결)는 고려해야 함(단일거래소 내 페어라 크로스거래소보다는 실행 리스크 작음).

## 스카우트 메모
- 강점: **원문 확인된 표본외(OOS) 백테스트**로 Sharpe 1.61, MDD 4.64%로 낮은 리스크 프로파일 — 방향성 베팅(롱/숏 바이어스)이 아닌 마켓뉴트럴 구조라 우리 기존 방향성 전략들과 **상관이 매우 낮음**(진짜 분산 효과). 기존 `btc-eth-zscore-spread`(고정 페어)를 **동적 페어 선정으로 일반화**한 버전.
- 의심점: 절대수익이 작음(18개월 6.84%, 레버리지 확대 없이는 임팩트 제한적) — 레버리지를 얼마나 태울 수 있는지가 관건. 127트레이드 표본이 크지 않아 통계적 유의성 낮음. 구현 복잡도가 이 목록의 다른 전략 대비 훨씬 높음(공적분 검정 파이프라인 신규 구축 필요 — 백테스트 우선순위에서 "구현비용 대비 기대이익"을 신중히 판단할 것).
- 우리 단타 슬리브와의 관계: **완전 보완**(마켓뉴트럴 vs 방향성). 다만 구현 난이도가 높아 **즉시 백테스트보다는 향후 스윙 슬리브 재가동 시 2순위 후보**로 검토 권장. 먼저 단순화 버전(고정 상위 3~5 상관페어만 대상, 공적분 검정 없이 상관계수+z-score만으로 근사)으로 개념검증 후 풀버전 확장을 고려할 만함.
