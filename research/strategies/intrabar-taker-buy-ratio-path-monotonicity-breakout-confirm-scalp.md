# [단타] 인트라바(3분 서브바) 테이커매수비율 경로 단조성 브레이크아웃 컨펌

- **출처**: 자체 설계 — 데이터 필드 근거: `data.binance.vision` 선물(um) klines 3분(`3m`) 표준 응답
  `taker_buy_volume`/`volume`(2026-08-27 직접 curl+unzip으로 BTCUSDT·ETHUSDT·SOLUSDT 3m 덤프 5일치
  실물 확인). "N개의 서브바로 쪼개 인트라바 경로의 형태(단조성)를 본다"는 기법 자체는 기존 보유
  `intrabar-oi-path-monotonicity-breakout-confirm-scalp.md`(1h봉을 5m 서브바 12개로 쪼갠 OI 경로)가
  이미 쓰지만, **원천 필드가 OI가 아니라 테이커매수비율**이고, **신호봉이 1h가 아니라 라이브 scalp15m과
  동일한 15m**이며, **서브바 분해도 5m×3개가 아니라 3m×5개**라는 점에서 다르다(2026-08-27,
  "인트라바"·"intrabar"·"테이커"·"taker" 키워드로 458개 전수검색해 "인트라바+테이커" 조합이 전무함을
  확인).
  **⚠️ 설계 과정에서 실측으로 폐기한 대안 명시(투명성)**: 처음엔 "15m 신호봉을 5m 서브바 3개로 분해"하는
  버전을 설계했으나, 3개 점의 순수 순서(단조 증가/감소)는 **점 3개의 가능한 순열 6가지 중 2가지가
  단조**이므로 독립동일분포(iid) 무작위 하에서도 이론적 기저율이 **33.3%**다. 2026-08-27 실측(BTC·ETH·
  SOL 5일 480봉씩)한 결과 실제 발생률이 **32.5~35.2%**로 이론 기저율과 사실상 구분 불가 — 즉 "단조성"
  자체가 정보를 전혀 담지 못하는 것으로 판명돼 그 버전은 폐기했다. 대신 **3분봉 5개(5!의 단조 경우 2가지
  = 1/60 이론 기저율 1.67%)**로 재설계 → 같은 5일 실측에서 **실제 발생률 2.08~2.71%**로 이론 기저율
  대비 **약 1.3~1.6배 초과**해 미약하지만 실재하는 자기상관(추세 지속성)이 있음을 확인했다. 이 실측
  경위 자체가 이 스펙의 "결합확률 실측" 항목이자 사전 설계 판단의 근거다.
- **참여지표**: - (자체 설계, 참여지표 없음)
- **백테스트 근거**: **없음(자체 설계, 정직히 표기)**. 위 실측은 소규모(5일) 스팟체크이며 전체
  백테스트가 아님.
- **타임프레임**: 15m 신호(3m 서브바 5개로 인트라바 경로 관찰) / 1h 확인.
- **시장/대상**: BTC·ETH·SOL·BNB·XRP·DOGE·ADA(표준 7종목).

## 진입 규칙
- 지표: 신호봉(15m)을 구성하는 3m 서브바 5개 각각의 `tbr_k = taker_buy_volume_k / volume_k` (k=1..5).
- 롱: `tbr_1 < tbr_2 < tbr_3 < tbr_4 < tbr_5`(완전 단조 증가, 매수압력이 15m 내내 순증) **AND**
  신호봉 종가가 20봉(15m) 돈치안 상단 돌파(브레이크아웃 컨펌) **AND** `tbr_5 − tbr_1 ≥ 0.10`(경로
  변화폭 최소 기준, 미세 단조를 배제).
- 숏: `tbr_1 > tbr_2 > tbr_3 > tbr_4 > tbr_5`(완전 단조 감소) **AND** 20봉 돈치안 하단 돌파 **AND**
  `tbr_1 − tbr_5 ≥ 0.10`.

## 청산 규칙
- 익절: ATR(1h)×1.0 트레일링(라이브 scalp15m과 동일).
- 손절: 신호봉(15m) 시가(라이브 SL 규칙과 동일 정합).
- 시간/조건 청산: 진입 후 8봉(15m=2h) 내 신고가/신저가 갱신 실패 시 모멘텀 소진 조기청산.

## 파라미터

- atr_trail_mult=1.0 · time_exit_bars=8(15m)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: klines 3m `taker_buy_volume`/`volume`(서브바 분해), 20봉 돈치안(15m), ATR(1h).
- 주의: 15m 신호봉의 `open_time`과 3m 서브바 5개의 정렬은 `open_time // 900000`으로 그룹화하면 되나,
  **거래소 점검·다운타임 등으로 3m봉이 5개 미만인 15m 구간은 신호 계산에서 제외**(부분 서브바로 단조성
  판정 시 편향 발생). 캐시 생성 시 다운로드 실패(NaN)와 실제 거래정지 결측을 구분해 실패는 재시도할 것.
  COIN-M 아님, REST/정적 덤프만으로 완전 구현 가능(3m은 표준 klines TF라 리샘플 불필요).

## 스카우트 메모
- **강점**: 기존 OI 인트라바 단조성 스펙과 같은 검증된 방법론적 골격을 재사용하면서, "3개 점은 정보
  없음(기저율과 구분 불가) → 5개 점(3m)은 정보 있음(기저율 대비 초과)"이라는 사전 실측으로 나이브한
  버전을 스스로 배제한 뒤 설계했다는 점에서 신중함이 확보됨. 또한 신호봉이 15m로 **라이브 scalp15m과
  타임프레임이 완전히 일치**해 채택 시 이식 마찰이 가장 적은 후보 중 하나.
- **의심점**: 초과분(2.08~2.71% vs 이론 1.67%)이 **미약**해서, 이 초과 자체가 진짜 정보인지 아니면
  3m봉의 미시적 자기상관(1분 캔들의 raw noise가 아니라 시장가 체결 클러스터링 등 구조적 특성)에 불과한
  "동어반복성 노이즈"인지 구분이 필요 — 아래 동어반복 점검을 반드시 통과해야 한다. `min_tbr_range=0.10`
  필터가 신호빈도를 얼마나 깎는지도 미실측(과잉제약 위험, 아래 예상 빈도 참조).
- **우리 단타 슬리브와의 관계**: 대체 후보(scalp15m과 TF·청산구조 동일, 진입 트리거만 완전히 다른 축).

## 사전 등록 폐기조건 (a)~(d) — 사후 변경 금지
- (a) OOS net PF(R) < 1.3 **또는** OOS 트레이드 단위 t < 1.96 중 하나라도 해당하면 폐기.
- (b) 무비용(fee=0·slippage=0) gross PF(R) < 1.05 이면 폐기(비용 이전부터 무엣지).
- (c) **부호 무작위화(방향 셔플) 100회 대조군**에서 실제 mean(R)의 백분위가 50 미만이면(무작위보다
  나쁨) 즉시 폐기. **승률 고정 순열검정도 병행**(과거 라운드에서 두 방법이 다른 결론을 낸 전례 있음).
- (d) OOS 고유 캘린더일 de-clustering 후 t<1.96 **또는** 3~5일 롤링 윈도우 de-clustering 후 t<1.96이면
  의사반복으로 판단해 폐기.

- 트리거 시점 한정 상관: 단조 조건이 실제 발화한 시점만 좁혀 위 상관들을 재계산.

## 비용 감당 산술
- SL 거리 = 신호봉(15m) 몸통. 단조 경로 조건이 강한 추세봉을 선호하므로 [추정] 몸통 크기가 평균보다
  다소 큼(가격의 0.15~0.25% 추정) → 왕복 0.14%가 SL 거리의 56~93% 수준으로 부담이 상대적으로 가벼운
  편(SL이 클수록 수수료 비중은 작아짐).
- 빈도가 종목당 연 40~120건으로 비교적 낮아 수수료 총 잠식액이 크지 않음(연 0.14%×2×40~120건은
  포지션 사이징 기준 잠식폭이 크지 않음 — 정확한 계산은 백테스터가 실제 사이징으로 수행).

## 예상 평균 승/패 R-배수와 근거
- ATR×1.0 트레일링(scalp15m과 동일) → 승리 시 [추정] 평균 +1.2~1.8R, 패배 시 −1.0R.
- 손익분기 승률 = 1/(1+1.5) = **40%** (avgR_win=1.5 가정). 5개 서브바 단조성이 순수 노이즈 대비
  1.3~1.6배 초과라는 미약한 엣지 규모를 감안하면, 이 승률을 실제로 상회할지 회의적 시각을 유지해야
  한다 — (c) 부호 무작위화 대조군이 이를 직접 검증.

## 수익 인과 경로
가설: 15m 신호봉 내부에서 매수(또는 매도) 압력이 3분마다 순증하는 "매끄러운 가속" 패턴은, 매수벽이
단발성이 아니라 지속적으로 유입되고 있다는 뜻이며(반대로 톱니형 경로는 단기 노이즈성 체결), 이런
매끄러운 가속이 브레이크아웃과 겹치면 후속 15~30분(1~2봉)간 추세가 이어질 가능성이 평시보다 높다는
것. 다만 초과분이 미약해 이 인과가 실전 수수료를 이길 만큼 강한지는 미지수.

## 라이브 실행 가능성
scalp15m(15m/1h, ATR×1.0 트레일링, SL=신호봉 시가)과 **청산 구조가 완전히 동일**하게 설계했다(고의로
정합). 진입 트리거만 3m 서브바 계산이 추가되며, 이는 REST klines 3m 조회로 충분(오더북·틱데이터
불필요). 3m klines가 표준 TF라 리샘플 오차 위험도 없음.

## 종목 간 신호 상관

  (미검증). 다만 브레이크아웃 조건(돈치안 돌파)은 매크로 이벤트에 동시 반응하기 쉬워 상관을 끌어올릴

- **위기 국면 점검 필수**: BTC 절대수익률 상위 5% 봉에서 이 신호(단조+돌파)가 여러 종목에 동시 발화하는

  매끄럽게 이어질 수 있어, LOO(leave-one-out)와 5일 롤링 클러스터 점검을 반드시 병행.

   동어반복 점검에서 정면으로 다룰 것 — 특히 **거래량 셔플·서브바 순서 셔플 대조군**으로
   단조성이 사라지는지 확인해야 한다.
3. 이 전제가 백테스트 초기 진단에서 무너지면(초과가 대부분 표본에서 비유의) **조기 폐기**를 검토할 것.
   빈도 자체가 연간 수십 건대로 얇아질 위험도 함께 본다.

**재현 커맨드**(부모가 실제로 실행해 위 표를 얻음):
```bash
# data.binance.vision 3m 월별 덤프 4개(BTC/ETH × 2024-06/2025-03)를 받아 압축 해제한 뒤
python3 -c "
import pandas as pd, glob, math
for f in sorted(glob.glob('*3m*.csv')):
    df=pd.read_csv(f)
    col=[c for c in df.columns if 'taker_buy' in str(c) and 'quote' not in str(c)][0]
    df=df[['volume',col]].apply(pd.to_numeric,errors='coerce').dropna(); df=df[df['volume']>0]
    tbr=(df[col]/df['volume']).values
    n=len(tbr)//5*5; a=tbr[:n].reshape(-1,5); N=len(a)
    inc=(a[:,1:]>a[:,:-1]).all(axis=1); dec=(a[:,1:]<a[:,:-1]).all(axis=1)
    obs=int((inc|dec).sum()); p=2/120
    print(f, N, obs, round(obs/N*100,2), round((obs-N*p)/math.sqrt(N*p*(1-p)),2))
"
```
