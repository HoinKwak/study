# [스윙] 돈치안 채널 중간선(Midline) 눌림목 추세추종

- **출처**: https://blog.traderspost.io/article/donchian-channel-trading-strategies (TradersPost) / https://www.luxalgo.com/blog/donchian-channels-breakout-and-trend-following-strategy/ (LuxAlgo) / https://www.tradingsim.com/blog/3-simple-donchian-channel-trading-strategies (TradingSim) / https://trendspider.com/learning-center/... (TrendSpider — 중간선 지지/저항 역할 설명)
- **참여지표**: - (다수 교육 블로그가 공통적으로 소개하는 돈치안 3대 전략 중 하나 — 채널 브레이크아웃과 별개로 "중간선 눌림목"을 트렌드 지속 진입법으로 별도 소개)
- **백테스트 근거**: 없음(개념·규칙 설명 위주, 구체 승률/PF 수치 미제시). 정량 수치 원문 미확인 — 지표 설명 기반으로 분류.
- **타임프레임**: 4h 진입 신호 / 1d 추세 필터
- **시장/대상**: BTC·ETH·주요 알트 USDT-M 무기한

## 진입 규칙
- 채널(4h): 상단=최근 20봉 최고가, 하단=최근 20봉 최저가, 중간선=(상단+하단)/2. ADX(14, 4h) 로 추세 강도 확인.
- 롱: 1d 종가 > 1d EMA(50)(상위 추세 상승) + 4h ADX(14) ≥ 20 + 4h +DI > -DI + 가격이 4h 중간선에 근접(중간선과의 거리 ≤ 0.3×ATR(14,4h))했다가 그 다음 봉 종가가 다시 중간선 위로 마감(눌림 후 되돌림 확인) → LONG.
- 숏: 1d 종가 < 1d EMA(50) + 4h ADX(14) ≥ 20 + -DI > +DI + 가격이 중간선 근접 후 다시 중간선 아래로 마감 → SHORT.
- (돌파형 채널 상단/하단 진입은 기존 `donchian-adx-breakout.md`가 이미 다룸 — 본 전략은 "채널 안쪽 중간선 되돌림"을 진입 트리거로 쓰는 트렌드 컨티뉴에이션 방식이라 신호 발생 로직이 다름.)

## 청산 규칙
- 익절: 직전 채널 상단(롱)/하단(숏) 도달 시 1차 청산, 이후 신고가/신저가 경신 시 chandelier 트레일(신고가−ATR×2.5, 신저가+ATR×2.5)로 잔량 트레일.
- 손절: 눌림 저점(롱)/눌림 고점(숏) − 0.5×ATR(14,4h).
- 시간/조건 청산: 4h 종가가 중간선을 반대 방향으로 재돌파(눌림 실패)하면 즉시 청산. 4h ADX가 15 미만으로 추세 소멸 시에도 청산.

## 파라미터
- donchian_period=20 (범위 15~30)
- adx_period=14, adx_min=20 (범위 18~25)
- midline_tolerance_atr=0.3 (범위 0.2~0.5)
- atr_period=14, sl_atr_mult=0.5, trail_atr_mult=2.5 (범위 2~3)
- trend_filter_ema=50 (1d)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 롤링 max/min(N봉), ADX(±DI/ATR 기반), EMA. 모두 바이낸스 REST 캔들만으로 충족.
- 주의: 오더북/틱/OI 불필요. 4h 데이터는 15m 리샘플로 생성 가능(15m이 최소 해상도이므로 4h 리샘플은 정합성 문제 없음, 1d도 동일).

## 스카우트 메모
- 강점: 채널 "돌파"가 아니라 "눌림목"에서 진입하므로 상대적으로 낮은 가격에 좋은 R/R로 추세에 올라탈 수 있음 — 스윙 수수료 부담이 낮은 우리 봇 특성과 궁합이 좋음(진입 빈도 낮고 손절폭 대비 목표폭이 큼). ADX/EMA 상위추세 필터로 횡보장 필터링.
- 의심점: "중간선 근접→반등" 판정이 주관적으로 서술된 자료가 많아(정확한 되돌림 폭 기준이 출처마다 다름) 파라미터(0.3×ATR)는 우리가 임의로 구체화한 것 — 백테스트에서 민감도 확인 필요. 트렌드가 약할 때 중간선을 자주 오르내리며 휩쏘 가능성.
- 우리 단타 슬리브와의 관계: **중장기(스윙) 신규 후보** — 현재 라이브는 단타(scalp15m) 단독이라 직접 대체 대상 없음. 과거 제외된 볼린저 눌림목 중기 전략과 개념적으로 유사(밴드 중심선 눌림)하나 밴드 산출식이 σ가 아닌 롤링 극값이라 완전히 다른 신호.
