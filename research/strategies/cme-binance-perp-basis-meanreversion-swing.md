## 진입 규칙
- **스프레드**: `spread_pct = (binance_perp_close - cme_futures_close) / cme_futures_close` (같은 4h 봉 종가 기준, UTC 타임스탬프 정합 필요).
- CME는 매주 토요일 03:00~05:00 UTC 정비휴장이 있어 그 구간 봉은 직전 유효 종가로 forward-fill.
- 스프레드의 최근 `zscore_window`=60봉(4h, 약 10일) 롤링 z-score `z_spread`.
- 롱(바이낸스가 CME 대비 비정상 저평가 — 크립토 네이티브 쪽 패닉/디레버리징이 기관 쪽보다 과도): `z_spread <= -2.0` **AND** RSI(14,4h) < 40(가격도 약세 확인, 스프레드만으로 진입 안 함) → 롱.
- 숏(바이낸스가 CME 대비 비정상 고평가 — 리테일 레버리지 롱 쏠림이 기관 포지셔닝보다 과도): `z_spread >= +2.0` **AND** RSI(14,4h) > 60 → 숏.

## 청산 규칙
- 익절: `z_spread`가 0으로 재수렴 또는 `rr_target`=2.0R 중 먼저 도달.
- 손절: 진입가 ∓ ATR(14,4h)×2.0.
- 시간 청산: `max_hold`=30봉(4h×30=5일) 내 미도달 시 강제청산(스프레드가 구조적으로 벌어진 것[예: 상장 이벤트·규제 뉴스]이면 되돌리지 않을 수 있음).

## 코딩 난이도 / 데이터 요구
- 필요한 지표: Yahoo Finance `BTC=F`/`ETH=F` 시계열(신규 외부 데이터 소스, 비공식 API — 공식 지원 종료·차단 리스크 있음, CME 자체 유료 데이터가 대안), 바이낸스 무기한 klines, RSI, ATR.
- 주의: **바이낸스 인프라 밖의 신규 데이터 소스**라 별도 커넥터 필요. Yahoo `chart` API는 비공식(공개돼 있으나 언제든 접근 제한 가능) — 백테스트는 가능해도 라이브 안정성은 별도 검증 필요. CME 선물은 **만기가 있는 근월물 연속계약**이라 롤오버(만기 전환) 시 가격 점프가 있을 수 있어(Yahoo가 연속계약을 어떻게 이어붙이는지 확인 필요) 스프레드 계산에 노이즈 유입 가능 — 백테스트 착수 시 롤오버 구간 스파이크를 반드시 점검.

## 스카우트 메모
- **예상 표본 빈도**: [추정] 2주(60봉×4h) z-score 2σ 이상은 자산당 연 10~20회 수준으로 추정(실측 필요) — 다만 CME 24/7 전환이 2026-05-29로 **불과 약 2.5개월 전**이라, 이 짧은 기간에는 위 구조가 온전히 성립하지만 그 이전(주말 CME 휴장 구간)은 스프레드 계산 자체가 결측되거나 왜곡될 수 있음 — 장기 백테스트를 하려면 **2026-05-29 이전 구간을 별도 취급**(주말 forward-fill 노이즈 인정 또는 그 구간 제외)해야 함.
- **gross 엣지 가설**: CME는 기관·규제된 참여자 중심, 바이낸스 무기한은 리테일 레버리지 비중이 커 펀딩비 유인에 따라 프리미엄이 실린다 — 두 시장 간 괴리가 과도하면 차익거래(cash-and-carry) 압력으로 수렴한다는 논리(전통 금융의 지수선물-현물 차익거래와 동일 원리를 크립토 이종 거래소 간에 적용). 다만 CME·바이낸스는 **서로 다른 결제통화·증거금 체계**(CME는 달러 결제 분기물, 바이낸스는 USDT 무기한)라 완전한 차익거래가 불가능해 괴리가 구조적으로 존재할 수 있음 — 논리가 100% 깨끗하지 않음을 인정.
- **엣지 대비 거래빈도**: 저빈도(자산당 연 10~20건 추정)로 수수료 부담은 작을 전망이나, 이 역시 저빈도=안전 등식이 아니라는 이번 라운드 교훈을 적용해 gross 엣지 자체를 우선 검증해야 함.
- **독립성/클러스터링 위험**: BTC·ETH 단 2종목뿐이고, CME-바이낸스 스프레드는 매크로 유동성 이벤트(예: 미국 증시 급락, 규제 뉴스)에 두 자산이 동조화될 가능성이 매우 높음 — 명목 표본이 소수의 고유 매크로 이벤트로 수렴할 위험.
- **7종목 신호 충분성**: **원천적으로 불가** — CME는 BTC·ETH만 상장. DVOL 스펙과 동일한 좁은 유니버스 제약.
- **강점**: 기존 어떤 스펙도 쓰지 않은 완전 신규 데이터축(전통 규제시장 선물가격) — `perp-spot-basis-spread-mean-reversion-swing.md`(현물-무기한, 동일 거래소군)·`coinbase-premium-streak-breakout-swing.md`(코인베이스 현물-바이낸스, 둘 다 크립토 네이티브 거래소)와 달리 **완전히 다른 규제·참여자 구조를 가진 시장**과의 비교라는 점에서 차별화됨.
- **의심점**: 비공식 Yahoo API 의존(라이브 안정성 리스크), 근월물 롤오버 노이즈, CME 24/7 전환 이전 구간 처리 복잡성, 표본이 2자산뿐이라 통계력 약할 수 있음.
- **우리 슬리브와의 관계**: 기존 베이시스 계열(현물-무기한, 분기물-무기한, USDT-M/COIN-M)과 "크로스벤뉴 프리미엄"이라는 상위 카테고리는 같지만 **비교 대상 시장(전통 규제 선물)이 완전히 달라 데이터 상관성이 낮을 가능성**. 채택 시 기존 베이시스 스펙들과의 신호 상관관계를 확인 권고.
