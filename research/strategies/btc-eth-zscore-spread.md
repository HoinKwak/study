# BTC-ETH z-스코어 스프레드 평균회귀 (마켓뉴트럴 페어)

- **출처**: https://blog.amberdata.io/empirical-results-performance-analysis (Amberdata, 수수료 반영 코인테그레이션 페어) / https://blog.amberdata.io/constructing-your-strategy-with-logs-hedge-ratios-and-z-scores / https://www.bitsilkinvestments.com/post/back-testing-mean-reversion-pairs-trading-for-bitcoin-and-ethereum
- **참여지표**: - (리서치 블로그)
- **백테스트 근거**: Amberdata ETC/FIL 페어(2021-2024, **"통상 크립토 거래소 수수료+슬리피지 가정 반영"**): 총수익 +62%, 연 16%, Sharpe 0.93, MaxDD −15.7%, PF 3.74 — **단, 5트레이드뿐(표본 극소)**. 별도 BTC-ETH 단순 페어: 변동성 큰 6개월(2021)에 포트폴리오 +43.4%. 경고: 크립토 페어 알파는 2018 이후 감소 추세. → 근거는 있으나 **표본/최근성 약함**.
- **타임프레임**: 1h 신호(스프레드 z-스코어) / 15m~1h 재조정.
- **시장/대상**: BTC 무기한 vs ETH 무기한 (동시 롱/숏, 델타 근접 뉴트럴)

## 진입 규칙
- 사전: log(ETH) 와 log(BTC) 회귀로 헤지비율 β 추정, 스프레드 = log(ETH) − β·log(BTC). ADF 검정 p<0.05(정상성) 확인된 구간에서만 가동.
- 스프레드의 롤링 z-스코어(N봉 평균/표준편차)를 계산.
- 진입(스프레드 고평가, z > +2): ETH 숏 + BTC 롱.
- 진입(스프레드 저평가, z < −2): ETH 롱 + BTC 숏.

## 청산 규칙
- 익절: z → 0 (평균 복귀) 또는 |z| < 0.5 도달 시 양다리 청산.
- 손절: |z| > 3.0 (관계 붕괴 신호) → 강제 청산.
- 시간 청산: 최대 홀딩 N봉 초과 또는 롤링 ADF 가 정상성 상실 시 청산.

## 파라미터
- lookback=100봉 (범위 50~200) — z-스코어 롤링 윈도
- entry_z=2.0 (범위 1.5~2.5)
- exit_z=0.0~0.5 (범위)
- stop_z=3.0 (고정)
- hedge_beta=롤링 회귀 추정 (재추정 주기 24~168봉)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 두 심볼 동기화 캔들, 로그가격, 롤링 회귀(β), 스프레드 z-스코어, (선택) 롤링 ADF. 캔들만으로 충족.
- 주의: **바이낸스 REST 캔들 2개 시리즈면 충족.** 오더북/틱 불필요. 단 **두 다리 동시 체결 = 수수료 2배**(라운드트립 ~0.28%) → 회귀폭이 이보다 커야 함. 봉 정렬/결측 동기화 처리 필요. 실행 복잡도는 이 목록 중 가장 높음.

## 스카우트 메모
- 강점: **마켓뉴트럴** → 방향성 리스크 제거, 우리 기존 전략들과 상관 매우 낮음(진짜 분산). 저빈도(z 극단에서만).
- 의심점: 표본 극소(5트레이드)·알파 감소 경고. 두 다리 수수료 2배가 엣지를 크게 갉아먹음 → **진입 z를 넉넉히(≥2)** 잡아 이동폭 확보 필수. 우리 백테스트 프레임이 단일심볼 가정이면 멀티심볼 확장 필요(구현비용).
- 우리 단타 슬리브와의 관계: 완전 신규(페어/뉴트럴). 대체 아님, **분산 전용 슬리브** 후보.
