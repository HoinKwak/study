# 트루 스트렝스 인덱스(TSI) 이중스무딩 모멘텀 [스윙]

- **출처**: 지표 원안 William Blau(1991). 참고: QuantifiedStrategies "True Strength Index Indicator (TSI)" https://www.quantifiedstrategies.com/true-strength-index/ (WebFetch 봇차단으로 본문 미확인) / Substack 재게시 https://quantifiedstrategies.substack.com/p/true-strength-index-tsi-trading-strategy
- **참여지표**: - (WebFetch 접근 실패로 조회수/구독자 등 참여지표 확인 불가. TSI 자체는 TradingView 빌트인 지표로 광범위하게 사용되는 표준 모멘텀 오실레이터.)
- **백테스트 근거**: **정량 수치 원문 미확인.** quantifiedstrategies.com은 봇 검증 페이지만 반환돼 WebFetch로 본문 확인 실패. WebSearch 요약에는 "TSI 시그널선 크로스오버가 SPY 대비 55% 아웃퍼폼", "금(gold) 대상 37% 승률·0.64% 평균수익"이라는 문구가 검색엔진 요약으로 노출됐으나, **원문 페이지를 직접 열람하지 못해 이 수치의 진위·정확한 문맥(자산군: 미국 주식/금, 크립토 아님)을 검증할 수 없음 → 인용하지 않음**. 자산군이 크립토가 아니라는 점도 별도로 명시.
- **타임프레임**: 4h 신호 / 1d 확인.
- **시장/대상**: BTC·ETH·알트 무기한 (원 소스는 주식·금 — 크립토 검증 안 됨, 지표 자체는 자산군 무관 범용 모멘텀 오실레이터).

## 진입 규칙
- TSI 계산: `PC = Close - Close[1]` (1봉 가격변화). `TSI = 100 * EMA(EMA(PC, r=25), s=13) / EMA(EMA(|PC|, r=25), s=13)`. 시그널선 = EMA(TSI, 7).
- 롱: 4h TSI가 0선 아래에서 **시그널선을 상향 돌파** + 동시에 TSI > TSI[1](모멘텀 가속) + 1d TSI > 0선 또는 0선 상향 근접(상위TF 정렬).
- 숏: 4h TSI가 0선 위에서 시그널선 하향 돌파 + TSI < TSI[1] + 1d TSI < 0선 근접.
- (선택 강화) 0선 자체 돌파(TSI가 음→양 전환)를 별도의 더 강한 추세개시 신호로 취급, 시그널선 크로스보다 우선순위 상위.

## 청산 규칙
- 익절: TSI가 반대 방향으로 시그널선 재돌파(모멘텀 소진) 시 청산, 또는 2.5R 고정 목표 중 먼저 도달.
- 손절: 진입봉 기준 1.5×ATR(4h,14), 또는 진입 직전 스윙 고/저(구조 기반) 중 더 타이트한 쪽.
- 시간 청산: 20봉(4h, 약 3.3일) 내 TSI 0선 미돌파 시 절반 축소.

## 파라미터
- r=25, s=13 (원지표 표준, 범위 r 20~30 / s 10~15)
- signal_period=7 (범위 5~12, 일부는 12 사용)
- sl_atr_mult=1.5 (범위 1.0~2.0)
- tp_rr=2.5 (범위 2.0~3.0)
- higher_tf_align=1d 필수 옵션

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 종가 기반 이중 EMA 스무딩(TSI), ATR, 상위TF 확인. 전부 표준 OHLCV.
- 주의: 바이낸스 REST 캔들로 완전 충족. 추가 데이터 불필요. 지표 계산 자체(이중 EMA)는 pandas ewm 두 번 체이닝으로 간단히 구현 가능.

## 스카우트 메모
- 강점: TSI는 **이중 지수평활(double-smoothed) 모멘텀**이라는 점에서 우리 보유 MACD류(단일 스무딩 차분)·RSI류(상대강도, 스무딩 없음)와 계산 구조가 명확히 다름 — trix-triple-smoothed-momentum(삼중 스무딩)과 스무딩 횟수만 다를 뿐 유사 계열이라는 점은 유의(구조적으로 가장 가까운 기존 후보는 TRIX). 0선+시그널선 이중 확인 로직 자체는 신규.
- 의심점: (1) 정량 근거 완전 미확인, 자산군도 주식/금이라 크립토 이식 시 파라미터 재검증 필수. (2) TRIX(이미 보유)와 개념적으로 상당히 겹침 — "다중 스무딩 모멘텀 오실레이터" 군으로 묶이면 신규성이 제한적일 수 있음. 채택 시 TRIX와의 신호 상관을 먼저 확인 권장.
- 우리 단타 슬리브와의 관계: 4h~1d 스윙 포지션 크기이므로 왕복 수수료 부담이 낮아 생존 가능성은 있으나, TRIX와의 구조적 중복 우려로 **백테스트 우선순위는 중간 이하**.
