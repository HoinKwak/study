# [단타] 미결제약정(OI) 변화율-가격 다이버전스 스퀴즈 반전 (15m/1h)

- **출처**: https://cryptoquant.com/insights/quicktake/684ae1a2c26bc826d28c7152-Binance-Open-Interest-Divergence-Signals-Caution-as-Bitcoin-Approaches-110K (CryptoQuant, OI-가격 다이버전스 국면 분류) /
  https://bikotrading.com/trading-strategy-on-open-interest-and-delta (Bikotrading Academy, "가격 급등+OI 급감=숏 청산 스퀴즈" 프레임) /
  https://www.utradealgos.com/blog/the-ultimate-guide-understanding-oi-based-strategies-in-algo-trading (uTradeAlgos, OI 기반 알고전략 가이드) /
  보강: 기존 봇의 OI 데이터 활용 근거(바이낸스 `openInterestHist` 이미 `scalp.py`에서 보조지표로 사용 중)
- **참여지표**: 없음(전문 데이터 블로그·거래소 리서치) — SNS 참여지표 미확인
- **백테스트 근거**: 없음(구체적 수익률·승률 수치 제시 자료를 찾지 못함) — **참여지표 대신 프레임워크의 재현성·업계 통용성으로 스크리닝**. CryptoQuant·바이낸스 공식 블로그 등 신뢰 가능한 파생상품 리서치 기관이 반복적으로 제시하는 "OI×가격 4분면 국면 분류"(OI↑+가격↑=건전한 추세, OI↓+가격↑=숏커버링/추세소진, OI↑+가격↓=숏누적, OI↓+가격↓=롱청산 플러시)를 규칙화한 것. **채택 전 반드시 자체 백테스트로 엣지 검증 필요**.
- **타임프레임**: 15m 신호 / 1h 확인
- **시장/대상**: BTC·ETH·시총상위 알트 무기한(OI 데이터가 유의미하게 잡히는 유동성 있는 종목)

## 진입 규칙
- OI 변화율(ROC): 최근 N=20봉(15m) 대비 현재 OI % 변화. 가격 변화율(ROC): 동일 구간 종가 % 변화.
- **롱(숏스퀴즈/청산 플러시 반전)**: 가격 ROC ≤ -1.5%(하락) 이면서 OI ROC ≤ -5%(OI 급감, 롱 강제청산으로 해석) + 15m 하락폭이 최근 20봉 ATR의 1.5배 이상(과매도성 급락) → 반전 롱. (숏 포지션이 걷힌 게 아니라 **롱이 청산되며 OI가 급감**한 국면을 노림 — "플러시 후 반등")
- **숏(추세소진/숏커버링 반전)**: 가격 ROC ≥ +1.5%(상승) 이면서 OI ROC ≤ -5%(OI 급감, 숏 강제청산으로 해석) + 상승폭이 ATR 1.5배 이상 → 반전 숏. ("숏 스퀴즈 후 추가매수 없이 청산 랠리만 발생한 국면"으로 되돌림 기대)
- 확인 TF(1h): RSI(14)가 극단(<25 롱 / >75 숏)일 때만 진입(과매도/과매수 동시 확인으로 다이버전스 신뢰도 강화).

## 청산 규칙
- **익절**: 신호 발생 직전 N=20봉 중간값(VWAP 또는 SMA20)까지 되돌림, 또는 1.5R 도달.
- **손절**: 신호봉의 극값(롱은 저가, 숏은 고가) - 0.3×ATR 여유.
- **시간 청산**: 진입 후 8봉(15m×8=2시간) 내 목표 미도달 시 손익 무관 강제청산(반전 실패로 판단, 스퀴즈 신호는 지속력이 짧음).

## 파라미터
- oi_roc_lookback=20 (범위 12~30)
- oi_roc_threshold=-5% (범위 -3~-8%, 값이 클수록 신호 희소해짐)
- price_roc_threshold=1.5% (범위 1.0~2.5%)
- atr_mult_for_extension=1.5 (범위 1.2~2.0)
- rsi_extreme_long=25, rsi_extreme_short=75
- max_hold_bars=8 (15m 기준)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: OI(미결제약정) 시계열, 가격 ROC, ATR, RSI, SMA/VWAP.
- 주의: OI는 바이낸스 선물 `/fapi/v1/openInterestHist`로 5m 최소 간격 제공 — **이미 우리 `scalp.py`가 OI를 보조지표로 쓰고 있어 인프라 재사용 가능**. 단, "OI 급감=청산"이라는 해석은 **실제 청산 데이터(liquidation stream)가 아닌 OI 변화만으로 추정한 간접 신호**이므로 실제 청산량과 괴리가 있을 수 있음(청산 vs 포지션 정리 구분 불가) — 이 점이 이 전략의 핵심 리스크.

## 스카우트 메모
- **강점**: OI 데이터는 이미 봇 인프라에 있어 구현 부담이 적음. "가격-OI 다이버전스"는 파생상품 트레이더들 사이에 널리 통용되는 프레임(CryptoQuant·바이낸스 공식 리서치도 동일 분류 사용)이라 로직 자체의 상식적 타당성은 높음.
- **의심점**: **정량 백테스트 근거가 전혀 없어** 이번 라운드 후보 중 검증 우선순위가 가장 낮음. OI 급감이 청산인지 자발적 포지션 정리인지 구분 불가하므로 다이버전스가 항상 반전을 의미하지 않을 수 있음(추세 지속 중 정상적 되돌림일 수도 있음).
- **우리 슬리브와의 관계**: 기존 단타 전략(`cvd-taker-volume-divergence-scalp.md`, CVD 테이커 볼륨 다이버전스)과 **컨셉이 유사**(둘 다 "가격은 움직였는데 포지셔닝 지표는 안 따라온다"는 다이버전스 논리)하지만 데이터 소스가 다름(CVD=체결 방향성 볼륨, OI=미결제약정) — **보완재**로 볼 수 있고, 채택 시 신호 상관관계를 반드시 점검해 중복 신호 여부 확인 필요.
