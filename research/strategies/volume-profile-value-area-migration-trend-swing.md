- **참여지표**: 없음(퀀트 교육 블로그, 개별 조회수 미확인)
- **백테스트 근거**: **없음(개념 기반)**. 원문(QuantVPS, 검색엔진 스니펫 기준)은 "오늘 Value Area가 어제보다 위에 있으면 상승추세 신호, 세션간 Value Area가 안 겹치면(non-overlapping shift) 추세일(trend day) 가능성, 추세장에서는 평균회귀가 아니라 브레이크아웃/마이그레이션을 추종하라"는 **정성적 원칙만 제시** — 정량 승률·PF 수치는 원문에 없음(스니펫 확인 범위 내). **⚠️ 정량 수치 없음, 직접 원문 WebFetch는 429로 실패해 검색결과 요약에만 의존 — 채택 전 원문 재확인 및 자체 백테스트 필수.**
- **타임프레임**: 세션(1d, UTC 00:00 기준) 단위 Value Area 산출, 4h 종가로 진입 트리거
- **시장/대상**: BTC·ETH·시총상위 알트 무기한

## 진입 규칙
- **세션 Value Area 산출**: 매 UTC 일(00:00~24:00, 1h×24봉)의 캔들들로 볼륨프로파일 구성(가격 구간 N=24 빈, 각 봉 거래량을 고가~저가 구간에 균등 분배 — 기존 `volume-profile-poc-value-area-scalp.md`와 동일한 근사 방식이나, **여기서는 세션(1일) 단위 이산 프로파일**을 매일 확정해 저장한다는 점이 다름, 롤링 24시간 윈도우 아님).
- 누적거래량 70%(`value_area_pct`) 구간의 상/하단을 오늘 VAH(t)/VAL(t)로 확정.
- **마이그레이션 판정**: 직전 `lookback_sessions`(예 2세션)의 VAH/VAL과 비교.
  - **상승 마이그레이션(비중첩 상방 이동)**: 오늘 VAL(t) > 직전 세션 VAH(t-1) (즉 오늘 가치영역 전체가 어제 가치영역보다 완전히 위에 위치, 겹침 없음).
  - **하락 마이그레이션**: 오늘 VAH(t) < 직전 세션 VAL(t-1).
- **롱**: 상승 마이그레이션 확정 **AND** 4h 종가가 오늘 VAH(t) 위로 돌파(추세일 확인, 눌림목 아님) → 롱 진입.
- **숏**: 하락 마이그레이션 확정 **AND** 4h 종가가 오늘 VAL(t) 아래로 이탈 → 숏 진입.
- 확인 필터: 마이그레이션 발생일의 거래대금이 최근 5세션 평균 대비 `volume_confirm_mult`=1.3배 이상(단순 저유동성 갭 배제).

## 청산 규칙
- **익절**: ATR 트레일링(4h, ATR×1.5)으로 추세 지속 추종, 또는 반대 방향 마이그레이션(비중첩 역전) 발생 시 청산.
- **손절**: 진입 시점 가격 기준 오늘 VA 반대 경계(롱=오늘 VAL, 숏=오늘 VAH) 이탈, 또는 −1.5×ATR(4h) 중 더 타이트한 쪽.
- **시간/조건 청산**: `max_hold_sessions`=5세션(5일) 내 후속 마이그레이션이 없으면(추세 정체) 시간청산.

## 파라미터

- lookback_sessions=2 (범위 1~3)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 세션(1d) 볼륨프로파일(캔들 고저·거래량 근사 방식, 기존 스펙과 동일 방법론), ATR(4h), 거래대금.
- 주의: 기존 `volume-profile-poc-value-area-scalp.md`와 마찬가지로 **근사 볼륨프로파일**(진짜 volume-at-price가 아닌 고가~저가 균등분배 근사)이라는 한계 공유. 바이낸스 REST 1h/4h 캔들(OHLCV)만으로 계산 가능, 오더북·틱데이터 불필요.
- 난이도: 중. 세션별 이산 프로파일 확정 로직(매일 UTC 리셋) + 세션간 비교(non-overlap 판정) + 4h 트리거 결합.

## 스카우트 메모
- **강점**: 기존 `volume-profile-poc-value-area-scalp.md`는 **롤링 24시간 윈도우 + 평균회귀(VA 바운스)**인 반면, 본 전략은 **이산 세션(1일 단위) + 세션간 이동(마이그레이션) + 추세추종(브레이크아웃)** 이라는 점에서 윈도우 정의·매매 방향성이 모두 다름(같은 볼륨프로파일 데이터를 정반대 논리로 사용). "마켓 타입(레인지 vs 추세)에 따라 다른 VA 전략을 써야 한다"는 원문 조언을 그대로 구현한 형태.
- **의심점**: 원문(QuantVPS)을 직접 WebFetch로 확인하지 못하고 **검색엔진 요약본에만 의존**했음 — 정량 수치는 없어 환각 리스크는 낮으나(개념 기반 스펙), 정성적 서술의 정확한 문구까지는 재확인 필요. 근사 볼륨프로파일의 부정확성이라는 기존 스펙과 동일한 한계 공유. 세션 경계를 UTC 00:00으로 고정하는 것이 크립토(24시간 무휴장)에 유의미한 경계인지는 불확실(전통 마켓프로파일은 거래소 개장/마감 기준 — 크립토엔 자연스러운 세션 경계가 약함).
- **우리 슬리브와의 관계**: 기존 `weekly-structure-breakout-retest.md`(주간 구조)·`bollinger-band-walk-trend-continuation-swing.md`와 "추세 지속 추종"이라는 상위 카테고리는 겹치나, **레벨 정의 방식(거래량 가중 VA vs 단순 고저/밴드)이 달라 보완재**. 기존 볼륨프로파일 스펙과는 자매 전략(같은 데이터, 반대 레짐 가정)이므로 두 전략을 함께 백테스트해 레짐 분기가 실제로 유효한지 비교 검증하면 좋음.
