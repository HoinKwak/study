# [스윙] 김치 프리미엄(한국 거래소 괴리) 극단 컨트래리언

- **출처**: 개념 정의 — https://www.ccn.com/education/cryptocurrency-kimchi-premium/ , https://www.spotedcrypto.com/kimchi-premium-explained/ (계산식: `Kimchi Premium(%) = (한국거래소 KRW가격 / KRW-USD환율) / 해외거래소 USD가격 - 1) × 100`, 업비트·빗썸이 대표 거래소로 언급).
  참여지표성 소스 — CNBC, "South Korea's 'kimchi premium' is in the spotlight again" https://www.cnbc.com/2024/04/03/south-koreas-kimchi-premium-in-the-spotlight-after-btcs-record-highs.html : **WebFetch 시도 결과 403(접근 차단)으로 원문 직접 대조 실패** — WebSearch 요약에만 등장한 "CryptoQuant 데이터 기준 Korea Premium Index가 5.5%를 넘은 10회 중 7회에서 30일 내 10~20% 조정" 수치는 **원문 대조 불가로 인용하지 않는다**(정직 표기). 마찬가지로 paperswithbacktest.com의 "Kimchi Premium in Cryptocurrency Trading" 코스(https://paperswithbacktest.com/course/kimchi-premium-cryptocurrency-trading)도 **WebFetch 확인 결과 개념 설명뿐 구체적 임계값·백테스트 수치는 유료 구독 전용**이라 미확인.
- **참여지표**: - (정량 참여지표 미집계). 다만 "김치 프리미엄"은 크립토 트레이딩 커뮤니티(X/트위터, 한국 커뮤니티 포함)에서 **한국발 소매 투기심리 프록시로 수년간 반복 인용**되는 대표적 지표(2017년 말 프리미엄 50%대 급등 사례가 업계에서 널리 회자) — 다출처 반복 등장으로 참여지표를 대체.
- **백테스트 근거**: **없음(정량 수치 원문 미확인, 개념 기반)**. 위에서 밝힌 대로 CNBC 기사의 구체적 통계는 WebFetch 차단으로 검증 못 해 인용 안 함. **채택 전 자체 백테스트 필수**, 이 라운드 후보 중 근거 신뢰도가 가장 낮은 축.
- **⚠️ 예상 신호빈도 사전 명시**: 김치 프리미엄은 대부분의 기간 0~수% 내 좁은 밴드에서 움직이다가 강세장 후반부(2017년말, 2021년초, 2024년초 등)에만 스파이크하는 **레짐성 이벤트**로 알려져 있다 — 연 단위로 보면 극단 스파이크는 강세장 사이클당 수 회 수준일 가능성이 높아, 6년 백테스트 구간에서 실제 트리거가 **10~30건 안팤으로 표본이 얇을 위험**을 사전에 명시한다. 백분위 임계값(상/하위 10%)이 이 스파이크 성격과 안 맞으면(즉 밴드 폭이 좁아 "상위 10%"가 절대적으로는 미미한 프리미엄일 수 있음) 신호가 무의미하게 잦아질 위험도 동시에 있다 — 두 방향 모두 백테스터가 실측 후 즉시 보고할 것.
- **⚠️ 전제의 내적 일관성 사전 검토**: 업비트·빗썸의 BTC 거래대금은 바이낸스 대비 훨씬 작아 **한국 거래소가 바이낸스 가격을 직접 움직일 개연성은 낮다** — 즉 프리미엄은 바이낸스 가격에 후행하거나 독립적인 "센티먼트" 신호일 뿐, 진입 신호의 가격 필터(N봉 신고가/신저가)와 **동시에 발생해야 할 구조적 이유가 약함(우연 결합일 수 있음)**. 이는 장점(허위 동시성 위험 낮음)이자 단점(결합조건이 너무 느슨해 필터로서 기능 못 할 위험)이니 백테스터는 가격필터 유무 두 버전을 비교할 것.
- **타임프레임**: 1d 신호(프리미엄·환율 데이터가 일 단위 수집이 안전) / 4h 확인·진입.
- **시장/대상**: BTC 무기한(업비트 KRW-BTC가 가장 유동적 — ETH 확장은 검증 필요).

## 진입 규칙
- **데이터**: 업비트 공개 REST API(`https://api.upbit.com/v1/candles/days`, 인증 불요·무료) KRW-BTC 일봉 종가 + USD/KRW 환율(Yahoo Finance `KRW=X` 일봉 종가) + 바이낸스 BTCUSDT 일봉 종가(기존 확보).
- **프리미엄 정의**: `premium(%) = (upbit_krw_close / usdkrw_close) / binance_usdt_close - 1) × 100`.
- **정규화**: `premium_pctile[i] = percentile_rank(premium[i], window=180봉(180일))` (z-score 대신 비모수 백분위 — 데미닝 함정 회피).
- **숏(과열 프리미엄 페이드)**: `premium_pctile >= 90` **AND** `premium >= premium_abs_min`(예 3%, 절대 수준 확인 — 백분위만으론 밴드가 좁을 때 오탐 가능) **AND** 종가가 최근 `price_lookback`=20봉 고가 갱신(가격도 동반 과열) → 숏.
- **롱(디스카운트 페이드, 역사적으로 드물 것으로 예상)**: `premium_pctile <= 10` **AND** `premium <= premium_neg_max`(예 -1%, 할인 상태) **AND** 종가가 최근 20봉 저가 갱신 → 롱.

## 청산 규칙
- 익절: `premium_pctile`이 중립대(40~60)로 복귀 시 청산, 또는 R:R 2:1 고정.
- 손절: 진입가 ∓ ATR(14,4h)×2.0.
- 시간 청산: 최대 보유 15봉(4h 기준 2.5일) 초과 시 강제 청산.

## 파라미터
- premium_window=180봉(180일) (범위 90~365)
- extreme_low_pctile=10 (범위 5~15), extreme_high_pctile=90 (범위 85~95)
- premium_abs_min=3.0% (범위 2.0~5.0)
- premium_neg_max=-1.0% (범위 -0.5~-2.0)
- price_lookback=20봉 (범위 15~30)
- max_hold_bars=15 (범위 10~20)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 업비트 일봉 종가(REST), USD/KRW 환율(Yahoo Finance), 바이낸스 일봉 종가, 롤링 백분위.
- 주의: **본 봇 라이브 인프라는 현재 업비트·원화환율 데이터를 보유하지 않음 — 신규 fetch 파이프라인 구축 필요**(둘 다 무료·인증불요라 구현 난이도 자체는 낮음). 업비트 API는 요청 빈도 제한(rate limit)이 있어 일봉 백테스트 규모에선 문제 없음. 오더북/틱/청산 불필요.

## 스카우트 메모
- **강점**: 이 목록 내 최초로 **국가별 거래소 간 가격 괴리**를 다루는 스펙 — 기존 코인베이스 프리미엄(`coinbase-premium-streak-breakout-swing.md`, 미국 기관 수요 프록시)과 대칭되는 "한국 소매 투기 수요" 프록시로 서로 다른 참여자 그룹을 반영. 데이터 소스가 완전히 새로운 두 축(업비트+원화환율)이라 기존 스펙과 데이터 중복이 전혀 없음.
- **의심점**: 핵심 정량 근거(CNBC의 "5.5%↑ 시 10~20% 조정")를 원문 차단으로 검증 못 해 **참여지표 수준 신뢰도**로만 채택 — 이 라운드 후보 중 가장 투기적. 표본 부족 위험(레짐성 스파이크라 트리거 희소)도 사전에 명시함. 신규 데이터 파이프라인(업비트+환율) 구축 비용도 다른 후보 대비 높음.
- **우리 슬리브와의 관계**: 완전 신규 메커니즘·완전 신규 데이터. 백테스트 우선순위는 **낮게** 권장(신규 커넥터 구축 비용 대비 근거 신뢰도가 이 라운드 후보 중 가장 약함) — 코인베이스 프리미엄 스트릭 스펙이 먼저 검증된 뒤 "거래소 프리미엄" 계열이 유효함이 확인되면 그때 우선순위를 올리는 것을 권장.
