# [스윙] 평균 체결규모(ATS) 급락 소진 반전(고래 이탈) 스윙

- **출처**: 자체 설계(스카우트 고안) — 데이터 필드 근거는 기존 `average-trade-size-accumulation-breakout-swing.md`와
  동일(CryptoQuant "Bitcoin Spot Average Order Size" 지표 해설, https://bitcoinist.com/cryptoquant-spot-average-order-size-whale-accumulation/,
  "거래대금을 체결건수로 나눠 소액 리테일 주문인지 대형 자본 흐름인지 구분"이라는 정의를 WebFetch로 확인 완료
  — 기존 스펙 파일에 이미 인용돼 있음, 재확인). **본 스펙은 기존 스펙과 데이터 필드는 같지만 방향과 용도가
  정반대**: 기존 스펙은 "레인지바운드 구간에서 ATS가 **상승**(대형 자본 조용히 매집) → 브레이크아웃 추종"인
  반면, 본 스펙은 "가격이 N봉 신고가/신저가를 갱신하는 **가격 극단 순간**에 ATS가 오히려 **급락**(대형 참여자
  이탈, 소액 리테일 추격 매수/매도만 남음) → 소진으로 보고 역추세 페이드"한다. 이 "가격 극단 + 참여자 구성
  악화"라는 다이버전스형 소진 논리는 오더북 심도 기반 "이탈 유동성(fading liquidity)" 통설의 klines 필드
  근사이며, **이 정확한 규칙을 직접 백테스트한 외부 자료는 찾지 못함 — 정직히 자체 설계로 표기**.
- **참여지표**: - (자체 설계, 참여지표 없음)
- **백테스트 근거**: **없음(자체 설계, 정직히 표기)**. 채택 전 자체 백테스트 필수.
- **⚠️ 예상 신호 빈도**: "N봉(4h, 기본 30봉=5일) 신고가/신저가 갱신" AND "ATS가 최근 5봉 평균 대비 40% 이상
  급락" 이중조건. [추정] 종목당 **연 20~40건** 수준(순수 N봉 극값 갱신만으로는 훨씬 잦지만 ATS 급락 조건이
  결합돼 크게 줄어들 것으로 예상).
- **⚠️ 전제의 내적 일관성 사전 검토(가장 중요)**: "가격이 신고가/신저가를 갱신하는 순간"과 "ATS가 급락"은
  **상호배타적일 위험이 있다** — 신고가 갱신은 통상 거래대금과 체결건수가 **함께** 급증하는 경우가 많아
  (돌파 시 거래량 폭증), ATS(=거래대금/체결건수)가 반드시 하락한다는 보장이 없다. ATS가 실제로 하락하려면
  "체결건수가 거래대금보다 상대적으로 더 급증"해야 하는데, 이는 소액 주문이 많아졌다는 뜻이지 대형 참여자
  이탈을 직접 증명하지 않는다 — **가설과 실측이 어긋날 위험이 이 스펙에서 가장 크다는 점을 사전에 인지**하고,
  실제로 신고가/신저가 갱신봉에서 ATS 방향(상승/하락) 분포부터 최우선 실측할 것(만약 신고가 갱신봉의 ATS가
  거의 항상 상승한다면 이 가설 자체가 성립 불가하므로 즉시 폐기).
- **⚠️ 종목 간 신호 상관 사전 예상**: 개별 종목의 국지적 소진 이벤트라 종목 간 독립성이 비교적 높을 것으로
  예상되나, 시장 전체 랠리/패닉의 클라이맥스 국면(예: 전체 알트시즌 정점)에는 다수 종목이 동시에 신고가와
  ATS 급락을 함께 보일 수 있음 — 동시발생일 비율 실측 필요.
- **⚠️ 핵심 대조군(반드시 실행)**:
  ① ATS 조건 없이 순수 N봉 극값 갱신만으로 페이드하는 버전(기존 `rolling-extremum-streak-fade-scalp`와 유사
  구조, ATS가 부가가치를 내는지 확인).
  ② ATS 조건을 **반대 부호**(급락이 아니라 급등)로 바꾼 버전과 비교해 방향성이 진짜인지, 아니면 ATS
  변화율 자체가 방향 무관하게 노이즈인지 확인.
  ③ 기존 `average-trade-size-accumulation-breakout-swing`(ATS **상승**+레인지바운드+브레이크아웃)과 신호
  발생 시점이 얼마나 겹치는지 대조(반대 방향 로직이라 겹치지 않아야 정상 — 겹치면 ATS 계산 자체에 문제).
- **⚠️ 사전 폐기 조건**: (a) 신고가/신저가 갱신봉의 ATS가 실측 대부분 상승 방향이면(전제 모순) 즉시 폐기,
  (b) 대조군①(ATS 없는 순수 극값페이드) 대비 부가가치 없으면 폐기, (c) IS gross PF<1이면 폐기.
- **타임프레임**: 4h 신호 산출 / 1d 확인.
- **시장/대상**: BTC·ETH·BNB·SOL·XRP·DOGE·ADA 무기한(표준 7종목).

## 진입 규칙
- **평균 체결규모(ATS)**: `ATS(t) = quote_asset_volume(t) / count(t)` (4h 캔들 기준, `count=0`이면 스킵).
- **극값 판정**: `extreme_window`(기본 30봉=4h×30=5일) 기준 Donchian 상단/하단.
- **ATS 붕괴**: `ats_drop(t) = ATS(t) / mean(ATS[t-5:t-1]) - 1` (직전 5봉 평균 대비 변화율).
- **숏(고점 소진)**: 종가가 `extreme_window` 고가를 신규 상향 돌파 **AND** `ats_drop(t) <= -0.40`(ATS 40% 이상
  급락, 대형 참여자 이탈 추정) → 숏(반전 기대).
- **롱(저점 소진)**: 대칭 — 종가가 `extreme_window` 저가를 신규 하향 돌파 **AND** `ats_drop(t) <= -0.40` → 롱.
- 1d 확인: 1d EMA20 기울기가 진입 방향과 강하게 반대(뚜렷한 상위TF 추세)면 신호 스킵(역추세 리스크 관리).

## 청산 규칙
- 익절: 극값 갱신 직전 수준(돌파 시작점) 복귀, 또는 ATR(4h,14) 트레일링×2.0.
- 손절: 신호봉 극값(숏이면 신호봉 고가) 재돌파, 또는 진입가 ∓ATR(4h,14)×1.8 중 더 타이트한 쪽.
- 시간/조건 청산: max_hold=7일(4h×42). 돌파 후 5봉(4h×5) 내 극값 방향으로 추가 신고가/신저가 갱신되면
  가설 실패로 즉시 청산.

## 파라미터
- extreme_window=30봉(4h, 범위 20~45)
- ats_drop_th=-0.40 (범위 -0.30~-0.55)
- atr_trail_mult=2.0, atr_stop_mult=1.8
- max_hold=7일

## 코딩 난이도 / 데이터 요구
- 필요한 지표: klines의 `quote_asset_volume`·`count`(이미 매 봉 수집), Donchian, ATR, EMA(20,1d). 추가
  REST 엔드포인트 불필요.
- 주의: 오더북/틱/실시간청산 불필요. **`count` 필드를 원시 레벨로 쓴 `daily-trade-count-churn-extreme-fade-swing`이
  이미 FAIL 확정**됐음을 인지 — 본 스펙은 `count`를 원시값이 아니라 `quote_asset_volume`과의 **비율(ATS)의
  변화율**로 쓰고 방향(극값 갱신 시 소진)도 다르지만, 동일 원천 필드(count) 재사용이라는 점에서 완전히
  독립적인 근거는 아니며, count 필드 자체의 바이낸스 집계 노이즈 위험을 열어두고 검증할 것(기존 ATS
  상승형 스펙에 기재된 동일 경고를 계승).

## 스카우트 메모
- **강점**: 기존 ATS 상승형(매집) 스펙의 논리적 반대짝(대칭 가설)으로, 데이터 구현 비용이 매우 낮고
  "가격 극단 + 참여자 구성 악화(다이버전스)"라는 프레이밍이 다수 종목 rolling-extremum 계열 페이드
  전략에 신규 필터를 더한 형태.
- **의심점**: 전제 일관성 우려(신고가 갱신 시 ATS 방향)가 이 라운드 신규 스펙 중 가장 근본적인 리스크 —
  실측이 가설을 즉시 기각할 가능성을 스스로 가장 높게 봄. 폐기 조건 (a)를 최우선으로 확인할 것.
- 우리 슬리브와의 관계: 기존 `rolling-extremum-streak-fade-scalp`(순수 가격패턴 페이드)의 확장판으로,
  ATS라는 신규 필터가 그 스펙 대비 부가가치를 내는지가 핵심 질문. 우선순위는 중간~낮음(전제 리스크 때문에).
