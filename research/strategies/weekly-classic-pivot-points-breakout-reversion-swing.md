- **참여지표**: TradingView "Pivot Points Standard"는 기본 내장(built-in) 지표라 개별 좋아요 수 집계가 없음 — 대신 **거의 모든 트레이딩 플랫폼(TradingView·바이낸스·트레이딩뷰 이외 다수)에 기본 탑재**돼 있을 만큼 업계 표준적 채택도가 매우 높다는 정황 근거. 정량 SNS 참여지표는 확인 안 됨(플랫폼 내장 특성상 별도 게시물 형태가 아님).
- **백테스트 근거**: **없음(참여지표/업계 관행 기반)**. 위 2차 자료들은 규칙(주간 피벗 계산식 + 브레이크아웃/되돌림 활용법)만 설명할 뿐 정량 승률·수익률 수치는 제시하지 않음. **채택 전 자체 백테스트 필수**.
- **타임프레임**: 주간(전주 H/L/C)으로 피벗 계산, 4h~1d 캔들로 신호 판정·진입
- **시장/대상**: BTC·ETH·시총상위 알트 무기한

## 진입 규칙
- **위클리 피벗 계산**(클래식 공식, 전주 UTC 월요일 00:00 ~ 일요일 24:00 기준 H/L/C 사용):
  - PP(중심) = (전주 High + 전주 Low + 전주 Close) / 3
  - R1 = 2×PP − 전주Low, S1 = 2×PP − 전주High
  - R2 = PP + (전주High − 전주Low), S2 = PP − (전주High − 전주Low)
  - R3 = 전주High + 2×(PP − 전주Low), S3 = 전주Low − 2×(전주High − PP)
- **브레이크아웃 롱**: 금주 4h 종가가 R1을 상향 돌파 **AND** 돌파봉 거래대금이 최근 20봉(4h) 평균 대비 `vol_confirm_mult`=1.3배 이상 → 롱(추세 지속, 목표 R2).
- **브레이크아웃 숏**: 금주 4h 종가가 S1을 하향 돌파 + 거래대금 확인 → 숏(목표 S2).
- **되돌림(리버전) 대안**: 가격이 PP를 상회한 채로 R1에서 **거부**(4h 캔들이 R1을 터치 후 종가가 R1 아래로 마감, 상단 꼬리 존재) → 단기 숏(PP 회귀 베팅). 대칭으로 S1 거부 시 롱.
- 두 방식(브레이크아웃 vs 리버전)은 상호배타적 가설이므로 **하나만 채택해 검증**(브레이크아웃 우선 권장 — 스윙 슬리브 성격상 추세추종이 손익비 확보에 유리).

## 청산 규칙
- 익절: 브레이크아웃 롱은 R2 도달 시 1차 청산(50%), R3 도달 시 잔량 청산(단계적 익절). 숏은 대칭(S2/S3).
- 손절: 브레이크아웃 진입 시 PP(돌파 실패 시 중심선 재진입 = 가설 기각) 하회/상회 시 손절.
- 시간 청산: 다음 위클리 피벗 재계산 시점(월요일 UTC 00:00)까지 목표 미도달 시, 신규 피벗 기준으로 포지션 재평가(피벗이 갱신되며 R2/R3 레벨 자체가 바뀌므로 사실상 주 1회 강제 리뷰).

## 파라미터
- pivot_recalc=weekly (UTC 월요일 00:00 기준 전주 H/L/C)
- vol_confirm_mult=1.3 (범위 1.0~1.8)
- tp1_level=R2/S2 (부분청산 50%)
- tp2_level=R3/S3 (잔량청산)
- sl_level=PP (중심선 재진입 시 손절)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 전주 H/L/C(1d 또는 1w 캔들에서 집계 가능), 파생 피벗 레벨(사칙연산), 거래대금. 4h 캔들로 돌파/거부 판정.
- 난이도: 낮음. 피벗 계산 자체는 단순 산술(지표 라이브러리 불필요), 매주 월요일 UTC 기준 레벨 갱신 스케줄러만 필요. 바이낸스 REST 캔들(1w 또는 1d 집계)로 완전 구현 가능, 오더북/틱 불필요.
- 주의: 원문들이 "주간 피벗"이라 통칭하나 정확한 위클리 기준일(월요일 UTC 자정)은 매체마다 다를 수 있어(일부는 일요일 자정 기준) 재현 시 우리 기준(UTC 월요일 00:00, 봇 표준시)을 명시적으로 고정해야 함.

## 스카우트 메모
- **강점**: 기존 195개+ 스펙 중 인트라데이 피벗(카마릴라·CPR)은 있으나 **위클리(주간) 피벗은 전무** — 순수 신규 타임프레임. 계산이 결정론적이고 과최적화 여지가 거의 없음(피벗 공식 자체엔 튜닝 파라미터가 없음, 거래량 확인 배수와 손익 레벨만 파라미터). 업계에서 가장 보편적으로 쓰이는 지지/저항 프레임워크 중 하나라 "다수 트레이더가 같은 레벨을 보고 있다"는 자기충족적 효과(self-fulfilling) 기대 가능.
- **의심점**: 정량 백테스트 근거 전무 — 참여지표도 "내장 지표라 흔함"이라는 간접 정황뿐, 직접적 성과 검증은 없음. 브레이크아웃 vs 리버전 두 가설 중 어느 쪽이 실제 크립토 시장에서 작동하는지 사전 판단 불가(전통 주식 피벗 트레이딩은 통상 리버전 쪽이 더 자주 언급되나, 크립토는 추세성이 강해 브레이크아웃이 더 나을 수 있음 — A/B 필수).
- **우리 슬리브와의 관계**: 기존 `central-pivot-range-cpr-breakout-fade-scalp.md`·`camarilla-pivot-fade-breakout-scalp.md`는 **일간 피벗 기반 단타**인 반면 이건 **주간 피벗 기반 스윙**이라 타임프레임·홀딩기간이 근본적으로 다름(레벨 갱신 주기가 7배 김 = 신호 빈도 훨씬 낮음, 수수료 부담 적어 스윙 슬리브 성격에 부합). 완전 대체보다는 별도 스윙 후보로 검증 권장.
