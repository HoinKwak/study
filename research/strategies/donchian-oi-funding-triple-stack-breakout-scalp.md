# [단타] 돈치안 브레이크아웃 + OI 증가 확증 + 펀딩 비과열 3중 스택 (파생 확인형 돌파)

- **출처**: 프레임 근거 https://trendspider.com/learning-center/donchian-channel-trading-strategies/ (돈치안 브레이크아웃 기본형) /
  파생 확인 로직 근거: https://cryptoquant.com/insights/quicktake/684ae1a2c26bc826d28c7152-Binance-Open-Interest-Divergence-Signals-Caution-as-Bitcoin-Approaches-110K (CryptoQuant, OI 국면 4분면) /
  기존 보유 `donchian-adx-breakout.md`(ADX+거래량 확인), `turtle-trading-dual-donchian-swing.md`(장기 스윙), `oi-roc-price-divergence-squeeze-reversal-scalp.md`(반전형)와 **차별화**: 이 스펙은 돈치안 채널 자체는 재사용하되 확인필터를 **가격지표(ADX)가 아닌 파생지표(OI 증가+펀딩 비과열) 2종으로 전면 교체**한 트렌드컨티뉴에이션(추세지속확증)형 — OI-ROC 스펙과 정반대로 "OI가 증가해야" 진입(그쪽은 OI 급감이 조건).
- **참여지표**: - (자체 규칙화, 개별 원문에 이 3중 조합 백테스트는 없음)
- **백테스트 근거**: **없음(자체 스태킹 설계, 정직히 참여지표/개념 기반으로 분류)**. 개별 요소(돈치안 브레이크아웃, OI 증가=신규자금 유입 확증)는 각각 업계에서 널리 통용되나 **이 3중 조합 자체의 정량 백테스트는 찾지 못함**. 채택 전 자체 백테스트 필수 — 특히 필터를 추가할수록 신호 빈도가 급감하므로 표본 부족 위험을 우선 점검.
- **타임프레임**: 15m 신호 / 1h 확인
- **시장/대상**: BTC·ETH·시총상위 알트 무기한 (OI·펀딩 데이터가 유의미한 유동성 종목)

## 진입 규칙
- 채널: 돈치안 상단 = 최근 donchian_n(예 20봉, 15m=5h) 최고가, 하단 = 최근 20봉 최저가.
- **3중 스택 조건(모두 동시 충족)**:
  1. **가격**: 종가가 돈치안 상단(또는 하단) 돌파 마감.
  2. **OI 확증**: 돌파 시점 OI가 최근 oi_lookback(예 12봉=3h) 대비 oi_roc_min(예 +4%) 이상 증가 — "청산 랠리가 아닌 신규 포지션 유입에 의한 돌파" 확인(청산 위주 돌파는 지속력이 짧다는 통설 반영).
  3. **펀딩 비과열 게이트**: 현재 펀딩률(`premiumIndex` 기준 예측 펀딩) 절대값이 funding_cap(예 0.08%/8h) 미만 — 이미 과열된 방향으로의 추가 진입(뒤늦은 추격)을 배제.
- 롱: 상단 돌파 + OI 증가 + 펀딩 비과열 → 롱. 숏: 하단 돌파(역방향 동일 조건) → 숏.
- 확인 TF(1h): 돌파 방향과 1h EMA20 기울기가 같은 방향일 때만 최종 진입(단기 노이즈 돌파 배제).

## 청산 규칙
- 익절: 돈치안 중간선까지 트레일링, 또는 목표 R:R 1.8~2.2 도달.
- 손절: 돌파봉 반대 극값(롱은 신호봉 저가) 또는 진입가 −1.2×ATR(15m,14) 중 더 타이트한 쪽.
- 시간/조건 청산: max_hold(예 16봉=15m×16=4h) 내 미도달 시 청산. OI가 재차 감소 전환하면 조기 청산(추세 신뢰 상실).

## 파라미터
- donchian_n=20 (범위 15~30)
- oi_lookback=12봉(15m, 범위 8~20), oi_roc_min=+4% (범위 2~6%)
- funding_cap=0.08%/8h (범위 0.05~0.12%)
- confirm_ema=EMA20(1h)
- atr_stop_mult=1.2 (범위 1.0~1.8)
- rr_target=1.8~2.2
- max_hold=16봉(15m 기준)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 돈치안 채널(고저가만), OI 히스토리(`openInterestHist`), 펀딩률/예측펀딩(`premiumIndex`), EMA20(1h), ATR. 캔들 + OI + 펀딩 3종 REST가 필요하나 모두 기존 스펙들(`funding-rate-extreme-contrarian`, `oi-roc-price-divergence-...`)과 인프라 공유.
- 주의: 오더북/틱/실시간청산 불필요. **3중 필터로 신호 빈도가 크게 줄 것으로 예상** — 백테스트 시 표본수(트레이드 건수)를 먼저 확인해 통계적 유의성 판단 필요.

## 스카우트 메모
- 강점: (a) 다중조건 확인 스태킹 + (b) 파생 고유신호(OI+펀딩)를 **가격 브레이크아웃과 결합**한 구조로, 기존 볼린저+거래량+OI 단타(진입필터 유사 철학이나 지표조합 다름: 돈치안+OI+펀딩 vs 볼린저+거래량+OI)와 **대체재이자 대조군**이 될 수 있음.
- 의심점: 이번 발굴 중 유일하게 순수 자체설계(원문 백테스트 없음) — 필터가 3개라 신호가 희소해질 위험 큼, 우리 유니버스에서 표본이 통계적으로 유의미한 수(예 트레이드 30건+)를 만들 수 있는지 먼저 점검 필요.
- 우리 슬리브와의 관계: 기존 단타(볼린저 돌파+거래량+OI, `vol_spike≥5·squeeze≤35%·body≥1.3ATR`)와 유사한 "돌파+확증" 철학이나 **지표조합이 다른 대안**(볼린저 대신 돈치안, 거래량 대신 OI+펀딩) — 교체 후보라기보다 병행 비교용 대조 전략으로 적합.
