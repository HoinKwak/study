# [스윙] Deribit DVOL-실현변동성 괴리(변동성 리스크 프리미엄) 레짐 필터

- **출처**: 데이터 — https://docs.deribit.com/ (Deribit 공식 API, `public/get_volatility_index_data` 엔드포인트. 2026-08-09 직접 curl로 실호출해 BTC 시간봉 IV 데이터[예: 2023-11-15 구간 56.63→60.44] 정상 반환 확인 — 인증 불필요, 무료 공개) /
  개념·근거 — https://arxiv.org/pdf/2410.15195 (Almeida, Grith, Miftachov, "Risk Premia in the Bitcoin Market", WebSearch 스니펫으로 확인: "실현-내재 변동성 스프레드가 BTC에서 지속적으로 음수이며 그 크기가 S&P500보다 훨씬 크다"는 학술적 발견) /
  실전 구현 사례 — https://github.com/pi-mis/btc-dvol-strategy (개인 개발자 저장소, "eVRP" 개념으로 DVOL 기반 페이퍼트레이딩 진행 중. **WebFetch로 원문 확인 — 백테스트 수치는 저장소에 게재돼 있지 않음**[진입임계값 `eVRP≥10.0`만 확인, 성과 미공개]).
- **참여지표**: - (arxiv 논문·개인 GitHub 저장소, SNS 참여지표 집계 대상 아님).
- **백테스트 근거**: **없음(옵션시장 변동성 리스크 프리미엄이라는 학술적으로 뒷받침된 현상을 futures 방향성 레짐필터로 번역한 자체 설계, 정량 수치 지어내지 않음)**. 위 arxiv 논문은 "BTC의 실현-내재 변동성 스프레드가 지속적으로 음수·대형"이라는 **정성적 방향성**만 확인됨(WebSearch 요약 기반, 논문 본문 수치까지는 미확인 — 원문 PDF 표 데이터는 별도 검증 필요). **이 논문은 옵션 델타헤지 기반 변동성 매도 전략에 대한 것으로, 본 스펙처럼 무기한 선물 방향성 매매로 번역한 버전의 성과는 검증된 바 없음**.
- **타임프레임**: 일봉(1d) 레짐 판정 → 4h 진입 타이밍.
- **시장/대상**: **BTC·ETH 무기한만**(Deribit DVOL은 BTC·ETH 두 자산만 산출 — SOL 등 확인 시도 결과 데이터 없음[2026-08-09 curl 확인]. 표준 7종목 중 5종목은 이 전략 적용 불가 — 유니버스가 본질적으로 좁음을 사전에 명시).

## 진입 규칙
- **DVOL**: Deribit이 산출하는 30일 선물지향적 내재변동성 지수(옵션 스마일 기반, 연환산 %). `get_volatility_index_data`로 일봉 종가 확보.
- **실현변동성(RV)**: BTC/ETH 무기한 klines close로 최근 20일 로그수익률의 연환산 표준편차.
- **변동성 리스크 프리미엄**: `VRP = DVOL - RV` (양수면 내재변동성이 실현변동성보다 비싸게 매겨진 상태 = 옵션시장이 앞으로의 변동을 과대평가 중).
- **레짐 판정**: `VRP`의 최근 90일 롤링 z-score `z_vrp`.
- **레짐 A(변동성 고평가, z_vrp ≥ +1.0)**: 시장이 실제보다 더 큰 변동을 각오하고 있는 상태 — 논문의 "VRP 지속적 음수·대형"(실현이 내재보다 낮게 나오는 경향) 발견에 근거해 **평균회귀(레인지/페이드) 전략을 선호**. 가격이 최근 20봉(4h) 볼린저(20,2) 상단 이탈 후 종가 재진입 시 숏, 하단 이탈 후 재진입 시 롱.
- **레짐 B(변동성 저평가, z_vrp ≤ -1.0)**: 실현변동성이 옵션시장 예상보다 더 뜨겁게 나오는 드문 상태(시장이 허를 찔림) — **추세추종/브레이크아웃 전략을 선호**. 가격이 최근 20봉(4h) 고점 상향 돌파 종가 확정 시 롱, 저점 하향 돌파 시 숏.
- 레짐 중립(`|z_vrp| < 1.0`) 구간은 **무포지션**(필터 미충족).

## 청산 규칙
- 익절: 레짐 A(평균회귀)는 볼린저 중심선(20MA) 도달, 레짐 B(추세)는 ATR(14,4h)×3.0 트레일링.
- 손절: 레짐 A는 진입 이탈폭의 1.5배 역행, 레짐 B는 돌파 레벨 종가 재이탈.
- 시간 청산: 레짐이 뒤집히면(`z_vrp` 부호 반전) 즉시 청산(레짐 전제 자체가 깨졌으므로).

## 파라미터
- rv_window=20일 (범위 14~30)
- vrp_zscore_window=90일 (범위 60~180)
- regime_th=1.0 (범위 0.75~1.5)
- bb_period=20 / bb_std=2.0 (4h 기준)
- atr_trail_mult=3.0 (범위 2.0~4.0)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: Deribit DVOL 일봉(신규 외부 API 연동 — 바이낸스 생태계 밖의 **첫 외부 데이터 소스**), BTC/ETH klines(실현변동성 계산용), 볼린저·ATR(기존 인프라).
- 주의: **Deribit API는 바이낸스와 별개 인프라**라 신규 커넥터 필요(무료·인증 불필요·rate limit 정보는 원문 미확인이라 과도한 폴링 주의). DVOL 히스토리 시작 시점(2021년 3월 DVOL 정식 출시 추정, [추정] 이전 데이터는 없거나 제한적일 수 있음 — 다운로드 시 실제 시작일 확인 필요).

## 스카우트 메모
- **예상 표본 빈도**: [추정] `|z_vrp|≥1.0`은 90일 롤링 기준 정규분포 가정 시 전체 기간의 약 30%가 레짐 A 또는 B에 해당하나, 여기에 볼린저 이탈/돌파 확인까지 추가로 요구하므로 실제 트레이드 트리거는 종목당(BTC·ETH 2종목뿐) 연 15~30건 수준으로 추정(실측 필요). 자산이 2종목뿐이라 총 표본 자체가 다른 7종목 스펙 대비 구조적으로 얇음 — 채택 시 이 점을 최우선 리스크로 취급.
- **gross 엣지 가설**: 학술 논문이 확인한 "BTC 실현-내재 변동성 스프레드 지속적 음수·대형"은 옵션 매도자(변동성 판매자)가 구조적으로 프리미엄을 수취해왔다는 의미 — 이를 그대로 방향성 매매로 옮기면 "IV가 비쌀 때는 실제로 덜 움직이는 경향이 있으니 레인지 매매가 유리, IV가 쌀 때는 실제로 더 움직이는 경향이 있으니 추세 매매가 유리"라는 논리적 다리를 놓은 것 — **이 다리 자체가 검증되지 않은 설계 가정**(옵션시장의 변동성 리스크 프리미엄이 방향성 예측력으로 전이된다는 보장 없음)이므로 우선순위는 중간으로 판단.
- **엣지 대비 거래빈도**: 저빈도(연 15~30건/자산)라 수수료 부담은 작을 것으로 예상되나, 이는 최근 라운드에서 "저빈도인데도 신호 자체가 무근거"로 FAIL한 사례(위클리 아웃사이드바 등)와 동일 리스크 패턴 — 빈도가 낮다고 채택 우선순위를 높이기보다 gross 엣지 검증을 반드시 선행해야 함.
- **독립성/클러스터링 위험**: BTC·ETH 단 2종목이라 표본 자체가 작고, 두 자산의 VRP 레짐이 매크로 변동성 사이클(예: 2022년 FTX, 2024년 4월 조정 등)에 강하게 동조화될 가능성이 높아 **명목상 "BTC+ETH 합산 N건"이 사실상 훨씬 적은 고유 이벤트 수**일 수 있음(다른 다수 스펙에서 반복 확인된 패턴과 동일 우려).
- **7종목 신호 충분성**: **원천적으로 불가** — Deribit DVOL이 BTC·ETH만 제공하므로 BNB·SOL·XRP·DOGE·ADA는 이 전략을 적용할 수 없음. CME COT(BTC 단독)와 유사한 좁은 유니버스 제약을 스펙 단계에서 명시.
- **강점**: 완전히 새로운 데이터 원천(옵션시장 내재변동성) — 캔들·OI·펀딩·롱숏비율 등 기존 축을 전혀 쓰지 않는 구조적으로 독립된 엣지 원천. 학술 논문의 뒷받침이 있어 "감으로 지어낸" 가설은 아님.
- **의심점**: 옵션시장 VRP → 방향성 신호 전이 가정이 검증되지 않음. 자산 2종목·저빈도로 통계적 유의성 확보가 어려울 수 있음(과거 BTC 200주선·CME COT처럼 "터치 횟수가 적어 검정 자체가 곤란"할 위험). 신규 외부 API 연동 비용도 있음.
- **우리 슬리브와의 관계**: 완전 신규 카테고리(파생상품 옵션시장 변동성) — 기존 GARCH(1,1)·파킨슨 변동성 스펙(가격 시계열 자체에서 추정하는 실현변동성 기반)과 달리 **시장이 매긴 가격(옵션 프리미엄)에서 기대변동성을 직접 관측**한다는 점이 본질적으로 다름.
