# [단타] 수익률-거래량 롤링상관계수 레짐전환 브레이크아웃 게이트

- **출처**: 개념 배경 — 거래량이 가격 움직임을 "확인(confirm)"해야 추세가 신뢰할 만하다는 고전 다우이론·OBV(Granville, 1963)류 통설. 본 스펙이 쓰는 **"수익률과 거래량의 롤링 피어슨 상관계수"라는 정확한 통계량 자체를 게이트로 쓰는 백테스트 원문은 찾지 못함 — 스카우트 자체 설계**(개념만 통설, 규칙·임계값은 지어내지 않고 자체 설계임을 명시).
- **참여지표**: - (자체 설계, 개념적 배경만 고전 통설)
- **백테스트 근거**: **없음(자체 설계)**. 채택 전 자체 백테스트 필수.
- **타임프레임**: 15m 신호 / 1h 확인 없음(단일 TF로 단순화, 게이트 자체가 통계적 필터라 상위TF 필터 중복 지양).
- **시장/대상**: BTC·ETH·시총상위 알트 무기한 (24h 거래대금 $10M+ 유니버스, 거래량 데이터 노이즈가 과도한 초저유동성 종목 배제).

## 핵심 아이디어 (신규성 / 직전 라운드 게이트 무가치 교훈 반영)
- 직전 라운드에서 "게이트 없는 순수 대조군이 게이트보다 오히려 우수"했던 실패(실현변동성 비대칭 게이트)를 반영해, 본 스펙은 **게이트의 정의 자체를 매우 단순한 기존 대조군(순수 Donchian 20봉 브레이크아웃, 우리 라이브 `scalp15m`의 볼린저+거래량 필터와도 다른 가장 기본적인 채널 브레이크아웃)과 나란히 반드시 비교**하도록 스펙 단계에서 못박는다. **"롤링 상관계수 게이트가 있는 버전"과 "게이트 없는 순수 브레이크아웃"을 반드시 병행 백테스트해 게이트가 실제로 승률/PF를 개선하는지 정량 확인할 것 — 개선 없으면 게이트 자체가 무의미하다는 결론이 유효한 결과다.**

## 진입 규칙
- 지표: `r(t)` = 15m 봉별 로그수익률, `v(t)` = 해당 봉 거래대금(quote volume).
- `corr(t) = rolling_pearson_corr(r[t-N+1..t], v[t-N+1..t])`, N=20봉(15m×20=5시간). **최소표본 요건: 유효 데이터 20개 미만이면(데이터 시작 구간·결측 구간) 상관계수 계산 안 하고 신호도 없음(부분표본으로 보간·대체 금지 — 직전 라운드 band_std 소표본 왜곡 교훈 직접 반영)**.
- 1차 조건(순수 브레이크아웃, 대조군과 동일): 종가가 최근 `donchian_n`=20봉 고가를 상향 돌파(롱) 또는 저가를 하향 돌파(숏).
- 2차 조건(게이트, 실험군에만 적용): `corr(t) >= +corr_th`(=+0.25, 상승 봉에 거래대금이 통계적으로 동반 — 광범위한 매수 참여)일 때만 롱 신호 확정. `corr(t) <= -corr_th`(=-0.25, 하락 봉에 거래대금 동반)일 때만 숏 신호 확정.
- 게이트 미충족 시(브레이크아웃은 발생했으나 상관계수 조건 미달) 신호 폐기(진입 안 함) — **단, 대조군 러닝에서는 이 2차 조건을 아예 제거하고 1차 조건만으로 진입해 비교**.

## 청산 규칙
- 익절: ATR(15m,14) 트레일링 × `atr_trail_mult`=1.2 (신고가/신저가 갱신 시 갱신).
- 손절: 브레이크아웃 봉의 반대쪽 극값(롱은 돌파봉 저가, 숏은 돌파봉 고가).
- 시간 청산: `max_hold_bars`=12봉(15m×12=3시간) 내 목표 미도달 시 강제청산.

## 파라미터
- corr_window(N)=20봉 (범위 15~40)
- corr_th=0.25 (범위 0.15~0.40)
- donchian_n=20봉 (범위 15~30)
- atr_trail_mult=1.2 (범위 1.0~1.8)
- max_hold_bars=12 (15m 기준, 범위 8~20)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 15m 캔들 종가·거래대금, 20봉 롤링 피어슨 상관계수(`pandas.Series.rolling(N).corr()` 등으로 구현 용이), Donchian 채널(20봉 고/저), ATR14. 오더북/틱/실시간청산 불필요 — **바이낸스 REST 캔들만으로 완전 구현 가능**(별도 OI·펀딩·metrics 덤프 불필요, 데이터 의존성 최소).
- 주의: 상관계수는 이상치(단일 초대형 거래량 봉)에 민감할 수 있음 — 극단치 클리핑(예: 거래량 상하위 1% 윈저라이징) 여부를 스윕에 포함 권고.

## 스카우트 메모
- **예상 표본 빈도**: 20봉 신고가/신저가 돌파(1차 조건 단독) 자체는 기존 돈치안 계열 스펙들에서 종목당 [추정] 연 100~200회 수준으로 흔함. 상관계수 게이트(2차 조건)가 추가되면 대략 정규분포 가정 시 대략 상관계수 20봉 표본에서 |corr|>=0.25를 만족하는 비율은 시장 상황에 따라 편차 크나 [추정] 30~50% 수준으로 예상 — 게이트 적용 후 **연 40~100건**으로 추정. 실측 필요, 특히 corr 임계값이 상시 쉽게 충족되는지(직전 라운드 "명목 2σ가 실제 12~13% 돌파"와 같은 임계값 명목-실측 괴리) 반드시 확인.
- **독립성**: 순수 가격·거래량 기반 종목 내부 통계량이라 종목 간 매크로 클러스터링 위험은 OI/펀딩 계열보다 낮음. 다만 시장 전체가 추세장일 때 여러 종목이 동시에 브레이크아웃+상관계수 조건을 동시 충족할 가능성은 있어(예: BTC 급등일에 다수 알트 동반 상승) 이벤트(일자) 단위 클러스터링 진단 권고.
- **강점**: 데이터 요구가 가장 가볍다(캔들만 필요) — 백테스트 착수 비용이 낮고, 기존 인프라(klines 덤프)만으로 즉시 실행 가능. 대조군 설계가 스펙 단계에서부터 명시돼 있어 "게이트 부가가치 있는지"를 첫 러닝부터 바로 확인 가능.
- **의심점**: "거래량이 수익률과 상관돼야 건전한 추세"라는 직관은 이미 OBV·AD Line·거래량 스파이크 필터 등으로 여러 형태로 시도된 통설이라(우리 카탈로그에도 유사 계열 다수 존재) 새로운 정보라기보다 **기존 거래량 확인 필터들과 정보가 상당 부분 중복될 위험**이 있음 — 직전 라운드 세미배리언스 게이트가 단순 모멘텀부호 게이트와 구분 안 됐던 것과 유사한 결과가 나올 수 있음을 인지하고 착수.
- **우리 슬리브와의 관계**: 라이브 `scalp15m`(볼린저 이탈+거래량 스파이크+OI 필터)과 15m·거래량이라는 공통 요소가 있으나, 신호 생성 메커니즘(볼린저 돌파 vs 순수 채널 브레이크아웃, 거래량 스파이크 절대량 vs 수익률-거래량 상관계수)이 달라 **신호소스 비교용**(직접 대체 목적 아님).
