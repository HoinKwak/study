# [단타] 아시아 세션 레인지(00:00~08:00 UTC) + 런던오픈 돌파 (ICT Asian Range)

- **출처**: FXNX 블로그, "The Asian Breakout I Run While Sleeping (Set & Forget)" —
  https://fxnx.com/en/blog/master-asian-session-breakout-ultimate-set-forget-strategy (**WebFetch로 원문 규칙 확인**).
  같은 개념의 커뮤니티 표준 정의: ICT(Inner Circle Trader) "Asian Range" — https://innercircletrader.net/tutorials/ict-asian-range/
  (WebFetch 실패·본문 미확인, 제목·검색요약 기준 보조 참고만). 다수의 FX/크립토 유튜브·블로그가 동일 프레임(아시아 박스 → 런던 브레이크아웃)을
  반복 제시(LiteFinance ORB 가이드, ForexFactory 스레드, Defcofx 등 다수 — 검색결과 상위 다건, 커뮤니티 표준 셋업으로 판단).
- **참여지표**: 개별 게시물 조회수·좋아요 미집계이나, "아시아 박스 + 런던 브레이크아웃"은 FX/ICT 트레이딩 커뮤니티에서 **가장 흔히
  반복되는 세션 브레이크아웃 프레임** 중 하나(검색 상위 다수 독립 출처가 동일 구조 서술) — 다출처 반복 등장으로 참여지표 대체.
- **백테스트 근거**: **없음(원문에 정량 백테스트 수치 부재, FXNX 원문 확인 결과 "이론적 예시만 있고 히스토리컬 성과 데이터 없음"이라고
  WebFetch 결과 명시됨)**. 참여지표(다출처 반복성) 기반으로 채택, 자체 검증 필수.
- **타임프레임**: 레인지 형성 00:00~08:00 UTC(8시간), 브레이크아웃 트리거는 15m~1h 봉.
- **시장/대상**: BTC·ETH 무기한(원래 FX 전략이나 크립토도 아시아·런던 유동성 시간대 차이가 존재해 커뮤니티에서 크립토에도 널리 적용).

## 진입 규칙
- **레인지 정의(아시아 박스)**: **00:00~08:00 UTC** 구간의 최고가·최저가로 박스 상/하단 설정(그 구간이 완전히 마감된 08:00 UTC 시점 확정).
- **프랑크푸르트 페이크아웃 필터**: 07:00~08:00 UTC(프랑크푸르트 프리마켓) 구간의 돌파는 무시 — **08:00 UTC 봉 마감 확인 후에만** 트리거.
- **롱**: 08:00 UTC 이후 15m(또는 1h) 종가가 아시아 박스 **상단 위로 마감** → 롱 진입(직후 봉 시가 또는 해당 봉 종가).
- **숏**: 종가가 박스 **하단 아래로 마감** → 숏 진입.
- 하루 중 박스당 최초 유효 돌파 1회만 트레이드(양방향 돌파 시 먼저 발생한 방향만 채택, 재진입 없음).

## 청산 규칙
- **손절**: 아시아 박스 폭의 **중간점(midpoint)**에 배치(박스 안쪽 절반까지는 되돌림을 허용해 노이즈에 의한 조기 손절 방지 — 원문 "Mid-Point Rule").
- **익절**: 해당 일 **ADR(Average Daily Range, 최근 14일 일봉 고저폭 평균)**의 **50~60%**를 목표로 설정(뉴욕 세션에서 되돌림 가능성을
  피하기 위해 익절을 보수적으로 설정 — 원문 권고).
- **시간 청산**: 다음날 00:00 UTC(새 아시아 박스 시작) 전까지 미도달 시 강제 청산(세션이 바뀌면 셋업 무효화).

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 없음(순수 가격 레벨 + UTC 세션 경계 + ADR(단순 고저폭 이동평균)). 오더북/틱 불필요.
- 주의: **바이낸스 REST 15m~1h·1d 캔들로 완전 구현 가능**. UTC 고정 시간창이라 America/New_York 기반이었던 기존 `ny-4h-orb`와
  달리 **서머타임(DST) 영향이 없음**(UTC는 DST 미적용) — 오히려 우리 인프라(캔들 타임스탬프가 UTC)와 궁합이 좋아 타임존 변환 버그 위험이 적음.

## 스카우트 메모
- **강점**: 아시아(저유동성 레인지 형성) → 런던(유동성 유입 시 방향성 확장)이라는 구조는 크립토 24시간 시장에서도 관측 보고가 많고,
  로직이 완전히 규칙 기반이라 구현이 매우 쉬움. UTC 고정이라 우리 기존 NY-ORB보다 타임존 버그 리스크가 낮음.
- **의심점**: 정량 백테스트 근거가 전혀 없어(원문도 이론적 예시만 제시) **참여지표(다출처 반복)만으로 채택**한 항목 — 크립토 실측
  전에는 승률·PF 전혀 모름. 기존 `killzone-session-timing.md`(런던/뉴욕 킬존 시간필터, FX 백테스트 승률68%·PF2.8이나 크립토 미검증)와
  세션 개념이 겹치지만, 이쪽은 **레인지 브레이크아웃이라는 독립 진입 로직**(킬존은 시간필터 오버레이일 뿐 자체 신호가 없음)이라는 점에서
  구조적으로 다름 — 서로 대체재보다 **병행 검증 대상**.
- **우리 슬리브와의 관계**: 기존 `ny-4h-orb-fakeout-fade-scalp.md`(뉴욕 첫4시간 레인지, **페이드/역추세**, 이미 자체검증 결과 승률32%로
  약한 마이너스 확인됨)와 프레임은 유사하나, 이 전략은 **돌파 추세추종**(페이드 아님) + **다른 세션(아시아→런던)** + **UTC 고정**이라는
  점에서 별개 가설. NY-ORB가 페이드로 실패했다는 사실이 이 전략(돌파 방향)에는 참고만 되고 직접 반증은 아님.
