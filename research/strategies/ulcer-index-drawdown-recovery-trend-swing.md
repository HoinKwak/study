# [스윙] Ulcer Index 드로다운 회복 기반 추세 건강도 필터

- **출처**: Martin, P. & McCann, B. (1987/1989) 원 지표 — https://www.earn2trade.com/blog/ulcer-index/ , https://gocharting.com/docs/charting/technical-indicator/oscillators/ulcer
- **참여지표**: - (학술/기술적 지표 원전, SNS 소스 아님)
- **백테스트 근거**: 없음. Ulcer Index/Ulcer Performance Index(Martin Ratio)는 리스크조정성과 지표로 널리 쓰이지만, 이를 **매매 진입 신호**로 쓰는 백테스트 결과는 검색에서 확인하지 못했다 — **정량 근거 없음, 정직히 표기**. 아래는 원 지표의 정의(낙폭의 깊이·기간을 함께 반영하는 RMS 낙폭)를 우리가 직접 트레이딩 규칙으로 설계한 것.
- **타임프레임**: 1d 신호 / 4h 확인
- **시장/대상**: 바이낸스 USDT-M 무기한, major_bases + 거래대금 $10M+ 알트

## 핵심 아이디어
Ulcer Index(UI)는 `UI = sqrt(mean(drawdown_i^2))`(drawdown_i = 최근 N봉 롤링 고점 대비 현재 종가의 %낙폭, 상승 시 0)로, **단순 최대낙폭(MDD)과 달리 낙폭의 깊이와 지속기간을 함께 반영**하는 RMS(제곱평균제곱근) 통증 지수다. 이 스펙은 "N일 신고가를 갱신했지만 그 직전 상승 구간의 UI가 낮다(=조정이 얕고 짧았다=건강한 상승)"을 추세 지속 신호로, "UI가 최근 급등(=낙폭이 깊어지는 중)"을 추세 종료/청산 신호로 쓴다.

## 예상 신호 빈도
- N일(20일) 신고가/신저가 갱신 자체는 종목당 연 15~35회 추정(추세장 편중).
- UI 하위 30% 백분위 게이트를 추가로 통과해야 하므로 실제 진입은 **종목당 연 8~20건** 추정. 스윙 취지(저빈도·고R)에 부합하나 표본이 얇을 수 있어 **7종목 합산 최소 표본 확보를 스펙 단계에서 유의**.

## 전제의 내적 일관성 사전 검토
- 전제: "낙폭의 깊이+기간이 함께 얕았던(=UI 낮은) 상승 후 신고가는, 단순히 최근 하락폭만 얕았던 경우보다 추세 지속력이 높다."
- **내적 모순 위험**: N일 신고가 갱신 자체가 정의상 최근 낙폭이 작다는 것과 상당 부분 중복(신고가 근처 = 되돌림이 얕았을 수밖에 없음) — UI가 "신고가"라는 조건과 별개의 정보를 주는지가 핵심 쟁점.
- **"이 전제 방향이 실측으로 성립하는지 먼저 확인"**: 백테스터는 (a) N일 신고가 시점들의 UI 분포를 먼저 뽑아 분산이 충분한지(전부 낮은 값에 몰려 있으면 게이트가 사실상 항상 통과=무의미) 확인하고, (b) UI 하위 30% 그룹과 UI 상위 30%~70% 그룹(둘 다 "신고가"라는 조건은 동일)의 신고가 후 N봉 순방향 지속 승률을 게이트 없이 비교해 실제로 차이가 나는지 먼저 집계한다.

## 동어반복(tautology) 위험 사전 점검
- **핵심 우려**: UI가 단순 "최근 되돌림 %(간단 MDD)"의 복잡한 재계산일 뿐일 위험.
- **사전 점검 방법**: UI(RMS 낙폭)와 동일 윈도우 **단순 최대낙폭(%)**의 상관계수를 먼저 계산. 상관 ≥ 0.85면 UI가 단순 MDD의 재포장이라 판단하고 반드시 대조군(단순 MDD 게이트)과 비교해 부가가치를 입증해야 한다. UI는 이론상 "짧고 깊은 1회성 조정"과 "길고 얕은 반복 조정"을 구분(후자가 UI를 더 높임)하므로 MDD와 완전히 같지는 않을 것으로 예상하나 실측 필요.

## 종목 간 신호 상관 사전 예상
- 신고가 갱신과 낙폭 건강도는 시장 전체 리스크온/오프 사이클(불장/약세장)에 강하게 연동돼 **종목 간 높은 상관**(예상 0.4~0.7, 특히 메이저-알트 동시 신고가/동시 조정)을 예상. 과거 여러 스펙(BTC-금 로테이션 등)에서 확인됐듯 "종목간 신호 상관이 높으면 LOO·다종목 확장이 착시 표본을 만든다" — 백테스터는 **종목별 독립 t-검정 + 동시진입일 비율**을 반드시 별도 보고한다.

## 진입 규칙
- 롱: 1d 종가가 최근 20일 신고가 갱신 + 해당 시점 UI(20일 윈도우, 일간 낙폭 RMS) 백분위(과거 1년 롤링) ≤ 30% + 4h 확인봉이 20EMA 위가 아니라 **단순 직전 4h 종가 대비 상승 마감**(고전지표 배제).
- 숏: 20일 신저가 갱신 + "역방향 UI"(랠리 중 되돌림의 RMS, 상승 낙폭을 낙폭으로 정의해 동일 계산) 백분위 ≤ 30% + 4h 확인봉이 직전 종가 대비 하락 마감.

## 청산 규칙
- 익절: 정해진 목표가 없이 **UI가 상위 70% 백분위로 급등(추세 건강 악화)** 시 전량 청산.
- 손절: 진입가 대비 −2.0×ATR(1d,14).
- 시간/조건 청산: 최대 보유 20일(1d봉 20개). 20일 내 UI 조건 미충족(백분위 여전히 낮음) + 손절 미도달 시 20일 시점 시장가 청산.

## 파라미터
- ui_window=20일 (범위 14~30)
- ui_percentile_entry=30% (범위 20~40%)
- ui_percentile_exit=70% (범위 60~80%)
- hh_lookback=20일 (범위 15~40, "채널"이 아닌 단순 극값 룩백)
- stop_mult=2.0×ATR(1d) (범위 1.5~3.0)
- max_hold=20일 (범위 15~30)

## 핵심 대조군 정의
- **대조군 A**: UI 게이트를 **단순 최대낙폭(%) 게이트**로 교체(동일 임계 로직) — UI의 RMS(깊이+기간) 정보가 단순 MDD 대비 부가가치 있는지 검증(동어반복 점검과 연동).
- **대조군 B**: 게이트 없이 20일 신고가/신저가만으로 진입 — 게이트 자체의 순가치 확인.
- **대조군 C(방향반전)**: 신고가에서 숏, 신저가에서 롱(반대 방향) — UI 저값이 방향 무관 정보인지 확인.

## 사전 폐기 조건
- UI와 단순 MDD 상관 ≥ 0.85이면서 대조군 A와 성과 구분 불가 → FAIL(MDD 재포장 판정).
- UI 하위30%/상위30%~70% 그룹 간 지속승률 차이가 실측으로 없으면(사전검토 단계에서) 설계 자체 폐기, 백테스트 착수 안 함.
- 표본이 7종목 합산 OOS n<20이면 "판단불가"로 분류(FAIL 단정 안 함, 과거 여러 스윙 스펙의 표본부족 전례 참고).
- 종목간 동시진입일 비율이 50%를 넘으면 이벤트 단위 de-clustering 재검정을 반드시 병행 보고.

## 코딩 난이도 / 데이터 요구
- 필요 지표: 1d·4h klines(종가), ATR14(1d), 롤링 UI 계산(20일 윈도우 낙폭 제곱평균제곱근) — 구현 난이도 낮음.
- 주의: 오더북/틱 불필요. 다만 표본부족 위험이 스펙 단계부터 예견되므로 백테스터는 착수 전 신호 카운트를 먼저 산출해 지나치게 희소하면(예 종목당 연 5건 미만) 즉시 보고하고 파라미터 완화 여부를 결정한다.

## 스카우트 메모
- **강점**: 기존 335개 중 "낙폭의 깊이×기간을 함께 보는" 지표는 없음(ADX/Choppiness/Hurst 등은 추세 강도·랜덤성 측정이지 낙폭 구조 측정이 아님). 계산이 간단해 구현 리스크 낮음.
- **의심점**: 동어반복(신고가=필연적 저낙폭) 위험이 구조적으로 크고, MDD 재포장 위험도 동시에 존재 — 이번 라운드 후보 중 사전검토 실패 가능성이 가장 높다고 판단됨. 표본부족 위험도 사전에 명시함.
- **우리 슬리브와의 관계**: 스윙(1d) 슬리브가 현재 비어있어(기존 스윙 전략은 손익비 미달로 제거됨) 채택 시 신규 스윙 슬리브 후보. 기존 볼린저 눌림목 중기와 트리거·게이트 모두 다름.
