# [스윙] 3대 롱숏비율 합의(voting consensus) 극값 컨트래리언

- **출처**: 지표 정의 — `data.binance.vision`의 `metrics` 덤프 3개 필드: `count_long_short_ratio`(전체 계좌수 기준 글로벌 비율), `count_toptrader_long_short_ratio`(상위 트레이더 계좌수 기준), `sum_toptrader_long_short_ratio`(상위 트레이더 포지션가치 기준). **이 정확한 3지표 합의(unanimity voting) 규칙은 스카우트 자체 설계 — 외부에 이 정확한 백테스트는 없음, 지어내지 않음.** 기존 보유 `toptrader-vs-global-ratio-spread-divergence-swing.md`(2지표 스프레드)·`toptrader-account-ratio-extreme-persistence-trend-swing.md`(단일지표 지속기간)·`toptrader-whale-concentration-count-vs-value-divergence-swing.md`(count vs value 다이버전스)와는 **2지표 스프레드/다이버전스가 아니라 3지표 전원 합의(voting) 여부를 이산 점수화**한다는 점에서 통계적 구성이 다름.
- **참여지표**: - (자체 설계)
- **백테스트 근거**: **없음(자체 설계, 정직히 표기)**. 채택 전 자체 백테스트 필수.
- **타임프레임**: 1d 신호 / 4h 확인.
- **시장/대상**: BTC·ETH·BNB·SOL·XRP·DOGE·ADA 무기한.

## 진입 규칙
- 데이터: `metrics` 3개 롱숏비율 필드(일봉 마감 시점 이전 마지막 5분 관측치 사용), ATR(22,1d).
- 각 지표 롤링 **60일** z-score 계산: `z_global`, `z_top_cnt`, `z_top_val`.
- **투표(vote)**: 각 지표별 `+1`(z>=+1.5, 롱 쏠림 극단) / `-1`(z<=-1.5, 숏 쏠림 극단) / `0`(그 외).
- **합의 점수**: `consensus = vote_global + vote_top_cnt + vote_top_val` ∈ {-3,...,+3}.
- **롱(컨트래리언)**: `consensus = -3`(3개 지표 전원 극단적 숏 쏠림 = 시장 전체 비관 극단) → 롱 진입.
- **숏(컨트래리언)**: `consensus = +3`(3개 지표 전원 극단적 롱 쏠림) → 숏 진입.
- `consensus`가 ±3이 아닌 경우(2/3 이하 합의) 진입하지 않음 — 백테스트에서 2/3 합의 대조군과 반드시 비교(아래 폐기조건 참조).

## 청산 규칙
- 익절: `sum_toptrader_long_short_ratio`의 z-score가 0을 재통과(평균회귀 완료)하거나 ATR22×2.5 트레일링 선도달.
- 손절: 진입가 ∓ ATR22 × 1.5.
- 시간 청산: 15일봉 경과 시 강제 청산.

## 파라미터
- z_window=60일 (범위 40~90), z_th=1.5 (범위 1.2~2.0)
- tp_atr_mult=2.5, sl_atr_mult=1.5, max_hold=15봉(1d)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: `metrics` 덤프 3개 롱숏비율 필드의 일별 추출·롤링 z-score, ATR(22,1d).
- 주의: 세 필드 모두 `metrics` 5분 덤프 필드로 실존 확인됨(기존 보유 3개 스펙에서 이미 실물 확인된 소스 재사용). 상위 트레이더 정의(계좌수 상위 20% 등)가 바이낸스 내부 기준이라 세부 방법론은 비공개 — 값 자체는 사용 가능.

## 스카우트 메모
- **예상 신호 빈도**: [추정, 넓은 범위] 단일 지표 `|z|>=1.5`는 경험적으로 전체 시간의 약 13~14%에서 발생(기존 정기루틴에서 실측된 값). 3개 지표가 완전 독립이면 전원 합의 확률은 `0.067^3≈0.03%`(12년에 1회)로 극히 희박하나, **세 지표는 서로 상관돼 있어(아래 참조) 실제 결합확률은 이보다 훨씬 높을 것** — 종목당 **연 8~25건**으로 사전 명시(불확실성 큰 추정임을 인정). 이 범위를 크게 벗어나면(특히 독립가정 수준으로 희박하면) 표본부족으로 판단불가 처리.
- **비용 감당 산술**: 1d 봉·1~3주 보유, 왕복수수료 0.14%가 목표(ATR×2.5) 대비 미미. 저빈도·고R 스윙 목표에 부합.
- **전제의 내적 일관성**: 3개 지표는 "누가 롱/숏에 쏠렸는가"라는 같은 상위 개념을 서로 다른 모집단(전체계좌·상위계좌수·상위포지션가치)으로 측정한 것이라 **예상 페어 상관 0.4~0.7**(중간~높음, 완전 동일은 아님)로 사전 명시. 상관이 0.85를 넘으면 세 번째 지표가 사실상 정보를 추가하지 않는(2지표로 퇴화하는) 것이므로, 백테스트에서 **"정확히 2/3 합의"와 "3/3 합의" 사후 수익률이 통계적으로 구분되는지**를 반드시 비교해 진짜 부가가치인지 확인.
- **종목 간 신호 상관**: 시장 전체 유포리아/캐피출레이션 국면에 메이저 전종목이 동시에 합의 극값에 도달할 가능성 있어 **예상 상관 0.3~0.6**(중간) — 종목간 동시발화일 비율 실측, de-clustering(고유 캘린더일 기준) 필수.
- **정규화 게이트 논증**: 각 지표의 롤링 z-score는 표준 자기정규화 게이트라 단일 지표 발화율은 정보와 무관하게 고정적(~13%)이나, **3개 전원 AND 조합이 유의한 선택성을 추가하는지**가 이 스펙의 핵심 주장 — 단일 최강 지표만 쓴 대조군(백테스트 필수 비교군) 대비 합의 조건이 실제로 더 나은 사후 수익률을 보이는지로 논증을 검증.
- **수익의 인과 경로**: 서로 다른 측정방법론(계좌수 기준·포지션가치 기준)이 동시에 동일한 극단을 가리킨다는 것은 소수 계좌의 왜곡이 아니라 시장 전반의 레버리지 소진(더 이상 태울 매수/매도 여력이 부족)을 의미해, 단일 지표 극값보다 스퀴즈/반전 신뢰도가 높다는 크라우디드 트레이드 컨트래리언 서사.
- **라이브 실행 가능성**: 1d 신호로 하루 한 번 판정, 종가 확정 후 다음날 메이커 지정가 진입 가능. 4h 확인TF은 체결 타이밍 미세조정용.
- **사전 폐기조건(사후 변경 금지)**: (a) OOS net PF < 1.2 또는 t 비유의(표본이 얇을 것으로 예상되므로 임계 다소 보수적으로 설정) (b) `consensus=±3` 사후수익률이 "단일 최강 지표 |z|>=1.5" 단독 대조군과 통계적으로 구분 불가 — 합의 조건의 부가가치 없음으로 FAIL (c) 종목간 동시발화로 실질 독립표본이 10건 미만이면 FAIL 대신 **판단불가**로 라벨 (d) 방향반전(모멘텀 추종) 대조군이 컨트래리언보다 명확히 우수하면 방향 가설 재검토.
- **강점**: 3지표 이산 투표 합의라는 구조는 기존 407개(2지표 스프레드/다이버전스, 단일지표 지속성)와 통계적 구성이 명확히 다름.
- **의심점**: 지표 간 상관이 예상보다 높아 3번째 지표가 정보를 추가하지 않을 위험, 절대 표본 희소성(연 8~25건 추정 자체가 넓은 범위).
- **우리 단타 슬리브와의 관계**: 스윙(1d)이라 라이브 `scalp15m`과 타임프레임 완전 분리. 기존 롱숏비율 계열 스펙들과 데이터 소스는 공유하나 결합 구조(투표)가 미중복.
