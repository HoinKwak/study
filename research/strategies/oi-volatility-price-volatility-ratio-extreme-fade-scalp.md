## 진입 규칙
- **시간당 변화율**: `oi_ret(t) = sum_open_interest(t)/sum_open_interest(t-1h) - 1`,
  `px_ret(t) = log(close(t)/close(t-1h))`(1h 리샘플 기준).
- **60시간 롤링 변동성**: `oi_vol60(t) = rolling_std(oi_ret, 60)`, `px_vol60(t) = rolling_std(px_ret, 60)`.
- **비율**: `vol_ratio(t) = oi_vol60(t) / px_vol60(t)`(분모 0 근접 시 스킵).
- **z-score**: `z(t) = (vol_ratio(t) - rolling_mean(vol_ratio,120)) / rolling_std(vol_ratio,120)`.
- **페이드 롱(레버리지 초과변동 후 안정화 기대, 직전 가격 하락 국면)**: `z(t) >= +2.0`
  **AND** 직전 4시간 가격수익률 합이 음수(가격이 하락하며 OI가 더 격렬히 흔들린 경우 — 청산·급
  디레버리지 추정) → 롱(반등 페이드).
- **페이드 숏**: `z(t) >= +2.0` **AND** 직전 4시간 가격수익률 합이 양수 → 숏(과열 페이드).
- (스윕 대상) 방향 필터 없이 `z>=2.0`이면 항상 평균회귀(중립) 진입하는 변형도 별도로 백테스트해
  방향 필터의 부가가치를 확인.

## 청산 규칙
- 익절: `vol_ratio` z가 0 이하로 회귀(안정화 확인) 또는 R:R 1.6 목표 중 먼저.
- 손절: 진입가 ∓ ATR(14,15m) × 1.2.
- 시간 청산: `max_hold_bars`=12봉(15m×12=3시간) 경과 시 강제청산.

## 파라미터

- zscore_window=120h (범위 60~180)

## 스카우트 메모
- **강점**: 실측 상관(0.288)으로 동어반복이 아님을 확인했고, 비율 분포(평균 1.4, |z|>=2가 5.5%/시간)
  가 합리적인 신호 빈도대를 시사한다. "OI vs 가격 각각의 변동성을 직접 비교"라는 축은 프로젝트 내
  처음이라 재포장 위험이 낮다.
- **의심점**: (1) 방향 필터("직전 4시간 수익률 부호")가 임의적 설계 판단이라 백테스트에서 반드시
  무방향(중립 평균회귀) 대조군과 비교할 것. (2) 60시간 롤링 표준편차 두 개의 비율은 분모가 작을 때
  극단값이 인위적으로 튈 수 있어(0으로 나누기 근접) 실측에서 이런 아티팩트 구간을 걸러낼 것.
  (3) 15m 확인 결합 시 실제 독립신호 빈도가 추정치([추정] 연 80~200건)와 크게 다를 위험 — 1차
  진단에서 최우선 확인.
- **우리 슬리브와의 관계**: 대체 아님(신규 후보). 라이브 scalp15m과 타임프레임은 유사(15m/1h)하나
  메커니즘(변동성 비율 페이드 vs 볼린저 돌파 추종)이 반대 성격이라 상호 보완 가능성 있음.
