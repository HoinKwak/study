# [스윙] MACD 시그널크로스 + RSI 필터 + 200SMA 추세필터 (4h)

- **출처**: https://stratbase.ai/en/blog/rsi-macd-combo-strategy (StratBase — **WebFetch 원문 확인 실패, 503 반복** → 아래 수치는 WebSearch 검색엔진 요약 인용, 신뢰도 낮음·재검증 필수. 기존 `stochastic-rsi-ema-adx-swing.md`와 동일한 출처 접근 제약) /
  보강: https://quant-signals.com/macd-trading-strategy/ (Quant Signals, "MACD Trading Strategy: 3 Variants Backtested Across 6 Markets" — MACD+EMA200필터, MACD+RSI콤보 변형 구조 확인)
- **참여지표**: 없음(퀀트 블로그) — SNS 참여지표 미확인
- **백테스트 근거**: StratBase 검색 요약 — "BTC/USDT 4H 백테스트에서 MACD 시그널선 크로스(방향) + RSI<45(롱 진입 타이밍, 과매수 아님) 조합이 **손익비(PF) 1.58**을 기록했고, 여기에 **200 SMA 추세필터를 추가하면 PF 1.72**로 개선"(원문 미확인, 표본 수·승률·기간 등 세부 수치 불명 — **원문 재확인 전까지 참고 수준으로만 취급**). Quant Signals 쪽은 같은 페이지에서 "MACD 전용 백테스트 데이터 없음(EMA 크로스오버로 대체 근사)"라고 명시해 신뢰도가 더 낮음.
- **타임프레임**: 4h 신호 / 1d(200SMA) 확인
- **시장/대상**: BTC·ETH 무기한(원 백테스트가 BTC/USDT 대상)

## 진입 규칙
- 추세필터: 4h 종가가 4h 200기간 SMA **위**(롱 허용) / **아래**(숏 허용).
- 롱: MACD(12,26,9) 라인이 시그널선을 **상향 돌파**(골든크로스) + 크로스 시점 RSI(14) < 45(과매수 아님, 되돌림 여지) + 4h 종가 > SMA200.
- 숏: MACD 라인이 시그널선을 **하향 돌파**(데드크로스) + 크로스 시점 RSI(14) > 55 + 4h 종가 < SMA200.

## 청산 규칙
- **손절**: 진입가 - 1.5×ATR(14, 4h) (숏은 반대).
- **익절**: 2×손절폭(고정 R:R 2:1) 또는 MACD 반대 크로스 중 먼저 도달하는 쪽.
- **시간/조건 청산**: MACD가 시그널선을 반대로 재크로스하면 즉시 청산(추세 소멸 판단).

## 파라미터
- macd_fast=12, macd_slow=26, macd_signal=9
- rsi_period=14, rsi_long_max=45, rsi_short_min=55
- sma_trend_period=200 (4h 기준)
- atr_period=14, sl_atr_mult=1.5, reward_risk=2.0 (범위 1.5~3.0)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: MACD, RSI, SMA200, ATR — 전부 바이낸스 REST 4h 캔들만으로 계산 가능. 오더북/틱 불필요.
- 주의: 200기간 SMA를 4h에 쓰려면 최소 200×4h=약 33일치 캔들 워밍업 필요(신규 상장 알트는 데이터 부족 가능).

## 스카우트 메모
- **강점**: 진입 로직이 매우 단순·결정론적이라 코딩·백테스트 재현이 쉬움. MACD+RSI+장기추세필터 3중 필터는 표준적이고 과최적화 위험이 낮은 조합(파라미터가 관행값 그대로).
- **의심점**: 근거 원문(stratbase)을 두 번 다른 파일에서 시도했으나 모두 접속 실패(503) — **PF 1.58/1.72 수치는 검색엔진 요약을 통한 간접 인용으로, 원문 재확인 전까지 신뢰도를 낮게 잡아야 함**. 표본 기간·거래 수 불명.
- **우리 슬리브와의 관계**: 기존 봇에 MACD 지표가 전혀 없어(볼린저·슈퍼트렌드·RSI 중심) **지표 다양성 보완** 성격. 4h TF는 현재 스캘프(10m/15m)·중기(15m/1h) 슬리브보다 느려 **스윙 슬리브 신규 후보**로 적합. `stochastic-rsi-ema-adx-swing.md`(4h, 다른 오실레이터 조합)와 타임프레임이 겹치므로 채택 시 상관관계 점검 필요.
