# [스윙] 거래대금 순위 급상승(Rank Migration) 모멘텀

- **출처**: 개념 조합 — 자체 설계. 배경(정성적, 어텐션-드리븐 트레이딩 일반론):
  https://www.osl.com/hk-en/academy/article/5-crypto-trading-strategies-to-ride-momentum ("Attention generates buying, and buying sustains the trend. A single listing, headline, or viral post can trigger vertical price changes."),
  https://altfins.com/knowledge-base/crypto-volume-tracker-spot-unusual-volume/ (비정상 거래량 포착 일반론). **둘 다 정량 백테스트 수치 없음** — WebFetch/WebSearch 원문에 승률·PF 등 수치 자체가 존재하지 않아 인용하지 않음, 개념 근거로만 사용.
  기존 보유 전략들과 차별화: 기존 거래량 기반 스펙들(`volume-climax-exhaustion-reversal-scalp` 등)은 **절대 거래량의 자기 히스토리 대비 급증(z-score/배수)**을 쓰는 반면, 이 스펙은 **유니버스 내 상대 순위(rank)**의 이동을 신호로 쓴다 — 시장 전체가 조용한 날에도 특정 코인만 상대적으로 부상하면 포착되고, 반대로 시장 전체 거래량이 늘 때(BTC 변동성 급등 등) 전 종목이 동반 상승하는 노이즈는 순위 지표 특성상 자동으로 걸러진다는 점이 절대량 z-score와의 핵심 차이.
- **참여지표**: - (자체 설계, SNS 참여지표 미집계)
- **백테스트 근거**: **없음(개념 기반, 정직히 표기)**. 순수 가설. **채택 전 자체 백테스트 필수**.
- **타임프레임**: 1d 순위 산출 → 4h 신호 진입
- **시장/대상**: 바이낸스 동적 유니버스($10M+ 거래대금) 알트코인 다수 (BTC·ETH는 이미 최상위 고정이라 순위 이동 신호 대상에서 제외)

## 진입 규칙
- **순위 산출**: 매일 00:00 UTC, 동적 유니버스(24h 거래대금 $10M 이상) 내 모든 심볼을 **24h 거래대금(quote volume) 내림차순**으로 순위 매김(1=최대). 우리 인프라가 이미 유니버스 선정에 이 데이터를 사용 중(CoinGecko derivatives 파생 API 또는 바이낸스 24hr ticker `quoteVolume`)이라 별도 수집 불필요.
- **급상승 판정**: `rank_jump = rank(t - lookback_days) - rank(t)` (양수면 순위가 개선/상승한 것). `lookback_days=3`일 기준 `rank_jump ≥ rank_jump_min(기본 20)`.
- **가격 확인**: 동일 3일간 종가 수익률이 **양수**(가격도 함께 오르고 있어야 함 — 순수 거래대금 회전만으로는 방향성 없는 노이즈일 수 있음).
- **최소 유동성 필터**: 순위 상승 이후에도 24h 거래대금이 $10M 이상 유지(우리 유니버스 편입 기준 재확인, 초소형 알트의 일시적 순위 왜곡 배제).
- **롱 전용**([설계 판단], 숏은 설계하지 않음 — 순위 급락은 유동성 고갈/상장폐지 루머 등 이례 상황과 섞여 위험이 비대칭적이라 판단): 위 3조건 충족 시 4h 봉에서 최근 5봉 고가 상향 돌파 시 진입.

## 청산 규칙
- 익절: ATR(4h,14) 트레일링 ×2.0(신고가 대비), 또는 진입가 대비 +15% 목표 부분청산.
- 손절: 진입가 −ATR(4h,14)×2.0, 또는 순위가 다시 rank_jump_min의 절반 아래로 반납되면 청산(어텐션 소멸 확인).
- 시간/조건 청산: max_hold=7일(어텐션 기반 플로우는 통상 단기간에 소진된다고 가정, [설계 판단]).

## 파라미터
- lookback_days=3 (범위 2~5)
- rank_jump_min=20 (범위 15~30, 유니버스 규모에 비례 조정 필요 — 유니버스가 ~100종목이면 20계단은 상위 20%p 이동)
- min_quote_volume=$10M (기존 유니버스 필터와 동일)
- entry_breakout_lookback=5봉(4h)
- atr_trail_mult=2.0, atr_stop_mult=2.0
- max_hold=7일 (범위 5~14)

## 코딩 난이도 / 데이터 요구
- 필요한 지표: 유니버스 전체 심볼의 일별 24h 거래대금 순위(이미 유니버스 선정 로직이 매일 계산 — 재사용 가능), 가격 캔들(4h), ATR.
- 주의: **포트폴리오 엔진 불필요** — 크로스섹셔널 로테이션 계열(다수 코인 동시 분산 보유)과 달리, 이 전략은 "순위가 급상승한 개별 심볼 하나하나에 대해 단일 심볼 트리거"로 작동해 **기존 단일 심볼 백테스트 엔진 그대로 적용 가능**(과거 여러 크로스섹셔널 스펙이 "포트폴리오 엔진 필요"로 후순위 밀린 것과 달리 이 전략은 그 제약이 없음 — 백테스트 우선순위 상 이점). 다만 백테스트 시 유니버스 전체의 일별 거래대금 순위를 매일 재계산해 저장해야 하므로 사전 전처리 단계가 필요.
- 오더북/틱/실시간청산 불필요.

## 스카우트 메모
- **강점**: 데이터가 이미 유니버스 선정 파이프라인에 존재(신규 API 불필요), 단일 심볼 트리거라 포트폴리오 엔진 없이 즉시 백테스트 가능 — 이번 라운드 후보 중 구현 편의성이 가장 높은 축.
- **의심점(표본 빈도·독립성, 사전 명시)**: 유니버스가 ~100종목이면 `rank_jump≥20`은 하루에 여러 종목이 동시에 충족할 수 있어 명목 표본은 충분할 것(추정 월 10~30건, 전체 유니버스 풀링 시). 그러나 **독립성 위험이 큼**: (1) "알트시즌" 국면에는 BTC 도미넌스 하락과 함께 다수 알트가 동시에 순위 상승(제로섬 순위 구조상 상위 몇 개가 오르면 다른 다수는 자동으로 밀려남 — 순위 자체가 zero-sum이라는 점을 반드시 유의), (2) 순위 급상승의 상당수는 단일 이벤트(거래소 상장 프로모션·인플루언서 언급·에어드랍 공지)에 의한 것으로 **가격 반전이 순위 상승보다 먼저 끝나는 생존편향** 위험이 큼. 백테스트 시 이벤트 발생 날짜의 유니버스 전체 겹침(며칠 이내 몇 종목이 동시 트리거되는지) 실측 필수.
- **gross 엣지 가설**: 상대적 관심(어텐션)이 급증한 자산은 신규 자금 유입이 이어지며 단기 모멘텀이 지속된다는 행동재무학적 가설(어텐션 이론)이나, 크립토 저시총 알트는 반대로 "펌프 후 급락"이 훨씬 흔한 패턴(신규상장 초기펌프 소진 스펙에서 이미 다룬 위험과 동일 계열)이라 **gross 엣지가 오히려 음수(순위 급상승 자체가 페이드 신호)일 가능성도 배제할 수 없음** — 백테스트 시 반드시 방향반전(순위 급상승 시 숏) 대조군을 함께 실행해 부호부터 확인 필요.
- 우리 슬리브와의 관계: 기존 스윙 슬리브와 무관한 신규 축(어텐션/자금흐름). 단타 `scalp15m`과는 타임프레임·트리거가 완전히 달라 중복 아님.
