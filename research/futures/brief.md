**dYdX(`dydx_chain`) API 429 지속**: 이번 회차 4회 연속 재시도(간격을 두고) 모두 429 Too Many
Requests를 반환해 ETH-USD·BTC-USD를 재확인하지 못했다. 직전 회차 수치를 이월 표기했으며,
다음 회차 재조회가 필요하다.

**OKX 거래량 산정 방식**: OKX ticker의 `volCcy24h`(기초자산 수량 기준)에 `last` 가격을 곱해
USD 환산했다. OI는 `/public/open-interest` 엔드포인트의 `oiUsd` 필드를 직접 사용해 계약승수
오산정 위험을 배제했다. funding은 BICO·CORE·CAP·GRAM은 이번 회차 `/public/funding-rate`로
개별 재조회했으나, PIPPIN·GIGGLE·BEAT·KAITO·MMT·AEON은 API 호출 최소화를 위해 **직전 회차
funding 수치를 이월**했다(가격·거래량·OI는 모두 신선). funding 절대값은 다음 회차 전체
재조회를 권장한다.
