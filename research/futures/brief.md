## 데이터 신뢰도

가격·chg24는 거래소 직접 API(OKX·바이낸스·HL·dYdX 공식 indexer)를 1차 근거로 삼았습니다.
**이번 회차 Bybit 직접 API(api.bybit.com·api.bytick.com·api.bybit.nl)가 전부 지역차단(CloudFront)
되어 CoinGecko 파생 API로 대체**했고, 직전 회차는 직접 API였으므로 Bybit 관련 수치는 소스가
바뀐 점을 감안해 주십시오. OKX는 직접 API(티커+펀딩+OI 개별 조회), Hyperliquid는 공식 API
POST, dYdX는 공식 indexer, Binance·Aster는 CoinGecko입니다. OrangeX는 계속 데이터 접근이
불가해 전량 미확인 상태입니다. TRUMP의 chg24 급락은 실제 하락이 아니라 24h 윈도우 롤오프
효과일 가능성이 크다고 판단해 md에 명시했습니다. BEAT는 5회차 넘게 가격-펀딩 관계가 반복
반전 중이라 단일 회차 판정을 확정으로 쓰지 않았습니다. LIT은 사장님 수동 트레이딩 종목이므로
수치만 기재하고 해석·전망은 배제했습니다.
