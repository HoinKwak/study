## 데이터 신뢰도

이번 회차 CoinGecko `binance_futures`·`bybit`·`okex_swap`·`hyperliquid`·`aster`·
`orangex_futures`는 초반 여러 차례 429(레이트리밋) 후 재시도로 대부분 확보했다. **Bybit
BTC/ETH/SOL·Binance BTC/ETH/SOL**은 응답 절단으로 확인하지 못했다(다만 이 종목들은 CEX 표에
넣지 않고 DEX(HL·Aster·dYdX) majors 추적으로 대체해온 기존 구조라 테마 판단에는 지장이 없다).
OKX 직접 API(KAITO·GIGGLE·MMT·PIPPIN·GRAM 5종의 ticker·open-interest·funding-rate 개별
엔드포인트)는 전부 정상 확보했다. BSB는 이번 회차 CoinGecko okex_swap 통합 조회로 확보했다.
dYdX는 개별 마켓 3종(BTC/ETH/SOL) `perpetualMarkets` 조회로 확보했고, `priceChange24H` 필드가
퍼센트가 아닌 달러 절대변동값이므로 `priceChange24H/(oraclePrice-priceChange24H)*100`으로
퍼센트를 재계산했다(예: ETH -5.824153/(1874.945054-(-5.824153))*100≈-0.31%). OI도 base 단위
필드에 oraclePrice를 곱해 USD로 환산했다.

**Bybit 커버리지**: AKE·APR·BANK·ACE·AEON·ALGO·AAVE·ADA·ATOM·ASTER·ALLO·AIO·1000RATS 13종을
정상 확보했고(1000RATS는 이번 회차 재확인돼 가중평균 복귀), BEAT·BICO·CAP·BSB·CORE·BTC·ETH·SOL은
표적 재조회로도 확인하지 못했다. AEON은 이번 회차로 **10회 연속 확인**돼 지속 상장이 사실상
확정적이다.

**데이터 무결성**: **Aster ETH**는 여러 차례 표적 재조회를 시도했으나 확인 실패해 **14회차
연속** 미확인이 이어진다. **Hyperliquid SOL-USD**는 이번 회차도 원시 티커 목록 재검색에서
발견되지 않아 재결측이 지속됐다. **Aster CASHCAT**은 직전 회차 두 차례 재조회 값 불일치에 이어
이번 회차도 응답이 자기모순적이었다(수치를 제시하면서도 위치·인접 심볼 설명이 서로 충돌) — 값을
채택하지 않고 '미확인'으로 처리했다. **BEAT Binance**는 직전 회차 사라졌던 것이 재등장했으나
거래량이 OI·다른 소스 대비 극단적으로 낮아 여전히 데이터 이례적으로 평가한다. **CORE**는
초저유동성으로 여러 회차 이월값을 써왔으나 이번 회차 재조회에 성공해 신선한 값을 확보했다.

## 한계

(a) CEX 신규 대형 급등 스캔은 기존 감시 종목·상위 리스트 범위 내에서 수행했으며 완전한 전체
시장 스캔은 아니다; (b) **주식화·상품·프리IPO 합성 perp 토큰**은 이번 회차도 규약에 따라
cex/dex 리스트에서 전부 제외했다; (c) KAITO·GIGGLE·MMT·PIPPIN·GRAM(OKX 직접 조회분)의 CEX
거래량·chg24는 OKX 직접 API 기반 재계산값이며(vol24h 필드를 vol24_usd로 채택, 기존 회차와의
연속성 유지), OI는 `oiUsd` 필드를 직접 채택, funding은 raw fundingRate×100 방식으로 계산했다;
(d) ADA·AAVE·ATOM·ASTER·AKE·BANK·ALGO·ACE·1000RATS·APR·ALLO·AIO 등 복수 거래소 종목의
`chg24`·`funding`은 이번 회차 Binance+Bybit 가중평균(거래량 가중)으로 산출했다; (e) Hyperliquid
원시 funding 필드가 이번 회차도 정상 스케일로 관측돼 보정 없이 raw 값을 그대로 사용했다;
(f) BICO·BEAT·CAP·AEON·MMT·GIGGLE·PIPPIN·KAITO·GRAM·CORE·BSB·BLESS는 Binance/Bybit 상장이
불확실하거나 없어 OKX·DEX로만 집계되는 구조다(AEON은 이번 회차도 Bybit 데이터 확보); (g) BTW·
CASHCAT·ANSEM·HYNA:PUMP·HYNA:HYPE는 DEX에서만 상장이 확인돼 해당 섹션에서만 집계했다;
(h) dYdX BTC/ETH/SOL의 OI는 base 단위 필드를 oraclePrice로 USD 환산했고, chg24는 `priceChange24H`
(달러 절대값)를 퍼센트로 재계산했으며, funding은 `nextFundingRate` 필드를 100배해 산출했다
(BTC는 raw 값이 0으로 관측돼 0.0으로 표기); (i) OKX 직접조회 GIGGLE·GRAM·PIPPIN의 funding이
왜 매 회차 동일값(0.00005)으로 관측되는지는 규명하지 못했다; (j) OKX ticker의 `vol24h`(계약수
단위)와 `volCcy24h`(통화 단위)가 종목별로 배율이 달라 이번 회차도 기존 회차와의 연속성을 위해
`vol24h`를 채택했으나 계약승수 정의는 완전히 검증하지 못했다; (k) ACE·BANK·AKE·BEAT 관련
급변동은 여러 독립 소스에서 방향이 대체로 일관돼 데이터 오류 가능성은 낮게 평가하나, 정확한
