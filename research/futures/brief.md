## ACE 재가속 판정 (요약)

ACE는 이번 회차 4벤뉴(Binance·Bybit·HL·Aster) 전부 동반 재가속했다(+27~28%대→+29~31%대).
**HL 단독 현상이 아님을 확인**했다. 동시에 펀딩은 계속 정상화(0 근접) 상태를 유지해(Binance
-0.00053→-0.00035, Bybit +0.00055→+0.00005, HL +0.000195→+0.0000125, Aster +0.00001→0.0)
괴리가 재확대되는 것은 아니다. **판정: 이번 재가속은 펀딩 왜곡을 동반하지 않는 건강한 가격
연속 상승**으로 판단된다.

## OrangeX 접근 불가 판정 (요약)

지난 회차 신규 도메인(api.orangex.com)에서 ACE·KAITO·AAVE·ADA·ALGO 실데이터를 확보했으나,
이번 회차는 동일 도메인의 여러 경로(public/tickers, public/get_ticker, public/ticker 등)를
재시도한 결과 전부 code 1000("No service found") 또는 code 5001("Instrument does not
exist")를 반환했다. 공식 문서(openapi-docs.orangex.com)를 확인한 결과 **ticker 엔드포인트가
POST 전용 JSON-RPC 구조**로 적혀 있으나, 부모 세션이 api·www 양 도메인을 직접 재검증하니
반환값이 기존 전면중단과 같은 code 1000이었다 — **원인 미규명**으로 남기고 단정하지 않는다.
**ACE OI 이상치 재현 여부는 확인 불가**다. 기존 추적 도메인(sapi/orx-openapi)도 여전히 불가 지속.
ACE·KAITO·AAVE·ADA·ALGO는 직전값을 이월했다.
