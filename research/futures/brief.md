## 데이터 신뢰도

이번 회차는 CoinGecko `binance_futures`·`bybit`·`hyperliquid`·`aster`·`orangex_futures`를
대부분 정상 확보했으나, **`okex`(OKX) derivatives 엔드포인트는 두 차례 404를 반환**해 OKX
공개 API(ticker/open-interest/funding-rate)로 직접 대체 조회했다. 이 과정에서 일부 종목
(MMT·AEON·APR·ATOM·GRAM·GIGGLE·PIPPIN·CORE·BSB의 OKX 라인)은 거래량·chg24는 새로 계산했으나
OI를 재조회하지 못해 직전 값을 이월했다(각 항목에 명시).

**⚠️ 신규 이상치**: OKX BICO의 거래량이 $1,275.03M로 조회됐는데, 같은 종목 OI($3.13M)와
비교한 거래량/OI 비율이 약 407배로 극단적이다(다른 종목은 대체로 4~12배). 두 차례 독립
재조회에서 동일한 값이 나와 단순 파싱 혼입은 배제되나, 규모 자체가 비현실적이라 vol24_usd를
미확인 처리했다.

**재확인 실패 2건**: 지난 회차 신규 확인됐던 KAITO Bybit(-0.842%)·BICO Bybit(-1.235%) 라인
모두 이번 회차 대용량 티커 목록에서 재확인하지 못했다(각 최대 2회 시도). 값을 이월하지 않고
미확인 처리했다.

**AEON Binance**는 지난 회차 신규 확인됐으나 이번 회차 재조회에 실패했다. 나머지 4소스
(Bybit·OKX·OrangeX·Aster)는 -5.99%~-7.26%로 정합적이었다.

**dYdX**는 개별 마켓 3종(BTC/ETH/SOL) `perpetualMarkets` 조회로 raw 값(oraclePrice·
priceChange24H·openInterest·nextFundingRate·volume24H)만 확보해 직접 계산했다
(`priceChange24H/(oraclePrice-priceChange24H)*100`으로 퍼센트 재계산, OI는 base 단위에
oraclePrice를 곱해 USD 환산, funding은 `nextFundingRate`를 100배). 이번 회차도 raw 값만
요청해 WebFetch 모델의 자체 오산출 문제는 재발하지 않았다.

**데이터 무결성**: **Aster ETH**는 이번 회차도 확인 실패해 **18회차 연속** 미확인이다.

재관측돼 stale 의심이 재점화했다(직전 회차엔 값이 바뀌어 해소됐다고 판단했었음). **CoinGecko
`/global`**은 정상 확보돼 총시가총액 $2,244.6B(직전 $2,247.4B), BTC 도미넌스 56.12%(직전과
동일)를 확인했다.

**BEAT Binance**는 이번 회차도 확인되지 않아 상장 안정성 의심이 지속된다.

**정정 사항**: 과거 여러 회차에서 CAP를 'Sui 기반 밈코인'으로 서술했으나, 이번 회차
WebSearch 재확인 결과 CAP는 스테이블코인 cUSD와 기관 신용을 결합한 **이더리움 기반 DeFi

cex/dex 리스트에서 전부 제외했다; (c) KAITO·GIGGLE·MMT·PIPPIN·GRAM·BEAT·CAP·BICO·ATOM·AEON·
APR·CORE·BSB(OKX 직접 조회분)의 CEX 거래량·chg24는 OKX ticker API 기반 재계산값이며(last·

funding은 별도 엔드포인트(open-interest·funding-rate)에서 재조회했거나(KAITO·BEAT·CAP·BICO)

회차도 정상 스케일로 관측돼 보정 없이 raw 값을 그대로 사용했다; (f) BICO·BEAT·CAP·AEON·MMT·

USD 환산했고, chg24는 `priceChange24H`(달러 절대값)를 퍼센트로 재계산했으며, funding은

작게 나와(BTC -0.0002, ETH -0.0003, SOL -0.0053) 단순 시점별 변동으로 판단했으나 스케일
