`orangex_futures` 6개 파생거래소 엔드포인트 중 `orangex_futures`와 `/global`이 1차
시도에서 429를 반환해 재시도 후 확보했다(나머지 4개는 1회 성공). OKX 직접 API
(KAITO·GIGGLE·MMT·PIPPIN·GRAM 5종의 ticker·open-interest·funding-rate 개별 엔드포인트)는
전부 정상 확보했다. dYdX는 `indexer.dydx.trade` 개별 마켓(`?ticker=BTC-USD` 등) 조회로
raw JSON 필드(`oraclePrice`·`priceChange24H`·`openInterest`·`volume24H`)를 직접 확인해
계산했다. bybit의 BTC/ETH/SOL 개별 티커는 CoinGecko `bybit` 응답에 이번 회차도 포함되지
않아 **13회 연속 미확보**로 HL·dYdX로 계속 대체했다 — 다만 이번 회차 bybit 응답에서

(a) CEX 신규 대형 급등 스캔은 기존 감시 종목·상위 리스트 범위 내에서 수행했으며 완전한

규약에 따라 cex/dex 리스트에서 전부 제외했다; (c) KAITO·GIGGLE·MMT·PIPPIN·GRAM(OKX 직접
조회분)의 CEX 거래량·chg24는 OKX 직접 API 기반 재계산값이며(vol24h 필드를 vol24_usd로
