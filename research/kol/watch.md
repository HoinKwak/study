- **FWA — GT API 복구**: 직전 회차 6회 이상 429를 반환했던 GeckoTerminal이 이번 회차 정상 응답해 교차검증을 완료했다. 일시적 API 이슈였던 것으로 추정된다.
- **이번 회차 GT 429 범위**: 우선추적 6개 항목(KEP·MANCER·LOUIE·CASHCAT·STONKBROKER·FWA)은 GT 조회에 성공했으나, 나머지 9개 추적 토큰(ROBO·JUGGERNAUT·lickingcat·Sheep·Prometheus·HORACE·TOAD·Dealer·Remus·BLINK·SLING)과 notable 중 PONS·PIPEDOG·ANSEM은 병렬 요청으로 인한 429가 반복돼(2회 재시도 후 포기) DS 단독 수치로만 기록했다. 시간 예산 초과를 피하기 위해 무한 재시도는 하지 않았다.
- **notable 섹션 관리**: TUT·TENDIES·STONK·TYGR·KIO·NASDANQ·HOODRAT 7종은 이번 회차 시간예산 또는 CA 미확인으로 재조회를 생략했다(carryover) — notable은 임의 삭제 없이 전량 유지해 12종을 유지한다. 이번 회차 CASHCAT·PONS·PIPEDOG·STONKBROKER·ANSEM 5종은 실측 데이터로 갱신했다.
- **신규 토큰 탐색**: WebSearch로 Robinhood Chain 신규 트렌딩을 확인했으나 이미 추적 중인 PONS 외 새로 편입할 만한 신규 후보는 발견하지 못했다(pools.trade 런치패드로 다수 신규 토큰이 생성되고 있으나 개별 검증 가능한 신규 후보는 이번 회차 확보하지 못함).
- **데이터 신뢰도 총평**: 우선추적 6개 항목(KEP·MANCER·LOUIE·CASHCAT·STONKBROKER·FWA)은 DS·GT 양쪽 교차검증에 성공했다. 나머지 9개 추적 토큰과 notable 중 3종(PONS·PIPEDOG·ANSEM)은 GT API 429로 DS 단독 수치이며 재확인 필요로 표기한다. X 직접 조회는 로그인월로 시도하지 않았다.
