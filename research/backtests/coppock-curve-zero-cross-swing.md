# Coppock Curve 제로라인 크로스오버 — 백테스트 리포트

- **전략 스펙**: `research/strategies/coppock-curve-zero-cross-swing.md`
- **출처**: Edwin Coppock(1962), 코딩·백테스트 예시는 EODHD Academy. **⚠️ 원문 정량치(수익률 91%
  vs SPY 40%, 51%p 초과수익)는 AAPL 주식 대상**(2020-01~약 3.5년) — **크립토 재현 여부 자체가
  검증 목적**. 승률/PF/거래횟수는 원문에 없어 "수익률 비교"만 참고 가능.
- **판정 목적**: 크립토(4h/1d, 22종목)로 처음부터 재현. 롱숏 vs 롱온리, confirm_bars/ROC기간
  민감도, ATR 손절 옵션을 대조.

## 구현/실행 방식

- **격리 스크립트**: `scratchpad/bt_coppock.py` (완전 독립, `src/crypto_trader/**` 무수정,
  `indicators.py`의 `atr`만 재사용). ROC+WMA+4봉 확인크로스 로직이 기존 swing 인터페이스와
  맞지 않아 TRIX/SMMA와 동일한 자체 이벤트기반 시뮬레이터 사용.
- **산식(원문 그대로)**: `Coppock = WMA(ROC(close,14) + ROC(close,11), 10)`,
  `ROC(close,n) = (close/close.shift(n) - 1) × 100`, `WMA`=선형가중이동평균(최근봉 가중 최대).
- **진입(원문 그대로)**: 롱 = 신호봉 직전 4개 봉이 모두 Coppock≤0 이고 신호봉이 >0으로 전환.
  숏(대칭, [추정] — 원문은 매수 규칙만 제시) = 직전 4개 봉이 모두 ≥0 이고 신호봉이 <0 전환.
- **청산(원문 그대로, 매도규칙)**: 반대 방향 확인크로스 시 청산. `long_only`는 청산만,
  `both`는 반대 포지션 스탑앤리버스. 손절(자체보강): 진입 직전 닫힌봉 ATR(14)×`atr_mult`.
- **룩어헤드 방지**: 신호는 신호봉(i-1, 닫힌 봉) 확정 4봉 확인크로스로 판정, 체결은 i봉
  시가(+슬리피지).
- **데이터**: `scratchpad/futdump100m/*.pkl` 15m → **4h·1d로 리샘플**(원문 일봉, 스윙 슬리브
  대역인 4h도 병행 검증).
- **종목**: 13개 장기이력 종목 풀링을 주 판정 근거, 전 22종목은 참고용.
- **IS/OOS**: IS 2022-01-01~2024-06-30, OOS 2024-07-01~2026-06-30.
- **수수료/슬리피지**: 진입/청산 각 taker 0.05% + 슬리피지 0.02%(사이드당).
- **실행 커맨드(재현)**:
  ```
  cd /home/user/study
  python3 scratchpad/bt_coppock.py BTCUSDT 4h
  python3 scratchpad/bt_coppock.py BTCUSDT 1d
  python3 - <<'PY'
  from scratchpad.bt_coppock import load_symbol, simulate, summarize, LONG_HISTORY_SYMBOLS
  for sym in LONG_HISTORY_SYMBOLS:
      df = load_symbol(sym, '4h')
      res = simulate(df, symbol=sym, direction='both', use_stop=False)
      print(summarize(res))
  PY
  ```

## 최종 판정: **HOLD (보류)** — 감사 **VALID** (동의)

> **backtest-reviewer 감사 VALID (2026-07-17).** `bt_coppock.py` 직접 재실행으로 4h pooled
> PF 1.195/1.178/1.216·t 3.67/2.36/2.88, 1d OOS PF 1.443·t 1.019를 재현(리포트와 일치). 파라미터는
> 원문 고정값(ROC11+ROC14·WMA10)에서 시작해 흔들어도 PF가 거의 안 움직여 KAMA 같은 그리드서치
> 선택편의 흔적 없음. 룩어헤드·단위 통과. 4h 안정·1d OOS 유의성 소멸 구분도 타당 → HOLD 동의(라이브 미반영).

**근거**:
1. **원문(AAPL 주식) 정량치는 애초에 크립토와 무관**하다. 크립토 재현 결과는 우리 자체
   백테스트로 처음부터 도출한 수치이며, 원문의 91% 초과수익 주장을 검증/재현한 것이 아니다.
2. **4h(가장 신뢰할 수 있는 구간)에서 통계적으로 유의한 약한 양(+)의 엣지가 확인된다.**
   PF net 1.20~1.25, t값 2.0~3.7로 유의하며, **IS→OOS가 거의 그대로 유지**(롱숏은 오히려
   OOS가 IS보다 나음)되고, confirm_bars·ROC기간을 합리적 범위에서 흔들어도 PF가 1.18~1.23에서
   안정적으로 유지된다 — 우연이나 과최적화로 보기 어려운 재현성 있는 신호다. 22종목 상세에서도
   13개 장기이력 종목 중 10개가 PF>1.0으로 종목 간 일관성도 TRIX/UO보다 낫다.
3. **다만 PF가 통과 기준(1.3)에 지속적으로 0.05~0.10p 못 미친다.** 어떤 파라미터 조합에서도
   4h PF가 1.3을 안정적으로 넘지 못했다 — "확실한 통과"라 부르기엔 근소하게 부족하다.
4. **1d는 헤드라인 PF가 1.4~2.1로 더 높아 보이지만 OOS pooled t값이 0.95~1.02로 유의하지
   않고**, 개별 종목 IS/OOS가 극단적으로 뒤집히는 패턴(SOL 2.41→0.57, ZEC 0.74→8.73 등)이
   확인돼 판정 근거로 채택하지 않는다(소표본 과최적화 정황).
5. 종목 간 일관성이 4h에서는 양호하지만 BNB(0.92)·TUSDT(0.89)·DODOX(0.96) 3종목은 여전히
   1.0 미만이라 "전 종목 일관 통과"는 아니다.

**PASS로 올리기엔 PF가 문턱에 근소하게 못 미치고, FAIL로 내리기엔 통계적으로 유의하고
파라미터에 강건한 재현 가능한 양의 엣지가 있다** — 애매한 경계 사례로 HOLD 처리한다. 만약
추가 검증(예: 진입 필터 추가·다른 청산 방식)으로 4h PF를 1.3 이상으로 안정적으로 끌어올릴
수 있다면 재평가 가치가 있다.

## 미검증/근사 요소 (정직한 한계 고지)

- **숏 방향은 원문 미제시([추정] 대칭 적용)**: 원 지표는 매수 타이밍용으로 설계됐고 숏 규칙은
  스펙 작성자의 대칭 적용 추정이다. 롱온리(4h PF 1.25)가 롱숏(1.20)보다 근소하게 나아 숏
  사이드가 순보탬이 되지 못하는 경향이 있다.
- **손절 방식**: 원문 미제시라 ATR(14)×2.0 자체보강. 개선 효과는 미미(±0.03p 수준).
- **9개 신규 상장 알트**: IS 구간 자체가 없어 판정 근거에서 제외, 참고용으로만 22종목
  상세표에 남김.
- **사이징**: 고정 명목가($10,000/트레이드, 비복리) — PF/승률/t값 등 사이징 불변 지표로
  판정했고 총수익률/MDD는 사이징 방식이 종목마다 겹치는 포지션을 무시하므로 신뢰하기 어려워
  본문에 신지 않았다(TRIX 리포트와 동일 관행).
