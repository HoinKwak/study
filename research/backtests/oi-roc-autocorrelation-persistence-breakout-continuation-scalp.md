## 핵심 로직(요약 인용)

```python
# oiacf_signals.py — 지표 계산
oi_roc = oi.pct_change()
acf1_oi = oi_roc.rolling(acf_window).corr(oi_roc.shift(1))          # lag-1 자기상관
acf1_oi_z = (acf1_oi - acf1_oi.rolling(acf_z_window).mean()) / acf1_oi.rolling(acf_z_window).std()
frac_pos = (oi_roc > 0).rolling(acf_window).mean()
frac_neg = (oi_roc < 0).rolling(acf_window).mean()
oi_dir = +1 if frac_pos>=oi_dir_consistency else (-1 if frac_neg>=oi_dir_consistency else 0)
don_up = high.rolling(donchian_len).max().shift(1)   # lookahead 방지(자기 봉 제외)
don_lo = low.rolling(donchian_len).min().shift(1)

long_sig  = (acf1_oi_z >= z_th) & (oi_dir ==  1) & (close > don_up)
short_sig = (acf1_oi_z >= z_th) & (oi_dir == -1) & (close < don_lo)
```

```python
# oiacf_strat.py — 청산: 고정 SL(진입가∓ATR14×1.2) + 챈들리어 트레일링(ATR×2.0, 단조)
#                  + 방향 미참조 스칼라 조건(acf1_oi_z 재붕괴<=0) 즉시청산 + max_hold=24봉
stop_price = entry - atr_stop_mult*atr   # (롱 기준, 숏은 대칭)
for j in range(entry_idx, entry_idx+max_hold+1):
    if low[j] <= stop_price: exit "trailing_stop"; break
    run_ext = max(run_ext, high[j])
    stop_price = max(stop_price, run_ext - atr_trail_mult*atr[j])   # 단조(유리한 방향으로만)
    if acf1_oi_z[j] <= 0: exit "acf_invalidation"; break            # 방향 변수 미참조(스칼라)
    if j == entry_idx+max_hold: exit "max_hold"
```

## ⭐1차 진단(최우선): 신호빈도 실측 vs 스펙 예상 + 임계값 백분위

| 항목 | 실측값 |
|---|---|
| `acf1_oi_z` 분포(BTC) | mean=0.009, std=1.187 |
| `z_th=2.0`(스펙 원안)의 백분위 | **95.3%ile** (극단 포착 — 과거 라운드의 "임계값=중앙값" 함정 아님) |
| `z>=2.0` 단독 발생률 | 4.69%/봉 (연 410h) — 스펙의 나이브 정규근사(연 200h대)보다 높음 |
| `oi_dir_consistency>=65%` 단독 발생률 | 6.68%/봉 |
| **결합게이트**(z≥2.0 & dir≥65%) 발생률 | **0.467%/봉 = 연 40.9건/종목** — 스펙 예상(40~150건/종목/년)의 **하한과 거의 정확히 일치** |
| Donchian(20,1h) 상단/하단 돌파 발생률(무조건부) | up 3.99% / down 3.72% |
| **최종 결합조건**(게이트+방향일치+Donchian 동시) raw 신호(IS+OOS, 7종목 합산) | **long 27 + short 10 = 37건** = **종목당 연 1.18건** |

**핵심 발견**: 스펙의 "40~150건/종목/년" 예상은 **게이트(ACF z + 방향일관성) 단독까지만 정확히
맞았다**(연 40.9건, 하한과 일치). 그러나 최종 조건에 **동시에 요구되는 Donchian 돌파 방향일치**가
추가로 빈도를 약 **35배** 붕괴시켜(무조건부 독립 가정 시 예상되는 수준과 거의 일치 — 즉 ACF 게이트
발화와 브레이크아웃 발생 사이에 양의 상관이 전혀 없다는 뜻) 실제 빈도는 스펙 예상의 **약 1/34~1/127**
(종목당 연 1.18건)에 그친다. 이는 과거 라운드(모닝스타/이브닝스타·삼백병삼흑아·불마켓서포트밴드)와
같은 **"결합조건 과잉제약"** 패턴으로, "느슨해서 죽었나(threshold 함정)"가 아니라 **"게이트와
Donchian이 서로 무관한 축이라 곱셈적으로 죽는" 구조적 문제**임을 실측으로 확인했다.

이 결과로 **폐기조건 3**("acf_z 임계값을 스펙 예상 빈도에 맞춰 역산했을 때도 PF가 무엣지면 → FAIL")을
직접 수행했다 — `z_th=1.0, oi_dir_consistency=0.55`(z=1.0은 78.9백분위, "느슨하지만 극단은 아닌"
지점, 여전히 통계적으로 의미있는 문턱)로 역산하면 종목당 OOS 연 환산 ~수십~백여 건 수준으로 빈도가
매칭되고(전체 IS+OOS n=884), 이 값을 이하 모든 진단에 사용한다("**빈도매칭판**"으로 표기).
스펙 원안 파라미터 자체(z=2.0, dir=65%)는 아래 §본 결과에서 별도 보고한다.

퇴화(즉시청산 쏠림)가 불가능하다 — 실측으로도 확인됨.

## 셔플 대조군(트리거 시점 무작위화, 100회 — 승률고정 항등식 함정 회피)

⚠️직전 라운드 감사에서 "승률·승패크기 풀 복원추출"식 셔플이 수학적 항등식(항상 50백분위)임이
드러나 지시사항대로 **트리거 시점(어느 봉이 신호인지) 자체를 무작위 재배치**하는 방식을 썼다 —
종목별 실제 OOS 트레이드 수(BTC 55·ETH 58·BNB 61·SOL 76·XRP 63·DOGE 71·ADA 61)만큼 OOS 구간
내 임의 봉을 비복원추출하고, 방향은 실제 롱비율(61.35%)에 맞춰 베르누이 추출한 뒤 **동일한
청산엔진**(SL/트레일링/무효화/시간청산)으로 시뮬레이션, 100회 반복.

- 실제 OOS R_net PF = **0.961**
- 셔플 100회 null 분포: mean=0.741, median=0.734, std=0.106
- **실제값의 백분위 = 97.0**

실제 결과가 무작위 진입시점 대비 97번째 백분위(단측 p≈0.03)로, **진입 타이밍 자체에는 순수
무작위보다 약간 나은 정보가 있음**을 시사한다(방향 비율은 null에도 동일하게 반영했으므로 이는
"롱 편향" 효과가 아니라 타이밍 효과). 다만 이 정보량은 ①경계선급 유의성(97th, 95% 문턱을 살짝
넘는 수준)이고 ②절대 성과는 여전히 손익분기 미만(net PF 0.961<1)이라 **"독립적인 정보가
있으나 실전 가치는 없다"**는, 이 프로젝트에서 GK/RS·거래대금가중VWAP 대비 체결건수가중VWAP
