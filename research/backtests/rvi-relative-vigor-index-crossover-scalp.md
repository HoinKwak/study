## 방법론 (반스누핑)

- **유니버스 사전고정**: 7메이저 = BTC/ETH/BNB/SOL/XRP/DOGE/ADA(USDT).
- **IS/OOS 사전고정**: IS 2022-01-01~2024-06-30, OOS 2024-07-01~2026-06-30.
- **XRP leave-one-out** 실시.
- **비용**: taker 0.05% + 슬리피지 0.02%, 각 사이드(왕복 약 0.14%) 반영.
- **룩어헤드 금지**: RVI/Signal 모두 과거·현재 확정봉만 참조(`(c-o)`/`(h-l)`의 0~3봉 전
  가중합 → SMA10 → 이를 다시 0~3봉 전 가중합). 신호는 바 i의 확정 종가로 판정하고 그
  확정치 그대로 바 i 종가에 체결(house 컨벤션, 미래 봉 미참조). SL/청산 체크는 진입봉
  자신은 제외하고 다음 봉부터 적용.

## 구현 규칙

- `num[i] = (c-o)[i] + 2(c-o)[i-1] + 2(c-o)[i-2] + (c-o)[i-3]`,
  `den[i] = (h-l)[i] + 2(h-l)[i-1] + 2(h-l)[i-2] + (h-l)[i-3]`, `RVI = SMA10(num/den)`,
  `Signal = (RVI + 2·RVI[1] + 2·RVI[2] + RVI[3]) / 6` (원문 산식 그대로).
- 롱: 직전 RVI<직전 Signal, 현재 RVI>현재 Signal(상향크로스) → 신호봉 종가 진입. 숏은 대칭.
- 청산: 반대크로스 발생 시 신호봉 종가 청산, 또는 SL=entry∓stop_atr_mult×ATR(14,15m)
  히트(SL 우선), 또는 max_hold 봉 경과 시 강제청산. 기본: stop_atr_mult=1.5(원문범위
  1.2~1.8 중앙값), max_hold=48봉(스펙 권고, 12h).
- **원문 외 보강**(htf_trend_filter, [설계 판단]): 1h EMA20 기울기 방향과 일치하는 크로스만
  채택 — **주 판정은 원문 그대로(필터 없음)로 하고, 필터 유무는 A/B 로버스트니스만 확인**.

| 표본 충분 | 매우 충분(풀드 n=88,694, 심볼별도 1.2만+) |
| 파라미터 민감도 | 강건하게 실패(SL/max_hold 무관) |
| 보강 필터(1h 추세) 적용 시 | 개선되나 여전히 미달(PF 0.79, t=-10.5) |

**7종목 전부·IS/OOS 양쪽·모든 파라미터 조합에서 PF가 1.0(손익분기)에도 미치지 못한다.**
원문(미국주식 일봉)의 "18%p 초과수익" 주장은 승률·PF·거래횟수·수수료 가정이 전혀
공개되지 않은 수익률 비교에 불과했고, **크립토 15m으로 전이 시 재현되지 않으며 오히려
확연한 손실 전략**이다. 근본 원인은 RVI와 Signal이 둘 다 최근 4~13봉의 가중평활값이라
저타임프레임에서 서로 거의 붙어 다니며 노이즈에 극도로 민감하게 교차한다는 점 —
평균 보유 4~5봉의 초단타 휩쏘 매매를 양산해 왕복 수수료(0.14%)를 감당하지 못한다.
1h 추세필터를 더해도 근본적 엣지 부재는 해소되지 않는다. **정직하게 FAIL 판정한다.
억지 PASS 없음.**
