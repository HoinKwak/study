## 1. 전략 요약

- 롱: RSI(14)가 직전봉 <30 → 현재봉 ≥30 상향돌파. 숏: 직전봉 >70 → 현재봉 ≤70 하향돌파.
- 청산: 진입가 대비 고정 -1% 손절 / +2% 익절(RR 1:2). 추세필터·거래량필터 없음.
- 원문(Medium, BTC/USDT 1년 단일표본) 실측: **4h가 최우수(거래 25건, 승률60%, PF 2.09, Sharpe 5.13)**.
  15m(15건, PF1.64), 1h(16건, PF1.21)는 소표본, 5m(PF0.94)·30m(PF0.91)는 저조.

## 2. 구현 해석(모호점 처리)

- **룩어헤드 금지**: RSI 크로스는 신호봉(i) 종가로 확정하고, 체결은 **다음 봉(i+1) 시가**(+슬리피지)에서
  이뤄진다. 같은 봉 종가로 즉시 시장가 체결한다는 원문 문구는 실전에서 봉 확정 후에만 알 수 있으므로
  1봉 지연 체결로 보수적으로 해석했다.
- **포지션 관리**: 단일 포지션(피라미딩·역전 없음). 보유 중 반대 크로스가 발생해도 무시(원문에 별도
  필터·반전 규칙이 없어 관찰만). 청산은 SL/TP만.
- **시간청산**: 원문에 명시 없음 → 기본은 무제한 보유(SL/TP 도달까지). 강건성 점검으로 `max_hold_bars`
  옵션(4h=40봉≈6.7일, 1d=10봉)을 별도 실행해 영향 확인(§5).
- **SL/TP 동시 도달**: 같은 봉에서 둘 다 닿으면 SL 우선(보수적, 프레임워크 표준 가정과 동일).
- **인트라바 정밀도**: 15m 원본을 리샘플해 1h/4h/1d를 만들므로, 상위봉 high/low는 실제 15m 데이터에서
  집계된 정확한 값(순서는 알 수 없어 SL 우선 가정으로 보완)이다.
- **수수료/슬리피지**: 편도 taker 0.05% + 슬리피지 0.02% = 편도 0.07%, 왕복 0.14%(프레임워크 기본값).
  진입 수수료는 `trade.fees`에 누적되고 청산 시 `pnl = raw_pnl - trade.fees`로 반영(진입+청산 모두
  포함) — `sanity_check_fees()`로 전 케이스 검증, 전부 통과(진입수수료 미반영 버그 없음 확인).
- **사이징**: `RiskManager.build_plan_with_stop` — 리스크 1%/트레이드, 레버리지는 `Settings.leverage_for`
  (BTC/ETH/BNB/SOL/XRP/DOGE/ADA 전부 major_bases → 30x). SL=1%이고 리스크=1%이므로 산술적으로
  notional≈equity(사실상 1x) — 레버리지 상한에 걸리지 않음.
- **TF**: 스펙 요청대로 15m/1h/4h/1d **4개 전부** 검증(외부 "저TF 붕괴·4h 최우수" 주장 교차검증 목적).

- **거짓 FAIL(억울한 탈락) 검토**: 같은 봉 SL/TP 동시도달 시 "SL 우선"(보수적) 가정이 결과를 얼마나

  가정의 민감도까지 점검했지만 FAIL 판정을 흔들 정도의 결함은 발견하지 못했다. **거짓 FAIL 아님 — 원
