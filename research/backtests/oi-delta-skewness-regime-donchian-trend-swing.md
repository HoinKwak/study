## 5. 사전 등록 폐기조건 판정 (①→②→③, 사후 변경 없음)

### ① (최우선) 게이트없음 대조군 대비 부트스트랩 우수성

- **결과: FAIL.** gated 의 OOS mean(R)(-0.006)은 ungated 표본(n=1,669)에서 gated 와 같은
  표본크기(449)로 10,000회 리샘플한 분포의 **11.9 백분위**에 위치한다 — 즉 gated 가
  ungated 보다 우수하기는커녕 **매칭된 표본크기 무작위 부분집합 중 하위 12% 수준**이다.
  ```
  matched-N bootstrap (ungated pool -> gated n): pctile=11.9, base_mean=-0.0060,
  pool_dist_mean=+0.0560, n=449, n_boot=10000
  ```
- **base⊆pool 오염 우려 점검**: gated 트리거(게이트+브레이크아웃)는 ungated 트리거(브레이크아웃
  단독)의 부분조건이라 완전한 독립표본이 아니다. 다만 실현 트레이드 키(종목+진입시각+방향)
  기준 실측 중첩은 812건 중 714건(88.0%)에 그쳤다(상태기계의 포지션 점유로 인한 경로의존성
  때문에 나머지 12%는 트리거 시점이 어긋남). 중첩을 제거한 **잔여(비중첩) ungated 표본
  (n=1,276)** 만으로 독립 Welch 검정을 별도 수행:
  ```
  잔여(비중첩) ungated OOS n=1276 mean=+0.0799
  Welch t(gated vs 잔여-ungated) = -1.200, p=0.2307
  ```
  방향은 여전히 gated 열세(음수 t)이며, base⊆pool 오염을 제거해도 결론(비유의하게 우수하지
  않음, 오히려 열세)이 바뀌지 않는다.
- **결론**: 정규화 게이트 논증(스펙 §진입규칙)이 요구하는 "게이트없음 대비 우수성"이 전혀
  성립하지 않는다 — **폐기조건 ① 충족, 이 시점에서 이미 FAIL 확정.**

## 8. 반전(reverse) 대조군

진입가 기준 SL/TP 대칭 재배치 + 청산조건 방향 분기(스톱/TP 좌우 반전) 모두 적용했고,
**레짐해소(서사무효화) 조기청산은 스펙 지시대로 원신호(orig_direction) 기준**으로 판정해
반전 트레이드에서도 뒤집히지 않게 했다.

```
zero_hold_frac (holding_bars==0), OOS: 정방향 2.4% / 반전 7.8%  (둘 다 낮아 트리비얼하지 않음)
청산사유 분포(OOS) 정방향: stop_loss 56.8% / take_profit 19.6% / time_exit 16.9% / regime_inv 6.7%
청산사유 분포(OOS) 반전  : stop_loss 55.3% / time_exit 23.6% / take_profit 12.8% / regime_inv 8.3%
평균 보유봉수 정방향 13.2봉(2.2일) / 반전 14.2봉(2.4일)
```
zero_hold_frac 이 양쪽 다 낮고(2~8%) 청산사유 분포도 자연스러워 이 엔진에서는 트리비얼하지
않다(과거 라운드들에서 반복된 "반전모드 청산조건 버그로 인한 즉시청산 퇴화" 패턴은 재현되지
않았다). PF(R) 는 reverse(0.947) < gated(0.990) 로 정방향이 근소하게 낫지만 둘 다 1.0
근방·비유의(t 둘 다 |t|<1) 라 "방향에 뚜렷한 정보가 있다"고 주장할 근거는 못 된다.

## 9. LOO(종목 하나씩 제외) · top-N 제거

**LOO (OOS, gated)** — 모든 조합에서 |t|<0.61, PF(R) 0.93~1.07 로 균질하게 무엣지:
```
ex-BTC  n=386 PF(R)=1.031 t=+0.260   ex-ETH n=382 PF(R)=1.065 t=+0.527
ex-BNB  n=378 PF(R)=0.996 t=-0.032   ex-SOL n=380 PF(R)=1.013 t=+0.112
ex-XRP  n=388 PF(R)=0.937 t=-0.559   ex-DOGE n=387 PF(R)=0.963 t=-0.316
ex-ADA  n=393 PF(R)=0.932 t=-0.600
```
**종목별 단독 OOS** (IS/OOS 순위 비일관성 — 과최적화 배제 근거이자 그 자체로 신호 부재의
증거):
| 종목 | IS PF(R) | OOS PF(R) | OOS n |
|---|---|---|---|
| BTC | 1.07 | 0.73 | 63 |
| ETH | 1.43 | 0.64 | 67 |
| BNB | 0.92 | 0.96 | 71 |
| SOL | 1.33 | 0.86 | 69 |
| XRP | **0.58** | **1.38** | 61 |
| DOGE | 1.00 | 1.15 | 62 |
| ADA | 1.36 | 1.47 | 56 |

IS 최악(XRP, 0.58)이 OOS 최고(1.38)로 뒤집히는 등 **종목 간 순위가 IS↔OOS 에서 전혀
일관되지 않는다** — 특정 종목·구간에 과최적화된 결과가 아니라, 반대로 애초에 안정적인
엣지가 없어 무작위에 가까운 변동을 보이는 패턴이다.

**top-N 제거 (OOS, gated, 트레이드 단위)**
```
top-N 최고승리 제거: N=1 PF=0.981 → N=5 PF=0.944 → N=10 PF=0.898 → N=20 PF=0.806
top-N 최악손실 제거: N=1 PF=0.994 → N=5 PF=1.010 → N=10 PF=1.030 → N=20 PF=1.072
```
최고승리 몇 건 제거로도 PF 가 빠르게 무너지는 반면(20건 제거 시 0.806), 최악손실 20건을
제거해도 PF 는 1.072 에 그쳐 PASS 기준(1.3)과 거리가 멀다 — "손실 몇 건이 결과를 왜곡한다"는
반론이 성립하지 않는다.

## 12. 종목 간 신호 상관 (평시 vs 위기국면)

일별 이진 신호(그 날 gated 진입 발생 여부) 기준 오프대각 평균 상관:
```
평시 오프대각 평균상관 = 0.150
위기국면(BTC |일간수익률| 상위5%, 83일) 오프대각 평균상관 = 0.158
```
평시와 위기국면의 차이는 미미했다(0.150→0.158). 다만 §5③ 매크로 클러스터 분해에서 확인한
대로 **4일 롤링 윈도우 기준 클러스터 다수가 7종목 전부를 포함**한다 — 이는 위기국면
동조화라기보다, OOS 기준 종목당 연 30건 안팎(≈12일에 1건)의 거래 빈도에서 7종목을 합치면
평균 4일 이내 최소 1건이 도착할 기대빈도가 이미 높다는 **거래빈도 자체의 base rate 효과**로
해석하는 것이 더 정확하다(오프대각 상관 0.15 는 완전독립(0)보다는 높지만 극단적 동조 수준은
아님). 두 해석 모두 §5③ 의 "소수 매크로 사건 의존"이라는 결론 자체를 바꾸지는 않는다.

## 13. 종합 판정

**FAIL** — 사전 등록 폐기조건 **①(최우선)** 과 **③** 둘 다 충족한다.

- ① 게이트없음(순수 Donchian) 대조군이 net·gross 양쪽에서 gated 채택안보다 뚜렷이 우수했다
  (OOS net PF(R) 1.140 vs 0.990, gross PF(R) 1.226 vs 1.038). matched-N 부트스트랩에서
  gated 는 ungated 매칭표본 분포의 11.9 백분위 — "비유의하게 우수"가 아니라 **열세**다.
- ③ 3~5일 롤링 de-clustering 후 net PF(R) 가 이미 0.45~0.51 로 1.0 미만이고, top-3 매크로
  클러스터(최고 기여 기준) 제거 시 0.16~0.53 으로 더 붕괴한다. 최악 클러스터 제거(대칭점검)
  에도 1.0 미만이라 방향에 무관하게 구조적이다.
- ② 표본수는 충분했다(종목별 OOS n 56~71) — 판단불가 사유 없음.
- 부가 증거: 무비용(gross) 상태에서도 gated 는 무엣지(t=0.339)이고 ungated 가 오히려
  유의(t=3.111) — 비용 잠식이 아니라 게이트 자체가 순 Donchian 대비 정보를 깎아먹는
  방향으로 작동했다. 파라미터 20변형 전부 무엣지에 수렴, LOO 7/7 무엣지, 종목별 IS↔OOS
  순위 완전 비일관, top-N 제거 비대칭(승리 제거에 취약·손실 제거에 둔감)까지 전부 같은
  결론(무엣지)으로 수렴한다.
- 트리거 시점 한정 상관에서 ADX14(-0.707)·ΔOI%(0.641) 와 상당히 얽히는 부분적 동어반복
  신호도 발견돼(§6), "왜도"라는 3차 모멘텀 축이 발화 시점 기준으로는 기존 추세강도 정보와
  꽤 겹친다는 점도 실패의 개연적 설명이 된다.
