## 1. 스펙 실측 주장 독립 재현 (⚠️ 최우선 검증 사항)

### 1-1. BTC 9개월 비연속 샘플 재현 (스펙: 삼백병 15건·삼흑아 8건, 1,662봉)

스펙과 동일한 표본(2023-01·04·07·10, 2024-01·04·07·10, 2025-01, (a)~(d)만 적용, 꼬리필터 미적용)을
**독립적으로 다시 계산**했다.

| ATR 정의 | 표본 봉수 | 삼백병 | 삼흑아 | 결합확률(백병/흑아) |
|---|---:|---:|---:|---|
| **프레임워크 표준(Wilder ewm, 채택)** | 1,662 | **11** | **4** | 0.66% / 0.24% |
| 단순 이동평균(SMA) ATR | 1,662 | 14 | 7 | 0.84% / 0.42% |
| 스펙 주장 | 1,662 | 15 | 8 | 0.90% / 0.48% |

봉수(1,662)는 정확히 일치한다. 건수는 ATR 정의에 따라 11~14(백병)/4~7(흑아)로, 스펙 주장(15/8)과
**같은 자릿수·같은 오더**로 재현되며, 단순 SMA ATR을 쓰면 거의 정확히 일치(14 vs 15, 7 vs 8 —
차이 1건씩)한다. 이는 스펙 저자가 롤링 SMA 기반 ATR로 사전 계산했을 가능성을 시사하나, 본
백테스트는 이 프로젝트 전체(`ind.atr()`, `strategy/scalp.py` 등)에서 사용하는 **Wilder EWM ATR로
통일**해 채택했다(프레임워크 정합성 우선, §5 코드인용 참조). 어느 정의를 쓰든 **결합확률이
독립가정(0.45×0.5)³≈1.1% 근사와 같은 자릿수**라는 스펙의 핵심 주장(모닝스타류의 극단적 희소성과
다름)은 **독립 재현으로 지지된다**.

## 9. 핵심 로직 (코드 인용)

### 3캔들 신호 벡터화 검출

```python
idx2 = np.arange(2, n)
i0, i1, i2 = idx2 - 2, idx2 - 1, idx2

# 인접성(정확히 4h 간격 연속) — 결측봉으로 인한 오탐 방지
dt = np.diff(ts).astype("timedelta64[ns]")
four_h = np.timedelta64(4, "h")
adj_ok = (dt[i1 - 1] == four_h) & (dt[i2 - 1] == four_h)

strong_all = strong(i0) & strong(i1) & strong(i2)   # body >= body_atr_mult*ATR
valid_atr = ~np.isnan(atr[i0]) & ~np.isnan(atr[i1]) & ~np.isnan(atr[i2])

bull0, bull1, bull2 = c[i0] > o[i0], c[i1] > o[i1], c[i2] > o[i2]
open_mono_up = (o[i2] >= o[i1]) & (o[i1] >= o[i0])
close_mono_up = (c[i2] > c[i1]) & (c[i1] > c[i0])

long_struct = bull0 & bull1 & bull2 & strong_all & open_mono_up & close_mono_up & valid_atr & adj_ok
# (숏은 대칭: bear/open_mono_dn/close_mono_dn)
if p.use_wick_filter:
    long_sig = long_struct & wick_ok_long   # upper_wick <= wick_ratio_max*body, 3봉 모두
else:
    long_sig = long_struct                  # §1-2 실측(88.4% 붕괴)에 따라 BASE는 이 경로
```

### 청산(초기 SL + ATR 트레일링 래칫 + 고정 R:R, 반전 대조군은 최종 방향만 참조)

```python
# 초기 SL 거리: '원래 방향' 공식(패턴 극값 vs ATR*1.5, 더 타이트한 쪽)으로 계산한
# 거리(스칼라, 방향무관)를 최종 방향(reverse 적용 후)에 대칭 배치한다.
if raw_dir == "long":
    cand_extreme_dist = entry_o - extreme          # extreme = pattern_low(i0,i1,i2 중 최저)
else:
    cand_extreme_dist = extreme - entry_o           # extreme = pattern_high
cand_atr_dist = p.atr_sl_mult * atr_sig
stop_dist = min(cand_extreme_dist, cand_atr_dist) if cand_extreme_dist > 0 else cand_atr_dist

final_dir = raw_dir if not reverse else ("short" if raw_dir == "long" else "long")
is_long = final_dir == "long"
if is_long:
    entry_price = entry_o * (1 + SLIPPAGE)
    stop_price = entry_price - stop_dist
    fixed_tp = entry_price + p.rr_target * stop_dist
else:
    entry_price = entry_o * (1 - SLIPPAGE)
    stop_price = entry_price + stop_dist
    fixed_tp = entry_price - p.rr_target * stop_dist

trail_dist = p.atr_trail_mult * atr_sig
for j in range(entry_i, hold_end + 1):
    if is_long:
        peak = max(peak, h[j])
        eff_stop = max(stop_price, peak - trail_dist)      # 래칫(초기SL보다 유리할 때만 대체)
        if l[j] <= eff_stop:
            exit_j, exit_price_raw = j, eff_stop
            reason = "trailing_stop" if eff_stop > stop_price else "stop_loss"
            break
        if h[j] >= fixed_tp:
            exit_j, exit_price_raw, reason = j, fixed_tp, "take_profit"
            break
    # (숏은 대칭 — peak=min, eff_stop=min(stop_price, peak+trail_dist) 등)
if exit_j is None:
    exit_j, exit_price_raw, reason = hold_end, c[hold_end], "time_exit"
```

모든 청산 분기(`trailing_stop`/`stop_loss`/`take_profit`)가 원신호 플래그(`raw_dir`)가 아닌
**최종 방향 변수(`is_long`, `final_dir`)만 참조**한다(SL 거리 스칼라 계산에만 `raw_dir` 사용,
이후 배치·청산 판정은 전부 `is_long` 기준). `zero_hold_frac`이 정방향/반전에서 유사하되 동일하지
않은 것(§4)이 이 설계가 올바르게 작동함을 방증한다.

워크트리에 존재하나 gitignore로 미추적 — 재현 필요 시 이 리포트의 코드 인용 + `bt_common.py`(공통

전량 독립 재실행**해 PF·t·거래수·종목별 분해·청산사유·부트스트랩 CI·백분위까지 **모든 수치가
소수점까지 완전 일치**했다("이 프로젝트에서 관측된 재현성 중 최상위 수준" 평가). 리포트가 하지
않은 아래 4건을 리뷰어가 추가로 직접 실행했고 전부 FAIL 결론을 강화했다.

**(1) 꼬리 필터 (e) 배제 판단 — 스펙 위반 아님이 확인되고, 포함판 직접 실행으로 편향도 해소**
스펙 원문(§진입 규칙 각주)에 "(e) 포함/제외 두 버전을 모두 돌려 빈도 붕괴 여부를 확인하고, 붕괴
시 (e) 제외판을 기본으로 채택할 것"이 **명시돼 있어** 본 리포트의 처리는 문자 그대로의 이행이다.
리뷰어가 (e) 포함판을 직접 실행한 결과:

| 구간 | n | net PF | gross PF | t(net) |
|---|---:|---:|---:|---:|
| FULL | 94 | 0.525 | 0.590 | -2.67 |
| IS | 42 | 0.830 | 0.943 | -0.49 |
| **OOS** | **52** | **0.345** | **0.384** | **-3.46** |

**(e) 포함판이 (e) 제외판(OOS net PF 0.627)보다 오히려 더 나쁘다**(0.345). 즉 (e) 제외 선택은
결과를 유리하게 만든 것이 아니라 **덜 나쁜 쪽을 기본으로 채택**한 것이라 설계판단 편향 우려가
실증적으로 해소된다(다만 OOS n=52로 얇아 이 보조 결과 자체는 참고용).

**(2) ATR 정의 독립 재구현** — 스펙의 "삼백병 15건·삼흑아 8건" 주장을 리뷰어가 처음부터 독립
재구현해 검증: Wilder EWM → 11/4, **SMA ATR → 14/7**(스펙 주장과 사실상 일치), 봉수 1,662 정확히
일치. 스펙 저자가 SMA 기반 ATR로 사전계산했을 가능성이 높다는 본 리포트의 추론이 재확인됐다.
스펙이 ATR 계산법을 명시하지 않은 것은 스펙 자체의 모호성이다.

**(3) 룩어헤드 확장** — 본 리포트가 절단 재실행한 BTC/ETH/XRP 외에 리뷰어가 **BNB(cut=500)·
SOL(cut=733)·DOGE(cut=2001)** 를 서로 다른 절단점으로 독립 재실행해 전부 완전일치
(128/128, 116/116, 86/86). **7종목 중 6종목이 독립 확인**됐다(ADA만 미확인, 위험 낮음).

**(4) de-clustering 대칭 점검** — 본 리포트는 최대 **수익** 클러스터 제거만 보였는데, 리뷰어가
반대로 최대 **손실** 클러스터를 제거해도 살아나는지 확인:

| 윈도우 | 제외 전 | 최대손실 1개 제외 | 최대손실 top-3 제외 |
|---|---:|---:|---:|
| 3일 | 0.355 | 0.401 | 0.470 |
| 5일 | 0.241 | 0.269 | 0.321 |

최악의 손실 클러스터를 빼도 net PF가 0.32~0.47로 **1을 한참 밑돌아**, FAIL이 특정 구간 탓에
과하게 매겨진 것이 아님이 대칭적으로 확증됐다.

**반전 대조군 청산 구조** — `trailing_stop`/`stop_loss`/`take_profit` 전 분기가 `is_long`(최종
방향 변수)만 참조하고 `raw_dir`은 SL 거리 스칼라 계산에만 쓰임을 코드 대조로 확인 → 반복
재발한 "원신호 플래그 참조" 버그 클래스 미해당. `zero_hold_frac`도 종목별 9.09~26.23%로
정상이고 정방향(15.07%)·반전(16.27%)이 유사하되 동일하지 않아 트리비얼 지표가 아님이 확인됐다.

**단위 함정** — `bt_common.load_klines`가 `unit="ms"` 명시 후 `datetime64[ns]`로 명시 캐스팅하고,
**인덱스를 `Timedelta` 덧셈으로 재구성하는 코드 경로가 없어**(정수 위치 인덱싱만 사용) 반복된
ms→us 업캐스트 함정이 구조적으로 미노출임을 확인. 캐시 pickle 샘플을 직접 열어
`open_time=1719792000000`(13자리 ms)도 대조했다.

**리뷰어 지적으로 정정한 것**(본문 §6·§8에 반영 완료): 부호 무작위화 "0 백분위"를 "방향 선택이
무작위보다 나쁘다 / 소진·반전 방향 신호 가능성"으로 읽은 초판 해석이 과장. 이 극단값은 승률
34.4%(<50%)에서 오는 산술적 귀결이며, **승률을 실제값으로 고정한 대안 검정에서는 92.9 백분위**로
방향 배정 자체에 특이점이 없다. 결론은 "반대 방향에 정보가 있다"가 아니라 "방향 자체에 신뢰할
정보가 없다"이며 FAIL 판정에는 영향이 없다.

**인프라 검증** — 백테스터가 격리 워크트리 복원을 위해 실행한 `git checkout origin/<브랜치> -- .`
가 공유 이력을 오염시키지 않았는지 리뷰어가 확인: 해당 워크트리 브랜치는 **원격에 존재하지 않는
로컬 전용 격리 브랜치**임을 `git ls-remote`로 확인(push된 적 없음), 워크트리와 메인 저장소의
리포트 파일이 **완전 동일**, 메인 브랜치 로그도 정상. **복원 영향이 워크트리 내부에 국한**됐다.
