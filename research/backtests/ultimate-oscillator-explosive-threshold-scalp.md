# Ultimate Oscillator(UO) 임계값 돌파 반전 스캘프 — 백테스트 리포트

- **전략 스펙**: `research/strategies/ultimate-oscillator-explosive-threshold-scalp.md`
- **출처**: Cryptohopper 블로그(OP 단일종목, 표준 7/14/28 대비 조정 파라미터 1/24/30, 과매도/과매수
  35/60). 표준 UO(7/14/28, 30/70)와 원문 조정 파라미터를 대조 검증하는 것이 목적.
- **판정 목적**: 표준 vs 원문조정 파라미터, 롱숏 vs 롱온리, ATR 손절 유무를 15m 단일 TF에서 대조.

## 구현/실행 방식

- **격리 스크립트**: `scratchpad/bt_uo.py` (완전 독립, `src/crypto_trader/**` 무수정,
  `indicators.py`의 `atr`만 재사용). 삼기간 가중합산+임계값 반전 로직이 기존 scalp 인터페이스와
  맞지 않아 TRIX/SMMA와 동일한 자체 이벤트기반 시뮬레이터 사용.
- **산식**: `BP=close-min(low,prevClose)`, `TR=max(high,prevClose)-min(low,prevClose)`,
  `Avg_k=sum(BP,k)/sum(TR,k)`, `UO=100×(4×Avg_p1+2×Avg_p2+Avg_p3)/7`.
- **진입**: 롱=UO가 oversold 아래→위로 상향돌파. 숏=UO가 overbought 위→아래로 하향돌파.
- **청산(원문 그대로)**: 롱은 UO가 overbought를 **상향**돌파(반대 임계값 도달)할 때 익절, 숏은
  UO가 oversold를 **하향**돌파할 때 익절(대칭 적용). 손절(자체보강): 진입 직전 닫힌봉 ATR(14)×
  `atr_mult`(기본 1.0), 인트라바 체크.
- **룩어헤드 방지**: 신호는 i-1(닫힌 봉) 확정 UO 교차로 판정, 체결은 i봉 시가(+슬리피지).
- **데이터**: `scratchpad/futdump100m/*.pkl` (바이낸스 선물 15m OHLCV). **원문 20분봉은 바이낸스
  비네이티브라 우리 최소 데이터인 15m으로 근사**(15m→20m 리샘플은 봉 경계가 어긋나 오히려 부정확
  — 15m 그대로 사용).
- **종목**: 13개 장기이력 종목(BTC/ETH/SOL/BNB/ADA/DOGE/XRP/ZEC/NEAR/1000XEC/TUSDT/DODOX/WLD,
  2022-01~ 또는 상장~2026-06) 풀링을 주 판정 근거, 전 22종목은 참고용 상세표.
- **IS/OOS**: IS 2022-01-01~2024-06-30, OOS 2024-07-01~2026-06-30.
- **수수료/슬리피지**: 진입/청산 각 taker 0.05% + 슬리피지 0.02%(사이드당).
- **실행 커맨드(재현)**:
  ```
  cd /home/user/study
  python3 scratchpad/bt_uo.py BTCUSDT     # 단일 심볼 스팟체크(표준 파라미터, 15m)
  python3 - <<'PY'
  from scratchpad.bt_uo import load_symbol, simulate, summarize, LONG_HISTORY_SYMBOLS
  for sym in LONG_HISTORY_SYMBOLS:
      df = load_symbol(sym, '15m')
      res = simulate(df, symbol=sym, p1=7, p2=14, p3=28, oversold=30, overbought=70,
                      direction='long_only', use_stop=False)
      print(summarize(res))
  PY
  ```
  (조정 파라미터는 `p1=1,p2=24,p3=30,oversold=35,overbought=60`, ATR손절은 `use_stop=True,
  atr_mult=1.0~6.0`으로 재현)

**근거**:
1. **표준 파라미터(7/14/28, 30/70)는 gross PF조차 1.0 근처(0.96~1.05)로, 수수료 이전부터
   엣지가 사실상 없다.** net PF는 전 조합에서 1.0 미만이거나 1.0에 겨우 걸친다.
2. **원문 조정 파라미터(1/24/30, 35/60)는 스펙이 경고한 대로 명백한 과최적화·이례적 조합이다.**
   13종목 풀링만으로 35만 건의 거래가 발생하는 비정상적 회전율을 보이며, t값 -50~-76으로
   **통계적으로 확실한 손실**이다. 크립토호퍼 원문의 OP 단일종목 608% 수익률은 우리 다종목
   검증에서 전혀 재현되지 않으며, 오히려 정반대(구조적 손실) 결과가 나왔다.
3. **종목 간 일관성이 없다** — 표준 파라미터 상세표에서 13개 장기이력 종목 중 net PF>1.0인
   종목은 2개뿐이고 나머지 11개는 손실권(0.75~1.02)에 흩어져 있다.
4. **임계값을 넓혀 PF를 개선하려 하면 표본이 붕괴한다**(20/80: n=105, 25/75도 OOS에서 PF·t값

5. **ATR 손절 배수 조정도 해결책이 안 된다**(1.0×~6.0×ATR 전 범위에서 net PF<1.0).

원문(크립토호퍼 OP 단일종목 백테스트)의 정량 주장은 우리 프레임워크·13~22종목·4.5년 데이터에서
전혀 재현되지 않는다. 표준 파라미터도, 원문 조정 파라미터도 모두 통과 기준에 크게 못 미친다.

## 미검증/근사 요소 (정직한 한계 고지)

- **20분봉 근사**: 원문은 바이낸스 비네이티브 20분봉을 썼으나 우리는 최소 데이터인 15m을 그대로
  사용했다(20분 리샘플은 봉 경계 정합성 문제로 배제). TF 차이가 결과에 영향을 줄 수 있으나,
  gross PF조차 1.0 근처인 raw 신호 약세가 TF 하나 차이로 뒤집힐 가능성은 낮다고 판단.
- **손절 방식**: 원문은 "스윙 저점/고점 또는 ATR"만 언급하고 구체 수치가 없어 ATR(14)×배수로
  자체 보강했다. 스윙 저점/고점 기반 손절을 시도하면 결과가 달라질 수 있으나, gross PF 자체가
  약한 상황에서 손절 방식 변경만으로 1.3 문턱을 넘길 근거는 낮다.
- **다이버전스 확장(강세/약세)**: 원문이 코드로 제시하지 않아 검증하지 않음.
