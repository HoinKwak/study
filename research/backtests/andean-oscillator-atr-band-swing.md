# Backtest — 안데안 오실레이터(Andean Oscillator) + ATR×3 밴드 스윙 (4h)

- **스펙**: `research/strategies/andean-oscillator-atr-band-swing.md`
- **구현**: `research/impl/andean_bt.py`(독립 백테스트 스크립트, `research/impl/rsutil.py` 공용유틸).
  안데안 오실레이터는 표준 TA 라이브러리에 없는 비표준 재귀식이라 `indicators.py`에 없고,
  단일방향(플랫→진입→ATR고정TP/SL) 구조가 `SleeveBacktester`의 swing 슬리브(RSI+슈퍼트렌드
  피라미딩) 와 달라 별도 루프로 구현.
- **판정: HOLD** — 4h 에서 파라미터·leave-one-out 전반에 걸쳐 **일관되게 완만한 양(+)의
  엣지**(OOS PF 1.13~1.34, MDD 심볼별 3.8~9.1%로 매우 낮음, 7종목 중 OOS 전원 PF≥1.07)를
  보이나, 가이드 기준 PF≥1.3 을 합산 기준으로 안정적으로 넘지 못해(최고 변형도 1.23) 확정
  PASS 로 올리지 않는다. 이번에 검증한 발굴 전략 2건 중 **위험도(MDD)·일관성 측면에서는
  더 우수한 후보**임을 밝혀둔다.

## 방법론 / 재현 커맨드

- **데이터/기간/수수료/사이징**: Gann HiLo 리포트와 동일 조건(7메이저, 데이터 2022-01~2026-06,
  IS/OOS 분할 동일, 왕복수수료 0.14%, `RiskManager.build_plan_with_stop` 1%리스크/SL거리 사이징,
  레버리지 메이저 30x). 자세한 공통 방법론은 `research/backtests/gann-hilo-activator-trend-flip-
  swing.md` 참조.
- **지표(재귀식, Alex Grover 2023 공개 Pine 스크립트 기준 재구현)** — 원저자가 룩어헤드 방지를
  위해 **시가(open)** 를 입력으로 쓰는 것으로 알려진 설계를 그대로 반영:
  ```
  alpha = 2/(length+1)
  up1 = max(o, up1[-1] - (up1[-1]-o)*alpha);  up2 = max(o², up2[-1] - (up2[-1]-o²)*alpha)
  dn1 = min(o, dn1[-1] + (o-dn1[-1])*alpha);  dn2 = min(o², dn2[-1] + (o²-dn2[-1])*alpha)
  bull = sqrt(max(dn2 - dn1², 0));  bear = sqrt(max(up2 - up1², 0))
  signal = EMA(max(bull, bear), sig_length)
  ```
- **진입**: `bull` 이 `signal×1.1` 을 상향돌파 → LONG, `bear` 이 `signal×1.1` 상향돌파 → SHORT
  (스펙의 "1.1배 노이즈 필터" 채택). **ADX 필터는 원문 임계값 미확인**이라 기본 비활성 —
  `--adx --adx-threshold 20` 옵션으로 민감도만 별도 확인(아래).
- **청산**: 진입가 ± ATR(14)×3.0 로 TP/SL 동시 고정. 보유 중 반대 크로스 발생 시 조기청산도
  허용([추정], 스펙 문서가 이미 이렇게 표기 — 원문에 명시 없음).
- **체결/룩어헤드 방지**: 신호는 확정봉 종가(bull/bear/signal 계산에 쓰인 시가는 이미 지나간
  같은 확정봉의 시가이므로 미래 데이터 아님)에서 판정, 체결은 다음봉 시가(+슬리피지). SL/TP 는
  그 다음부터 매 봉 인트라바 체크(손절 우선).
- **재현**:
  ```
  cd research/impl
  python3 andean_bt.py --tf 4h --length 50                      # 주 결과(표준값 50)
  python3 andean_bt.py --tf 4h --length 25                      # 민감도(표준값 25)
  python3 andean_bt.py --tf 4h --length 10                      # 민감도
  python3 andean_bt.py --tf 4h --length 50 --atr-mult 2.0       # ATR배수 민감도
  python3 andean_bt.py --tf 4h --length 50 --atr-mult 4.0
  python3 andean_bt.py --tf 4h --length 50 --adx --adx-threshold 20   # ADX 필터 민감도
  python3 andean_bt.py --tf 4h --length 50 --dogeless           # DOGE leave-one-out
  python3 andean_bt.py --tf 1d --length 50                      # 1d(원문 예시와 다른 TF, 참고용)
  ```

### 강점 — 7종목 전원 OOS PF≥1.07, MDD 매우 낮음(3.8~9.1%)

Gann HiLo 와 대조적으로, **7종목 전부 OOS PF 가 1.0 을 넘는다**(최저 XRP 1.09, 최고 DOGE 1.37).

- **length**: 50이 25·10 대비 뚜렷이 우수(1.21 > 1.13 > 1.03) — 스펙이 시사한 "표준값 범위(10~50)"
  중 상단이 우리 데이터에서 더 낫다.
- **atr_mult**: 2.0~4.0 범위에서 OOS PF 1.17~1.23 로 **좁게 안정적** — 특정 배수의 우연이 아님.
- **ADX 필터**: 임계값(20) 추가 시 거래수는 558→445 로 줄지만 PF 는 1.21→1.23 로 소폭 개선 —
  원문이 암시한 "추세강도 필터가 성과에 도움"이라는 방향과 일치(단 원문 임계값 자체는
  미확인이므로 20 은 우리가 임의로 선택한 값).
- **DOGE leave-one-out**: OOS PF 1.21→1.19 로 **거의 변화 없음** — 원 스펙이 인용한 CRO·CAKE
  같은 개별 알트 100%+ ROI 사례와 달리, 이 결과는 특정 코인 편중이 아니라 여러 종목에 걸쳐
  나타나는 완만한 공통 엣지로 보인다.

## 판정: HOLD — 근거

- **PF≥1.3 가이드 기준 미충족**: 주 결과(OOS PF 1.21)와 모든 민감도 변형(1.13~1.23)이
  가이드가 제시한 통과선(PF≥1.3)에 못 미친다. 개별 심볼 중 BTC·SOL·DOGE 는 OOS PF 1.34~1.37로
  기준을 넘지만, 7종목 합산·파라미터 전반으로는 안정적으로 넘지 못한다.
- **그러나 완전 FAIL 은 아님 — 이번에 검증한 두 전략 중 상대적으로 우수**: (1) 7종목 전원
  OOS PF≥1.07(일관성 양호), (2) 심볼별 MDD 3.8~12.8%(Gann HiLo 의 8.7~70.3% 대비 훨씬 낮은
  리스크), (3) 표본 충분(OOS n=558, 심볼당 75~87건), (4) 파라미터(length·atr_mult·ADX) 전반에
  걸쳐 PF 가 1.0~1.3 범위에서 좁게 움직여 특정 값의 우연이 아님, (5) DOGE leave-one-out 에서도
  결과가 거의 불변해 밈코인 편중이 아님 — 원 스펙이 우려한 "사이트 자체의 과최적화 경고"와
  달리 우리 검증에서는 과최적화 징후가 뚜렷하지 않았다.
- **IS 가 OOS 보다 약한 것도 특이점**(IS PF1.08 < OOS PF1.21) — 다른 두 전략(Gann HiLo 포함,
  다수 선행 리서치)에서 흔한 "IS 는 화려하고 OOS 는 무너지는" 과최적화 패턴과 **반대** 방향이라,
  이 결과가 IS 기간에 유리한 우연으로 부풀려진 것은 아닌 것으로 보인다(다만 이 자체가 엣지의
  증거는 아니며, 표본 나눔의 우연일 수도 있다는 점은 유의).
- **결론**: FAIL 로 단정할 근거(과최적화 징후·밈코인 의존·표본부족·MDD 과다)가 나타나지 않았고
  오히려 리스크 프로파일이 양호하지만, 가이드 통과선(PF≥1.3)에는 못 미치므로 **HOLD**(라이브
  반영 보류, 추가 파라미터 탐색·페이퍼 모니터링 권고)로 판정한다.

## 한계

- ADX 임계값은 원문에 구체 수치가 없어 20 으로 임의 설정(민감도로만 확인, 주 결과는 미적용).
- "반대 크로스 시 조기청산" 규칙은 원문에 명시가 없어 자체 추정([추정], 스펙 문서가 이미 표기).
  이 규칙을 끄면(ATR TP/SL 만으로 청산) 결과가 달라질 수 있으나 이번 검증에는 포함하지 않았다.
- 7종목 합산 MDD 는 계산하지 않았다(Gann HiLo 리포트와 동일 사유 — 심볼별 독립 복리 사이징을
  하나의 가상 공유풀로 합치면 이중복리 왜곡 발생). MDD 는 심볼별(각자 $10k 기준) 수치만 신뢰.
- 원문(TradeSearcher 173개 백테스트 집계, PF1.3·Sharpe0.12) 과 직접 수치 비교는 자산군이
  혼합(주식+크립토)돼 있어 불가 — 이 결과는 원문 재현이 아니라 우리 프레임워크·유니버스에서의
  독자 검증이다. 원문 자체가 "과최적화 우려"를 명시했던 것과 달리, 우리 검증에서는 뚜렷한
  과최적화 징후 없이 완만한 양의 결과가 나온 점이 상반된다 — 표본·자산군 차이로 추정.
