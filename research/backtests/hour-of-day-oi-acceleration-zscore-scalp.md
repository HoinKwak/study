## 핵심 로직(요약 인용)

```python
# ⚠️ pandas 3.0.5 ms/us 함정 대응: klines open_time(ms epoch int)과 metrics
# create_time(날짜 문자열)을 파싱 직후 반드시 .astype('datetime64[ns]') 로 명시 통일.
# (klines: to_datetime(unit='ms')는 ms dtype 유지 / metrics: 문자열 unit미지정 파싱은 us 추론
#  — 두 dtype 이 병존한 채 Timedelta 연산을 하면 조용히 어긋나는 것이 반복된 함정)
idx = pd.to_datetime(df["open_time"], unit="ms").astype("datetime64[ns]")
ts  = pd.to_datetime(metrics["create_time"], format="%Y-%m-%d %H:%M:%S").astype("datetime64[ns]")

# 1) 5분 OI → 정시 그리드 매칭(±5분 허용오차, 스펙 명시)
grid = pd.date_range(start, end, freq="1h")
oi_hourly = merge_asof(grid, oi_5m, direction="nearest", tolerance=Timedelta(minutes=5))
oi_hourly = oi_hourly.mask(oi_hourly <= 0)     # ⚠️0-fill 결측 방어(자체발견, 아래 참조)

# 2) 시간당 OI 변화율 → 슬롯(0~23시)별 45일 롤링 z(shift(1)로 당일 자기참조 배제)
hour_chg = (oi_hourly - oi_hourly.shift(1)) / oi_hourly.shift(1) * 100
for h in range(24):
    sub = hour_chg[hour_chg.index.hour == h]
    mean = sub.rolling(45, min_periods=20).mean().shift(1)
    std  = sub.rolling(45, min_periods=20).std().shift(1)
    z_hod.loc[sub.index] = (sub - mean) / std

# 3) 가격 컨펌: 정시 첫 15m봉(open_time==t) 자신의 body/ATR(15m,14, Wilder)
confirm_bar = df15.loc[t]
body_ok = abs(confirm_bar.close - confirm_bar.open) >= 0.8 * atr15[t]
is_long  = (z_hod[t] >= 2.0) and body_ok and confirm_bar.close > confirm_bar.open
is_short = (z_hod[t] >= 2.0) and body_ok and confirm_bar.close < confirm_bar.open

# 4) 체결: t+15m봉 시가(다음봉) + 슬리피지
# 5) SL = 신호봉(raw 방향) 반대극값 vs entry∓ATR*1.2 중 타이트한 쪽(반전 대조군은 이 '거리'를
#    실제 매매방향에 대칭 재배치 — 아래 버그 발견/수정 참조)
# 6) 부분익절: R:R=2.0 도달 시 50% 청산, 잔량은 ATR(15m,14)*1.5 트레일링(다음 봉부터 유효)
# 7) 시간청산: 진입 후 12봉(3h) 경과 시 강제 종가청산. SL 우선순위 최상단.
```

## 해석·설계 선택(스펙 모호성 명시)

스펙의 청산 규칙 "익절: ATR×1.5 트레일링, 또는 R:R 2.0 선도달 시 부분 익절"은 두 규칙의
결합 방식이 명시적이지 않다. **다음과 같이 구현**했다: SL 은 항상 활성이고, 트레일링 스톱은
진입 직후부터 매 봉 갱신(단조 강화, 다음 봉부터 유효)되며, 가격이 R:R=2.0 목표에 먼저 닿으면
그 시점에 잔량의 50%를 청산하고 나머지 50%는 계속 트레일링 스톱을 따라간다(스톱은 트레일링과
초기 SL 중 더 유리한 쪽을 유지). 이는 프레임워크의 기존 `momentum_trail`(50% 익절+ATR 트레일링
러너) 청산 패턴과 정합적인 해석이나, 스펙이 문자 그대로 규정하지 않은 설계 판단이므로 명시한다.
아래 파라미터 스윕에서 `trail_atr_mult`(1.0~2.5)를 흔들어도 결론이 바뀌지 않음을 확인했다
(민감도 절 참조) — 이 해석 선택이 결과를 유리/불리하게 편향시키지 않았다.

### 최우선 쟁점 ① — 시간대 조건화 무가치 판정: 결론 **강화**

부모 세션이 최우선으로 지시한 "24h 풀링 대조군을 엔진에 의존하지 말고 독립 재구현" 요구에

|---|---|---|
