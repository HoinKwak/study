# [백테스트] ICT 오더블록(Order Block) + BOS + FVG 컨플루언스 되돌림 추세지속

- **전략 스펙**: `research/strategies/ict-order-block-bos-confluence-swing.md`
- **판정: FAIL** (수수료 반영 후 PF 0.82, 수수료 제외해도 PF 0.99 — 원가 이전부터 유의미한 엣지 없음)

## 구현 요약

- TF: 신호 1h(리샘플, native 15m→1h) / 확인 4h(리샘플, BOS 방향 필터).
- 오더블록: 임펄스봉(몸통≥`impulse_mult`×ATR14, 종가가 `bos_swing_lookback`봉 스윙고/저 돌파)
  직전의 **마지막 반대색 캔들**을 존(캔들 몸통 range)으로 등록. FVG 필수 옵션: 존 형성부터
  임펄스봉까지 구간에 3봉 갭(low[k+2]>high[k] 또는 high[k+2]<low[k])이 하나라도 있으면 통과.
- 진입: 존 재진입(고/저 겹침) + 반전캔들(반대방향 꼬리≥wick_frac×레인지, 반전방향 마감) 확인
  → **다음 1h봉 시가**에 체결(과제 지침 "진입은 다음봉" 준수, 원문의 "그 봉 종가"보다 보수적).
  4h 확인TF는 detect_regime(ADX/DI, 기존 인프라 재사용)으로 BOS 방향(TREND_UP/DOWN) 일치 요구.
- 청산: SL=존 먼쪽 끝 ± sl_buf×ATR14, TP=진입±rr×리스크(SL/TP 동시터치 시 SL우선),
  max_hold_bars(48봉=2일) 경과 & 미실현 1R 미만이면 시간청산, 반대 BOS 재발생 시 즉시 종가청산.
- 무효화: 종가가 존을 완전히 관통(반대편 이탈)하면 폐기. 존 최대 대기 150봉(1h≈6일, [설계값],
  spec 미명시분 보강).
- 수수료: 테이커 0.05%/side + 슬리피지 0.02%/side (왕복 0.14%, SleeveBacktester 관례 동일).
- 사이징: RiskManager.build_plan_with_stop — 리스크 1%/trade, 레버리지 30x(전 심볼 major).
- 데이터: data.binance.vision 선물 15m 덤프(scratchpad 캐시, 2022-01-01~2026-06-30) →
  resample_ohlcv로 1h/4h 생성. 인덱스 ms→ns 명시 캐스팅(승격버그 회피 확인).

## 최종 판정: FAIL

근거:
1. 수수료 반영 후 PF 0.82(<1.3 기준 크게 미달), 수수료 제외해도 PF 0.99로 원가 이전부터 엣지 부재.
2. IS(0.85)·OOS(0.78) 모두 PF<1, 표본외에서 더 악화(과최적화 흔적조차 아니라 애초에 유효구간이
   없음).
3. 7종목 중 4종목 명확한 손실, leave-one-out 전부 PF<0.9로 특정 종목 의존이 아닌 구조적 약점.
4. 파라미터 스윕 11개 설정(핵심 파라미터: R:R, 임펄스 임계값, 스윙룩백, FVG 필수여부, wick 완화,
   4h 필터 on/off) 전부 손실 — 강건하게 재현되는 마이너스 엣지.
5. 표본(371건, IS 189/OOS 182)은 판정에 충분(>=20).

**해석**: ICT 오더블록의 "존 재진입 시 반전캔들 확인" 방식은 우리 데이터/비용 구조에서 승률
(27.5%)이 R:R 3.0을 상쇄하지 못함(손절 68% 도달 vs 익절 22%). 원문은 정성적 설명 위주로 백테스트
근거가 전무했고("backtest 50-100 trades to establish validity"라고만 권고), 이번 검증에서 그
권고를 충족하는 표본으로도 재현되지 않았다.
