# Backtest — Gann Hi-Lo Activator 추세전환 스탑앤리버스(SAR) 스윙 (4h/1d)

- **스펙**: `research/strategies/gann-hilo-activator-trend-flip-swing.md`
- **구현**: `research/impl/gann_hilo_bt.py` (독립 백테스트 스크립트, `research/impl/rsutil.py` 공용유틸).
  스탑앤리버스(항상 시장 참여, 반대신호=청산+반전)라는 실행 모델이 `SleeveBacktester`의
  swing/mid/scalp 슬리브(고정 SL/TP 인트라바 체크 또는 RSI+슈퍼트렌드 피라미딩) 어디에도 맞지
  않아 별도 루프로 구현하되, 수수료/슬리피지 부호 규칙(`_fill`/`_fee`)은 동일하게 재현.
- **판정: HOLD** — 원 스펙이 예시로 든 4h 는 우리 7메이저에서 **명백히 FAIL**(PF<1, MDD
  최대 70.3% — 원문의 64% MDD 경고를 그대로 재현·확인), 1d 는 파라미터 전반에서 완만하지만
  일관된 양(+)의 엣지(OOS PF 1.20~1.32)를 보이나 종목별 편차가 크고 MDD 도 여전히 10~25%로
  낮지 않아 **PASS 로 단정하기엔 이름**. 아래 근거 참조.

## 방법론 / 재현 커맨드

- **데이터**: scratchpad 캐시 `vendor_data/15m/<SYM>USDT.pkl`(바이낸스 선물 15m, 2022-01-01~
  2026-06-30 UTC) → `resample_ohlcv` 로 4h/1d 생성. 종목: BTC/ETH/BNB/SOL/XRP/DOGE/ADA(표준 7메이저).
- **기간**: 전 구간(2022-01-01~2026-06-30)을 단일 연속으로 재생한 뒤, 개별 거래를 **진입시각**
  기준으로 IS(2022-01~2024-06)/OOS(2024-07~2026-06) 버킷에 분류(FULL = IS ∪ OOS). 스탑앤리버스는
  구간 경계에서 포지션을 인위적으로 플랫 리셋하면 왜곡되므로, Weinstein/Qullamaggie 리서치와
  동일하게 "연속 재생 후 거래 분류" 방식을 채택.
- **지표**: `hi_line = SMA(high, N)`, `lo_line = SMA(low, N)`. 원 지표 관례(displace=1, TradingView
  공개 스크립트 표준형)대로 **전봉(shift 1)** 의 SMA 값과 당일 종가를 비교:
  `state = +1 if close > hi_line[-1] else (-1 if close < lo_line[-1] else state[-1])`.
- **진입/반전**: `state` 가 바뀌는 확정봉(t) 발생 시, **다음봉(t+1) 시가**에 기존 포지션 청산
  + 반대 포지션 신규진입(각각 별도 체결 — 수수료/슬리피지 각 1회씩, 이중계상 아님). 최초
  포지션(워밍업 이후 첫 state 확정)은 청산 없이 진입만.
- **손절**: 활성 추적선(진입 시점의 lo_line/hi_line, `shift(1)` 값) 자체가 트레일링 스탑이며,
  이 선을 종가로 재이탈 = 반전 신호이므로 **별도의 인트라바 SL 체크는 하지 않음**(스펙 그대로).
- **사이징**: `RiskManager.build_plan_with_stop`(risk_per_trade_pct=1%, 레버리지=메이저 30x).
  스탑거리 = |진입가 − 신호봉의 활성 추적선 값|.
- **수수료/슬리피지**: 왕복 0.14%(테이커 0.05%×2 + 슬리피지 0.02%×2). **메이커 가정 없음**(지시대로).
- **룩어헤드 방지**: 상태 판정은 확정봉 종가 vs 전봉 SMA(shift 1)만 사용, 체결은 다음봉 시가.
- **재현**:

## 판정: HOLD — 근거

- **원문 MDD 64% 경고, 4h 에서 그대로 확인됨**: 4h·length3 은 FULL PF 0.96(손실), 심볼별 MDD
  최대 **70.3%(BNB)** — 원문 집계(PF1.1·MDD64%)와 같은 수준의 위험한 결과가 우리 7메이저에서도
  재현됨. **4h 는 명백히 FAIL**.
- **1d 는 완만하지만 파라미터에 걸쳐 일관된 양(+)의 엣지**: OOS PF 1.20~1.32(4개 length 값
  전부 1.0 초과), 표본도 충분(OOS n=340~706, 심볼당 40~105건으로 <20 결론보류 기준을 넉넉히
  상회), DOGE leave-one-out 에서도 결과가 거의 불변(밈코인 편중 아님) — 이 부분은 긍정적.
- **그러나 PASS 로 판정하지 않는 이유**: (1) 원 스펙이 실제 예시로 든 TF(4h, PEPE)에서는
  전략이 무너진다는 점 자체가 "원문 그대로의 사용법"에 대한 반증이며, TF 를 1d 로 바꿔야
  간신히 살아나는 것은 원문 재현이 아니라 우리가 유리한 조건을 찾은 것에 가깝다. (2) 1d 에서도
  **종목별 편차가 큼**(BTC/SOL/ADA OOS PF<1, XRP·DOGE 는 크게 위 — "다수 종목 일관성" 기준
  미충족). (3) 심볼별 MDD 가 1d 에서도 최대 24.5%(BTC OOS) 로, 스탑앤리버스 구조상 **포지션을
  절대 플랫으로 두지 않는다는 점**(변동성 급등 시 갭 리스크에 항상 노출)이 구조적 위험 요인으로
  남아있어, 표면 PF 만으로 안전하다고 보기 어렵다.
- **종합**: 4h FAIL + 1d 완만한 양의 엣지(하지만 종목 비일관·MDD 잔존)이므로, 라이브 반영을
  권하지 않되 "완전한 무의미"로도 단정하지 않는 **HOLD** 로 판정한다.
