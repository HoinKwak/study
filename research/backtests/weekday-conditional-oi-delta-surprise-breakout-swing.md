## 판정: **FAIL**

스펙이 **사전 등록한** 폐기조건 (a) "OOS PF(R) < 1.15 **또는** t 비유의 → FAIL"에 해당한다.
OOS PF(R)=1.216으로 1.15는 상회하지만, **OOS t=+0.867(p=0.388, df=104)로 통계적으로 전혀
유의하지 않다**(이 프로젝트의 |t|≥1.96 관행 기준에 크게 미달). 표면 PF(R) 수치가 과제 가이드의
"OOS PF≥1.3" 문턱에도 못 미치므로 이중으로 미달한다. 표본은 충분하나(OOS n=105, 고유일=82≥15)
**OOS 순익의 85.5%가 5일 롤링 윈도우 기준 단 3개 클러스터(17건, 16.2%)에 몰려 있고, 그 중
하나(2025-07-10~14, BTC 신고가 브레이크아웃 하나가 상관종목 3~4개에 복제된 사건)만으로 총
순익R의 약 86%를 설명**한다. top-5(4.8%) 트레이드 제거만으로 PF(R)가 1.216→1.015(사실상
손익분기)로 붕괴하고, 파라미터 스윕 14개 변형 전부 OOS t가 유의수준(1.96)에 못 미친다.
**긍정적 신호도 있다** — 요일 조건화 게이트(wd)가 전체 풀링 대조군(pooled)을 뚜렷이 상회하고

방향에 실재하는 정보가 있음을 시사한다. 그러나 이 두 가지 긍정 신호로는 (a)의 통계적 유의성
미달과 극단적 사건 집중을 상쇄하지 못한다. **라이브 미반영을 권고한다.**

```python
def weekday_conditional_zscore(doi_pct: pd.Series, lookback_weeks: int = 12) -> pd.Series:
    """요일 조건부(자기포함) 롤링 z-score. 프로젝트 관례(ATS z-score 등)와 동일하게
    self-inclusive rolling(주의: 이는 미래데이터 미참조 — rolling 은 과거~현재까지만 사용)."""
    wd = doi_pct.index.dayofweek
    out = pd.Series(index=doi_pct.index, dtype=float)
    for w in range(7):
        mask = wd == w
        sub = doi_pct[mask]
        mean_w = sub.rolling(lookback_weeks, min_periods=lookback_weeks).mean()
        std_w = sub.rolling(lookback_weeks, min_periods=lookback_weeks).std(ddof=1)
        out.loc[sub.index] = (sub - mean_w) / std_w
    return out.sort_index()


@functools.lru_cache(maxsize=None)
def build_daily_frame(sym, wd_lookback_weeks=12, th_zoi=1.5, donchian_len=20,
                       atr_period=14, pooled_window=90):
    d1 = L.load_klines(sym, "1d").copy()
    oi = L.load_oi_daily(sym)
    d1["oi"] = oi.reindex(d1.index)
    d1["doi_pct"] = d1["oi"] / d1["oi"].shift(1) - 1.0
    d1["z_wd"] = weekday_conditional_zscore(d1["doi_pct"], wd_lookback_weeks)
    pm = d1["doi_pct"].rolling(pooled_window, min_periods=pooled_window).mean()
    ps = d1["doi_pct"].rolling(pooled_window, min_periods=pooled_window).std(ddof=1)
    d1["z_pooled"] = (d1["doi_pct"] - pm) / ps
    # Donchian 20일 채널 — 신호봉 자기참조 방지(shift(1)로 "직전 20일"만 사용)
    d1["donch_high"] = d1["high"].rolling(donchian_len, min_periods=donchian_len).max().shift(1)
    d1["donch_low"] = d1["low"].rolling(donchian_len, min_periods=donchian_len).min().shift(1)
    d1["atr"] = _atr(d1, atr_period)
    breakout_up = d1["close"] > d1["donch_high"]
    breakout_down = d1["close"] < d1["donch_low"]
    d1["long_sig"] = (d1["z_wd"] >= th_zoi) & breakout_up
    d1["short_sig"] = (d1["z_wd"] >= th_zoi) & breakout_down
    d1["long_sig_pooled"] = (d1["z_pooled"] >= th_zoi) & breakout_up
    d1["short_sig_pooled"] = (d1["z_pooled"] >= th_zoi) & breakout_down
    return d1
```

```python
def group_conditional_z(doi_pct, group_labels, lookback=12):
    out = pd.Series(index=doi_pct.index, dtype=float)
    df_ = pd.DataFrame({"x": doi_pct, "g": group_labels})
    for g in np.unique(group_labels):
        sub = df_.loc[df_["g"] == g, "x"]
        m = sub.rolling(lookback, min_periods=lookback).mean()
        sd = sub.rolling(lookback, min_periods=lookback).std(ddof=1)
        out.loc[sub.index] = (sub - m) / sd
    return out.sort_index()
```
