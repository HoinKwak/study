## 핵심 로직(요약 인용)

```python
# 지표(1h, 롤링 48봉=2일):
tp = (high+low+close)/3
vwap_vol = rolling48(sum(tp*quote_volume)) / rolling48(sum(quote_volume))
vwap_cnt = rolling48(sum(tp*count))        / rolling48(sum(count))
spread_pct = (vwap_vol - vwap_cnt)/vwap_cnt * 100
spread_z = zscore_60(spread_pct)             # 평균차감 포함(데미닝)

# 4h EMA20 확인 — 인과적 정렬(완결 4h봉만, ns 정수연산으로 ms/us 업캐스트 함정 회피):
ends_4h = df4h.index.asi8 + NS_4H          # 각 4h봉 완결시각
decision_ts = df1h.index.asi8 + NS_1H       # 각 1h봉 확정시각
counts = np.searchsorted(ends_4h, decision_ts, side="right")
ema4h_aligned[i] = ema4h[counts[i]-1]  if counts[i]>0 else NaN

# 진입(프레시크로스):
long_raw  = (spread_z>=+1.5) & (spread_z.shift(1)<+1.5) & (close_1h > ema4h_aligned)
short_raw = (spread_z<=-1.5) & (spread_z.shift(1)>-1.5) & (close_1h < ema4h_aligned)

# 체결: 신호봉(i) 확정 → 다음 1h봉(i+1) 시가 + 슬리피지(shift(1))
# 청산(entry_i부터 max_hold=12봉 이내, 우선순위 SL>TP/트레일>스프레드무효화>시간청산):
#   SL = 진입가 ∓ ATR(14,1h)*1.2
#   exit=rr(기본): TP = 진입가 ± ATR(14,1h)*1.2*1.8(R:R=1.8 고정)
#   exit=trail(비교): ATR(14,1h)*2.0 트레일링(신고가/신저가 갱신마다 스톱만 유리하게 이동)
#   스프레드 무효화: '원신호(raw) 극값 기준'으로 재확장 시 그 봉 종가 조기청산
#     (is_long_raw and spread_z<=-1.5) or (is_short_raw and spread_z>=+1.5) → 조기청산
```

## 방향반전 대조군 청산조건 버그(자체발견·수정)

최초 구현은 스프레드 무효화 청산을 **최종 보유방향(`direction_long`)** 기준으로 판정했다
(`direction_long`이면 `spread_z<=-1.5`에서 무효화, 아니면 `spread_z>=+1.5`에서 무효화 —
"모든 청산 분기는 최종 방향을 참조해야 한다"는 프로젝트 관례를 그대로 적용한 것). 그런데
이 조건은 진입 트리거와 **동일한 임계값(z_th=1.5)**을 마진 없이 재사용하는 구조라, **정방향**
에서는 문제가 없었지만(진입 시 spread_z가 막 +1.5를 돌파했을 때, 그 반대쪽 -1.5까지 가려면
z-스코어가 3.0 단위를 이동해야 하므로 자연스러운 무효화 조건), **반전 대조군**에서는 다음과
같은 구조적 퇴화가 발생했다: 원신호가 `long_raw`(spread_z가 막 +1.5를 돌파)인데 반전으로
포지션은 숏(`direction_long=False`)이 되면, 무효화 조건이 `spread_z>=+1.5`가 되고 — 이는
**진입을 유발한 바로 그 조건**이라 진입 직후 거의 항상 참이다. 실측 결과 반전 대조군의
`zero_hold_frac`(진입봉 즉시청산 비율)이 **83.96%**로 퇴화(정방향은 16.18%로 정상 범위)했다.

**진단**: 스프레드 무효화는 SL/TP처럼 포지션-상대적 개념이 아니라, 유발 지표(spread_z) 자체의
궤적이 반전됐는지를 보는 "테제 무효화" 조건(과거 posflow 다이버전스 건의 `div_revert`류와
동일 성격)이다. 이런 조건은 **원신호(raw) 극값 쪽을 기준**으로 판정해야 정방향/반전 양쪽에서
동일한 트리거 시점을 공유하며, SL/TP만 방향에 맞게 대칭 재배치하면 된다. 이 원칙에 따라
`is_long_raw and spread_z<=-z_th` / `is_short_raw and spread_z>=+z_th` 로 수정 후 재실행하니
반전 대조군 `zero_hold_frac`이 **18.33%**로 정상화됐다(정방향 16.18%와 유사한 범위). 이하
모든 결과는 수정된 버전 기준이다. **교훈(신규)**: "모든 청산 분기는 최종 방향을 참조" 원칙은
SL/TP류의 포지션-상대적 청산에는 유효하나, 유발 지표 자체의 재확장/복귀를 판정하는 "테제
무효화"류 청산은 원신호(raw) 기준이 맞는 경우가 있다 — 반전 대조군을 만들 때 두 유형을
구분하고, `zero_hold_frac`으로 즉시 검증할 것.

±0.03 이내로 정상 데미닝됨(std≈1.35~1.38, 정규분포와 근사 일치).
