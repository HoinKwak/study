# VWAP 되돌림/재탈환(reclaim) 인트라데이 — 백테스트 리포트

- **전략 스펙**: `research/strategies/vwap-reclaim-intraday.md`
- **출처**: QuantifiedStrategies("3년 6072트레이드 +713%" 주장, 수수료·표본외 반영 불명확)
  / FXOpen(규칙 보강). **원문 수치의 자산·수수료 가정이 불투명 → 크립토·우리 비용구조로
  직접 재현하는 것이 검증 목적.**
- **판정 목적**: 세션 VWAP 재탈환(되돌림 후 VWAP 재돌파) 신호가 15m·1h 크립토에서 수수료를
  이기는 엣지가 있는지 확인.

## 구현/실행 방식

- **격리 스크립트**: `scratchpad/bt_vwap_reclaim.py` (완전 독립, `src/crypto_trader/**` 무수정,
  `indicators.ema`/`atr`만 재사용). 자체 이벤트기반 시뮬레이터.
- **세션 VWAP**: UTC 앵커(`session_anchor_hour`, 0 또는 14) 기준 일 리셋. VWAP[i] = 세션 내
  cumsum(typical×volume)/cumsum(volume) (typical=(H+L+C)/3), 해당 세션의 닫힌 봉만으로 인과적
  계산(미래 누출 없음).
- **방향 바이어스**: EMA(`bias_period`) 대비 종가 위치(원문 "당일 시가/추세" 대체 — 크립토는
  세션 오픈갭이 주식만큼 뚜렷하지 않아 이평 기반 바이어스로 대체. [원문과 다른 확장, 명시]).
- **진입(원문 그대로)**: 신호봉(i-1, 닫힌 봉)에서 종가가 VWAP를 재탈환(직전 봉은 반대편, 신호봉
  종가가 바이어스 방향으로 VWAP 크로스) → 다음 봉(i) 시가(+슬리피지) 체결.
- **청산(원문 그대로)**: SL=최근 `swing_lookback`봉 저점/고점 ∓ `atr_buffer_mult`×ATR14,
  TP=entry±`rr`×risk. 옵션 `vwap_reloss_exit`(반대편 VWAP 재이탈 시 조기청산, 원문 명시 규칙).
  세션 종료 강제청산(당일 오버나이트 회피, 원문 명시).
- **룩어헤드 방지**: 신호는 i-1(닫힌 봉) 확정, 체결은 i봉 시가. VWAP·스윙·ATR 모두 신호봉까지의
  닫힌 데이터만 사용.
- **데이터/종목/IS·OOS/수수료**: ORB 리포트와 동일(`scratchpad/futdump100m`, 13종목 장기이력
  풀링 주 판정, 22종목 참고, IS 2022-01~2024-06/OOS 2024-07~2026-06, taker 0.05%+슬리피지
  0.02% 사이드당, net/gross PF 병기).

## 파라미터 민감도 (IS 기준)

- `swing_lookback`(5~30봉): 넓힐수록(더 여유있는 SL) PF가 개선되는 경향(15m 0.86→0.94,
  1h 그리드에서도 30이 최선) — SL이 너무 타이트하면 정상적인 되돌림에도 조기 손절된다는 뜻.
  다만 개선폭이 크지 않고 1.3까지는 한참 남는다.
- `rr`(1.5~4.0): 1.5~2.5 구간이 4.0보다 근소하게 낫다 — VWAP 재탈환 이후 큰 폭의 추세
  지속은 드물다(평균회귀적 반등에 가까움).
- `vwap_reloss_exit`(True/False): **False(조기청산 비활성)가 전 구간에서 일관되게 더 나음**
  — 원문이 명시한 "VWAP 반대편 재이탈 시 조기청산" 규칙이 오히려 손실을 조기 확정시켜
  전체 성과를 깎는다(정상적인 눌림을 노이즈로 오인해 너무 일찍 나감).
- `bias_period`(20~150봉): 큰 영향 없음(20이나 150이나 PF 차이 미미) — 방향 바이어스
  필터 자체가 결정적 요인이 아니다.
- `session_anchor_hour`(0 vs 14): 14가 소폭 우세하나 결정적이지 않음.
- **knife-edge 아님**: 넓은 그리드에서 완만하게 변화 — 특정 값의 우연이 아니라 구조적으로
  약한 신호.

## 최종 판정: **FAIL**

**근거**:
1. **IS 그리드서치(192개 조합)에서 net PF 최댓값이 15m 0.939·1h 1.022** — 1h에서 겨우
   1.0을 근소하게 넘긴 지점(t=0.73, 통계적으로 무의미)조차 **held-out OOS에서 0.954로
   재차 1.0 아래로 떨어진다.**
2. **13개 장기이력 종목 전원(15m·1h 공통) net PF<1.3.** 1h에서 ADA·SOL·DOGE 3종목이
   1.05~1.16까지 근접했으나 여전히 기준 미달이고, 나머지 10개 종목은 1.0 미만이다.
3. 원문이 명시한 "VWAP 반대편 재이탈 조기청산" 규칙을 **끄는 쪽이 일관되게 더 나았다**는
   점은 원문 규칙 자체가 크립토 데이터에서 손실을 확정시키는 역할을 한다는 뜻으로,
   원문의 "+713%" 주장이 크립토·우리 비용구조에서 재현되지 않음을 뒷받침한다.
4. 표본은 충분(종목당 수천 건)해 표본부족 문제는 아니다.

세션 VWAP 재탈환은 이론적으로 그럴듯하지만(추세 방향 되돌림 매수), 크립토 15m·1h에서는
"재탈환처럼 보이는" 크로스가 지속적 방향성을 갖지 못하고 곧바로 재차 반대로 흔들리는
경우가 많아(승률 37~44%, PF gross조차 1.0~1.1 수준) 왕복 수수료 0.14%를 감당하지 못한다.
**라이브 반영하지 않는다.**

## 미검증/근사 요소 (정직한 한계 고지)

- **방향 바이어스를 EMA로 대체**(원문 "당일 시가/추세"): 세션 시가 대비 위치를 바이어스로
  쓰는 원문 그대로의 버전은 미검증. 다만 스윙 룩백·rr 민감도 패턴을 볼 때 바이어스 방식
  차이가 결과를 1.3까지 끌어올릴 가능성은 낮아 보인다.
- **직전 스윙 고/저 기반 SL은 단순 rolling min/max**(정교한 프랙탈 스윙포인트 탐지 아님).
- **9개 신규상장 알트는 IS 구간이 짧거나 없어 판정 근거에서 제외**(전 22종목 상세는
  `scratchpad/vwap_final_detail_*.csv` 참고용으로만 제공).
