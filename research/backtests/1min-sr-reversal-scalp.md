## 실행 조건 / 재현성

- **구현 방식**: 기존 리서치 관행(`ema-9-21-crossover.md`)과 동일하게, 커스텀 `SRReversalStrategy`
  를 `SleeveBacktester(sleeve_kind="mid", confirm_tf=None)` 에 주입(`bt.strategy = ...`)해
  프레임워크의 수수료·슬리피지·인트라바 SL/TP(손절 우선)·CLOSE 청산 로직을 그대로 재사용.
  **프로덕션 코드(`src/crypto_trader/**`)는 전혀 수정하지 않음.**
- **수수료/슬리피지 = 프레임워크 기본값**: 테이커 0.05%/편도 + 슬리피지 0.02%/편도 ≈
  **왕복 0.14%**. 사이징: 리스크 1%/트레이드(계좌 대비, `RiskManager.build_plan_with_stop`),
  레버리지 상한 3x(프레임워크 기본, 노셔널 캡). 손절 우선(같은 봉에 SL/TP 둘 다 닿으면 SL).
- **룩어헤드 방지**: S/R 프랙탈 스윙(좌우 k봉)은 전체 시리즈에 대해 벡터화 계산하되, 신호봉
  시점 `i` 에서는 `j+k<=i` 로 확정된 스윙만 사용하도록 필터링(사용 시점에서 걸러냄). 진입은
  반전캔들 **종가 확정 직후**(같은 봉 종가 + 슬리피지 체결, 프레임워크 관례와 동일).
- **규칙 재해석(스펙의 "코딩용 재해석" 절 그대로 구현)**:
  - S/R: 좌우 `swing_lookback_k`봉 프랙탈 스윙고/저, 최근 `sr_lookback`봉 이내, 신호봉
    저가(롱)/고가(숏)가 레벨에 `±sr_touch_tolerance` 이내 근접.
  - 모멘텀 약화: 직전 5봉 평균 레인지 대비 최근 3봉 평균 레인지가 `contraction_ratio` 이하로
    축소(기본값. `momentum_filter=rsi_div|none` 변형도 구현).
  - 반전캔들: 해머/슈팅스타(꼬리≥몸통×`wick_body_ratio_min`) 또는 불리시/베어리시 엔걸핑 +
    거래량이 직전 `vol_lookback`봉 평균 대비 `volume_mult_min`배 이상.
  - 손절: 반전캔들 반대쪽 극단 바로 바깥(0.05% 버퍼). 익절: `rr_target`×R.
  - 시간청산: `timeout_bars` 내 미도달 시 종가 청산. 브레이크이븐 트레일링([추정] 요소)은
    봉종가 해상도로 근사 구현(인트라바 아님) — 기본 OFF, 민감도에서만 ON 테스트.
  - 구조 필터(higher-low/lower-high, [추정] 요소)도 기본 OFF, 민감도에서만 ON 테스트.
- **데이터**: `data-api.binance.vision` 현물 미러(선물 API 451 차단 시 자동 폴백, 실제로 매
  요청 모두 폴백됨). **1m: 최근 25일**(데이터 한계상 캡, 36,000봉/심볼), **5m: 최근 150일**
  (43,200봉/심볼, 표본 수 확보 목적). 대상: BTC/USDT, ETH/USDT, SOL/USDT(알트 대표) 무기한.
- **재현 커맨드**:
  ```
  .venv/bin/python research/impl/scalp_sr_reversal.py base   # 1m 25d + 5m 150d 기본
  .venv/bin/python research/impl/scalp_sr_reversal.py oos    # 5m 150d 전체/전반/후반

  .venv/bin/python research/impl/scalp_sr_reversal.py all    # 위 전부
  ```
- **기본 파라미터**: `swing_lookback_k=3, sr_lookback=75, sr_touch_tolerance=0.15%, rsi_period=14,
  wick_body_ratio_min=1.5, volume_mult_min=1.3, vol_lookback=10, rr_target=3.0,
  momentum_filter=contraction, contraction_ratio=0.85, structure_filter=off,
  breakeven_trigger=off, timeout_bars=20`, cooldown_bars=5(SleeveBacktester 과매매 억제).

- **수수료 제거(gross) 후에도 PF<1.0(BTC/SOL) 또는 <1.3(ETH 0.83)** — 즉 수수료가 손실의
  전부는 아니지만(승률/R구조 자체가 열세) **손실을 2~4배 증폭**시키는 주범이다.
- 트레이드 로그 검사 결과, 반전캔들의 손절 거리(R)가 극도로 좁은 경우가 흔함(예: ETH 5m 한
  트레이드 risk=$29.2 인데 fee=$29.34 — **수수료 단독이 R 전체를 잠식**). 스캘핑 특성상
  반전캔들 꼬리가 짧아 손절 거리가 좁고, 레버리지 상한(3x)에 걸려 명목가치가 거의 항상
  캡(계좌×3배) 근처로 고정되면서, **수수료(명목가치 비례)/리스크($ 비례) 비율이 심하게
  불리**해진다 — "저빈도·고R" 컨셉이라는 스카우트의 기대와 달리 실제 R이 매우 작게 형성됨.
  스펙의 "3R 익절로 수수료를 이긴다"는 논리가 손절폭 자체가 좁을 때는 성립하지 않음.

4. **일관성**: 3종목·2TF·IS/OOS·12파라미터 변형 전부 같은 방향(손실) — 특정 종목/구간 과최적화
