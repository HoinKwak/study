### 진짜 OHLC 갭 존재 여부(크립토 연속거래) 실측

절대값 불일치(`open[i] != close[i-1]`)는 봉의 **약 50%**에서 발생한다(BTC 49.98%).

> **⚠️ 리뷰 정정 (backtest-reviewer)**: 초판은 이 불일치를 "부동소수/체결시각 미세오차"로
> 서술했으나, 리뷰어가 diff 값을 직접 확인한 결과 **부동소수 오차가 아니라 거래소 최소
> 틱사이즈 단위의 실제 1틱 차이**였다(BTC diff = ±0.01 = 틱사이즈, ETH 0.01, XRP/ADA 0.0001,
> DOGE 0.00001). 경제적으로 무의미한 틱레벨 미시구조이지 계산 오차가 아니다.

상대크기 0.01% 초과("의미있는 갭") 기준 비율은 **종목별로 크게 다르다**:
BTC 0.16% / ETH 0.42% / BNB 2.24% vs **SOL 15.17% / XRP 30.20% / DOGE 24.25% / ADA 43.90%**.

> **⚠️ 리뷰 정정 (backtest-reviewer)**: 초판은 BTC 기준값(0.16%)만 근거로 "크립토는 갭이
> 사실상 없다"고 **일반화**했으나 이는 과장이다. 저가 알트는 **가격 대비 최소호가단위 비율이
> 커서** 0.01% 임계값이 사실상 모든 1틱 변동을 "의미있는 갭"으로 분류하는 정의 아티팩트가
> 발생한다(ADA 틱 0.0001 / 가격 0.4575 ≈ 0.0219%로 이미 임계값 초과). 따라서 이 결론은
> **메이저(BTC/ETH/BNB) 한정**으로만 지지되며 알트 전체로 일반화할 수 없다.

어느 해석을 취하든 갭 포함 변형은 표본이 **n=3**으로 붕괴해 판정에서 제외되므로,
이 정정은 **최종 FAIL 판정에 영향을 주지 않는다**. 원 정의(주식 일봉의 갭업/갭다운)를
크립토 1h 연속거래에 그대로 적용하면 신호가 사실상 소멸한다는 결론은 유지된다.

## 10. 핵심 로직 (코드 인용)

### 조건 벡터화(3캔들 구조 + 거래량 + RSI + 인접성/갭)

```python
k = np.arange(2, n)  # i = k (캔들3), i-1, i-2
c1o, c1c, c1h, c1l = open_[k - 2], close[k - 2], high[k - 2], low[k - 2]
c2o, c2c = open_[k - 1], close[k - 1]
c3o, c3c = open_[k], close[k]
atr1, atr2, atr3 = atr[k - 2], atr[k - 1], atr[k]
rsi1, rsi2 = rsi[k - 2], rsi[k - 1]
vol3, vola3 = vol[k], vol_avg[k]
adj = adj_ok[k - 1] & adj_ok[k]  # 정확히 1시간 간격 연속인가

c1_body = np.abs(c1c - c1o)
c1_range = c1h - c1l
c1_body_frac = np.divide(c1_body, c1_range, out=np.zeros_like(c1_body), where=c1_range > 0)
c1_strong = (c1_body >= p.body1_atr_mult * atr1) & (c1_body_frac >= p.body1_range_frac)

c2_body = np.abs(c2c - c2o)
c2_small = c2_body <= p.body2_atr_mult * atr2

c3_body = np.abs(c3c - c3o)
c3_strong = c3_body >= p.body1_atr_mult * atr3

c1_bear = c1c < c1o
c3_bull = c3c > c3o
retrace_long = c3c >= (c1o - p.retrace_pct * (c1o - c1c))

s_long = c1_bear & c2_small & c3_bull & c3_strong & c1_strong & retrace_long
vol_ok = (vola3 > 0) & (vol3 >= p.vol_mult * vola3)
rsi_ok_l = (rsi1 <= p.rsi_th_long) | (rsi2 <= p.rsi_th_long)
l_sig = s_long & vol_ok & rsi_ok_l & adj    # (require_gap=True 이면 gap_l 도 AND)
```

### 청산(초기 SL + ATR 트레일링 래칫 + R:R 1:2 + 시간청산), 반전 대조군 대칭 배치

# 초기 SL 거리: "원래 방향" 공식으로 계산(캔들2 저가/고가 ∓ 0.1×ATR)
raw_stop = (low[i - 1] - buf * atr_i) if original_long else (high[i - 1] + buf * atr_i)
stop_dist = abs(entry_fill - raw_stop)

# 최종 방향(반전 적용 후) 기준 대칭 배치 — 절대레벨 재사용 없음
if direction_long:
    stop_price = entry_fill - stop_dist
    fixed_tp = entry_fill + p.rr_target * stop_dist
else:
    stop_price = entry_fill + stop_dist
    fixed_tp = entry_fill - p.rr_target * stop_dist

trail_dist = p.tp_atr_mult * atr_i
...
if direction_long:
    peak = max(peak, h)
    eff_stop = max(stop_price, peak - trail_dist)          # 래칫: 초기SL보다 유리할 때만 대체
    if l <= eff_stop:
        exit_j, exit_price, reason = j, eff_stop, (

   갭으로 오분류하는 **정의 아티팩트**(ADA 틱/가격 ≈ 0.0219%로 이미 임계값 초과).
   결론은 **메이저 3종목 한정**으로만 지지된다.
3. **RSI 단독 대조군 대비 "부가가치 없음"이 다소 강한 표현** — 두 대조군의 이벤트 중복률이
