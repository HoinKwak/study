**6. 표준 감사**: 표 전체 재현(모든 섹션 bit 단위 일치) / IS+OOS==FULL 3개 경계 전부 실제 확인 /
OOS_END 상한 초과 진입 0건 확인 / 회계정합(218건 전수 `raw-fees-pnl` max|diff|=0.0) 확인 /
룩어헤드(절단 재실행 + 독립 boolean 방식 둘 다) 확인 / 워밍업 설계선택 문서화 확인 / 0-fill
결측: 이 전략은 klines만 사용해 metrics 계열의 0-fill 문제 자체가 해당 없음(대신 SOL/XRP
klines 결측 갭 발견, 위 9번 참고) / ms/us dtype 함정 없음(직접 확인) / t 단위 혼용 없음(t(R)과
t($)를 표에서 항상 별도 열로 분리 표기, 본문 서술도 어느 쪽인지 명확).

**7. 판정 라벨 의견**: **FAIL이 정확**. 스펙 자체 사전폐기조건(OOS n<20 → 판단불가)을 표본이
상회하고(n=100), 판단불가로 몰릴 근거가 없다. 오히려 표본이 검증가능한데도 (a) 스펙 자신이
정한 동어반복 폐기조건이 문자 그대로 충족되고 (b) 정식 대조군(게이트없음)이 채택안보다 IS에서
통계적으로 더 우수하며 (c) OOS 순익이 사실상 단일 사건에 의존 — 이 세 가지는 서로 다른 각도의
독립 근거로, 모두 이번 검증에서 재확인됐다. HOLD로 완화할 근거를 찾지 못했다.
