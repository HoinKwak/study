## 지표·신호 정의 (1분봉과 동일, 각 TF의 봉으로 계산)
| 지표 | 파라미터 | 극단 임계값(SHORT / LONG) |
|---|---|---|
| RSI(14) | Wilder | ≥90 → SHORT / ≤10 → LONG |
| StochRSI %K | RSI(14)→Stoch(14)→%K(SMA3) | ≥95 → SHORT / ≤5 → LONG |
| Williams %R(14) | 표준 | ≥-10 → SHORT / ≤-90 → LONG |
| MACD(12,26,9) 히스토그램 | macd-signal | **확장(expanding) 분위수** ≥95%ile → SHORT / ≤5%ile → LONG |

- **MACD 분위수 룩어헤드 처리**: 1분봉과 동일하게 매 시점 `t`의 임계값은 `hist[0..t].expanding()
  .quantile(0.95/0.05)`만 사용(전체표본 고정분위수 아님).
- **워밍업**: 지표/분위수 안정화를 위해 3일 상당 봉수를 신호에서 제외 — 5분봉 864봉, 3분봉 1,440봉
  (1분봉의 4,320봉과 동일한 "3일" 기준을 TF에 맞춰 환산).
- **최초 크로스만**, **동일방향 재진입 금지**(만기 청산 전 신규 진입 불가). 모든 지표는 닫힌 봉만
  사용(룩어헤드 없음).
