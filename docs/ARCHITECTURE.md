# 아키텍처

## 설계 목표

1. **안전 우선** — 기본 모드는 `dry_run`. 실전 전환은 명시적으로만.
2. **모듈 분리** — 데이터 수집 / 시그널 / 전략 / 리스크 / 실행을 독립적으로 교체·테스트 가능.
3. **멀티 시그널 가중 합산** — 어떤 단일 지표에도 의존하지 않고 여러 근거를 점수로 통합.

## 시그널 점수 규약

모든 시그널은 **-1.0 ~ +1.0** 범위의 float 를 반환합니다.
- `+1.0` = 강한 롱(매수), `-1.0` = 강한 숏(매도), `0.0` = 중립.

합산 엔진이 카테고리별 가중치로 가중 평균을 내고, 그 절대값이
`ENTRY_SCORE_THRESHOLD` 이상이면 해당 방향으로 진입 신호를 냅니다.

기본 가중치 (`aggregator.py` `DEFAULT_WEIGHTS`):
```
technical    : 0.40   (RSI, MACD, ADX, 캔들패턴 소계)
funding_oi   : 0.20
liquidation  : 0.20
long_short   : 0.20
```

## 리스크 규칙 (기본값)

- 1회 매매 리스크 = 계좌의 `RISK_PER_TRADE_PCT`% (SL 거리로 수량 역산)
- 손절: 진입가 ± `ATR × k`
- 익절: 손절 거리 × R배수 (기본 1.5R)
- 레버리지 상한 `MAX_LEVERAGE`
- 동시 보유 포지션 `MAX_OPEN_POSITIONS` 개
- 일일 손실 `DAILY_MAX_LOSS_PCT`% 도달 시 당일 신규 진입 중단

## 실행 모드

| 모드 | 주문 | 자금 | 용도 |
|------|------|------|------|
| `dry_run` | ❌ 로그만 | - | 로직 검증 (기본) |
| `paper` | ✅ 테스트넷 | 모의 | 실거래 유사 검증 |
| `live` | ✅ 실계좌 | 실제 | 실전 (⚠️) |

## 로드맵

- **Phase 1 (완료)**: 코어 파이프라인, 페이퍼 트레이딩 루프
- **Phase 2**: 백테스팅 프레임워크 (과거 데이터로 전략 검증 + 파라미터 튜닝)
- **Phase 3**: 실전 실행 강화 (포지션 리컨실, 부분 체결, 재시도, 상태 영속화)
- **Phase 4**: 모니터링 (텔레그램/메일 알림, 대시보드, 성과 리포트)
