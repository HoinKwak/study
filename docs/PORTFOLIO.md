# 멀티 타임프레임 포트폴리오 설계

계좌를 3개 **슬리브(sleeve)** 로 나눠 서로 다른 시간 지평에서 독립 운용한다.
각 슬리브는 배정된 자본 예산 안에서 리스크를 계산하고, 바이낸스 **헤지 모드**로
같은 심볼에 대해서도 슬리브별 방향을 독립적으로 가질 수 있다.

## 슬리브 구성

| 슬리브 | 배분 | 시그널 TF | 확인 TF | 전략 |
|--------|------|-----------|---------|------|
| 중장기 (swing) | 50% | 4h | 1d | RSI 20/80 역추세 → 슈퍼트렌드 피라미딩, Fib+CVD TP |
| 중기 (mid) | 25% | 15m | 1h | 레짐 인지 멀티 시그널 (기술+파생) |
| 단타 (scalp) | 25% | 1m | 5m | 볼린저 이탈 + 거래량 급증 + OI, TWAP 진입 |

- **자본 배분은 논리적**: 바이낸스 선물은 USDT 지갑이 하나이므로, 각 슬리브는
  `배정 자본 = 총 자본 × 배분비율` 을 기준으로 포지션을 사이징한다.
- **isolated 마진**: 포지션별 청산 격리. 헤지 모드 + isolated 로 운용.
- **확인 TF**: 시그널 TF 의 진입 방향이 확인 TF 의 레짐과 정면 배치되면 진입 보류
  (예: 중장기 4h 롱 신호라도 1d 가 하락추세면 보류).

## 헤지 모드

- 바이낸스 `dualSidePosition=true`. 주문 시 `positionSide` 를 LONG/SHORT 로 명시.
- 한 심볼에 롱·숏 포지션이 동시에 존재 가능 → 슬리브 간 방향 충돌 없음.
- 주의: **같은 방향**(예: 두 슬리브가 모두 BTC 롱)은 거래소에서 하나의 포지션으로
  합산된다. 슬리브별 수량/손익은 저널에서 논리적으로 추적한다.

## 단타(scalp) 전략 상세

**지표**: 볼린저밴드(20, 2σ) + 거래량 급증 + 실시간 OI 증감

**진입 조건** (1분봉 종가 확정 시):
1. 거래량이 최근 N봉 평균의 `vol_spike_mult` 배 이상 급증
2. 강한 양봉/음봉이 볼린저밴드 상단/하단을 이탈 (종가가 밴드 밖)
3. (보강) OI 가 동반 증가 → 신호 신뢰도 가중
4. 양봉 → LONG, 음봉 → SHORT

**체결**: 신호 후 **다음 3분간 TWAP** 로 분할 진입 (해당 방향).

**SL**: 신호 봉의 **시가(open)**.

**TP**: 손익비(R) 고려하되, **최소 신호 봉의 고가(롱)/저가(숏)**.
- `TP = 방향별로 max/min( entry ± R×|entry−SL|,  신호봉 고가/저가 )`

**청산**:
- SL/TP 도달, 또는
- 급등/급락이 끝나고 **횡보장 진입**(확인 TF 5m 레짐이 RANGE) 시 종료.

## 중장기(swing) 전략 상세

**지표**: RSI + 슈퍼트렌드(ATR) + 피보나치 되돌림 + CVD(캔들 테이커 매수량 근사)

**1단계 — 역추세 초기 진입** (계좌의 15%, 시계열 TWAP 최대 30%):
- RSI ≤ 20 (과매도) → LONG 최초 오픈
- RSI ≥ 80 (과매수) → SHORT 최초 오픈
- 초기 진입엔 SL 설정(극단 지속=낙하는 칼 대비).

**2단계 — 추세 확인 피라미딩** (계좌의 최대 50%까지 TWAP 추가, SL 재설정):
- 초기 진입 SL 이 안 나간 상태에서, 가격이 목표 방향으로 반전한 뒤
- **슈퍼트렌드 매수/매도 신호**(방향 전환)가 진입 방향과 일치하면 추가 진입
- 추가 후 평균단가 기준으로 SL 재설정(예: 슈퍼트렌드 라인/직전 스윙 아래·위).

**TP**: 직전 스윙 고점/저점 기준 **피보나치 되돌림**(0.382/0.5/0.618/확장) +
CVD 다이버전스/모멘텀 데이터로 목표가 확정.

**포지션 모델**: 다단계 분할진입(scale-in) — 여러 TWAP 엔트리, 평균단가,
동적 SL 을 추적하는 스테이지드 포지션이 필요.

## 실행 구조

- 단일 프로세스에서 슬리브별 **독립 주기**로 평가:
  - 단타: 매 1분(봉 마감 근처)
  - 중기: 매 15분
  - 중장기: 매 4시간
- 각 슬리브는 자신의 열린 포지션만 관리(저널의 sleeve 태그로 구분).
