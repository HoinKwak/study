# solbot — 솔라나 밈코인 자동매매봇 (드라이런 우선)

우리가 구축한 **KOL 리서치 + 밈월렛 스마트머니 추적** 시그널을 실제 매매로 연결하는 사이드 프로젝트.
Jupiter 애그리게이터로 솔라나 DEX에서 스왑한다. **실제 자금이 걸리므로 드라이런(페이퍼)로 엣지를
검증한 뒤에만 라이브로 전환**한다.

## ⚠️ 먼저 정직하게 (리스크)
- **시그널이 아직 검증된 엣지가 아니다.** 밈월렛봇은 원래 알림 도구였고, "스마트머니 따라 사면
  수익난다"를 백테스트로 증명한 적이 없다. KOL 워치도 X 로그인월로 실시간 코로보가 약하고 대상
  토큰 상당수를 워시트레이딩으로 플래그한다. → 수수료·슬리피지·러그 감안 시 **-EV일 수 있다.**
- **밈코인 고위험**: 러그풀·허니팟(매도불가)·급락·MEV. $100이 빠르게 0이 될 수 있다.
- 그래서 **드라이런으로 가상 PnL을 1~2주 모아 +인지 확인**하고, 필터(유동성·가격영향·블랙리스트)와
  일일 손실 킬스위치를 둔다. 리스크 수준은 사장님 결정.

## 사이징·리스크 (config.py, 사장님 결정값)
- 트레이드당 **포트폴리오 5%**, 동시 보유 **최대 20개**(5%×20=100% 완전투입 상한)
- 일일 실현손실 **-30%**면 당일 신규진입 중단(킬스위치)
- 진입필터: 최소 유동성 $30k·최대 가격영향 3%·워시트레이딩 심볼 블랙리스트
- 청산(EXIT_MODE): 기본 `assist`(반자동 — 손절·시간초과 자동, 익절은 알림·승인).
  `trailing`(신고가 -25%) / `fixed`(+50%/-30%)도 파라미터 준비됨.

## 구성
| 파일 | 역할 |
|---|---|
| `config.py` | 사이징·필터·청산·모드 파라미터(사장님 결정값) |
| `jupiter.py` | Jupiter 견적/스왑. 드라이런은 견적만 사용(무거운 의존성 불필요) |
| `engine.py` | 페이퍼 브로커: 필터→사이징→가상매수→마크→청산→저널 |
| `keygen.py` | 봇 전용 솔라나 지갑 1회 생성(사장님 PC에서) |
| `state/paper_journal.json` | 페이퍼 포지션·실현손익(gitignore) |

## 진행 단계
- **Phase 1 (완료·현재)**: Jupiter 실행견적 + 페이퍼 브로커 + 저널 + 지갑생성. 실제 돈·키 불필요.
- **Phase 2 (다음)**: 밈월렛(스마트머니 매수)·KOL 시그널을 엔진에 연결 → 드라이런으로 가상 PnL 수집.
  ※ 밈월렛 감지가 정상 동작 확인되는 것이 전제(현재 퍼널 진단 중).
- **Phase 3 (검증 후)**: 가상 PnL이 +로 확인되면 `DRY_RUN=False` + 라이브 스왑 서명(소액부터).

## 지갑 만들기 (Phase 2 전 병행 가능)
```
pip install solders base58
python sideprojects/solbot/keygen.py
```
→ 출력된 **공개주소**로 Phantom에서 $100치 SOL 전송. 개인키는 `secret.json`에만 저장(커밋 금지).
**절대 메인 Phantom 시드를 봇에 넣지 않는다** — 봇 전용 새 지갑만 사용.

## 빠른 점검(드라이런, 의존성 없이)
```
python3 sideprojects/solbot/jupiter.py <mint> 10        # 견적·왕복 슬리피지
python3 -m sideprojects.solbot.engine <mint>            # 가상매수→마크→요약 데모
```
